## 사용자 화면은 무엇을 보여주는가

사용자 첨부 `image(20261009-184246).png`와 `image(20261009-184255).png`는 같은 세실리아의 모밭Lv25에서 번개6개·불21개의 **비경 보상**을 표시한다. 돌파 결제 요구량 화면이 아니다. 양쪽 모두 오늘 첫3회 재료2배를 이미 사용한 기본 보상이며, XP220은 동일하다.

출력버그나4·5성차이는 아니다. 0.16.16에 도입한 `ASCENSION_GEMS_V01616` 고정표가 실제 보상과 미리보기 양쪽에 사용된다. 비경 보상은 키울 캐릭터의 성급과 무관하다. 같은 등급 재료의 수량 척도가 원소마다 벌어져 유저에게 ‘한 원소가3.5배이득/다른 원소불이익’처럼 보이는 설계 문제다. 의도한 구현이라는 사실이 좋은 설계라는 뜻은 아니다.

## 왜 이렇게 커졌는가

높은 재료 비경이 낮은 단계보다 반복 효율이 좋아야 하고 육성 총량이 너무 빨라져서는 안 된다는 사용자 요구를, 원소별 보상 확대와 그에 비례한 요구량 확대로 처리했다. 기본 선별은 엠버·케이아·리사의 Lv55/+6/중간 특성 편성으로 전체 단계 비교였고, 저레벨 추가 표본은 불·물에 한정됐다.

당시 Lv55 편성의 Lv25 여행자 평균은 불14.58초/번개13.67초, 이세계인은 불19.15초/번개22.33초였다. 그래서 이 화면의3.5배 차이를 ‘그 단계 전투 시간이3.5배 다르기 때문’이라고 설명하면 틀린다. 후기 효율·일부 조기 부담·단계간 우위를 하나의 원소별 표에 넣으며 요구량과 보상 숫자를 과도하게 팽창시킨 방식이다.

현재0.16.19 전투 수정 이후의 모든 원소/단계/편성 효율은 이번 질문 점검에서 재측정하지 않았다. 현재의 공정함을 입증한 표가 아니다. 다음 실제 수정에서는 동레벨4성C0/C6와5성C0, 실제 해금 단계·연속2배속 전투·숙박·모라·일일/주간 수급을 다시 비교하고 같은 단계 재료의 가치를 읽을 수 있는 수량 체계를 우선 검토한다. 음식 수정에 요구량/보상 변경을 몰래 끼워넣지 않는다.

여행자와 이세계인은 사용 원소와 무관하게 중립 보석을 쓰고4성기준 비용이다. 보석 요구량은6단계3/6/12/45/192/1250, 모라는800/2400/6000/14000/28000/42000으로 두 루트가 같다. 동료5성만 재료2배·모라1.8배다. 주인공 운명의별 교환에서 쓰는5성취급을 돌파비용과 혼동하지 않는다.

실제 견적210개·단계/원소 보상96개·두 주인공의 결제/저장/동일 영수증 재시도12개에서 기존표와 일치했다. 0.16.19 기준과 현재의 보상표·요구량표·원소선택/결제 함수도 동일했다. 최종4성/주인공25승분·5성50승분은 보석의 기본 비율이지 전체 성장 시간 확정값이 아니다. 그날 일일 첫3회의2배를 최종 재료에만 쓰면25→22승/50→47승이다.
