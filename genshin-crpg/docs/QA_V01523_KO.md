# 0.15.23 검증 기록 · 2026-10-06

이번 판의 범위는 튜토리얼 수정, 밸런스 관찰, 관찰 중 확인한 진행 오류 수정이다. 설치형 가로 UI와 원래 전투 구도 복원은 다음 담당이다. 아래 통과 결과를 UI 전체 품질이나 전체 밸런스 완료로 인용하지 않는다.

## 전체 회귀와 재검사

`python tools/verify_release.py`의 등록된 스크립트 109개를 실행했다. 첫 실행에서 107개가 통과하고 2개가 실패했다. 실패를 삭제하거나 성공으로 덮어쓰지 않고, 원인을 수정한 뒤 해당 경로를 재검사했다.

- `test_growth_v01522.cjs`: 이미 끝난 비경의 `finishBattle(true)`를 다시 호출할 때 새 튜토리얼 래퍼가 없는 전투의 `origin`을 읽었다. 전투 존재 검사를 추가했다. 재검사 16항목 통과. 원래 정산의 중복 방지 검사도 유지했다.
- `test_mond_full_v01344.cjs`: 구형 여행자 시험 계정이 첫 전투에 엠버를 편성하지 않고 들어가려 했다. 새 규칙에 맞게 실제 `PARTY`와 `EQUIP`을 실행한 뒤 입장하도록 시험 계정을 수정했다. 남/여 여행자 두 전체 분기 재검사 통과(874/875행동, 각 56회 복원). 이세계 5분기는 첫 실행에서 통과했다. 이 검사는 강한 합성 파티를 쓰므로 성장 밸런스 증거가 아니다.

전체 첫 실행 결과는 `evidence/release/results.json`에 남는다. **최종 소스로 109개를 한 번에 다시 실행해 전부 통과했다는 뜻이 아니다.** 아래 최종 빌드 및 영향 경로 재검사와 함께 판단한다.

## 브라우저에서 누른 흐름

`node tools/check_tutorial_v01523.cjs`는 Chromium의 1280×800, 가로 844×390, 세로 390×844에서 다음 실제 UI 조작을 확인한다.

목적지 → 이동 → 도착 이야기 → 편성 → 동료 자리 → 엠버 → 장비 변경 → 무기 칸 → 장착 → 준비 화면 복귀 → 전투 준비 → 전투 시작 → 기본 공격 → 적 카드 → 실행.

- 바깥 메뉴 클릭과 Escape로 진행을 건너뛰지 못한다.
- 적 카드의 정보 버튼은 대상 선택 실습을 대신하지 않는다.
- 대상의 키보드 포커스와 Enter 선택을 확인했다.
- 고정 안내 카드 `.scenario-guide`는 없다. 안내는 실제 대상 위 오버레이다.
- 스크린샷과 결과: `evidence/v01523/tutorial/`.

이는 **실물 Android/iOS 설치·가로 강제·전체 화면 가독성 검사가 아니다.** 현재의 전투 카드 배치는 사용자가 거절했으며 다음 UI 담당이 고쳐야 한다.

## 온라인 및 배포 파일 검사

최종 클라이언트와 서버를 다시 빌드한 뒤 기존 온라인 브라우저 네 경로가 모두 통과했다.

| UI 파일 | 실제 시험 서버 | 결과 | 소요 |
|---|---|---|---:|
| source | Worker + SQLite | 통과 | 106.4초 |
| source | Durable Object | 통과 | 107.4초 |
| dist | Worker + SQLite | 통과 | 105.7초 |
| dist | Durable Object | 통과 | 103.3초 |

명령은 `node tests/test_online_browser.mjs`. 배포 파일은 `CRPG_TEST_DIST=1`, Durable Object는 `CRPG_TEST_BACKEND=do`로 지정한다. 기록은 `evidence/v01523/online/matrix.json`과 각 모드의 로그/결과에 남겼다. 실제 서버 엔진과 SQLite 또는 Durable Object 시험 환경을 쓰며 운영 서버에 연결하지 않는다.

대화 중 메뉴 전환, 배치 저장, 응답 유실·중복 요청·새로고침 복구, 서버 거부 후 계속 진행, 생활 타이머, 장비 장착, 이동, 전투 지연 응답·HP 재생·일시정지·재개, 전투 새로고침 패배 규칙을 유지해서 검사했다. 방어 튜토리얼은 실제 버튼 선택 후 바로 실행으로 이어지는 것을 확인했다.

최종 빌드 뒤 튜토리얼/성장/교착/첫 전투 HTTP/UI/기존 장비/엔진 일치/배포 격리/배포 콘텐츠 경계의 9개 명령도 전부 통과했다(`evidence/v01523/final/results.json`). 별도의 첫 이동 브라우저 검사는 세 뷰포트에서 모두 통과했다. 패키지와 배포 메타데이터의 버전은 모두 `0.15.23`이다.

온라인 검사 중 두 실제 충돌을 추가로 찾았다. 긴 강제 실습을 없애자 옛 자동 장비 설명 팝업이 통신 재시도 버튼을 가렸으므로, SPOTLIGHT 저장에서는 자동 팝업을 억제했다. 방어는 자기 자신을 대상으로 갖는 내부 카드이므로 '적을 고르라'는 단계로 가지 않고 실제 실행으로 이어지게 고쳤다. 저장 복구/응답 유실/전투 재생의 기존 검사는 제거하지 않았다.
