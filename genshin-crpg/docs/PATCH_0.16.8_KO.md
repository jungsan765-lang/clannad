새 회귀는 전투 경계26, 제어/반응14, 장비4, 음식/경제8, 임무 확장11, 임무 경계9, 성장7(실제 전투16), 다인 HTTP7구간, 일시정지6을 통과했다. 데이터 검사에는 240개 실제 ID/지도/재료/편성/보상과 총 후보12/8을 포함한다. 별도 장비 특성 도구는 전투 입장 시 기본 장비와 제어 면역을 반영한 시험 조건으로 바로잡아 누락된 마지막 검사까지 15/15를 확인했다.

`python tools/verify_release.py`의 **전체 140개 실행 결과는 120통과/20실패, 종료 코드1**이다. 이후 3개는 별도로 재실행해 통과했다: 일시정지 변경에 맞춘 오래된 소스 문자열 검사, 복구 공간의 누락된 팬 프로젝트 문서, 누락된 기존 배포 워크플로를 읽는 검사다. 합쳐 서로 다른 검사 123개를 확인했지만 **140/140 일괄 통과가 아니다**.

남은 17개는 로컬 복구 공간의 이미지·소리·매니페스트 누락 15개, 과거 Git 저장 fixture 부재 1개, 작성용 주석 행을 이미 제거한 실행용 DB로 원본 행을 검사한 경우 1개다. 새로 바꾼 코드의 미해결 회귀는 이 실행과 로그 검토에서 확인하지 못했다. 정확한 140개 원본 결과·실패 원인·3개 재실행은 [data/release_v0168_checks.json](data/release_v0168_checks.json)에 있다.

몬드 전체 이야기, 리월의 두 갈래 10개 흐름, 나선 12층×3방, 기존 오셀/필드 보스, 전멸 정산, 기존 튜토리얼, 저장/성장 이전, 다인/서버/재접속/동시 요청과 시장·생활 회귀는 통과했다. 검사 실행 중 제거한 임무 소스 후행 공백 한 글자는 위 성장 검사와 같은 변경이며 실행 규칙을 바꾸지 않는다. 최종 서버 엔진을 다시 생성하고 엔진 식별 검사도 별도로 통과했다(0.16.8/런타임117개).

실제 브라우저 일시정지 검사는 Chromium이 없어 실행하지 못했으며 선택 검사 파일로만 남겼다. VM/가상 시계와 실제 HTTP 결과를 실물 UI/PWA 통과로 확대하지 않는다. 테스트 게시 후 워크플로는 기다리지 않고 SHA 고정 적용 소스를 제공한다. 적용 순서와 테스트/운영 명령은 [APPLY_0.16.8_KO.md](APPLY_0.16.8_KO.md)다. 실제 운영 설치/main 병합은 수행하지 않는다.

### 검사 입력의 출처

작업 공간을 복구할 때 0.16.7에서 바뀐 소스 파일은 해당 커밋에서 다시 읽었고, 데이터는 감사 때의 서버 실행용 DB를 사용했다. 이 로컬 DB에는 작성용 주석이 없으므로 성장 검사 해시는 원격 Git 전체의 원본 바이트 해시와 구분한다. 게시할 때는 원격 0.16.7 트리를 부모로 삼아 변경한 파일만 교체하며 원격 `content/db.json`과 기존 이미지·소리·과거 파일을 유지한다. 복구한 실행용 DB나 부분 작업 공간 전체를 원격 원본으로 덮어쓰지 않는다.
