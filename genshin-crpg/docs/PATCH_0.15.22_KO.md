# 0.15.22 · 이동부터 배우는 여행과 성장 개편

기준 버전은 0.15.21이다. 이번 판은 테스트용이며 기존 저장을 자동 초기화하지 않는다. 운영 서버 설치와 초기화는 별도 작업이다.

## 직접 해 볼 순서

1. **새 여정에서 첫 이동을 해 본다.** 여행자는 속삭임의 숲에서 몬드 외곽 초원으로, 이세계인은 몬드 외곽 초원에서 몬드성으로 간다. 안내에 현재 위치와 목적지가 나오고, 지도에서 실제 이동해야 다음 안내가 열린다. 도착하면 그곳의 이야기를 계속한다.
2. 자유행동에서 **캐서린 방문 → 의뢰 받기·고정 → 채집·채광 → 의뢰 보상**을 진행한다. 이어 기원·편성·무기 장착·전투 훈련·책·비경·제작·강화·첫 돌파·특성을 안내한다. 중간에 나왔다면 도움말의 ‘여행 실습 이어가기’를 누른다.
3. 몬드성 메인 화면에서 **비경·토벌 → 성장 비경**을 연다. 경험치·돌파·특성·장비 중 종류와 단계를 골라 실제 전투를 한다. 돌파 비경은 필요한 원소를 고른다. 보상 뒤 ‘같은 비경 다시 도전’을 쓸 수 있다.
4. 같은 지역의 전투를 성장 전후에 비교한다. 적 레벨과 수가 파티를 따라 오르지 않으므로 성장할수록 정리가 빨라진다.
5. 적이 많은 전투에서 창 크기를 바꿔 본다. 적 8칸, 양쪽 소환체 3칸씩과 행동 버튼이 전투 틀 안에 유지된다.

새 몬드 개인 이야기 10명은 제작 중인 원고를 기다린다. 이번 변경에는 합치지 않았다. 새 그림·소리는 받지 않았다.
