# 0.16.23 작업 결과

운영자 화면에서 직접 수치를 바꾸는 도구를 구현했다. 기존 보스 공략 오류 3곳도 수정했다. **일일보스가 공략 없이 쉽게 끝나는 모든 조합의 밸런스까지 완성한 것은 아니다.** 단순 HP 증가 후보는 문제를 해결하지 못해 적용하지 않았다.

## 실제 변경

| 대상 | 변경 |
|---|---|
| 운영자 화면 | `/admin.html`의 **밸런스** 탭. 한국어 검색, 숫자 입력, 변경 전후 미리보기, 적용, 이력 복구, JSON 내보내기·가져오기 |
| 편집 범위 | 적·보스 최종 능력치, 기존 적 편성, 캐릭터 능력치, 지원되는 기술 피해·회복·보호막, 음식·장비·제작·상점, 비용·보상, 단계별 비경·돌파·특성 수량 |
| 적용 안전성 | 운영자 별도 인증, SQLite 변경 이력, 동시 수정 충돌 확인. 진행 중 전투는 시작 당시 설정 유지. 최대 HP 증가로 무료 회복하지 않음 |
| 고대 바위 용 도마뱀 | 반사 성공 뒤 영구적으로 공략을 건너뛰지 않도록 기존 노출 창에만 효과 적용 |
| 유적의 뱀 | 다음 잠행에서 갑주가 다시 닫히도록 수정. 앞선 공략 한 번으로 이후 주기까지 계속 열리던 오류 제거 |
| 타르탈리아 일일 재도전 | 광역 기술이 앞의 두 명만 때려 AI가 선택한 후열 대상을 무시하던 오류 수정 |

보스 변경은 새로 시작한 전투에 적용한다. 옛 저장 전투와 이야기의 타르탈리아는 기존 처리대로 끝낸다. 게임 화면 배치·이야기·보스 수치·드롭·숙박비는 이번에 바꾸지 않았다. 원격 DB와 그림 파일은 선별 게시에서 보존한다.

## 검증과 판정

- 실제 필드보스 공개 행동 비교: 같은 Lv48 편성의 바위 용 도마뱀에서 대응 없는 반복은 **21라운드 패배**, 예고에 맞춰 바위 방어·노출 공격을 한 경우 **11라운드 승리, 4명 생존**. 장비·특성·시드 조건은 원자료에 있다.
- 일일보스 8조건은 최종 소스로 다시 실행했다. 적·아군 시작 수치는 이전과 같고, 타르탈리아의 후열 피격 수정만 확인했다. **8승·전투불능 0이며 5성 보호막 편성의 무손실이 남아 있어 공략 필수 난도 달성이라고 판단하지 않는다.**
- 새 필드 공략 32조건과 일일 대상 17조건은 소스·브라우저 생성본·서버 생성본에서 각각 통과했다. 기존 빌드 대조 219조건도 통과했다.
- 운영자 런타임, 실제 API·비경 정산, 운영자 화면과 휴대폰 적용·복구를 검증했다. 마지막 미지원 피해 배율 7개는 편집 목록에서 제외하고 지원 검사를 추가했다.
- 관련 회귀 30프로그램은 최초 29통과/1실패였다. 옛 갑주 개방 규칙을 검사하는 사례에 저장 전투 버전3을 명시한 뒤 해당 프로그램 전체 22조건이 통과했다. 최초 실패를 지우지 않았다. 전체 등록 검사와 모든 자연 육성 계정을 새로 완주한 결과는 아니다.

최종 소스 변경 뒤 다시 실행한 검사 수와 엔진 지문, 원자료·실패 기록은 [검증 원장](data/balance_v01623/README_KO.md)을 따른다. 로컬 검사 DB는 운영 편집 DB 전체 원문과 동일하다고 보장하지 않는다.

## 남은 밸런스

HP만 늘린 일일보스 후보는 폐기했다. 4성 편성 일부는 사망자가 늘지만 종려·진 포함 5성 명함 편성은 여전히 손실이 거의 없어, 시간만 늘리는 해결책이었다. 보호막 흡수·치유·실제 HP 손실·수동 대응을 함께 비교해야 한다.

다음 수치 조정은 첫 장비 재료 수급 전의 준비물, 패배로 소모되는 일일 입장, 필드와 일일의 강화도 차이, 음식·숙박·모라·육성 시간을 함께 확인한다. 새 도구의 기본 설정은 기존 수치를 그대로 사용한다. 코드 게시만으로 테스트 서버의 운영자 설정이 본서버에 복사되지 않는다.
