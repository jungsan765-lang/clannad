## 1. 주인공이 쓰러졌을 때 부활 막기

다시 재 보니 4성 파티가 주인공이 쓰러진 뒤 끝없이 지거나 끌렸다.

- **무상의 뇌전:** 프리즘은 주인공만 부술 수 있었다. 주인공이 쓰러지면 아무도 부수지 못해 보스가 계속 일어나고 파티가 졌다.
- **무상의 바위:** 동료만으로는 3라운드 안에 기둥 3개를 부수기 어려웠다. 보스가 26번 다시 일어나 245라운드를 끌었다.

`runtime_field_bosses.js`:

- 주인공이 서 있으면 프리즘은 지금처럼 주인공 몫이다. 주인공이 쓰러져 있으면 동료가 프리즘을 노리고 부순다(번개는 여전히 흡수).
- 무상의 뇌전·바위가 쓰러질 때 주인공이 쓰러져 있으면, 부활을 막는 시간이 2라운드 늘어난다(「다음 5라운드 안에 … 주인공이 쓰러져 2라운드 더」).
- 부활은 여전히 막아야 한다. 부활을 건너뛰는 길은 만들지 않았다(0.16.22에 정한 대로).
- 결과: 뇌전 4성 5판 모두 승(지던 판 67%). 바위 245라운드 판은 33라운드, 지던 판은 44라운드에 승.

## 3. 휴대폰 화면 조금 크게

`index.html`: 휴대폰은 화면을 1280×640(2:1)으로 그린다. 전에는 태블릿과 같은 1280×720(16:9)이었다.

- 옆으로 든 휴대폰은 대개 2.1:1이라 16:9 화면은 양옆이 남고 작게 그려졌다. 이제 가로 폭은 그대로, 높이만 80px 짧다. 같은 화면이 약 12% 크게 보인다.
- 태블릿(1280×720)과 컴퓨터(1600×900)는 그대로다.
- 이전 틀로 열린 화면은 한 번 다시 연다(`CRPGFrameRev` 3).

높이가 짧아져 안 들어가던 것은 화면 검사(`tests/test_screen_fit_v01629.mjs`, 휴대폰 1280×640)로 모두 찾아 `screen_v01629.css` 끝의 `@media (max-height:680px)` 묶음에서 맞췄다. 컴퓨터와 태블릿에는 적용되지 않는다.

| 화면 | 문제 | 고침 |
|---|---|---|
| 보스 미니게임 11종 | 창이 1256×704로 고정돼 제목·설명·「시작」이 화면 밖 | 창이 화면 크기에 맞춰 줄어듦 |
| 편성(파티) | 카드 4장이 75px 넘쳐 칸에 스크롤 | 얼굴 그림 150→96px, 카드 여백 줄임 |
| 캐릭터 → 운명의 자리 | 아래 안내 줄이 27px 잘림 | 별자리 그림 120→88px |
| 가방 상세 | 「상점에 올리기」가 26px 잘림 | 줄 사이 여백 줄임 |
| 전투 결과(비경·보스) | 「다시 도전」·「메인 화면으로」가 80px 아래로 | 제목 띠와 여백 줄임 |
| 메뉴 | 마지막 줄 칸이 아래 버튼 줄과 겹침 | 칸 높이 112→92px |
| 임무 → 진행 중 | 두 칸이 3px 모자라 한 쪽에 한 칸씩, 반이 빔 | 칸 안 여백 줄임 |
| 리월 세부 지역 | 3쪽에 한 곳만 남아 창이 빔 | 묶음 여백 줄여 2쪽 |
| 지역 정보(보스 장소) | 「만날 수 있는 적」 목록이 통째로 들어가 쪽 번호를 밀어냄 | 아래 쪽 나누기 수정 |
| 비경 카드(가장 넓은 것) | 왼쪽 칸이 2px 넘침 | 줄 간격 4px |

**쪽 나누기**(`app_mainscreen_v0167.js`, 모든 화면 공통): 카드 안 자리를 셀 때 카드의 안쪽 여백·테두리와 덩어리의 위아래 여백도 뺀다. 자리보다 조금 작다고 잘못 계산해 통째로 넣던 목록이 이제 줄 단위로 나뉜다. 컴퓨터 화면 검사에서도 새로 생긴 문제는 없다.

**화면 검사에 겹침 추가**: 글자·버튼이 다른 글자·버튼 위에 그려지면 잡는다(「overlap」). 예를 들어 잠긴 비경 단계 칸의 글자가 옆 칸으로 넘친 것, 메뉴 마지막 줄이 아래 버튼과 겹친 것. 일부러 위에 얹은 배지·숫자(위치를 지정한 것)와 창이 덮은 뒤쪽은 세지 않는다. 컴퓨터 1600×900에서는 0건이다.
