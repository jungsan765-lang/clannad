# 0.16.13 · 돌파 비경 효율과 캐서린 의뢰 표시

> 후속 정정: 아래는0.16.13 당시 기록이다. 보상만 올려 빨라진 최종 돌파는 [PATCH_0.16.14_KO.md](PATCH_0.16.14_KO.md)에서 요구량800/1,600개로 함께 보정했다. 현재 수치는0.16.14를 따른다.

기준 소스는 `447145bb95cc4b457e45992ffc2e1affc0753bd6`(0.16.12)이다. 이번 사용자 지시는 돌파 비경 보상, 캐서린 시설 버튼, 5성 스타라이트 교환 가격, 임무 이름·목표 설명에 한정한다. 사용자가 말한 “스토리”는 **임무 내용**이며 새 이야기나 대사는 만들지 않았다.

## 돌파 비경

| 단계 | 기존 기본 보석 | 변경 기본 보석 | 첫 3회 재료 보너스 적용 시 |
| --- | ---: | ---: | ---: |
| Lv.5~50 | 1~10 | 1~10 유지 | 2~20 |
| Lv.55 | 11 | 20 | 40 |
| Lv.60 | 12 | 32 | 64 |

같은 종류의 원소 돌파 보석을 유지하고 후반 두 단계만 상향한다. 경험치 비경·특성 비경 보상, 경험치 책의 지맥 전용 획득, 적의 수치·편성, 돌파 요구량과 기타 재료 비용은 유지한다. 첫 3회의 재료 2배는 특성·돌파 비경이 공유하며, 경험치 비경은 이 횟수를 쓰지 않는다.

최고 단계의 기존 시간당 보상이 하위 단계를 반복하는 것보다 불리한 문제를 실제 4인·2배속 전투 모델로 확인했다. 비교 조건·원소별 차이·수급 모델은 [ASCENSION_EFFICIENCY_V01613_KO.md](ASCENSION_EFFICIENCY_V01613_KO.md)에 기록한다. 모든 개별 전투가 일정한 초 안에 끝난다는 뜻이나 모든 인접 단계의 시간당 효율이 항상 상승한다는 뜻은 아니다.

4성 마지막 돌파는 300개, 5성은 600개다. Lv.60 기본 보상 기준 각각 10회·19회, 해당 날의 공유 보너스 3회가 모두 남아 있으면 7회·16회로 보석을 충당한다. 전체 여섯 번 돌파는 441개·882개이며, 특산물·보스 재료·모라·경험치·장비 투자는 별도다. 이 숫자를 캐릭터 육성 전체 완료 시간으로 해석하지 않는다. 주간 20승과 돌파에 적용된 2배 6회를 가정한 수급은 832개이며 실제 순서에 따라 달라진다.

업데이트 전에 이미 시작한 돌파 비경은 당시 보상을 유지한다. 새 입장에만 새 보상을 적용하며 재접속·정산 재전송으로 두 번 받을 수 없다. 완료한 돌파와 기존 보석은 그대로다.

## 캐서린과 교환

몬드·리월의 캐서린을 주변 시설 첫 칸에 둔다. 작은 화면에서도 이름은 ‘캐서린’이며 깊은 초록 배경과 금색 테두리로 강조한다. 다른 시설의 상대 순서, 칸 크기·지도·쪽 넘기기·방문 버튼·잠금 사유는 유지한다.

현재 스타라이트 교환 대상은 **보유 동료의 운명의 별**이다. 5성 동료와 기존 5성 가격 경로를 쓰는 주인공은 100개, 4성은 25개다. 미선택 안내·선택 가격·실제 결제를 함께 바꿨다. 미보유 동료와 운명의 자리 상한은 그대로 차단하며, 이미 구매한 별과 과거 결제 재시도 기록은 보존한다.

## 임무 이름과 내용

기존 의뢰 칸에 `모험 길잡이 / 전투 의뢰 / 생활 의뢰 / 물자 의뢰`를 표시하고 일반 의뢰의 기본 분류는 `길드 의뢰`로 둔다. 새 탭이나 임무 시스템은 만들지 않는다.

안내 24개의 제목을 자연스러운 한국어로 정리했다. 예를 들어 `경험치 비경으로 레벨링`은 **비경에서 쌓는 경험**이다. 연속 활동 240개는 갈래와 차수의 짧은 제목, 실제 장소·편성·승수는 목표 본문으로 표시한다. 납품 24개는 품목·수량을 유지한다. 새 이야기·서사는 추가하지 않고 기존 작성된 내용도 덮어쓰지 않는다.

이름은 표시용 메타데이터로 분리한다. 수락 당시 정의·목표·보상과 169/171/172의 검증 자료·선행 갈래는 그대로다. 임무 revision172, 일일11·주간27·일회성288개, 동시 수락5개와 전체 달성20/200원석을 유지한다. 자세한 이름·저장 경로는 [TASK_WORDING_V01613_KO.md](TASK_WORDING_V01613_KO.md)를 따른다.
