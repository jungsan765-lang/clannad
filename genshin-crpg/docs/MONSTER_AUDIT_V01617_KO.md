# CRPG 0.16.17 몬스터 전수 점검

검사일: 2026-10-09 UTC. **점검만 했다. 게임 코드·DB·제품 문서·테스트·서버를 수정하거나 배포하지 않았다.**

## 먼저 볼 결과

몬스터 **228종 전체 데이터**와 적 기술 **415개**, 편성 **331개**를 확인했다. 실제 런타임에서 생성한 **103종**은 공통 제어 효과와 AI도 검사했다. 미공개·미지원 몬스터는 정적 검사로 구분했다. 모든 몬스터·레벨·편성의 승률을 완전 검증했다는 의미가 아니다.

재현된 문제는 **8개**다. 슬라임·물 형상·심연 메이지의 원소 면역 누락과 무상의 얼음의 부활 핵 우회가 전투 규칙에 직접 영향을 준다. 사망한 엄호·수호 대상에게 다단 공격이 계속 향하는 문제도 적·아군 양쪽에 있다. 별도로 침수의 물 부착과 석화의 즉시 충전 중단 판정이 어긋난다.

기존 무한 석화와 패배 뒤 전투 지속은 이번 검사 경로에서 재발하지 않았다. 오셀 본체 공격도 삭제된 것이 아니라 실제 전투에서 발동했다.

- **무한 제어:** 실제 생성 103종에 빙결·석화·기절·물 감옥을 각각10회 반복하는 412조건, 자기 턴 경계 4,120회를 확인. 턴이 실제로1→10 진행하는지 검증했고 반복 제어 실패0. 기존 종려·중운 무한 석화 관련 회귀4개 통과. 강제로 상태를 넣은 수명 검사는 보스가 합법 기술로 석화된다는 고증 증명이 아니다.
