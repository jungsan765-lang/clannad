# 0.16.43 · 현장 의뢰 카드와 장면 창 · 글자를 가리는 표시 · 쪽마다 카드 제목

사용자 요청 (2026-10-13), 휴대폰 사진 2장(속삭임의 숲 「숲길의 숨겨진 보관함」: 2쪽에 의뢰 카드, 3쪽에 「낙엽 속의 끈」 장면이 따로):
- 「일단 화면은 잘 바뀌었는데 이 현장의뢰 이거 ㅅㅂ 이어져있지도 않고 글도 밀리고 전체적으로 다 찾아보라고 했는데 왜 이러는거냐 진짜」

## 원인
- 현장 의뢰 카드 하나에 설명, 보상, 단계, 현재 장면(긴 글 · 페이몬 · 고르기 세 개), 현장 기록이 모두 들어 있었다. 한 쪽보다 길어서 쪽 나누기가 카드를 잘랐고, 장면 부분은 의뢰 제목 없이 다음 쪽에 혼자 나왔다.
- 고르기 버튼의 💬는 버튼 위에 따로 그린 표시였다. 왼쪽 칸의 버튼 여백을 줄인 규칙 때문에 💬가 글 첫 글자(「“끈」, 「“살」)를 덮었다.
- 화면 검사는 「잘림」만 봤고, 이 두 가지(제목 없이 떨어진 카드 조각, 글자 위의 표시)는 보지 않았다. 검사에 현장 장면이 있는 의뢰도 없었다.

## 수정
- **현장 의뢰 카드**(`app_field_scenes.js`):
  - 왼쪽 칸에는 제목, 한 줄 설명, 작은 보상 칩, 단계 칩(1·2·3), 목표 한 줄, 「현장 살피기 · 지금 단계 이름」 버튼, 「현장 기록 · N」 버튼만 둔다.
  - 장면(글 · 페이몬 · 고르기)은 창으로 열린다. 고르면 창이 닫히고 결과 창이 나온다(전과 같다).
  - 현장 기록도 창으로 본다(전에는 칸 안에서 펼쳐져 칸을 늘렸다).
- **고르기 버튼**: 💬 / ⚔를 버튼 안의 글자 옆 칸으로 옮겼다. 여백이 어떻게 바뀌어도 글을 덮지 않는다.
- **어디서든**(`app_mainscreen_v0167.js`): 카드가 쪽으로 나뉘면 그 카드의 제목(h2~h4)이 쪽마다 함께 나온다. 작은 라벨 줄이 제목보다 앞에 있어도 마찬가지다.

## 화면 검사에 더한 것
- 검사 두 가지(모든 화면):
  - 버튼 위에 그린 표시가 글자에 닿으면 「mark over words」로 잡는다.
  - 쪽으로 나뉜 카드의 조각이 제목 없이 보이면 「card part without its title」로 잡는다.
- 장면 세 가지: 현장 장면이 있는 의뢰(한 번 틀린 뒤), 장면 창, 현장 기록 창.
- 컴퓨터 1600×900과 휴대폰 1280×720 전체 검사: 문제 0개.
