## 1. 서리 열매 치기

`source/app_bossgames_v01646.js` `FROST_FRUIT`. 걸어가 줍고 던지는 방식은 그대로다.

원작과 비교하면 이렇다.

| | 원작 | 이 게임 |
|---|---|---|
| 같은 점 | 얼음 보호막에 숨은 무상의 얼음이 서리 열매를 뿌리고, 열매를 보스에게 보내 보호막을 깎는다. 불 원소도 보호막을 깎는다. | 같다. |
| 다른 점 | 열매 뒤에 서서 강공격으로 쳐서 굴린다. | 열매를 주워 던진다. |

**얼음 조각의 박자.** 전에는 얼음 조각 4개가 쉬지 않고 빠르게 돌아(초당 1.7, 6초 뒤 2.2라디안) 운에 가까웠다. 이제는 박자가 있다.

- 돈다(1.0~1.5초, 초당 1.5라디안, 7초 뒤 ×1.2).
- 멈춘다(0.6초). 화면 위에 「멈췄다! 지금이야」가 나온다.
- 반짝인다(0.3초, 「곧 다시 돈다」).
- 다시 돈다. 다섯 번에 세 번은 반대로 돈다.
- 빨라지고 멈출 때 부드럽게 속도가 변한다. 조준선은 이 박자를 앞질러 계산해, 열매가 닿을 때의 조각 위치로 색을 정한다.

조각 폭은 0.92 → 1.0라디안이다(틈이 조금 좁아짐).

**판정과 손맛.**

| 판정 | 조건 | 결과 |
|---|---|---|
| 완벽! | 틈 한가운데를 지남(조각 가장자리에서 0.2라디안 이상) | 금색 조준선, 금빛 파편, 잠깐 느린 화면과 흔들림. 던지기 횟수가 줄지 않는다. 이어서 완벽이면 「완벽! ×2」 |
| 명중! | 틈을 지남 | 파편, 흔들림 |
| 막힘 | 조각에 닿음 | 열매가 조각에서 부서지고, 조각이 번쩍인다 |

- 보호막은 남은 횟수만큼 겹으로 그려지고, 맞힐 때마다 바깥 겹이 떨어져 나간다. 안의 핵은 점점 빨리 돌고 밝아진다.
- 마지막 한 번에 보호막이 산산조각 나며 「보호막 붕괴!」, 화면이 하얗게 번쩍이고 0.5초 느려진다.
- 던질 때 팔을 휘두르는 호와 열매의 꼬리가 보인다.

**알아보기.**

- 서리 열매는 잎이 달린 푸른 열매 모양이고, 늘 「서리 열매」 이름표가 붙어 있다.
- 시작 화면과 처음 몇 초에는 「얼음 조각 · 막힘」, 「얼음 보호막」 이름표가 붙는다.
- 설명 칸: 「얼음 조각이 멈출 때가 기회」, 「조준선 파랑 = 들어감 · 금색 = 완벽(던지기 그대로)」.

## 2. 미니게임 이름표

「이건 뭐지?」가 없도록 했다.

- 주워야 하는 것에는 늘 이름이 붙는다: 바람 원소, 서리 열매.
- 노리거나 피할 것에는 시작 화면과 처음 몇 초에 이름이 붙는다: 바람길 · 빠름, 약점, 냉기 핵, 얼음 가시, 부식 결정, 얼음 조각 · 막힘, 얼음 보호막.
- 바람 원소(바람 탄막 피하기 · 바람 원소 모으기)는 탄환과 똑같은 동그라미였다. 이제 세 갈래 소용돌이 모양이다. 바람 탄막 피하기에서는 사라지기까지 남은 시간이 둥근 줄로 보인다.

> 「일단 다 좋은데, 뭔가... 원이나 사각형 이런거로만 이루어져있는거같아서 개짜치는데... 에셋 없나....」, (충격파 넘기 그림과 함께) 「이런 ㅅㅂ 억까는 뭔데 ㅋㅋㅋㅋ」

  - 무상의 바람·무상의 얼음: `enemy_fb_anemo_hypostasis`·`enemy_fb_cryo_hypostasis`. 그림 속 핵이 게임의 핵 자리에 오도록 맞췄다.
  - 냉기 핵 쫓기: 무상의 얼음 그림
  - 약점 저격: `enemy_fb_ruin_serpent`
  - 부식 결정 저격: 드발린의 둥지
  - 질주 피하기: 늑대의 영역
  - 타르탈리아: 황금 저택
  - 충격파 넘기: 야타용왕 경기장

  - 다음 충격파의 틈은 앞 틈에서 조금만 옮겨 간다.

- 바람 탄막 피하기: 옆·위에서 오는 바람 벽의 틈이, 벽이 닿기 전에 갈 수 있는 거리 안에 생긴다.
- 서리 열매가 화면 맨 위 안내 글자와 겹치지 않게 맨 위 띠에는 떨어지지 않는다.

검사(`tests/test_boss_core_v01657.cjs`): 같은 봇으로 충격파 넘기 30판이 평균 1.2대 이하, 가장 많이 맞아도 3대 이하, 8판 이상 무피해인지 확인한다. 바람 원소 모으기는 원소 평균 3.5개 이상, 맞음 평균 0.8 이하인지 확인한다.

## 3. 전투 순서 칸과 소환물

> 「야 이번엔 토끼백작이 너무 빨리 나오잖아 전체적으로 전투 순서부분에서 드러나는걸 좀 다 체크해봐 스킬별로 전부 다; 과부하인가 초전도인가 그거도 뭔가 하나씩 하나씩 터지는 문제가 있던거같은데 그냥 다~~ 체크해봐」

동료 43명 전원을 15팀으로 나눠 실제 전투를 재생해 보고(재생기와 같은 `CRPGPresentation.delta`·`actionFrames`), 순서 칸과 소환물 칸에 무엇이 언제 보이는지 확인했다. 전투 기록·상태·수치는 바꾸지 않았다. 보여 주는 쪽(`source/app_summons_v01652.js`, `source/app_battle_fx_v01521.js`)만 고쳤다. `presentation.js`와 `app_av.js`는 그대로다.

**소환물** (`app_summons_v01652.js`):

- 소환물은 그것을 만드는 스킬을 쓰는 박자에 나온다. 전에는 주인의 원소전술·원소폭발이면 아무거나 소환물을 데려와서 미리 보였다.
  - 엠버가 화살비(원소폭발)를 쏠 때 토끼 백작이 6~10박자 먼저 보였다.
  - 향릉 원소폭발에서 누룽지가, 감우 원소폭발에서 얼음 연꽃이 미리 보였다.

  | 소환물 | 만드는 스킬 |
  |---|---|
  | 토끼 백작 | 엠버 원소전술 |
  | 오즈 | 피슬 원소전술·원소폭발 |
  | 번개 장미 | 리사 원소폭발 |
  | 누룽지 | 향릉 원소전술 |
  | 얼음 연꽃 | 감우 원소전술 |
  | 선기 병풍 | 응광 원소전술 |
  | 월계 | 요요 원소전술·원소폭발 |
  | 지핵의 석주 | 종려 원소전술 |
  | 보스 소환물 | 뇌광 프리즘·현암 기둥·부활·물의 형상 기록(`FB_PRISM`·`FB_PILLARS`·`FB_REVIVE`·`FB_OCEANID_FORMS`) |

- 같은 재생 안에서 만들어지고 터진 소환물(토끼 백작이 다음 라운드에 바로 터짐)은 마지막 상태에 없어서 안 보였고, 폭발이 갑자기 날아왔다. 이제 스킬에서 모양을 만들어 보여 준다.
- 터지거나 끝난 소환물은 자기 마지막 박자가 끝나면 칸에서 사라진다(전에는 재생이 끝날 때까지 남음).
- 토끼 백작의 「다음 라운드 · 폭발」은 소환하는 박자에 순서 칸에 붙는다(전에는 재생이 끝난 뒤에야 보임). 적에게 맞아 먼저 터지면 「폭발」로 바뀐다.

**전투 순서 칸** (`app_battle_fx_v01521.js`):

- 「현재」 표시, 큰 차례 표시, ×N은 그 사람의 실제 차례에만 붙는다(`turnFrame`). 다음 것은 다른 사람의 차례 안에서 일어나는 일이라 차례를 옮기지 않는다:
  - 장판·소환물의 지속 피해와 반응
  - 추가 공격: 행추·북두·야란·한운·소·타르탈리아
  - 모나 거품
  - 진·치치·요요의 지속 회복
  - 적에게 붙는 효과
  - 주인공 합동 공격에서 동료가 치는 몫
- 회복만 하는 차례(바바라 원소폭발)는 카드 표시가 없다. 그 사람의 차례 수가 올라간 줄로 알아본다. 주인공의 미니게임(`BOSS_ARENA`)도 차례다.
- ×N은 박자 수가 아니라 행동 번호 수로 센다. 전에는 한 번 행동해도 ×2~×4가 붙었다(한운·소·타르탈리아·응광·행추·야란·감우·모나·미카·북두·케이아·엠버).
- 새 라운드 목록에서 쓰러짐(회색·취소선)은 재생 화면에서 실제로 쓰러진 뒤에만 표시된다. 전에는 마지막 HP로 미리 표시했다.
- 재생기(`app_av.js`)가 반응·회복 박자에서 「현재」를 옮기면, 차례인 사람에게 다시 돌려놓는다.

## 4. 반응이 한 명씩 터지던 것

재생의 박자는 같은 사람·같은 카드·같은 종류의 줄이 이어질 때 묶인다. 공격이 일으킨 것이 그 사이를 끊어서, 한 공격이 대상마다 따로 터졌다.

- 장판의 지속 피해와 반응: 클레 원소폭발이 「피해 A · 과부하 A · 피해 B · 과부하 B · 피해 C · 과부하 C」 여섯 박자. 리사 장미, 케이아·설탕·감우·향릉·신학 원소폭발, 오즈도 같았다.
- 초전도의 방어 감소가 맞은 적의 이름으로 기록되어, 공격 사이에 「적 · 효과」 박자가 끼었다(모든 일반 공격·지속 피해·합동 공격).
- 소리 없는 상태 변화(효과가 풀림, 재사용 대기)가 공격과 반응 사이를 끊었다. 디오나·신학·달리아·미카·타르탈리아의 빙결, 벤티 원소폭발이 해당한다.
- 토끼 백작의 폭발이 일으킨 과부하가 엠버 이름으로 기록되어 「토끼 백작 → 엠버 과부하 → 토끼 백작」, 두 번 공격하는 것처럼 보였다. 다음 차례 엠버의 기본 공격에 「폭발」이 붙기도 했다.
- 다른 동료의 추가 공격(한운·행추)이 소 원소전술 같은 공격을 두 박자로 갈랐다.

`app_summons_v01652.js` 아래쪽에서 박자를 만들기 전에 정리한다(`CRPGPresentation.tidyBeats`):

- 공격이 일으킨 반응·반응 피해·그 적에게 남은 효과는 그 공격에 붙는다.
- 소리 없는 상태 변화는 일어난 박자에 붙는다. 차례 시작의 변화는 다음 줄에 붙는다.
- 다른 동료가 끼어든 추가 공격은 그 공격 바로 다음 박자로 미룬다. 단, 같은 적을 먼저 친 경우는 미루지 않는다. 그래서 대상마다 HP가 바뀐 순서는 그대로다.

**측정**(동료 43명 15팀, 츄츄 정예·슬라임·아비스 메이지, 시드 2개, 1,080턴):

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 한 사람의 한 행동이 여러 박자로 갈라진 곳 | 1,097 | 117 |
| 대상마다 보이는 HP 순서·마지막 HP가 달라진 곳 | | 0 |
| 한 번 행동했는데 ×2 이상 | 412 | 0 |
| 한 행동 번호를 둘 이상이 차례로 가져감 | | 0 |

남은 117곳의 대부분은 따로 보이는 것이 맞는 경우다. 케이아 원소폭발의 지속 피해와 케이아 자기 차례, 모나의 허상과 폭발, 신염의 연소 피해와 장판이 해당한다. 일부는 같은 적을 먼저 친 추가 공격이라 HP 순서를 지키느라 남겼다.

**남은 것(작음)**:
- 얼어서 차례를 건너뛴 사람은 지난 라운드 순서 목록(재생 중 박자로 만든 목록)에 안 나온다.
- 종려 원소폭발로 남은 순서가 바뀐 것은 재생이 끝난 뒤에 반영된다.

**게임 규칙 메모(바꾸지 않음)**: 토끼 백작은 소환한 라운드가 끝나고 다음 라운드가 시작될 때 터진다(`explodeAt = round + 1`). 엠버가 라운드 맨 끝에 행동하면 적이 한 번도 때리지 못하고 터진다.
