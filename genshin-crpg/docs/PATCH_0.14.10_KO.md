# 0.14.10 패치 노트 (테스트 서버 후보)

0.14.8~0.14.9 테스트 의견을 반영한 묶음입니다. 승인 전에는 main 병합과 운영 반영을 하지 않습니다.

## 위쪽 메뉴 줄의 스크롤 막대 (`source/shell.css`)

- **원인**
  - 옛 사이드바 규칙(`style.css`: `aside{max-height;overflow-y:auto}`)이 위쪽 메뉴 줄(`aside.shell-hud`)에도 적용됐습니다.
  - 아이콘 아래 이름표(`.hud-nav-label`)가 줄 밖으로 18px 나와 있어서, 줄이 스크롤되며 오른쪽 끝에 작은 위아래 막대가 생겼습니다.
  - 같은 이유로 아이콘 이름표가 잘려 안 보였습니다.
- **수정**: 메뉴 줄은 `overflow:visible`, `max-height:none`입니다.
- 0.14.8에서 숨긴 것은 페이몬 메뉴 상자(`.pm-box`)의 막대였고, 사용자가 말한 막대는 이것이었습니다.

## 이동 지도 누르기 (`source/app_navigation.js`, `source/shell.css`)

- **원인**
  - 버튼을 누르는 동안 적용되는 공통 스타일(`button:active{transform:scale(.98)}`)이 지도 번호 버튼의 가운데 맞춤(`translate(-50%,-50%)`)을 덮어썼습니다.
  - 그래서 누르는 동안 번호 버튼이 22px 아래오른쪽으로 밀려나고, 손을 떼는 위치가 버튼 밖(지도)이 되어 눌리지 않았습니다.
  - 아주 빨리 누를 때만 됐습니다. 자동 검사의 빠른 클릭으로는 드러나지 않았고, 실제처럼 0.12초 누르면 재현됩니다.
- **수정**
  - 지도 표시(번호, 위치 점, 길 위 번호)는 누르거나 마우스를 올려도 자리와 크기가 그대로입니다. 누름은 색으로 보여 줍니다.
  - 크기가 변하면 가장자리에서 누름을 놓치기 때문입니다.
- **새로 누를 수 있는 것**
  - 길 위의 번호: 버튼
  - 작은 위치 점: 번호가 옆으로 옮겨진 경우 실제 위치
  - 길 자체: 투명한 18px 굵기 선
  - 여러 목적지가 함께 쓰는 길 구간은 누르지 않습니다. 다른 길과 화면에서 10px 이상 떨어진 「자기 구간」만 누름과 번호를 받습니다. 번호는 다른 번호에서 28px, 번호 버튼에서 30px 떨어진 자리에 둡니다(자리가 없으면 번호 버튼만 씀).
- **끌기**: 4px 넘게 움직였을 때만 지도를 끌고, 끈 뒤에는 누름으로 처리하지 않습니다. 다음 누름이 삼켜지지 않도록 누를 때마다 끌기 표시를 초기화합니다.
- **버튼 상태**
  - −/+는 확대 한계(1~4배)에서 흐려집니다.
  - 「주변 보기」·「지역 전체」는 지금 보는 쪽이 켜집니다(`aria-pressed`).
- 카드에 마우스를 올리면 그 목적지의 번호 버튼·길·번호·카드가 함께 강조됩니다(`NavigationUI.hover`).

## 화면 크기 (`source/index.html`, `source/app_shell.js`)

- **원인**
  - 높이 상한이 1200으로 고정이었습니다.
  - 창 높이가 1020 이상인 모니터(예: 2560×1440)에서는 「작게」와 「보통」이 같은 크기가 됐습니다.
- **수정**
  - 상한을 `1600 / 배율`로 바꿨습니다. 이제 큰 모니터에서도 세 선택이 다릅니다(85·100·120%).
  - 1280×720 하한은 그대로입니다. 그래서 작은 창(예: 1366×768 노트북)에서는 「크게」가 더 커지지 않습니다.
- **설정 표시**
  - 틀 쪽 `CRPGFrameMeasure(이름)`이 각 선택의 결과 배율을 알려 줍니다.
  - 선택지에 「작게 · 85%」처럼 표시하고, 창 때문에 더 키우거나 줄일 수 없으면 그렇다고 적습니다.

## 글자 크기 (`source/app.js`)

- **단계**: 80·90·100(기본)·112·125·150%. 줄이는 단계(80·90%)를 더했습니다.
- **기본**: 100%(16px) 그대로입니다. 사용자가 처음에는 112%를 기준으로 하자고 했다가 「100%가 맞았다」며 되돌렸습니다.
- 예전 값(100·112·125·150)은 그대로 유효하므로 옮길 저장이 없습니다.

## 이름 정리

- **화면 이름**: 한 화면에 하나의 이름을 씁니다.
  - `SYSTEM` = 「설정」
  - `STATUS` = 「캐릭터」(C): 장비·특성·운명의 자리. 원신 PC의 C 키 화면과 같은 이름입니다.
  - `INVENTORY` = 「가방」(B)
- **바꾼 곳**
  - 셸 `NAV`, 메뉴 줄 이름표·제목·`aria-label`, 페이지 제목(`pageHead`)
  - `app_revision.js` 사이드바, `app_gear.js`
  - 안내 문구: `app_party.js`, `app_equipment.js`, `app_experience.js`, `app_tutorial.js`, `app_version.js`, `app_motion.js` 팁
- **손대지 않는 파일의 이름**: `app_online.js`·`app_av.js`가 만드는 이름은 셸의 `RELABEL`로 표시만 바꿉니다.
  - 자동저장·계정 → 설정
  - 소리 시작 → 소리 켜기
  - 게임 시작 화면 → 시작 화면으로
  - 상위 20위 → 나선비경 랭킹
- 페이몬 메뉴 아래쪽에 설정 타일과 겹치던 설정 버튼을 뺐습니다.
- 「왼쪽 메뉴의 장비 장착」처럼 0.14.7 이전 화면을 가리키던 문구도 고쳤습니다.

## 지도 문구

- 「지도 표시 기준」(승인된 지도, 미검증 입구, 흐린 영역 등 개발 메모)을 「지도 보는 법」(번호·점·점선을 읽는 법)으로 바꿨습니다.
- 리월 세부 지역 안내에서 「원본 좌표 X/Y」, 「880 × 786 원본의 왼쪽 위 기준」, 「…기준점」 표시를 지웠습니다. 좌표는 `data-point`에만 남깁니다(`tests/v01315_coordinates.py`가 읽음).

## 전투 화면 (작은 창)

- **원인**
  - 1280 너비 틀에서는 적 칸이 250px 두 줄이 됐습니다(auto-fit이 최대 폭 250px로 칸 수를 셈).
  - 셋째 적이 아랫줄로 내려가고, 줄 높이가 카드보다 낮게 눌려 카드가 겹쳤습니다.
- **수정**
  - 줄은 항상 카드 높이에 맞춥니다(`grid-auto-rows:max-content`). 넘치면 무대가 스크롤됩니다.
  - 761~1400px에서는 188px 칸 세 개와 낮은 초상(`--enemy-h`)을 씁니다.
