# 0.15.7 패치 노트 (알파 테스트) — 휴대폰에서 앱처럼 하기

기준: 0.15.6(`dec6356`). 사용자: 「휴대폰으로 인게임 들어갈 때 위아래가 잘리는 느낌이 없지 않아서 apk가 필요할 것 같다」. 두 방법(A: 홈 화면에 추가 · 전체 화면, B: APK 파일) 중 「일단 A 해봐」.

## 원인
- 게임 화면은 이미 휴대폰에서 보이는 높이(`100dvh`)에 맞추고, 아래 막대는 홈 표시줄 위(`env(safe-area-inset-bottom)`)에 둔다. 게임이 잘라 먹는 곳은 없다.
- 휴대폰 브라우저의 주소창(위)과 도구 막대(아래)가 화면을 차지해, 게임이 쓸 수 있는 높이가 줄어든 것이 「위아래가 잘리는 느낌」이다.

## 바뀐 내용 (`app_install_v0157.js`, `manifest.webmanifest`, `index.html`, `app_shell.js`, `shell.css`)
- 설치한 게임(홈 화면 아이콘)은 전체 화면으로 열린다: 매니페스트 `display: fullscreen`, `display_override: [fullscreen, standalone]`(전체 화면을 못 하는 곳은 주소창 없는 창). 아이폰 홈 화면 앱용 설정(`apple-mobile-web-app-capable`, 상태 표시줄 `black`, 아이콘 `icon-192.png`)을 더했다. 노치 아래로 화면을 넓히는 `viewport-fit=cover`는 쓰지 않았다(기기 확인 전에는 위쪽 HUD가 가려질 수 있다).
- 첫 화면(휴대폰, 아직 설치 안 함)에 「앱으로 설치」: 브라우저가 설치 창을 주면(안드로이드 크롬 `beforeinstallprompt`) 그 창을 띄우고, 아니면 브라우저별 방법을 보여 준다(아이폰 사파리: 공유 → 홈 화면에 추가, 처음 한 번 다시 로그인 / 삼성 인터넷: ≡ → 현재 페이지 추가 → 홈 화면 / 크롬: 점 세 개 메뉴 → 앱 설치 또는 홈 화면에 추가 / 카카오톡 · 디스코드 등 앱 안의 브라우저: 먼저 「브라우저로 열기」). 이미 설치한 앱으로 열었거나 PC에서는 나오지 않는다.
- 전체 화면(Fullscreen API, `navigationUI: 'hide'`): 설치 창의 「설치하지 않고 지금 전체 화면으로」와 페이몬 메뉴 아래 「전체 화면 / 전체 화면 끄기」. 브라우저가 허락하는 곳(안드로이드)에서만 보인다. 아이폰 사파리는 페이지 전체 화면이 없으므로 나오지 않는다.
- 첫 화면은 이 파일이 읽히기 전에 그려질 수 있어(저장소가 열리는 동안 뒤 스크립트가 아직 읽히는 중), 읽힌 즉시와 화면이 바뀔 때마다 단추를 확인한다.

## 확인
- `tests/test_v0157.cjs`(게이트 등록, 6개): 매니페스트 · 메타 · 스크립트 순서, 안드로이드 크롬(설치 창 → 설치 완료 안내, 전체 화면 단추), 아이폰 사파리(방법만, 전체 화면 없음), 채팅 앱 브라우저(브라우저로 열기), 페이몬 메뉴 전체 화면(`navigationUI: 'hide'`), 이미 설치(전체 화면 · 창) · PC는 단추 없음.
- 브라우저(로컬, 375×812 폰 화면, 실제 클릭): 첫 화면 「나선비경 랭킹 · 설정 · 앱으로 설치」 → 「앱처럼 하기」 창(크롬 방법 · 앱 안 브라우저 안내 · 「설치하지 않고 지금 전체 화면으로」) → 게임 안 페이몬 메뉴 아래 「전체 화면」. 미리보기 창은 페이지 전체 화면을 허락하지 않아 실제로 화면이 커지는 것은 휴대폰에서 확인해야 한다.
- 전체 확인 `python tools/verify_release.py`.
