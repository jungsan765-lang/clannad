## 규칙 (`source/runtime_field_bosses.js`, 0.16.46 조작 블록)
새로 여는 전투에만 붙는다(`controlRevision:1`). 필드 보스는 자기 도전 장소에서 연 전투(행동판 5·공격 압력 1), 일일 보스는 재료 도전(`MATERIAL_CHALLENGE:`)이다. 0.16.45까지 저장된 전투는 시작할 때의 규칙 그대로 끝난다. 협동(공유) 전투에는 미니게임 카드가 나오지 않는다(서버가 카드·대상·방식만 전달한다).

미니게임은 **주인공의 한 행동**이다(시스템 카드). 화면이 게임을 하고, 결과를 같은 `COMBAT` 행동에 `mini:{kind,id,hits,orbs}`로 실어 보낸다. 규칙이 최대값으로 자르고, 다른 탄막의 결과(번호가 다름)는 「피하지 않음」으로 친다. 무늬는 전투의 시드에서 나와 기기마다 같다.

| 보스 | 원작 고증 | 이 게임에서 |
|---|---|---|
| 무상의 바람 | 무상 계열은 핵이 드러날 때만 피해를 받는다 · 바람 탄막 · 원소 입자 | 탄막을 모으거나 떠 있는 동안 **핵 닫힘**(피해 0, 동료는 방어). 공격을 마치면 **핵 노출**(받는 피해 +50%). 순서: 돌풍 탄환 → 바람 탄막(예고) → 흡인 회오리 → 상승 기류. 「바람 탄막 피하기」: 맞은 수 × 0.25 계수로 파티 전원 피해(안 피하면 4발), 모은 바람 원소 하나마다 파티에서 가장 오래 남은 원소폭발 재사용 −1차례. 탄막은 주인공에게 한 번은 차례를 준 뒤 날아온다. |
| 무상의 뇌전 | 부활할 때 프리즘 3개 · 번개 외 공격으로 파괴 | 부활 프리즘은 **주인공의 행동으로만** 부서진다. 번개가 아닌 한 방에 하나. 「함께하는 일격」은 참가한 동료마다 남은 프리즘을 이어서 친다. 동료는 그동안 방어한다. 체력 50% 프리즘(2개)은 전과 같다. |
| 무상의 얼음 | 쓰러지면 냉기 핵이 도망치며 부활을 노림 | 「냉기 핵 쫓기」: 달아나고 순간이동하는 핵을 눌러 맞힌다(한 번에 최대 3번). 얼음 가시를 누르면 1초 얼어붙음. 불·파쇄로 맞히는 기존 방법도 그대로. |
| 드발린 | 몸의 부식 결정을 쏘아 떨어뜨림 | 3라운드마다 「부식 결정 저격」: 탄 6발, 폭풍이 불 때 쏘면 빗나감. 2개 → 받는 피해 +50%(다음 라운드까지), 3개 → 추락(한 차례 행동 불능·근접 공격도 닿음). |
| 안드리우스 | 2페이즈 질주·얼음 발톱 | 3라운드마다 라운드 끝 「얼음 발톱 질주」 → 「질주 피하기」. 맞은 수 × 0.13 전원 얼음 피해(안 피하면 4발), 0발이면 빈틈(+50%). |
| 타르탈리아 | 마왕 무장의 물 칼날·번개 창 | 3라운드마다 라운드 끝 「극악기·진멸」 → 「진멸 피하기」. 2페이즈는 번개, 그 밖은 물. 0발이면 빈틈. |
| 야타용왕 | 땅을 구르는 충격파·운석 | 3라운드마다 라운드 끝 「지맥 충격파」 → 「충격파 넘기」(퍼지는 원의 틈으로 빠져나가기 + 그림자 진 곳의 운석). 지금 원소로 피해. 0발이면 빈틈. |

## 화면 (`source/app_bossgames_v01646.js`, 새 파일)
- 미니게임 카드는 행동 줄에서 테두리가 빛나고, 고르면 실행 버튼이 「▶ 바람 탄막 피하기 시작」으로 바뀐다(스페이스도 된다).
- 창: 제목 + 짧은 칩(조작·목표) + 640×400 판 + 남은 시간 막대 + 「시작」「돌아가기」. 시작 전에는 돌아갈 수 있고, 시작하면 3·2·1 뒤 끝까지 간다. 끝나면 결과를 1초 보여 주고 바로 행동이 실행된다.
- 조작: 컴퓨터는 WASD·방향키(피하기), 마우스(쫓기·저격). 휴대폰·태블릿은 화면 방향 버튼(누르는 동안 이동)과 판을 끌기, 터치.
- 보스 카드의 효과 칩 맨 앞에 상태가 보인다: 「핵 닫힘」「핵 노출」「남은 핵 N」「냉기 핵 0/4」「프리즘 부활」「부식 결정」「추락」「질주 준비」「극악기·진멸 준비」「빈틈」. 전에는 접힌 「전투 정보」 안에만 있었다.

## 무상의 얼음 점검
- 시작 · 얼음 가시 방벽(보호막 6600) · 핵 단계를 컴퓨터 1600×900과 휴대폰 1280×720에서 찍어 확인했다. 카드가 밀리거나 잘리지 않는다(화면 검사 `fb-mini-cryo-start/wall/core`).
- 편성 3가지 × 공략 2가지 × 12판을 끝까지 싸운 측정에서 오류는 없었다.
- 찾은 것 1: 냉기 핵의 「몇 번 남았는지」가 접힌 정보 안에만 있었다 → 카드 칩 「냉기 핵 0/4」로 보이게 했다.
- 찾은 것 2 (0.16.45에도 같음, 고치지 않음): 4성 명함 편성에서 주인공이 쓰러진 뒤 노엘 혼자 100라운드 넘게 자동으로 싸우는 판이 있다. 얼음 가시 방벽(보호막 6600)이 2차례마다 다시 생겨 혼자서는 뚫지 못한다. 밸런스 작업에서 정한다([밸런스 준비](BALANCE_PREP_0.16.46_KO.md) 4번).
