# 0.16.19 · 원소 반응, 회복·보호막과 필드보스 조정

사용자가 승인한 0.16.18 검토를 실제 코드에 적용했다. **명확한 계산·차례 오류를 먼저 고치고, 네 명 동시 회복·보호 때문에 후반 소모가 사라지는 수치를 조정했다.** 숙박을 매번 강제하거나 모든 적을 한꺼번에 강화하는 방식으로 맞추지 않았다.

기준 게시 소스는 `1e1b2442b53d42873d29556898f5f612d52d0c7a`의 0.16.18이다. 기존 원격 DB·이미지·음악·화면 배치를 보존한다. 기술 정보와 보호막 막대의 기존 숫자만 실제 계산에 맞춘다. 성장 XP·모라·비경 보상·돌파/특성 요구량·음식·숙박비·임무·별 등급 성장 배율은 이번에 바꾸지 않는다.

## 3. 보호막: 여러 보호막은 같은 피해를 함께 소모

아군 보호막이 여러 개이면 각각 같은 원래 피해를 받는다. HP에는 가장 많이 막은 보호막을 기준으로 남은 피해가 들어간다. 보호막을 차례대로 깎아 흡수량을 모두 더하던 기존 처리는 제거했다. 예를 들어 300과 400의 두 보호막에 500피해가 오면 둘 다 소진되고 HP는 100 감소한다. 적의 원소 보호막·면역·갑옷의 기존 순차 처리는 별도 규칙으로 유지했다.

새 종려 보호막은 기존 양의 65%로 생성한다. 기본 최대 HP20%가 **13%**가 된다. 같은 출처 갱신은 기존처럼 남은 양과 새 양 중 큰 값이며 더해서 쌓이지 않는다. 운명의 자리의 같은 출처 보호막, 치유·제어·엄호와 기술 재사용 조건은 유지한다.

남연 보호막의 원소 전환은 전체 HP 피해를 절반으로 낮추던 처리 대신 **그 보호막 자신의 바람 및 전환 원소 흡수 효율 2.5배**로 적용한다. 보호막을 넘는 피해나 동료의 다른 보호막에 전환 혜택을 잘못 주지 않는다. 결정과 남연의 같은 원소 효율은 각 보호막에 따로 적용한다.

기존 보호막 막대는 아군의 현재/초기 개별 보호막 중 가장 큰 기본 양을 표시한다. 여러 보호막의 합계를 실제 HP 방어량처럼 보이지 않게 숫자 계산만 바꿨다. 개별 원소 효율과 원시 소모량은 이 기본 막대 수치와 구분한다.

`shieldBefore−shieldAfter`는 모든 보호막 풀의 원시 소모량 합계다. 동시 소모에서는 실제로 막은 HP 피해와 다르므로 피해 수지는 `absorbed`를 사용한다. 반올림 후에도 실제 HP 피해+막은 피해가 원래 피해와 맞도록 검사했다. 실전 전후 비교와 원자료: [보호막 검증](data/shield_balance_v01619/README_KO.md).

같은 54조건의 첫 적 구성이 모두 동일하고 실행 오류는 0이었다. 적정 Lv.40/50/60 비경 30조건은 전후 모두 3연승했다. 전원 Lv.25의 깊은 층암거연에서 여행자·종려·다이루크·진 C0의 첫 승은 양쪽 3/3, 3연승은 양쪽 2/3이지만, 성공한 반복의 **마지막 정산 전 HP**가 99.5~100%→1.1~82.8%로 낮아졌다. 세 동료 모두 C2인 별도 편성은 3연승 2/3→1/3이었다. 종려 혼자만 C2인 검사가 아니다. 레벨업 뒤 전원 HP100%가 된 조건을 힐로 무소모였다고 세지 않았다.

- 신규 보스는 `behaviorRevision:2`로 구분한다. 이전 진행 중 보스의 수치·차례/핵 기한 규칙은 저장된 이전 경로로 마친다.

4성 C0의 새 패배 네 조건은 무상의 얼음 기본 특성2, 무상의 바위 기본 특성5의 각 두 시드다. 합법 특성 상한과 같은 +6/+10 장비를 쓰는 추가 12조건은 모두 승리했다. 바위 본체의 면역을 고려해 노엘·향릉·바바라 C0/+6/특성5로 바꾼 별도 세 조건도 3/3승리했고, 36~40→45~52라운드·종료 HP86.1~98.9→45.6~60.4%였다. 4성 풀돌이나 5성이 없으면 보스를 못 깨게 만든 결과가 아니다.

다만 5성 준비 편성의 종료 HP100%는 12/18→7/18로 줄었어도 남는다. 초기 보스 72조건의 65승·7패→공격력만 복원한 54승·18패와 중간 통합 53승·19패는 **최종54/추가12/균형3의 서로 다른 조건 집합**이다. 한 승률로 합치거나 전구간 균형 완료라고 쓰지 않는다.

## 5. 저장, 검증 범위와 후속

이전 진/바바라/추가 회복의 이미 생성된 상태·영역은 새 수치 표시가 없으면 기존 잔여 효과를 유지한다. 기존 보호막 풀도 소급 삭감하지 않는다. **앞으로 받는 아군 다중 보호막 피해의 동시 소모 규칙은 기존 전투에도 적용된다.** 저장값 보존을 모든 과거 전투 동작 불변이라는 의미로 쓰지 않는다. 완료한 육성·옛 보상/결제 기록은 재청구하지 않는다.

같은 레벨·장비·특성·시드에서 비교하되 반응/보스/치유가 함께 바뀐 실전은 한 항목의 단독 효과라고 단정하지 않는다. 승리 직전 HP, 보상 뒤 레벨업 완전 회복, 승리 후 주인공 부활을 분리한다. 패배 때문에 숙박이 막힌 0모라는 경제 이득이 아니다.
