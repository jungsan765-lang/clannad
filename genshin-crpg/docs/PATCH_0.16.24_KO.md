필드보스 9종의 실제 수치와 소환체·부활 저지 기한을 변경했다. 일일보스 4종도 별도로 검증해 반복 도전의 전투 부담을 조정했다. **이야기·일반 비경을 통째로 강화하거나 종려·치유 캐릭터를 전역 약화하지 않았다.** 진행 중인 저장 전투는 시작 당시 수치와 규칙으로 끝낸다.

이야기 전투가 아닌 기존 일일 재도전에만 적용한다. 방어력은 유지했다.

타르탈리아의 기존 광역3종은 기존 피해의1.6/2/2.5배, 야타의 기존 꼬리 폭풍은2배로 조정했다. 새 기술·공략 버튼은 추가하지 않았다. 보호막 소모 배율은 기존 흡수 처리에 연결하며, 보호막이 없는 HP 피해를 이 배율로 곱하지 않는다. 방패가 빨리 깨지면 실제 HP 손실이 늘어난다. 원소·중첩 방패·종려6돌의 기존 흡수 후 회복은 유지된다.

새 일일 `dailyPressureRevision:1`을 시작 시 고정한다. 예전에 진행 중이던 전투는 새 배율을 받지 않는다. 운영자 밸런스 탭에는 반복 도전 기본 수치와 해당 전용 공격 배율을 표시하며 기존 정확 수치 설정은 우선한다.

## 회복·육성·경제 영향

종려의 방패를 전역25%로 낮추는 후보는 일반 Lv20 특성 비경의 두 번째 연속 전투에서 주인공이 쓰러져 폐기했다. 해당 후보52전투와 폐기 이유는 원장에 보존하며 제품 결과로 세지 않는다. 음식·숙박·경험치·돌파·특성 수량·모라·입장 횟수·드롭은 이번에 변경하지 않았다.

필드 최초 장비 재료를 얻기 전의 조건은 일반 제작 장비+3/+6, 강화 상한10, 성유물·자기 보스 재료 장비 없이 검증한다. 일일은 일반 제작+10이며 +12 개방이나 자기 보스 장비를 최초 재료의 필수 준비물로 가정하지 않는다. 소유·동레벨·특성·이야기 해금은 준비된 테스트 계정 조건이다. 자연 계정의 뽑기·전 구간 육성 시간을 재실측한 것은 아니다.

Lv40 4성명함/+6의 첫 돌파 정수 수급 경계도 별도6전투로 확인했다. 늑대25·드발린28 모두3시드 승리·전투불능0, 실제 정수1~2개가 지급됐다. 같은 레벨·보유·특성·이야기 해금을 준비한 조건이며 신규 계정이 재료·강화비를 자연 조달했다는 증명은 아니다.

필드 보상은12시간당 공유3승, 일일은 보스별 하루1회이며 일일 패배도 입장을 소모한다. 이런 비용을 고려해 수급 경로를 막는 과도한 후보는 제외했다. 전투 후 실제 HP와 전투불능·대상별 숙박 견적을 비교하며, 회복 총합만으로 손실을 판단하지 않는다.
