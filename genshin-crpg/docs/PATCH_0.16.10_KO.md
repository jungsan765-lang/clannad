# 0.16.10 · 가로 휴대폰의 여정 준비 카드 수정

기준 게시 소스: 0.16.9 `eff71f71bde2430e96ad6f10148bcbec44c491e4`.

사용자 첨부의 왼쪽 준비 카드에서 글자가 한 글자씩 세로로 내려가고 버튼이 겹치는 부분만 수정했다.

## 원인과 이전 담당의 의도

0.16.4는 왼쪽 칸을 좁히고 지도를 넓혔다. 0.16.7은 그 안의 메인 임무를 짧게 두고 아래 시설·활동 탭에는 기존 쪽 넘기기를 사용했다. `PATCH_0.16.4_KO.md`, `PATCH_0.16.7_KO.md`, `app_mainscreen_v0167.js`와 실제 여정 카드 생성 함수를 확인했다.

가로 폰의 `.main-objective`가 기본 가로 flex로 바뀐 상태에서 `app_journey.js`의 준비 문단·다음 장소·이동 버튼·이야기 버튼·하단 설명이 모두 남았다. 이들이 150~170px 안에서 서로 폭을 나눠 써 글자가 세로로 길어졌고 아래 탭을 밀어냈다.

## 수정 범위

실제 표시 변경은 `source/landscape_v01524.css`의 기존 가로 휴대폰 media 안에 추가한 규칙 5개다. 모두 `.shell-loc-left .journey-objective`에만 적용된다.

- 목적지와 기존 행동 버튼을 위아래로 놓고 버튼을 줄어들지 않게 했다.
- 목적지 줄이 있으면 반복 준비 안내와 다음 장소 줄을 중복 표시하지 않는다. 도착해 이동 버튼이 없을 때는 기존 다음 장소 줄을 남긴다.
- 마지막 공통 활동 안내만 접는다. 경로가 잠긴 이유와 `.choice-note` 안내는 유지한다.
- DOM과 행동 버튼·인자·비활성 판정은 수정하지 않았다. 이야기 화면에서는 전체 안내가 그대로 나온다.

지도 크기·왼쪽 폭·탭·시설 타일·다른 메인 임무 카드·고정 의뢰·현장 목표·전투·밸런스는 변경하지 않았다. media 밖의 데스크톱·세로 화면 규칙도 변경하지 않았다.

## 검사

- 기존 `tests/test_v0167.cjs`: 10/10 통과. 임무·저장·기존 메인 화면/캐릭터/전투 UI 계약과 이전 판 기록을 확인한다. 실제 픽셀 배치 검사는 아니다.
- `tests/test_update_recovery.cjs`: 통과.
- `tests/test_engine_identity.py`: 통과. UI 전용 변경의 규칙 호환성을 확인했다.
- 0.16.10 서버 빌드: 통과(기존 런타임119개). 실제 설치는 실행하지 않았다.
- 소스 변경 대조: `source/`에서 바뀐 파일은 `landscape_v01524.css` 하나이고, 추가한 5규칙은 기존 가로 media 안의 여정 카드만 대상으로 한다. 기존 CSS는 삭제·수정하지 않았다.
- 760×352·640×320 등의 실제 여정 함수/폰트/쪽 넘기기 비교 fixture를 준비했으나, 로컬 Chromium 다운로드 실패와 클라우드 브라우저의 로컬 페이지 접근 제한으로 브라우저 실행은 완료하지 못했다. 실제 폰·브라우저의 폭/높이·탭 접근을 통과했다고 기록하지 않는다.

설치 후에는 첨부와 같은 이동+이야기 버튼 두 개 상태, 도착 뒤 이야기 버튼 하나 상태, 잠긴 경로의 이유, 아래 시설 탭을 휴대폰 가로에서 확인한다. 전체 화면 개편이나 다른 임무 카드의 문구 숨김으로 해결하지 않는다.

## 이어 받을 때

0.16.10의 여정 카드 CSS만 이번 좁은 예외다. 전체 메인 화면의 `.main-objective` 문구를 숨기거나 폭을 다시 바꾸지 않는다. 고정 의뢰와 현장 목표에는 필수 진행 안내가 있다.

적용은 이전 판과 같은 SHA 고정 설치·승격 도구를 사용한다. 최종 답변과 PR20의 0.16.10 커밋으로 설치하고, 실제 서버 설치 여부는 소스 게시와 구분한다. 운영 설치와 main 병합은 이번 작업에서 실행하지 않는다.
