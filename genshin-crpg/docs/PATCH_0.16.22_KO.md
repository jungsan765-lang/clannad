## 후반 방어와 치유

새 일반 전투에서 적이 아군에게 주는 직접 피해의 방어 계산은 `K / (K + 실제 DEF)`, `K = 100 + 5 × max(0, 적 레벨 − 35)`다. 적Lv35 이하의 K100은 기존과 같고 적Lv60은 K225다. 성장 보정 이후 `combatStat(DEF)`를 사용하는 기존 경로를 유지한다.

이 계산은 이야기·필드·보스·나선·비경의 공유 피해 경로에 적용된다. 장비의 DEF 숫자와 노엘의 DEF 기반 공격·보호막·회복량은 유지한다. 아군이 적을 때리는 방어 계산과 반응의 별도 고정 피해도 유지한다. 새 전투에는 `defenseRevision: 1`을 저장하며 이 표시가 없는 진행 중 전투는 기존K100으로 끝낸다.

기지를 지키는 `PROTECT_FORMATION` 목표 전투는 새 표시가 있어도 K100이다. 오셀처럼 별도의 기지 내구도와 공격 회수가 정해진 전투에 일반 후반 보정을 겹치면 기존 피해 예산까지 바뀌었다. 이 목표에만 기존 예산을 보존하며 기지 내구도·패턴·적 구성·보상은 새로 바꾸지 않는다.

한운은 즉시 회복 `ATK×0.03+1,250 → ATK×0.03+850`, 지속 회복 `ATK×0.08+600 → ATK×0.08+400`으로 조정한다. 대상·비율 계수·발동 제한을 유지한다. 회복 버전이 없는 옛 전투에서는 이후 사용하는 기술도1,250/600을 쓰며 이미 저장된600도 유지한다.

진은 영역 생성 때 비율과 고정량을 저장하고 그 값으로 회복하도록 보강했다. 수치가 없는 옛 집중 영역은 기존 `ATK×0.03+60`, 더 오래된 전원 영역은 전원 `ATK×0.35`로 끝낸다. 음식 회복량·조리비·숙박 단가·모라 수입은 이번에 추가 변경하지 않았다.
