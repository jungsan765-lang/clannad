# 0.16.5 · 전투 이펙트를 빛과 입자로 다시 그림

> ⛔ ChatGPT는 이 판의 UI·비경·성장 구조를 고치지 않는다(`genshin-crpg/AGENTS.md`). **드롭다운(`<select>`) 절대 금지.**

기준 소스는 0.16.4(`de921d0`)다.

사용자 지시(2026-10-07): 「일단 하던거 하고 나중에 전투 이펙트도 좀... 전체적으로 퀄이 낮아서... 외부 에셋을 쓰던지 뭐 어떻게든 해봐...」

## 무엇을 바꿨나

- 예전 연출은 페이지 조각(CSS로 그린 원 · 줄 · 점)이었다. 이제 전투 위에 캔버스 한 장(`app_vfx_v0165.js`)을 깔고 빛을 더하는 방식(가산 합성)으로 그린다.
- 그림은 파일이 게임 시작 때 직접 그린다. 부드러운 빛, 줄 불꽃, 얼음 조각, 불꽃 혀, 물방울, 잎, 바위 조각, 별빛, 연기, 육각형이다. **내려받는 그림은 없다.** 외부 그림 묶음(무료 CC0 등)을 쓰려면 파일 · 출처 · 크기를 먼저 묻는다.
- 원소마다 입자가 다르다.

| 원소 | 모습 |
|---|---|
| 불 | 불티가 튀어 오르고, 가운데서 불꽃 혀가 솟고, 검은 연기 |
| 물 | 물방울이 튀었다 떨어지고, 빛 방울 |
| 얼음 | 얼음 조각이 돌며 터지고, 눈이 내림 |
| 번개 | 갈라지는 번개 줄기, 튀는 불꽃, 작은 전기 |
| 바람 | 혜성 같은 바람 팔이 돌며 좁혀 들고, 잎이 휘말림 |
| 바위 | 바위 조각이 튀었다 떨어지고, 금빛 별, 육각형 빛 |
| 풀 | 잎과 빛 알갱이 |

- 충격파는 그린 원이 아니라 빠르게 퍼지며 옅어지는 빛의 띠다.

## 어디에 쓰나

- 기술 연출(`app_skill_fx_v0162.js`): 섬광 · 충격파 · 입자 · 줄기 · 번개 · 소용돌이 · 빛기둥이 캔버스로 간다. 떨어지는 것(별, 검, 우박 등)은 꼬리 빛이 붙는다. 불꽃 · 돌풍 · 할퀴기 · 얼음 베기도 빛으로 그린다. 원소폭발이 적을 맞히면 그 줄이 한 번 흔들린다.
- 무기 공격(`app_battle_fx_v01521.js` `LIGHT`):
  - 한손검: 엇갈리는 검광 두 번
  - 양손검: 크게 내려치는 검광, 땅 울림
  - 장병기: 세 번 찌르는 빛줄기, 찌른 쪽으로 튀는 불꽃
  - 활 · 법구: 맞는 자리에서 빛이 터짐
  - 적: 할퀴기 · 둔기 · 내려찍기
- 장비 · 운명의 자리로 강해진 공격의 빛(4★ 보라, 5★ 금색, 잔상, 충격파)은 그대로 커진다.
- 치명타는 금빛 섬광과 불꽃이 튀고, 맞은 쪽 줄이 짧게 흔들린다.
- 원소 반응 11가지(`LIGHT_REACTION`)와 보호막 깨짐도 빛으로 그린다. 과부하 · 쇄빙은 흔들림도 있다.
- 「움직임 줄이기」를 켜면 캔버스를 쓰지 않고 예전 페이지 조각이 그대로 나온다. 전투 속도가 시계이고, 재생의 일시정지가 멈춘다. 재생을 건너뛰면 바로 꺼진다.
- 휴대폰은 입자를 560개, PC는 1,200개까지만 둔다. 화면 밀도는 2배까지만 쓴다.
