# 0.16.50 · 요리에 비경 피로 적어 두기 · 0.16.49 CI 수정

사용자 (2026-10-16): 「피로에 대해서 유저들이 잘 이해할 수 있게끔 요리에 잘 적어두고, 그 다음 비경 도는것에 대해 좀 밸런스를 맞춰보는게 좋아보여.」 이번 판은 앞부분(요리)이다. 비경 밸런스는 다음 판이다.

## 요리 화면 (`source/app_cooking.js`)
- 회복 요리 카드에 「비경 피로」 줄: 「Lv20까지 −N · Lv40까지 −N · Lv41~ −N」(못 풀면 「없음」). 지금 주인공 레벨 칸이 밝다. 마우스를 올리면 「Lv21~40 · 피로를 못 풂 (드문 재료가 더 필요)」 같은 설명.
- 재료 칸: 드문 재료(점수 1·2)에 「드묾」 표시. 마우스를 올리면 왜 드문지.
- 필터 「피로 풀기」: 지금 주인공 레벨에서 피로를 푸는 회복 요리만.
- 효과 줄은 다시 「체력 N 회복 · ○○ 기준」만(피로는 따로 줄).
- 가방·상점 요리 설명 끝에 「비경 피로 Lv20까지 −N · Lv40까지 −N · Lv41~ −N」(`source/app_fatigue_v01648.js`).

## 드문 재료 목록을 고정 (`source/runtime_reading.js` 끝)
- 0.16.49는 드문 재료 점수를 채집표·상점표에서 그때그때 계산했다. 같은 규칙이지만, 화면과 서버가 다른 표(빌드에 따라 다른 조리법 데이터)를 보면 다른 답이 나올 수 있다. 실제로 로컬 화면 검사에서 예전 빌드의 게임 데이터를 읽어 「몬드 감자전」이 0점으로 나왔다(실제 게임 데이터에서는 6점).
- 그래서 점수 1·2인 재료를 엔진에 고정 목록으로 둔다: 사과·일몰 열매·연꽃받침·죽순·절운고추·유리백합·별소라 1점, 송이버섯·금어초·솔방울·과일잼·통통 연꽃·등불꽃·야박석 2점.
- 조리법 재료는 요리가 실제로 쓰는 제작 재료 표(`48_RECIPE_INGREDIENT_DB`)에서 읽는다.
- `tests/test_fatigue_v01648.cjs`가 채집표(갈 수 있는 곳, 한 번 시도에 나오는 평균 개수)와 상점표로 점수를 다시 계산해 목록과 다르면 실패한다.
