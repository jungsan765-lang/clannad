# 0.15.22 검증 기록

## 구분

실제 런타임 전투·로컬 HTTP/SQLite·격리된 Chromium 입력 검사다. 운영 계정이나 VPS의 데이터를 사용하지 않았다. 테스트용 시작 상태와 실제 수행한 버튼 조작을 구분한다.

| 범위 | 수행 내용 | 기록 |

성장 체감 비교: 울프 영지 고정 Lv.17 적은 파티 Lv.10에서 평균 3라운드, Lv.17/30에서 2라운드. 리월 고정 Lv.32 적은 파티 Lv.20에서 5.67, Lv.32에서 3, Lv.50에서 2라운드. 모든 단계에서 적 수치가 동일함을 단언한다. 시험 파티는 준비해 주되 피해 계산·적 행동·승패는 실제 엔진을 사용했다.

여행자 새 여정의 첫 이야기 전투도 별도로 확인했다. 레벨·아이템·능력치를 변경하지 않고 이동→전투 준비→전투 시작→기본 공격/E로 5라운드 승리했다. 이것은 첫 전투 한 건의 확인이며 전체 자연 성장 완주를 뜻하지 않는다.

오셀: Lv.60 준비 파티가 세 난수에서 모두 9라운드 승리, 저레벨 두 조건은 각각 세 번 모두 패배. 증원은 활성 8마리 안에 보관한다. 일반 필드 보스, 드발린·안드리우스, 타르탈리아·야타, 나선비경 12층의 참조 파티 완주는 별도 기존 회귀에 포함된다. 공략 내용은 공개하지 않는다.

이야기 전체 경로 검사는 진행·저장 호환성 검사이며 강한 시험 캐릭터를 사용한다. 자연 플레이의 난도나 서사 품질을 증명하지 않는다. 중간 실패의 대부분은 옛 Lv.20 상한·자동 영입·타이머 채집을 전제로 한 시험 조건이었다. 새로운 소유권·돌파 상한에 맞춰 준비 상태를 고쳤으며, 실제 서버의 중복 보상·변조 거절 단언은 유지한다. 나선비경 결과가 이전 결과로 덮어써지는 실제 정산 오류와 화면 지도 카드 잘림·상태 칩 설명 갱신·옛 효과 예측표의 남은 참조·전투 재생 띠가 전투판 밖으로 나가는 문제도 검사 중 수정했다.

전체 회귀 이후 효과 재생 로그의 시전자 식별 보정에 대해 성장 규칙 16항목과 실제 E 부여 프레임을 다시 통과했다. 배포본의 비밀 파일·운영 파일 제외, 콘텐츠 연결 검사도 각각 7항목을 통과했다. 최종 커밋은 GitHub에서 같은 106개와 온라인 브라우저 4조합을 다시 실행한 후 테스트 묶음으로 게시한다.

## 이번에 확인하지 않은 범위

- 실물 iOS·Android, OS 글자 배율, PWA 설치·가상 키보드·안전영역 전 조합.
- 실제 VPS 장기 세션·활성 사용자 대규모 부하, 장기 파밍·시장 수요의 체감.
- 제작 중인 새 몬드 개인 이야기 10명과 이야기 말투 편집.
- GitHub 묶음 게시와 VPS 설치는 별도 상태다. 이 문서만으로 설치 성공을 뜻하지 않는다.
