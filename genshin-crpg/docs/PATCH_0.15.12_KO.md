## 검사와 증거의 범위

- `test_client_connection_recovery.cjs`: 실제 클라이언트/서비스 워커 소스를 격리한 시간·응답 환경에서 실행한다. 짧은 연결, 무응답, 정상 유지 신호, 숨김/복귀, 초기 조회, 탭 간 묶음 공유, 해시 오류 후 재시도를 확인한다. 실제 통신사망이나 휴대폰 시험은 아니다.
- `test_popup_lifecycle_v01512.cjs`: 실제 팝업 소스에 응답 지연과 순서 역전을 넣어 목표 안내·모험가 창·토벌 목록·오류·로그인 전환을 확인한다. 합성 DOM 검사는 실제 CSS 배치와 구분한다.
- `test_server_coop_recovery_v01512.mjs`: 임시 SQLite 파일과 별도 Node 프로세스를 사용한다. 대기 명령 중 이탈/재가입/방 재생성, 강제 종료 후 새 프로세스의 전투·명령 영수증 복원, 전투 저장 뒤 보상 전 종료, 보상 트랜잭션 실패, 동시 수령과 두 번째 재시작의 중복 지급 방지를 확인한다. 실제 VPS를 종료하거나 플레이어 저장을 조작하지 않는다.
- 기존 `test_online_browser.mjs`에 전투 재생 중 중복 안내 숨김·재생 버튼 표시와 조건 문장 줄바꿈 검증을 추가했다. 기존 소스/배포 UI × 기본/DO 백엔드의 네 CI 경로에서 실행한다.
- 릴리스 검사에 새 스크립트 3개를 추가해 등록 수는 **85개**다. 등록 수는 통과 수가 아니다. 정확한 실행 결과와 게시 커밋은 PR #20 최신 기록을 기준으로 한다.

새 연결 검사 **9개**, 팝업 검사 **9개**, 협동 복구 검사 **6개**가 로컬에서 통과했다. 협동 복구는 실제 프로세스 강제 종료/재기동을 세 차례 포함한다. 기존 연결·설치·팝업·협동 회귀도 관련 변경 범위에서 통과했다. GitHub 전체 회귀와 소스/배포 브라우저 CI 및 게시 결과는 PR에 따로 기록한다.

0.15.11의 기존 CI 증거 8장(1440×1000 Chromium)을 실제 이미지로 확인했다. 전투 중복 안내와 조건 문장의 줄바꿈 문제는 이 사진에서 확인했으며, 수정 전후는 해당 CI의 `combat.png` 및 `relationship-locked.png`로 비교한다. 이 증거가 320px~4K 전수 검사나 물리 클릭 검사를 대신하지 않는다. 0.15.11 증거 묶음 SHA-256은 `660239b820a71434a79487658e91f567e7a88ccf85774f42b173ec5cdbf229f0`이다.

사용자가 올린 `image(2).png`도 다시 읽었다. 작은 이야기 화면의 과거 캡처이며, 사진만으로 설치 버전·전체 뷰포트·스크롤 끝을 확인할 수 없다. 현재 모바일 수정의 통과 근거로 쓰지 않는다.

## 아직 남은 확인

- 직접 브라우저 관찰은 이번에도 자격 증명 보호 오류로 막혔다. 새 수동 조작·폰별 키보드·PWA·안전 영역·전체 해상도 조합 검사는 미완료다.
- 기존 관계 화면 캡처에서 튜토리얼 안내와 일시 알림이 맞닿아 있다. 적절한 위치와 실제 입력을 확인하기 전 임의로 다른 버튼 위로 옮기지 않는다. 전투 피해 숫자가 체력 정보 위에 뜨는 모습도 일시 연출 캡처이므로 지속적인 가림으로 단정하지 않는다.
- 고유 그림 부재, 대사·관계·인과의 장면별 검수, 실제 많은 사용자와 긴 세션의 부하는 이전 실행표의 남은 항목이다.

- 현재 환경에서 기존 VPS SSH 22번 연결은 거부됐다. GitHub 테스트 묶음 게시와 실제 VPS 설치는 구분한다. 운영자의 설치 후 공개 버전·서버 빌드·커밋을 다시 확인한다.
