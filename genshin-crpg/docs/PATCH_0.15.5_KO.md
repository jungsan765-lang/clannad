# 0.15.5 패치 노트 (알파 테스트) — 다인 모드

기준: 0.15.4(`417abe4`)에 다인 모드 브랜치 `crpg/coop-v0153`(`e12eb1d`, 0.15.2 위에서 만든 작업)을 병합했다. 사용자: 「다인모드 구현 시키고」, 「알파 테스터가 다인모드를 들어가서 시험해보고 할거야. 문제 있으면 알려줄게」. 규칙 · 서버 · 화면 · 알려진 한계 · 두 계정 시험 방법은 `docs/COOP_0.15.3_KO.md`에 있다.

## 바뀐 내용
- 다인 모드: 필드 전투(무작위 조우 · 필드 보스(변이 도전 제외) · 지맥의 꽃 · 지역 사건)를 방장과 손님 최대 3명이 함께 싸운다. 손님은 자기 저장의 캐릭터 하나를 데려오고, 자기 차례에 20초 안에 고른다(넘기면 자동). 이기면 손님도 그 전투의 경험치 · 모라 · 재료를 자기 여정에 받는다. 이야기 전투 · 나선비경 · 공동 토벌전 등은 혼자 한다.
- 서버 기능 스위치 `coop`. 테스트 서버(DB 경로에 `live-staging`)는 기본으로 켜진다. 운영(알파) 서버는 환경 파일 `/etc/genshin-crpg-production.env`의 `CRPG_FEATURES`에 `coop`를 더해야 켜진다(`CRPG_FEATURES=chat,trade,coop`). 새 표 `coop_rewards`는 서버가 켜질 때 만든다.

## 병합하며 맞춘 것
- `server/game-core.mjs`: 0.15.4의 공동 토벌전 이벤트(`r.raidServerEvent`)와 다인 모드의 방 정보(`r.coopContext`)를 둘 다 행동마다 넘기고 끝나면 지운다.
- `server/fixed-region-live.mjs`: 0.15.4의 캐시 사본 실행(거절되면 원래 상태로 되돌림)과 다인 모드의 방 정보 전달 · 저장 뒤 알림을 합쳤다. 서버가 켜질 때 `installCoopSchema` 뒤에 0.15.3의 이름 정리(`migrateHeroNames`)를 한다.
- `source/index.html`: `runtime_coop_v0153.js`는 0.15.3 모듈(이른 이야기 · 이야기 흐름 · 시작 장비) 뒤, 런타임 맨 끝이다(다인 모드의 감싸기가 가장 바깥이어야 한다). `app_coop_v0153.js`는 화면 스크립트 맨 끝.
- 시험 2개(`tests/test_coop_v0153.cjs`, `tests/test_server_coop_v0153.mjs`)의 「공동 토벌전은 혼자」 확인은 0.15.4부터 토벌전이 운영자 이벤트이므로, 이벤트를 연 뒤 출격하게 고쳤다.

## 확인
- 전체 확인 `python tools/verify_release.py`.
- 브라우저(로컬 서울 서버, 다인 모드 스위치 켬): 방장은 PC 틀, 손님은 375×812 폰으로 실제로 눌러 봤다.
  - 방장 「공개 모집으로 열기」 → 손님 목록에서 「참여」 → 캐릭터 고르기(하루) → 양쪽 방 화면 갱신.
  - 방장이 몬드 외곽 초원에서 「1시간 기다리기」로 조우 → 손님 폰에 전투 창(「방장이 「전투 시작」을 누르면 시작합니다」) → 「전투 시작」.
  - 손님 차례: 방장 화면 「하루 님의 차례 · 남은 초」, 방장 카드는 이유와 함께 잠김. 손님 폰에서 E 기술 실행(재사용 대기 이유 표시), 다음 차례는 고르지 않아 20초 뒤 자동, Q 기술로 합동 공격.
  - 승리: 손님 결과 「내 여정에 들어온 보상 · 하루 경험치 54 · 36 모라 · 가면 4개」, 손님 모라 40,000 → 40,036. 방장도 자기 보상을 그대로 받음.
  - 손님 「방 나가기」 → 방장 화면 0/3, 방장 「방 닫기」.
  - 공동 토벌전 타일은 이벤트가 없으면 페이몬 메뉴에 나오지 않는다(0.15.4).
