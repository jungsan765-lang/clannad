# 플레이어 이름 표시와 일반명사 보존 감사

2026-10-03, 0.15.14 작업 트리 기준. 승인 원고의 의미·말투·사건은 수정하지 않았다. 검사에서는 실제 Runtime 데이터와 출하 UI 표시 함수를 Node에서 호출했다. 실제 브라우저 화면 확인은 관찰 제한으로 대기 상태다.

## 확인한 범위

`fresh('MAP_MOND_CITY','ROUTE_ISEKAI')` → `installMarketContent()` → `storyIndex()`의 25,619노드에서 본문(row 9)과 선택지(row 10)를 확인했다. 문자열 `주인공`은 9개 행에 각 1회 있다. 8개는 보이는 이야기의 일반명사, 나머지 `TRV_LY2_START` 1개는 META 설명이다. 이 숫자는 데이터 전부에서 등장한 횟수가 아니라 **실제 설치한 스토리 색인의 본문·선택지 열** 기준이다.

`source/`에서는 큰 생성 콘텐츠 파일 두 개를 제외한 JS 43개에 `주인공`이 있고, 그중 app 파일은 16개다. 편성·전투·아이템·레벨 안내에도 사용하는 기존 호칭이다. `tests/test_mond_content_v01344.cjs:19`는 이름에 맞춰 ‘주인공’을 치환하는 기존 계약을 명시적으로 검증한다. 따라서 전역 문자열 치환을 제거하면 정상 기능이 바뀐다.

## NT-01 · 일반명사까지 플레이어 이름으로 바뀜

`source/readable_text.js`의 `named`는 `{PLAYER_NAME}`과 평문 `주인공`을 구별하지 않고 이름으로 바꾼다. `readable`의 이름 보호·조사 보정, `app_journey.js`의 `displayText`, `app_legacy.js`의 `el`까지 같은 텍스트가 여러 번 표시 변환을 거친다. 한 번만 일반명사를 보호해서는 대화 기록이나 다음 변환에서 다시 바뀔 수 있다.

### 승인 후 적용한 제한된 수정

1. `named/readable`에 `literalProtagonist` 표시 옵션을 추가한다. 이 옵션은 평문 `주인공`만 보존하고 명시적 `{PLAYER_NAME}`과 다른 번역·조사 처리는 유지한다. 기본값은 기존 동작이다.
2. 위 8개 노드 ID에서 읽은 **원문 문자열만** 표시 보존 목록에 등록한다. `app_journey.js`의 `bindLiteralStoryText`가 현재 Runtime 색인에서 고정 ID를 조회하며, `displayText` 진입과 `app.js displayHistory` 시작에서 먼저 호출된다. 장면을 먼저 열어 둘 필요가 없다. `readable`은 동일 원문이 대화 기록·DOM 헬퍼로 다시 들어와도 같은 보호 옵션을 적용한다. 문장을 다른 단어로 재작성하거나, ‘책’ 등이 있으면 일반명사라고 추측하지 않는다.
3. 런타임 스토리 내용·DB·세이브·진행 플래그는 바꾸지 않는다. 등록 대상의 8개 노드와 출력 문구만 집중 검사하며 정상 플레이어 호칭은 기존 테스트를 유지한다.

보존 목록은 허용된 8개 ID를 키로 하는 private Map이며, 다른 ID 등록은 거절하고 같은 ID는 값만 교체한다. 크기가 8개를 넘지 않는다. 8개가 모두 등록된 색인은 WeakSet으로 기억해 반복 조회를 피한다. 저장을 불러와 색인 객체가 바뀌면 새 색인의 원문으로 등록한다. 원문 8개에는 이름 placeholder가 없으므로 두 번째 표시 변환에서도 등록한 원문과 동일하게 대조된다.

제품 변경 파일은 `source/readable_text.js`, `source/app_journey.js`, `source/app.js` 세 개다. 표시 동작만 바꾸며 승인 원고·DB·세이브는 변경하지 않았다. `@text` 28개 미반영 문제는 별도 감사 사항으로 남겨 두었고 이번 변경에 포함하지 않았다.

## NT-02 · 이름 뒤 ‘이라고’가 ‘가라고’로 깨짐

실제 첫 인사 `LEG_ISK_MOND_NOELLE_V143_FIRST_01`은 CHOICE이다. 원문 label은 `{PLAYER_NAME}이라고 해`를 포함한다. 기존 파서는 긴 `이라고`를 인식하지 않고 앞의 `이`를 주격 조사로 먼저 처리했다. 모음으로 끝나는 ‘클라나드’에서는 **‘클라나드가라고 해’**가 됐다.

승인된 좁은 수정은 `source/readable_text.js`의 이름 조사 처리와 `source/app_journey.js`의 중복 이름 조사 처리에 `이라고/라고`를 긴 항목으로 먼저 추가하는 것이다. 원문이나 노엘 선택지를 수정하지 않았다. 받침 있는 이름은 ‘수진이라고’, 받침 없는 이름은 ‘민수라고’, ㄹ 받침 이름은 ‘하늘이라고’로 나온다. 현재 색인의 본문·선택지·화자에서 `{PLAYER_NAME}` 뒤의 한국어 접미어를 별도로 추출했고, 해당 `이라고` 용례는 실제 노엘 선택지 1개였다. `입니다` 2개는 원래 정상이며 회귀에서도 보존했다. 새로운 미확인 접미어로 수정을 확장하지 않았다.
