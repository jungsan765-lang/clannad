# 운영자 밸런스 조정 사용법 · 0.16.23

게임 주소 뒤에 `/admin.html`을 붙여 기존 운영자 계정으로 로그인한 뒤 **밸런스**를 누른다. 일반 게임 계정과 운영자 로그인은 별개다.

## 수정 순서

1. `적·보스`, `적 편성`, `캐릭터`, `기술`, `육성·비경` 등에서 수정할 종류를 고른다.
2. 이름으로 검색하고 항목을 누른 뒤 숫자를 입력한다. 여러 항목을 수정해도 초안은 유지된다.
3. **미리보기**에서 현재 값과 바뀔 값을 확인한다. 확인 뒤 다시 숫자를 바꾸면 적용 버튼이 잠기므로 다시 미리본다.
4. 필요하면 변경 메모를 적고 **확인한 변경 적용**을 누른다.
5. 결과가 마음에 들지 않으면 아래 **변경 기록 → 이 저장 선택**에서 차이를 확인한 뒤 **이 저장으로 복구**한다.

숫자 칸을 비우면 코드의 기본값으로 돌아간다. **이 항목 기본값 사용**은 해당 항목의 수정만 지운다. 이력 복구는 선택한 저장 전체를 복구하며 새 저장 번호로 기록된다. JSON 내보내기·가져오기도 지원한다. 가져오기는 미리보기까지 수행하며 자동 적용하지 않는다.

## 조절 가능한 값

| 종류 | 지원하는 수치 |
|---|---|
| 적·보스 | 레벨, 최종 최대 HP·공격력·방어력·속도·명중·회피·상태 저항 |
| 적 편성 | 기존 편성의 적 종류, 종류별 최소·최대 인원. 최대 합계 8마리 |
| 캐릭터 | 주인공과 동료별 최대 HP·공격력·방어력 배율 |
| 기술 | 실제로 연결된 기술의 직접 피해·회복·보호막 배율 |
| 육성·비경 | 기존 성장 비경 단계별 재료 수량·경험치, 돌파 단계별 공통 보석 요구, 몬드·리월 특성 단계별 수련서 요구 |
| 아이템 | 이름, 기본 회복량, 표에 있는 매입·판매 가격 |
| 장비 | 이름, 기본 공격력·방어력·HP, 치명타 수치, 필요 레벨, 속도·명중·회피·저항 보정, 판매가 |
| 요리·제작 | 기존 조리법의 결과 수량·제작 모라, 재료별 필요 수량 |
| 상점 | 기존 상품 표시명·가격·재고 |
| 공통 배율 | 숙박·제작·돌파·특성의 모라 비용, 전투 경험치·모라 보상 |

배율 `1`은 기존 값이다. `0.8`은 80%, `1.2`는 120%다. 음식의 기본 회복량에는 실제 사용 대상의 레벨 보정과 기존 식사 제한이 추가로 적용된다. 돌파 보석은 주인공·4성의 공통 요구를 편집하며 5성은 기존 2배를 유지한다. 비경 재료는 기존 일일 추가 보상 배율을 그대로 적용한다.

적의 회색 기준값은 표시된 기준 레벨의 참고값이다. 레벨만 바꾸고 HP·공격력 칸을 비우면 기존 성장식이 새 입장 레벨에 맞춰 계산한다. 입력한 적 수치는 동일 몬스터 ID를 쓰는 전투에 공통 적용되므로 이야기와 재도전에서 같은 몬스터를 사용하면 양쪽에 영향을 준다.

## 적용 시점과 기존 진행

- **진행 중 전투는 시작 당시 설정으로 끝낸다.** 기술·회복·보상까지 같은 설정을 유지하며 다음 전투부터 새 설정을 쓴다. 이 도구가 생기기 전 전투는 기본 설정 0번을 쓴다.
- 전투 밖 구매·제작은 현재 설정으로 계산한다. 예전 화면의 견적이면 서버가 거부하고 최신 값을 받는다. 이미 결제한 요청의 재전송은 중복 결제하지 않는다.
- 최대 HP를 늘려도 현재 HP를 무료로 채우지 않는다. 줄일 때는 새 최대치까지만 제한한다. 완료한 돌파·특성, 보유 재고와 과거 영수증은 소급 차감하지 않는다.
- 다른 운영자가 먼저 적용했다면 내 초안은 남는다. 최신 설정을 읽고 차이를 다시 확인한 뒤 적용한다.
- 테스트 서버와 본서버 설정은 각 서버의 DB에 저장된다. 코드 승격만으로 테스트 서버에서 입력한 숫자가 본서버에 자동 복사되지는 않는다. 원하는 설정은 JSON으로 옮겨 미리보고 적용한다.

## 이번 도구의 경계

편집 화면에 나오는 수치만 실제 지원한다. 보스 공격 패턴·원소 반응 규칙·운명의 자리 동작·장비의 특수 효과·시장 수수료·입장 제한·레벨업 필요 경험치 곡선은 코드 규칙이다. 이 화면에서 임의 코드나 새 항목을 만들어 바꾸는 기능은 없다. 성장 비경이 입장 때 만드는 동적 적 편성도 현재의 **적 편성** 목록과 별개다.

숫자를 바꾸면 승리 시간뿐 아니라 음식·숙박 소모, 보스 재료, 강화와 육성 비용도 달라진다. 변경 기록의 메모에 대상 편성·레벨·장비 조건을 적어 두고 실제 전투와 수급을 함께 비교한다. 도구 구현 완료를 전체 공략 밸런스 달성으로 해석하지 않는다.
