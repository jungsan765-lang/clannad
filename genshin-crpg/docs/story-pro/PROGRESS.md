## 검증의 범위와 한계

Node 문법 검사 통과. 첨부 원문 및 읽은 소스에 맞춰 재구성한 작은 검사 자료에서 연결·옛 저장 지점 재개·출구 보존·중복 설치·타 루트 불변·표시 문구 검사 47개 통과. 저장된 소스의 Git blob SHA는 로컬 검증 파일과 일치한다. 이것은 전체 실제 게임 플레이/브라우저/서비스 배포 검사가 아니다. 해당 변경은 런타임 해시에 영향을 주므로 같은 engineVersion의 서버와 클라이언트가 필요하다.

의존성은 바꾸지 않았다. package-lock.json의 루트 버전 메타데이터는 0.14.5로 남아 있다. 전체 빌드 검증 때 npm install --package-lock-only --ignore-scripts로 해당 메타데이터만 갱신하고 의존성 변경이 없는지 확인할 것.
