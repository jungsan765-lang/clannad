## 완료 범위

001.01의 서술 여섯 곳과 각청의 응답 한 곳을 수정했다. 본문은 1,895자, 대사/서술 22개다. 최초 001.01에서 유지한 기존 8개 진행 지점, 옛 단일 선택 3개, 추가 14개 지점과 다음 선택 연결은 그대로다. 이번 개정에서 새 진행 지점은 추가하지 않았다. 001.02 이후와 개인 이야기·호감도 집필은 진행하지 않았다.

각청이 현장을 직접 확인하고, 병사에게 일을 맡기고, 주인공의 말을 기다리며 걸음을 맞추는 행동을 중심으로 바꾸었다. 짐꾼의 생사, 제군의 몸을 옮긴 주체, 기억이 사라진 원인을 확정하지 않았다. 실제 주인공 발화는 닉네임을 유지한다. 이야기 인덱스의 NARRATION은 화자 표시 이름만 ‘이야기’로 통일하며, 다른 구간의 본문이나 실제 캐릭터 대사 이름은 바꾸지 않았다.

## 이어받을 사용자 정정

‘나’라는 말 자체를 금지하는 것이 아니다. ‘나는 느꼈다/나는 생각했다/나는 깨달았다’를 반복하며 모든 장면을 주인공의 자기 설명으로 만들지 않는다. 시점은 주인공에게 두되, 함께 있는 캐릭터가 무엇을 보고 어떻게 움직이고 판단하며 주인공을 대하는지에 초점을 둔다. 필요한 ‘내가/나에게’와 실제 주인공 발화는 남긴다. 서술의 표시 이름은 ‘이야기’다. 캐릭터의 식사·취향·생활은 해당 상황에 맞게 드러내며, 긴박한 사건 현장에 억지로 끼워 넣지 않는다. 이 원칙을 각청 한 장면에만 한정하지 않는다.

## 검증의 범위와 한계

Node 문법 검사와 재구성한 작은 장면 자료의 연결·기존 지점 재개·출구 보존·중복 설치 방지·서술 이름·실제 발화 이름·개발 용어 노출 검사를 실행하여 51개 통과했다. 저장된 소스 및 검사 파일의 Git blob SHA는 로컬에서 검사한 파일과 일치한다. 실제 전체 이야기 인덱스, 브라우저 화면, 온라인 서비스 배포의 검증은 아니다. 이번 원고는 CRPG 창작이며 공식 대사의 인용이 아니다. 신규 원작 사실이나 음식 취향을 추가하지 않았고, 이번에 공식 한국어 음성 대조를 완료했다고 보고하지 않는다.

원고 본문, scene_001_01.json, 소스의 SCENE 텍스트가 일치한다. 사람용 원고의 ‘플레이어 닉네임’은 소스에서 기존 {PLAYER_NAME} 치환을 사용하며 이 문자열 자체를 게임에 표시하려는 변경이 아니다.

의존성은 변경하지 않았다. package-lock.json의 루트 버전 메타데이터 0.14.5는 이전부터 남은 미완료 항목이다. 전체 빌드 검증 때 버전 메타데이터만 갱신하고 의존성 차이가 없는지 확인할 것.

## 배포 상태

테스트서버 배포는 이전 작업에서 미완료인 상태를 유지한다. 이번 요청은 현재 원고와 화자 표시 수정이며, 배포 구조를 다시 분석하거나 수정하지 않았다. main·자동배포 감시 브랜치·운영·DNS·DB는 변경하지 않았다. 기존 자동배포의 운영 활성화 호출 문제와 이 작업 브랜치의 test-package 조건 미충족은 별도 배포 담당자가 해결할 항목이다. PR 수정이나 0.14.6 표기를 테스트 사이트 적용 완료로 보고하지 말 것.
