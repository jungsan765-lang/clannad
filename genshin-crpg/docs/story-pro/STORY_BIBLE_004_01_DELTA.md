# 004.01 이야기 기준 변경분
기존 STORY_BIBLE.md를 대체하지 않고 함께 읽는다. 핵심 세계 사건·기척의 원인·기억상실 원인·범인·생사 상태를 새로 확정하지 않았다.

K1의 자기 신고와 K2의 짐 목격은 기존 방향을 유지한다. 차이는 ‘누구를 믿을 것인가’의 정답 문제가 아니라 지금 어떤 정보를 꺼내고 어떤 확인에 참여하는가다. K1의 개인 경고가 K2의 각청에게 공유되어서는 안 된다. K2의 현장 확인을 K1에서 했다고 소급하지 않는다.

새 일반 선택은 질문의 방식과 즉시 응답을 바꾸며 호감도 수치·장기 선택 기억·보상을 새로 추가하지 않는다. 확인한 정보가 같아도 관찰한 행동은 선택마다 다르다. 004.01의 한 경로에는 일반 선택 두 번과 기존 방향 선택 한 번이 포함된다. 실제 게임 연결은 미구현이다.
