## 아직 직접 읽지 못한 제어 연결
content/db.json은 파일 크기로 본문을 확보하지 못했다. 001~003, 012~017과 해당 FIELD_GATE/이동/시간 경과가 어떻게 이어지는지는 실제 인덱스로 확인해야 한다. 이번 초고를 001 앞에 임의 삽입하거나 011 다음을 018로 직결하지 않는다. 전후의 효과·이동·보상·기존 저장 지점은 별도로 보존한다. 필요한 경우 first-day 도입의 이전 대사와 이번 시작을 맞추는 짧은 편집만 추가한다.

## 새 선택
SCENE_005_01.json의 한 선택 묶음은 LOCAL_DIALOGUE다. ‘내가 일을 늦췄는지’ / ‘같은 설명을 다시 해야 하는지’가 각기 다른 응답을 받고 같은 K2 종료 상태에 합류한다. JSON 키나 작업번호는 게임 노드 ID가 아니다. 아직 실제 ID를 발급하거나 게임 실행기에 연결하지 않았다.

새 route flag, 보상, 호감도 수치, 신분·영입·사망 변화 없음. 선택 문구가 플레이어 발화이며 같은 문구를 직후 다시 읽히지 않는다. 기존 묶음 대화 읽기와 저장 경계를 사용한다. 일반 대화 선택마다 새 서버 왕복을 만들지 않는다.

## 진입·출구
진입: 1장의 K2 확인과 대기 접수를 마친 뒤, 2장 첫날 저녁. 소의 경고는 각청에게 전달하지 않은 상태. 항구는 계속 봉쇄되어 있고 도시 안의 시설 이용 허가는 없다.
출구: 인계 문제 미해결. 반복 검수 방지와 병사에게 알린 뒤 일시 이석이 가능하다고 안내받음. 실제 이동·숙박·회복·하루 경과·다음날 재회는 아직 실행하지 않음. 다음은 005.02에서 첫날 마무리와 이튿날 연결을 확인한다.
