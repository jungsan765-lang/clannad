# 현재 집필 맥락 — 002.01-r2 종료

다음 집필: 002.02. 아직 시작하지 않았다. 001.01-r3는 시간상 뒤의 리월 사건 시범 원고다.

진이 가방끈을 손봐 주고 도착 소식을 부탁한다. 주인공이 죽어 있던 드발린을 떠올리며 기록을 부탁하자, 진은 죽음과 귀환 둘 다 남기고 필요하면 증언하겠다고 한다. 진은 자기 업무로 돌아간다. 구슬 미소지는 유지하지만 여기서 다시 설명하지 않는다. 편지는 서사상 약속이며 실제 발송·보상이 발생하지 않는다.

현재 기본본과 호감도 60점 이상 친밀한 본문이 있다. 인명 표시는 ‘진’, 주인공의 직접 호칭은 ‘진 단장’. 60점은 작업판 설계값이다. 관계가 달라도 새 사건을 추가하거나 원래 약속을 바꾸지 않는다. 양쪽 원고는 WORK_002_01.md와 WORK_002_01_FAMILIAR.md다.

최신 기준은 EDITORIAL_RULES.md의 03:45 정정까지 읽는다. 말투 전환은 허용되며, 분량은 사용자가 승인한 몬드 초반의 읽기 호흡을 기준으로 한다. 평소는 캐릭터 중심, 큰 충격은 주인공 중심이지만 이 원칙을 장문의 내면 해설로 오해하지 않는다.

다음에는 ISK_L01_K_016~021과 직접 연결된 이동·현장 대사를 읽는다. 진의 리월 자동 동행이나 개인 이야기 완료를 가정하지 않는다. 전체 기존 존비어·분량 및 실제 브라우저 검증은 미완료다.
