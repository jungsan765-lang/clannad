# 진 — 말투 작업 기준

원작의 특정 호감도에서 전체 음성이 일괄 바뀐다는 규칙은 확인하지 못했다. 이전 확인 기록의 한국어 음성 전사 후보는 https://genshin-impact.fandom.com/wiki/Jean/Voice-Overs/Korean 이며, 원본 한국어 음성과의 교차 대조는 미완료다. 이번 말투 분기는 원작 규칙을 재현했다고 주장하는 것이 아니라 사용자가 허용한 프로젝트용 각색이다.

002.01에서 직접 호칭은 ‘진 단장’, 화자 이름은 ‘진’. 기본본은 존댓말, 진의 기존 호감도 값이 60점 이상이면 친밀한 본문을 선택한다. 원작 수치나 사용자 지정 문턱이 아닌 작업판 설계값이다. 친밀한 말투에도 같은 기록·증언·편지 약속만 있고, 연인 관계나 새 과거사를 가정하지 않는다.

공식 한국어 명칭의 새 확인이나 새로운 공식 설정은 추가하지 않았다. 다른 인물에게 하는 말까지 반말로 일괄 치환하지 않는다. 진이 먼저 필요한 행동을 안내하고 주인공은 짧게 답한다. 중요한 기억에서는 주인공의 부탁과 진의 대답으로 이어가며 장문의 내면 설명을 반복하지 않는다.
