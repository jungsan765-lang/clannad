## 검증

구문 검사 통과. 재구성한 작은 자료에서 002.01 설치기 검증 67개 및 기존 001.01-r2 검사 51개 통과. 텍스트 일치, 원고 순서, 이름표, 기존 연결/조건/효과 보존, 옛 선택 표시, 중복 설치, 오류 시 부분 변경 방지, 타 경로 불변을 검사했다.

이는 전체 실제 게임 인덱스 검증이 아니다. 기준 content/db.json 본문을 도구가 반환하지 못했으며, archive는 원문 참고 자료다. 실제 실행 인덱스에서 모든 대상 ID가 남아 있는지, 표시 문구의 다른 덮어쓰기가 없는지, 앞뒤 실제 이동·화면 연결이 맞는지는 전체 빌드/브라우저 검증이 필요하다. strict 검증은 대상 종류/임무가 달라졌을 때 적용을 중단한다. 테스트서버에 배포하기 전 이 검증을 통과해야 한다. 검사를 수행했다는 수치로 서사 품질이나 서비스 배포를 증명하지 않는다.
