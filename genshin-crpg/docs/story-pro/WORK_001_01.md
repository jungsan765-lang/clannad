# 001.01 · 돌아온 자리 — 개정 4

의례장 복귀 → 시신의 부재 확인 → 짐꾼 수색 지시. 기존 CRPG 설정을 바탕으로 다시 쓴 창작 장면이다. 서술 표시는 ‘이야기’, 실제 주인공 발화는 플레이어 닉네임을 사용한다.

---

**이야기**  
짐꾼도, 모락스의 거대한 몸도 보이지 않았다. 빈자리를 보자 숨이 턱 막혔다.

**플레이어 닉네임**  
“시신까지 없어졌어. 분명히 저기에 있었는데…… 누가 옮긴 거야?”

**현장 병사**  
“옮기라는 명령도, 인계받은 곳도 찾지 못했습니다. 여기 남은 사람들도 본 적이 없다고 합니다.”

**각청**  
“남아 있는 사람들만 물어본 거야? 그날 일하고 돌아간 사람들도 찾아봐.”

**현장 병사**  
“아직 확인 중입니다. 알아내는 대로 보고드리겠습니다.”

**플레이어 닉네임**  
“그 짐꾼도 없어. 부두에 짐만 남아 있고.”

**이야기**  
짐꾼을 끌어안았던 팔이 떨렸다. 각청이 병사에게 잠시 기다리라는 손짓을 했다.

**플레이어 닉네임**  
“내가 여기 두고 갔어. 조금만 더 끌었으면 됐을지도 모르는데.”

**각청**  
“그건 아직 모르는 일이잖아. 어디까지 옮겼는지 보여 줘. 거기서부터 찾아보자.”

**플레이어 닉네임**  
“여기. 돌아오면 같이 짐을 확인하기로 했는데.”

**이야기**  
발치를 가리키자 각청이 몸을 낮춰 살폈다. 끌고 왔다는 방향까지 확인하고 병사를 불렀다.

**각청**  
“부두의 검수 병사에게 사람을 보내. 맡겨 둔 짐으로 신원을 알아보고, 함께 일한 사람들도 찾아. 부상자를 옮긴 곳도 확인해 줘.”

**플레이어 닉네임**  
“이름도 못 들었어. 얼굴은 알아보는데.”

**각청**  
“그럼 넌 얼굴을 확인해 줘. 이름은 검수 병사에게 물어보면 되잖아. 찾을 방법이 없는 건 아니야.”

**이야기**  
병사를 보낸 각청은 내 곁에 남아 다음 말을 기다렸다.

**플레이어 닉네임**  
“내 말이 맞는지도 모르잖아.”

**각청**  
“그러니까 확인하는 거야. 기억나지 않는다고 네가 틀렸다고 할 순 없지. 사람이 사라졌다는 말을 듣고 그냥 넘길 수도 없고.”

**플레이어 닉네임**  
“찾으면 알려 줘. 다쳤으면 내가 가 볼게.”

**각청**  
“알았어. 소식이 오면 바로 알려 줄게. 그때까지는 내 옆에 있어. 지금 혼자 뛰어다닐 상태는 아니잖아.”

**이야기**  
각청은 보폭을 늦춰 걸음을 맞추고, 남은 병사에게 의례장 밖을 가리켰다.

**각청**  
“제군의 몸을 옮긴 흔적도 찾아봐. 큰 짐을 실은 수레가 나갈 만한 길부터. 그쪽은 네가 맡아 줘.”

**이야기**  
각청이 짚은 길을 보다가, 내가 알던 이야기에서 제군의 몸을 옮겨 두었던 곳이 떠올랐다.

## 작가용 메모 — 게임에 표시하지 않음

작업 범위는 ISK_L03_K2_019~026과 이전 개정에서 그 사이에 넣은 V146_M00101_001~014다. 001.01-r3의 표시 본문만 다시 작성하며 22개 표시 단위와 다음 선택 연결은 유지했다. 각청의 수색 지시, 주인공의 목격·죄책감, 짐꾼의 신원·생사 미확인, 제군의 몸을 옮긴 주체 미확인을 보존한다. 수색 결과가 이미 나왔거나 주인공의 주장이 사실로 입증되었다고 쓰지 않는다.

첫 충격과 죄책감은 주인공의 목격·짧은 반응으로, 이후의 진행은 각청의 질문·현장 확인·역할 배분으로 보여 준다. 한 화면의 문장을 쪼개 새 클릭 수를 늘리지 않는다. 실제 ‘내가/내’ 지칭은 남기고 기획 용어는 본문에 넣지 않는다.

각청에게 새 호감도 문턱이나 존댓말 전환을 만들지 않았다. 기존 장면의 상대별 말투를 유지한다. 이미 승인된 002.01-r2의 기본/친밀한 대사, 진 단장 호칭, 호감도 읽기 전용 분기는 바꾸지 않는다.

다음 연결은 기존 G_ISK_L03_K2_027 선택 그룹이다. 그 안의 두 접근과 이후 황금옥 경고·선인 도착은 이번에 다시 쓰지 않았다. 정규 다음 집필은 002.02이며 001.02는 관리번호 6의 미완료 연결로 유지한다.

검증은 첨부 인수인계 소스와 현재 작업 브랜치의 Git blob 일치 확인, 실제 Node 구문·국소 연결 검사, 기존 말투 분기 회귀 검사에 한정한다. 전체 게임·브라우저·온라인 배포 확인이 아니다. 공식 한국어 페이지는 본문을 반환하지 않아 공식 음성 대조는 완료하지 못했다. 한국어 전사 보조 자료는 따로 기록하되 공식 검증 완료로 간주하지 않는다.
