# 007.01 — 머리색 묘사 정정

2026-10-01 17:23 (한국 시각). 사용자 질문: “타르탈리아가 붉은 머리야?”

수정 전: 타르탈리아... 붉은 머리요. 무너지기 전엔 바로 앞에 있었는데...
수정 후: 타르탈리아... 주황빛 갈색 머리요. 무너지기 전엔 바로 앞에 있었는데...

이미지 검색에서 확인한 캐릭터 일러스트의 머리색은 주황빛이 도는 갈색으로 보였다. 단순한 ‘붉은 머리’가 선명한 적색을 연상시킬 수 있어 보다 구체적인 묘사로 정정한다. ‘주황빛 갈색’은 시각 관찰에 따른 한국어 묘사이며 공식 대사의 직접 인용이나 공식 색상 규격으로 검증한 명칭이 아니다.

확인한 이미지 출처:
- https://wikiwiki.jp/genshinwiki/%E3%82%BF%E3%83%AB%E3%82%BF%E3%83%AA%E3%83%A4 — 캐릭터 일러스트 재게시. 공식 운영 사이트가 아닌 외부 위키다.
- https://www.hoyolab.com/article/31277458 — 이미지 검색에서 확인한 생일 그림 재게시. 해당 게시자의 공식 계정 여부는 확인하지 않았으므로 공식 게시물이라고 주장하지 않는다.

공식 캐릭터 페이지는 동적 본문을 반환하지 않았다. 이번에는 위 이미지들을 시각 비교했으며 최신 모든 의상이나 게임 대사를 전수 대조했다고 보고하지 않는다.

원고와 구조화 본문의 해당 발화 한 곳만 정정한다. 이전 서사·선택·감정·배포 관련 교정은 유지한다. 기존 원고 표현도 외형의 공식 근거로 자동 인정하지 않는다. 다음 작업 번호는 그대로 007.02이며 이번에 진행하지 않는다.

게임 소스·세이브·서버·운영·main은 변경하지 않는다. 이번 수정은 0.14.6 작업 브랜치의 집필 자료에 한정하며 게임 적용 완료가 아니다.
