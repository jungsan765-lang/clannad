## 위험과 검사

선택마다 해당 응답만 읽고 같은 경로 안에서 합류한다. 선택 문구를 별도 주인공 발화로 중복 출력하지 않는다. 원고의 편집용 K1/K2·합류 제목·JSON 키는 플레이어 본문에 노출하지 않는다. NARRATION 화자는 이야기, 실제 플레이어 발화와 선택은 기존 닉네임 치환을 사용한다. 본문에 {PLAYER_NAME} 자리표시자를 문자 그대로 띄우지 않는다.

신규 대화 선택에는 추가 보상·벌점·호감도·자동 저장 왕복을 붙이지 않는다. 기존 묶음 읽기와 저장 경계를 유지할 것. 새로 시작/선택 직전 재개/각 선택 직후 재개/기존 커서 재개를 별도로 검증한다. K2의 대사·각청의 후속 반응에 소의 경고가 새지 않는지, K1이 아직 하지 않은 짐 조사를 완료했다고 말하지 않는지 확인한다.

본 작업에서 기존 게임 소스·세이브·서버·배포 설정은 변경하지 않았다. 원고 구조 검사 8개 조합을 게임 회귀 검사라고 부르지 않는다.
