# 0.15.13 후속 UI 경계 검토

대상: `5e05a75bdb2538636f3d2004bba0c41942db91c8`. 이 문서는 개발용 검사 기록이며 게임 배포물이 아니다.

## 이번에 확인한 범위

직전 최종 CI의 1440×1000 Chromium 캡처 8장을 검토한 뒤, 이번 요청에서는 남은 가림 후보의 실제 DOM 조립 코드와 CSS 스크롤 경계를 추적했다. 새로운 해상도에서 브라우저를 실행했다는 뜻은 아니다.

| 항목 | 근거와 판단 | 남은 확인 |
|---|---|---|
| 관계 화면 마지막 유대 행 | `app_shell.js`의 `layoutMenu`가 본문을 `.shell-page-body`에 옮기고 `RELATIONS`가 `.relations-body`를 붙인다. `shell.css`의 본문은 `flex:1;min-height:0;overflow:auto`다. 캡처 아래에서 마지막 행이 잘린 것만으로 접근 불능을 확정할 수 없다. | 실제 끝까지 스크롤·Tab 이동 후 마지막 행 조작 |
| 모바일 관계 본문 | 760px 이하에서 `.panel.shell-page` 자체가 세로 스크롤을 맡고, 본문의 `flex:0 0 auto;min-height:auto;overflow:visible`과 자식의 `flex-shrink:0`로 본문 높이를 유지한다. 기존 인물 앵커 복원 검사는 이 구조의 상태 전달만 검사했다. | 작은 높이·큰 글자·가상 키보드에서 실제 넘침과 초점 이동 |
| 생활 행동의 마지막 시작 버튼 | `layoutLocation`은 생활 패널을 `todo`로 분류해 PC 탭 본문 또는 모바일 주변 탭으로 옮긴다. 해당 영역에 내부 스크롤이 존재한다. 생활 대기 사진에서 버튼 일부가 경계에 걸린 상태는 정지 이미지만으로 오류 확정 불가다. | 탭 끝까지 스크롤 후 시작·취소, 저장 대기 중 조작 |
| 피해 숫자가 체력 문구를 덮음 | `app_av.js`의 impact 배치는 대상 카드 사각형의 중앙을 사용한다. 기존·신규 CI 사진 모두 숫자20이 체력 일부를 덮는다. `style.css`의 `.impact`는 `pointer-events:none`이므로 이 요소 자체가 클릭을 먹는 구조는 아니다. 시각적 가림은 남아 있다. | 초상 위/카드 바깥으로 옮길 때 좁은 화면·다단 공격·여러 대상의 겹침을 함께 검증해야 한다. 화면 확인 없이 위치만 임의 변경하지 않았다. |
| 모달 뒤 입력 | `app_shell.js`는 최상단 모달을 선택하고 배경에 inert를 적용한다. 비활성·숨김·음수 tabindex의 초점 제외 및 닫힘 뒤 초점 복원을 기존 합성 DOM 회귀가 검사했다. | 실제 키보드·화면낭독기·중첩 창·좌표 클릭 |
| HUD/안내와 안전 영역 | 작은 화면 하단 dock에 safe-area 값을 포함하고, 본문·HUD·모달·알림은 top inset을 공유한다. 안내창은 알림 높이와 dock 높이를 빼서 스크롤 한도를 계산한다. | 노치·가로 모드·브라우저 확대·iOS 키보드에 대한 실기기 확인 |

확인한 코드만으로 추가적인 확정 UI 수정은 하지 않았다. 기존 안내/알림 겹침은 최종 CI 사진에서 해소됐으며, 이를 다른 해상도 전체의 통과로 확대하지 않는다.

## 직접 브라우저 접근 상태

사용자가 계속 진행을 요청한 뒤 문서화된 브라우저 API를 다시 확인했다. 기존 브라우저의 `tabs.list()` 단계에서 다음 보호 오류가 재발했다.

> Browser observation is unavailable for a document containing native credentials.

직전 요청에서는 새 로컬 문서와 문서화된 수동 인계 호출도 같은 오류를 반환했다. 새 요청에서도 화면 관찰에 도달하지 못했으므로, 360개 계획 조합에 새 PASS 행을 추가하지 않았다. 별도 브라우저 자동화로 보호 제한을 우회하지 않는다. 이 오류를 게임 서버 장애나 사용자의 브라우저 장애로 해석하지 않는다.

## 이어서 실행할 최소 확인

1. 접근 복구 후 관계·생활의 마지막 버튼을 끝까지 스크롤해 실제로 누른다.
2. 같은 상태로 작은 폰 세로/가로·760px 경계·태블릿·FHD/QHD/4K와 글꼴100/125/150%를 구분해 캡처와 입력 증거를 남긴다.
3. 전투 숫자의 배치를 바꿀 경우 다단/광역·회복·보호막·긴 숫자와 큰 글자까지 확인한다.
4. 실제 iOS/Android의 가상 키보드·안전 영역·홈 화면 앱은 별도 결과로 기록한다.

검사 페이지·합성 계정·결과 문서는 플레이어 게임에 포함하지 않는다.
