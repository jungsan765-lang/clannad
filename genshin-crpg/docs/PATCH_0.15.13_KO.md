# 0.15.13 — 추가 오류 수정과 검사 자료 배포 분리

0.15.12 커밋 `4b6d7543d284ae128e3e3a34d06cbb090f1baa1b` 이후의 테스트 후보 작업이다. 사용자는 남은 점검과 확인된 오류 수정을 요청했고, 검사했다는 문구나 합성 검사 데이터가 게임에 남지 않도록 요구했다. VPS 실행은 사용자가 맡는다. 이 문서는 개발 기록이며 게임 내 변경 내역과 별도로 보관한다.

**작성 시점 상태:** 마지막 변경 내역 수정 뒤 클라이언트·서버 빌드가 성공했고 배포 분리 7/7·콘텐츠와 에셋 7/7이 통과했다. 등록된 전체 92개 로컬 회귀는 진행 중이며 92개는 아직 통과 수가 아니다. 새 직접 브라우저 관찰은 보호 오류로 차단됐고 새 CI·테스트 묶음 게시 결과는 PR #20 최신 기록을 기준으로 한다. 2026-10-03 21:17 KST 공개 응답에서 실제 VPS는 0.15.12/`4b6d754`로 확인했으며 SSH를 실행하지 않았다. 담당 검사 통과를 전체 점검 완료로 해석하지 않는다.

## 남은 확인과 보존한 정책

- 화면 행렬의 360개는 계획 수다. 직접 브라우저의 보호 오류 이력, 물리적 폰, 모바일 키보드·안전 영역·PWA, 긴 세션 및 FHD/QHD/4K와 확대 조합은 실제 실행 증거 없이 통과로 바꾸지 않는다.
- 본편·개인·호감도 대사의 소개·말투·감정·목적·인과는 장면별 편집 검수가 남아 있다. 기술적 연결과 자동 실행을 문학적 품질 검수로 표현하지 않는다. 이번에 원고나 공식 한국어 고유 명사를 새로 고치지 않았다.
- 고유 그림이 없는 일부 보스와 보조 NPC가 남아 있다. 장비 상인·천암군·서기에는 초상 연결이 없다. 주인공의 그림 없는 화면은 별도 설계와 구분한다. 관계 화면 하단 접근성과 안내 겹침 등 과거 사진의 후보는 새 입력·스크롤 증거로 확인해야 한다.
- 이벤트 전용 인물의 신규 개인 임무 진입 거절과 기존 합류 저장 보존은 확인했다. 과거 개인 임무를 마친 뒤 동행을 보류한 저장의 재합류 정책은 명시되지 않아 그대로 보존했다. 닫힌 자동 시작점의 미등록 잠금 플래그는 정상 저장을 막는 경로를 확인하지 못했으므로 확정 결함으로 세지 않는다.
- 서버의 보유 객체 감소와 일부 경쟁 상황 복구를 실제 VPS 수용 인원, 장시간 부하 완료, 모든 외부 장애 복구로 확대 해석하지 않는다.

설치 절차는 `VPS_TEST_INSTALL_KO.md`를 따른다. 사용자가 VPS에서 실행하며, 이 작업으로 main을 병합하거나 운영으로 승격하지 않는다. 게시·설치·실제 서버 확인은 각각 별도로 기록한다.
