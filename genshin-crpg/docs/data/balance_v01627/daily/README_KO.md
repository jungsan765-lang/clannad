# 0.16.27 일일보스 후보 재계산 · 최종 공개 전투 검증

**후속 변경:** 신규 드발린 재도전 바람길 제거로 아래132개 중 드발린27개는 대체되었다. [새63조건 검증](dvalin_no_wind/README_KO.md)을 우선한다. 다른3종105개는 당시 기록을 유지한다. 아래99승33패는 바람길 제거 전 전체132개 결과다.

이 폴더는 0.16.26 원격 authored DB와 실제 공개 입장/전투를 사용한 기준선, 수치 후보 및 최종 통합132조건 기록이다. 제품 적용 후 최종 결과는 **99승33패, 오류0, 입력 드리프트0**이다. 기준선과 선택 후보를 최종 결과로 혼동하지 않는다. 제품 수정과 게시를 담당하는 root에게 이 검증을 전달한다. 상세 결과와 남은 강한 편성은 [FINAL_NATIVE_KO.md](FINAL_NATIVE_KO.md)를 읽는다.

## 입력과 동작

- 고정 4인: 주인공 명함 + 4성 동료 3명 풀돌 또는 5성 동료 3명 명함. 각자의 합법 돌파 단계와 해당 레벨 기본 특성 상한을 적용한다. 동료 풀돌은 각 6회 공개 `CONSTELLATION_UNLOCK`로 적용한다.
- 주인공은 여행자 바람. 안드리우스 기본군은 면역을 피하여 물리 평타를 쓴다. 별도 바위 공명군은 공개 석상 상호작용으로 공명한다.
- 기본 장비는 제작 무기/보강 가죽 방어구/치유 브로치 +10, 성유물과 전용 무기 없음. 원시 스탯 점수로 고른 고급 장비 +10 및 자연 성유물 300회 선택 +5 군을 별도 기록한다. 이는 장비 패시브 전체 최적화나 실제 수집 시간 검증이 아니다. 전용 무기 고정군은 별도 `selected_exclusive`/최종 기록에 둔다.
- 보유/육성/재료/진단 모라/선행 클리어를 지급하고 준비 단계에 한 번 체력을 가득 채운다. 공개 입장 후 3번 배치의 최대 HP +5%가 현재 HP를 늘리지는 않아 해당 1명은 실제 초기 HP 약95.24%로 시작한다. 나머지는 초기100%다. 초기 actor HP/maxHP를 원자료에 그대로 기록했으며 모두100%로 다시 채워 보정하지 않았다. 실제 HP, 보호막, 저항/면역, 원소 반응, 쿨다운, 동료 AI, 보스 단계, 전투불능, PRNG는 런타임 처리한다. 전투 중 음식/숙박/무제한 부활은 지급하지 않는다.
- `REPEAT_QE`: 주인공 궁/스킬/평타 반복. `PREPARED`: 드발린 바람길 및 공개 체력/순서에 따른 주인공 방어. 동료 AI는 두 군 모두 기존 정책으로 행동한다. 이 구분이 모든 보스의 최선 수동 공략을 대표하지는 않으며, 주인공 방어가 화력 손해로 이어져 일부 패배가 늘어난다.
- 기본 시드는 717/4242/9031, 40회 공개 주인공 입력/대화 상한. 입력 상한/입장 제한/fixture 오류는 패배나 승리로 합치지 않는다. 고급 장비군은 성유물 생성 후 전투 시작 전에 선언한 시드로 고정하고, 생성으로 소비한 PRNG도 기록한다.
- `preRewardHp`는 종료 정산 전 전체 아군 HP 비율, `hp`는 퇴장 10% 회복 이후 비율이다. `ko`는 종료 직전 실제 전투불능 목록이다. 종료 후 체력이 양수라는 이유로 무전투불능이라고 판정하지 않는다.

## 권고 수치

이 숫자는 반복 일일보스 origin에만 적용한다. 다른 이야기 전투와 진행 중 저장 전투를 이 표로 덮지 않는다. 보호막 손상 배율과 기술 피해 배율은 이번 후보에서 그대로 유지했다.

| 보스 | HP 이전 → 후보 | ATK 이전 → 후보 | 표시 DEF 이전 → 후보 | 성장 challenge 배율 HP / ATK / DEF |
|---|---:|---:|---:|---|
| 안드리우스 | 20,094 → 20,094 | 2,055 → 2,466 | 236 → 248 | 1.75 / 2.64 / 1.05 |
| 드발린 | 42,540 → 42,540 | 3,744 → 4,492 | 270 → 270 | 4 / 3.36 / 1 |
| 타르탈리아 | 125,761 → 144,625 | 9,703 → 16,010 | 591 → 709 | 2.415 / 3.135 / 1.2 |
| 아즈다하 | 137,874 → 151,661 | 13,189 → 18,465 | 778 → 856 | 1.65 / 2.03 / 1.1 |

공동 `enemyBalanceRevision:1` 정책은 Lv35 이후 아군 공격의 방어 기준을 `K=100+5×(공격자Lv−35)`로 계산하고 적의 저장 DEF에도 해당 적 레벨 K/100을 반영한다. 위 표 DEF는 이 공동 보정 **이전**의 후보 비교값이다. 실제 신규 저장 표시 DEF는 안드리우스248, 드발린270, 타르탈리아1,241, 아즈다하1,926이다. 동일 레벨에서는 공동 방어 보정만으로 피해 감쇠가 바뀌지 않으며, 낮은 레벨이 높은 레벨의 방어를 우회하기 어려워진다. 새 레벨/등급 입장 문턱은 추가하지 않는다.

표시 DEF는 `combatStat`에서 레벨 곡선의 제곱근으로 나눠 적용한다. 표시 수치를 그대로 최종 방어력이라고 해석하지 않는다. 드발린은 8라운드 지형 제한 때문에 HP/DEF를 올려 합법 평범한 장비의 5성 명함을 시간 초과로 일괄 탈락시키는 후보를 피했다.

공동 정책 포함 간이 8조건은 `preliminary_product`에 있다. 실제 출력 DEF104.72/106.50/330.69/447.51, revision1, 입력 드리프트0/오류0을 확인했다. 최종 필드 수치까지 통합한 불변 소스로132조건을 다시 측정했다. 후속 보상 편집의 전체 소스 fingerprint 차이와 동일한 일일보스 수치 앵커를 최종 문서에 구분해 기록했다.

## 폐기/선택 근거

- 현재 authored DB 기준 기본 48조건은 35승 13패였다. 0.16.25 QA DB 자료의 38승을 현재 입력 결과로 재사용하지 않는다.
- 강한 후보 A를 평범한 제작 장비에 적용한 16조건은 3승 13패였다. 아즈다하 A(HP +25%, ATK +90%, DEF +25%)는 고급 +10에서도 4성/5성 양쪽 패배하여 제외했다.
- 아즈다하 D(HP +15%, ATK +55%, DEF +15%)는 고급 +10 4성 풀돌 수동군 1/3승으로 준비 선택 폭이 너무 좁아 E로 완화했다.
- 아즈다하 E(HP +10%, ATK +40%, DEF +10%)는 제작 +10 4성 풀돌 0/6승, 고급 +10/성유물 4성 풀돌 반복/수동 모두 3/3승이었다. 수동군의 종료 정산 전 HP는 약 31~36%이며 KO가 0~2명 있었다. 5성 명함 기본군은 6/6승이지만 모든 전투에서 주인공 KO가 있었다. 장비 투자가 난도와 생존에 실제로 영향을 준다.
- 전용 무기 고정 +10/성유물 3시드 late24조건은 24/24승이었다. 아즈다하 5성 명함의 종려/다이루크/진 전용군은 4턴, 종료 정산 전 HP 약 58~70%, KO0이었다. 이 강한 편성은 남아 있으므로 모든 편성의 공략 강제나 쉬운 승리 전부 제거를 주장하지 않는다.
- 초반 후보 C에서도 Lv40 4성 명함/제작 +6 첫 정수 확보 군 6/6승을 유지했다. 이는 전체 계정 자연 육성이나 동레벨 모든 명함 편성 승리를 입증하는 검사가 아니다.
- 반복 Lv50/60은 기존 공개 입장 Lv45/55 제한으로 Lv25/35 진입이 막혔다. 해당 입장 차단을 전투 패배로 계산하지 않았다. 사용자가 말한 저레벨 Lv55 격파의 핵심 재현은 별도 필드/이야기 담당 기록을 확인한다.

## 재현

최종132개 전체 입력은 `final_cases_132.json`이다. 메모리 누적을 피하려면 [FINAL_NATIVE_KO.md](FINAL_NATIVE_KO.md)의12개씩 순차 실행 명령을 사용한다. `final_cases.json`도 같은132개 입력으로 갱신했다. 이전108개 입력은 `preliminary_final_cases_108.json`으로 보존한 예비 기록이다.

최종 cases에는 VM 후보 패치가 없다. 선택 수치를 제품에 적용한 뒤 실행해야 하며 예상 적 HP/ATK/레벨, 보호막 정책, 캐릭터 정책, operator profile 0과 장비 제한을 확인한다. 각 후보 `native.json.gz`에는 준비 영수증, 실제 장비/특성/운명의 자리, 입장 상태, 공개 행동과 보스 단계, 종료 직전 HP/KO가 들어 있다.
