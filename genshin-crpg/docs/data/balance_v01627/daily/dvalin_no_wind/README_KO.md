신규 드발린 재도전은 `mondBossBalance.rematchNoWindRevision:1`을 저장하고 바람길 카드를 노출하지 않으며 직접 호출도 거절한다. **HP42,540·ATK4,492·저장DEF270·Lv28과 기존8라운드 지형 붕괴는 유지**한다. 새 버튼·기믹·AI 반복이나 추가 등급 문턱으로 대체하지 않았다.

바람길이 있던 이전132검사의 드발린27조건(기본12·고급12·첫정수3)은 이 변경 후 검증으로 사용하지 않는다. 다른3종 보스105조건은 당시 고정 수치/기록을 유지한다. 아래 **새 바람길 금지63조건은32승31패**, fixture 오류·드리프트·입력 상한·입장 차단0이다. 준비가 없는 패배 대조군과 준비 성공군이 섞인32/63을 실제 유저 전체 승률이라고 해석하지 않는다.

## 숫자를 내리지 않은 이유

- 적정 Lv28·제작+10에 기존 공중 접근 장신구를 준비하면 4성 풀돌/5성 명함 각각3/3승이었다. 향릉·피슬·디오나는3라운드, 종려·다이루크·진은6~7라운드이며 종료 전 HP66.9~73.4% / 50.7~58.2%였다.

- 같은 기본 편성에 공중 접근 준비 없이 장비 수치만 높인 대조군에서는 제작4성/5성 모두0/6승, 고급4성4/6·5성0/6승이었다. 고급 장비의 원시 스탯 자동 선택을 보스 공략 준비와 혼동하지 않았다.

- Lv35 제작+10+공중 접근과 Lv28 고급+10/성유물+공중 접근은4성 풀돌·5성 명함 모두3/3승이었다. Lv40 4성 명함·제작+6·접근 장신구+6 첫 정수 조건3/3승도 유지했다.
