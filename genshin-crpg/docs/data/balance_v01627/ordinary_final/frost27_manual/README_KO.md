## 수치 후보와 최종 동일성

후보는 VM에서 정확히1곳의 ATK 적용 식만 교체했습니다. ≤30은 이전1.6-derived 계수 `1+0.6*w`, 30~40은1.15→2.21 직선, ≥40은 기존 `1+(spec.atk-1)*w`입니다. 일반 HP·DEF, v4비경, 보스/나선/레이드/보호대형·구저장 정책·조우/변형/난수·음식·아이템은 추가 변경하지 않았습니다. 루트가 실제 제품에 독립 anchor표를 적용했고 그 최종native를 다시 실행했습니다.
