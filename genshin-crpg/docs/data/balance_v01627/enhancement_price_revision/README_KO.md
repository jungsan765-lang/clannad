# 0.16.27 후반 장비 강화 가격 폭등 조정

장비 자체의 +80%를 캐릭터 전체 +80%로 계산하지 않았습니다. Lv60 실제 총스탯에서 +10→12의 이득은 약0.4~2.2%였는데, 4인12슬롯의 추가 기대 현금만371.7만모라였습니다. 강화 효과·확률을 올려 전투/치유 밸런스를 다시 흔드는 대신 기존 +11/+12 모라·광물 가격 두 단계만 낮췄습니다. 최종 장비의 추가 투자는 남기면서 급격한 지출 상승을 완화한 보수적 조정입니다. 모든 장비의 순수 능력치 대비 가격이 똑같이 효율적이라는 뜻은 아닙니다.

목표 +1~10의 비용·확률, 모든 강화 스탯·고유효과, 한도 돌파3,000모라·잔향3·핵1·수정5, 재료 취득/보스 입장 조건은 유지했습니다. 기존 유료 강화 영수증을 새 가격으로 소급 환급하거나 다시 결제하지 않습니다.

모라·각 광물·강화시도에 대해 6경로의 재귀 기대값과 독립 흡수 마르코프 상태전이 행렬을 양쪽 정책에 각각 풀었습니다. 60개 연립방정식의 최대 절대 오차는 5.82e-11이며, 성공률만 나눠 강등 비용을 누락한 계산이 아닙니다.

## 실제 공개 동작과 저장 검증

- 전체13검사 통과. 실제 강화 가능 장비169종, 모든13강화도의 스탯2197건·고유효과 및 +1~10 견적은 genuine0.16.26과 일치합니다.
- 진짜0.16.26의 이전+10 장비를 현재 런타임으로 정확히 로드하고 공개 EQUIP_ASCEND·ENHANCE를 사용했습니다. 세 시드717/4242/9031의 진행11쌍에서 실제 지불 비용만 달라지고 성공/유지, 장비/캐릭터 스탯·HP, PRNG, 게임 날짜/시각이 같았습니다.
- 별도로 원래 xorshift 첫 굴림을 관찰하여 선정한 시드로 +11/+12 각각 성공·유지·강등6경계를 공개 동작으로 확인했습니다. die/확률/지불 함수를 덮어쓰지 않았습니다. 경계용 선정 시드와 완주3시드는 구분합니다.
- 매 시도의 실제0.26 유료 영수증을 현재 엔진으로 로드하고 같은 요청을 재시도해 영수증·전체저장·자원·PRNG가 그대로임을 확인했습니다. 완주한 구+12 저장도 전체 동일했습니다.
- 모든169종의 돌파 장비 거래 금지 및 NPC 매각 가격은 그대로입니다. 강화 비용 인하가 강화품을 NPC에 되팔아 수익을 만드는 경로는 생기지 않습니다.

기존 +12를 준비한 전투의 능력치·치유/보호막 및 난도가 비용 변경으로 바뀌지 않습니다. 전체 공개 준비120장비/1030시도와36비경의 최종 실측은 [최고 강화 최종 원장](../enhancement_final/README_KO.md) 및 [전투 동일성](../enhancement_final/final_policy_invariance.json)을 함께 읽습니다. 이전 가격으로 지불한 역사 자료는 새 가격 영수증으로 바꿔 적지 않습니다.
