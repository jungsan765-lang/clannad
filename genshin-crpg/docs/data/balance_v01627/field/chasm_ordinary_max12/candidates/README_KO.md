## 준비와 공정성

5성 조건은 앞선 README의 최대+12/자연60회 점수선택 성유물+5/종려·다이루크·진C0/이세계인 후열을 그대로 썼습니다. Lv25 기본특성4, Lv50 기본특성8입니다.4성 조건은 향릉·피슬·바바라C0+이세계인, 일반 단조무기·철갑 갑옷·치유사의 브로치 강화6, 성유물·전용·보스장비·음식 없음, 기본특성8입니다. 지원 바바라 전열 / 향릉·피슬 공격 우선 / 이세계인 후열 DIAMOND이며 E표식→Q 반복의 같은 공개 정책을 사용했습니다. 4성/5성 사이 적 강화 개체가 모두 같다는 주장을 하지 않습니다. 동일 준비의 후보끼리 비교하고 실제 source/등급/affix를 남겼습니다.

후보27개(3계수×9조건), 기존1.6의4성 대조 추가3개, 최종 제품9개 재확인을 구분합니다. 최종9개는 같은 조건의 재확인이므로9개의새고유밸런스조건으로 중복 가산하지 않습니다. 독립 child의 별도SAVE_ID 4성6건도 `independent_four6.json`에 참고 기록하며 주표27에 섞지 않습니다.

HP/DEF·무기·특성·아군·기믹·조우·RNG판정은 추가 수정하지 않았습니다. 원래 H.load combat candidate hook은 null로 유지하여 이세계인 배율이 섞이지 않았습니다. 문자열이 정확히1번임을 검증하며 실패 시 중단합니다. 원본 성장 소스 SHA는 `5280d8c6a32e8a7424c1a76b835cb345d264a8cec8c675b11b74a44737b5872d`이고 각 변경 소스SHA와 baseline fingerprint는 원자료 `vmCandidate`에 있습니다.

`immutable_loaded_input.tar.gz`는 원래 엔진이 실제 로드한 모든 script·index·presentation·authored db·준비 helper를 담았습니다. 각 파일 SHA는 `immutable_loaded_input_manifest.json`입니다. 후보 runner를 압축해제한 입력 ROOT로 실행하면 됩니다. 공유 제품 파일은 이 담당자가 변경하지 않았고 적용 결정과 수치 변경은 루트가 수행했습니다.
