## 실제 준비와 입장

- 정확한 맵: `MAP_CHASM_SURFACE`(층암거연 지상), 현재 native 지역 고정 Lv50. `MAP_LY_DETAIL_CHASM_RIM`에서 공개 `MOVE {edge:'EDGE_LY_DETAIL_038_A'}`(20분)로 입장했습니다. 옛 평야 직행은 비활성 경로입니다.
- 네 명 고정: 이세계인, 종려, 다이루크, 진. 모두 명함(C0), DIAMOND, 순서 종려→다이루크→진→이세계인. 종려·진은 지원 우선, 다이루크는 공격 우선. 동료 행동은 원래 native AI입니다.
- 레벨에 맞는 돌파 단계와 합법 특성 상한: Lv25는 기본 평타/E/Q 각각4, Lv50은 각각8입니다. 특성 요청10을 실제 상한으로 제한했고 운명의 자리 특성 보너스는 없습니다.
- 두 레벨 장비가 정확히 같습니다. 이세계인 호박 법구 / 종려 전용 / 다이루크 백영검 / 진 전용, 전원 철갑 갑옷·생명 반지. 무기·방어구·장신구 모두 강화12 및 상한12. native 공개 EQUIP, 입장 전과 RANDOM 생성 직후 validateSave 통과. 실제 장비 인스턴스·성유물 수치는 원자료 `equipment`에 있습니다.
- 성유물은 actor별 자연60회 roll에서 ATK + HP×0.05 + DEF×0.4 + CRIT×3 점수로 한 개 선택하여 +5. 직업·요구 레벨·전용 소유자 조건을 확인한 장비 중 ATK+DEF+HP×0.15 점수로 선택합니다. 이는 모든 가능한 세팅의 최적성을 보장하지 않는 선언된 선택 기준입니다.
- 계정 보유·지역/이야기 접근·장비·강화·재료/모라는 진단용 지급입니다. 본인이 저레벨에서도 장비를 계정으로 전승받을 수 있는 조건을 포함하려는 검사이고, 자연 수급이나 첫 지역 진입 비용을 검증한 결과가 아닙니다. 음식·추가 HP 초기화는 없습니다.
- 장비 준비가 소비한 PRNG 상태와 입장 상태를 모두 원자료에 남겼습니다. 입장 전 선언 전투 seed717/19/43으로 초기화하고 `ENCOUNTER_COOLDOWN=0`인 준비 상태에서 공개 MOVE를 호출했습니다. 조우 함수를 대체하거나 적·강화등급·HP·공격력·판정을 수정하지 않았습니다. 같은 seed의 두 파티는 처음부터 같은 SAVE_ID와 준비 action38회로 구성하여 native 해시 강화개체까지 동일하게 생성했습니다.

## 실제 적과 비교 조건
