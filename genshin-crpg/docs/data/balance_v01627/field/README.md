# 0.16.27 필드 보스 실제 전투 재점검

이 문서는 **필드 보스 9종**의 수치·공략 압력과 실제 장비/특성 투입 여부를 정리한다. 일일보스·일반전투·비경·경제의 결과는 각 담당 문서를 참조한다. 여기서 필드가 어렵다는 이유로 회복량, 원소 반응, 동료 능력, 보상이나 입장 제한을 바꾸지 않았다.

## 적용 수치

같은 레벨에서 방어 감쇠를 유지하면서 낮은 레벨 공격자가 높은 레벨 적을 때릴 때 실제 격차가 나도록 공통 방어 기준이 바뀌었다. 아래 DEF는 새 방어 기준까지 적용된 **전투 시작 시 실제 값**이다. 저레벨 편성을 보고 적 수치를 다시 낮추거나 인원 수에 따라 바꾸지 않는다.

| 필드 보스 | 고정 Lv | 기존 HP → 새 HP | 기존 ATK → 새 ATK | 기존 DEF → 새 실제 DEF | 보호막 소모 계수 |
|---|---:|---:|---:|---:|---:|
| 무상의 바람 |18|18,000 → 19,800|1,600 → 1,760|180 → 198|2|
| 무상의 뇌전 |20|16,000 → 16,800|1,700 → 1,785|210 → 210|2|
| 얼음 나무 |22|26,000 → 28,600|1,950 → 2,048|220 → 231|2|
| 무상의 얼음 |30|30,000 → 33,000|1,850 → 2,128|294 → 323|2|
| 폭염 나무 |38|60,000 → 63,000|4,000 → 4,200|460 → 555|2|
| 물의 정령 |40|40,457 → 48,548|4,000 → 4,800|430 → 591|2|
| 무상의 바위 |45|52,113 → 57,324|4,117 → 4,940|508 → 801|3|
| 고대 바위 용 도마뱀 |48|64,000 → 70,400|5,500 → 6,050|570 → 987|1.5|
| 유적의 뱀 |56|83,496 → 91,846|8,500 → 9,350|700 → 1,507|4|

HP/ATK만 일괄 올리면 보호막 없는 4성 명함이 먼저 막히고 종려·진 조합은 여전히 쉽다는 결과가 나왔다. 그래서 과도한 후보는 폐기하고 기존 공략의 값을 유지했다.

- 무상의 바위의 기존 바위 낙하·지면 융기는 공격 계수 ×1.5. 기존 공격 대상·예고·가드·내성 대응은 그대로다. 바위 낙하는 기존 무작위 2인 단타이며 새 예고를 붙이지 않았다.
- 고대 바위 용의 원암 분사만 ×1.15. 보호막이 있을 때 75% 피해 감소, 2인 이상 막을 때 반사·핵 노출은 유지한다. ×1.5 후보는 4성 명함 수동 승리가 1/3으로 떨어져 폐기했다.
- 유적의 뱀은 일반 공격 계수를 더 올리지 않고 직접 공격의 보호막 소모를 ×4로 했다. ×1.5 공격 후보가 명함 수동을 모두 막아 폐기했다.
- 보호막 소모 계수는 직접적인 해당 보스/소유 소환체의 `FB_` 공격에만 적용된다. 맨몸 HP 피해 전체를 같은 배수로 늘리는 방식이 아니다. 반응·지속피해·장판·오브젝트·자기 비용에 중복 적용하지 않는다.
- 물의 정령 형상 HP는 기존 보정 원본 대비 20% 증가했다. 무상의 바위 기둥은 본체 HP가 10% 오른 만큼 비율을 `0.07/1.1`로 조정해 기존 절대 HP와 3라운드 파쇄 가능성을 유지한다.
- 새 `pressureRevision:1`은 새 공개 필드 보스 입장에만 붙는다. 기존 저장 전투의 수치·공격·미래 기둥/형상·난수 흐름에는 이 변경을 소급하지 않는다.

## 실제로 무엇을 넣고 돌렸는가

원격 작성본 `content/db.json`을 사용했다. 원시 SHA256는 `dcc2800000f20684e2c57420404aa3a3a7fe68b9042c608306ba2ec62bd178da`다. 관리자 수정은 **revision 0 / 빈 설정**이다. 보스를 약하게 바꾸거나 HP를 임의로 제거하지 않았고 난수/명중/회피도 고정하지 않았다.

4인 고정이며 주인공 명함 + 동료 3명이다. `FOUR_C0`는 4성 명함 3명, `FOUR_C6`는 같은 동료 3명의 풀돌, `FIVE_C0`는 5성 명함 3명을 뜻한다. 주인공은 주로 이세계인, 바위 용 공략만 바위 여행자다. 돌파 단계와 특성은 해당 레벨의 합법 상한을 사용했다. 요청 특성 10을 실제 상한으로 제한하며 초기 실제 배우의 HP/ATK/DEF/traits, 장비 ID·강화·성유물, 특성·돌파·별자리·진형을 원시 기록에 저장했다.

기본 격자는 일반 제작 무기·회복 장신구와 보스 내성에 맞는 제작 방어구다. Lv35 미만 +3, 이후 +6이며 성유물·전용/보스 장비·음식은 없다. 진형과 동료 지원/공격 역할은 공개 설정을 사용한다. 폭염 나무 4성은 케이아·행추·베넷이며 행추→케이아→베넷→이세계인 후열 순서를 실제 `FORMATION_SET`으로 설정했다. 5성은 기본 종려·다이루크·진이며 바람에는 감우, 불 나무에는 야란으로 맞는 원소/사거리 공략을 준비했다. 같은 3명으로 9종 전체를 무시한 실험이 아니다.

소유권·지역/이야기 접근·성장 재료와 모라·장비 강화·초기 회복은 실험 준비로 지급했다. 전투에는 공개 `PLACE_ENTER`→`BOSS_ROUTE`→`COMBAT_BEGIN`→`COMBAT`과 실제 동료 AI를 사용했다. 준비 비용을 벌고 모든 재료를 직접 모으는 자연 육성 시간 실험은 아니다. 전투 중 HP 재설정, 동료 카드 강제 실행, 적 처치 강제 처리는 없다.

`REPEAT`는 주인공 Q→E→평타 우선 반복과 실제 동료 AI다. 완전 자동전투라는 뜻이 아니다. `MANUAL`은 공개 핵/기둥/프리즘·예고·보호막·굴속/머리 노출을 읽는 제한된 공략 입력이다. 완벽한 사람 공략을 구현한 것이 아니어서 경우에 따라 반복보다 못한다. 보스 공략 AI가 자연스럽게 대응하는 것도 막지 않았다. 기본 무상의 바람 공략 1조건은 패배 확정이 아닌 80입력 한도이며 반복은 3조건 모두 승리했다.

종료 후 회복된 화면만 보지 않았다. `finishBattle` 직전 배우 상태, 실제 HP 피해·보호막 소모·회복·전투 중 최소 합산 HP·전투불능을 측정했다.

동레벨 9종 × 3투자 × 2정책 × 3 seed(717/19/43) = 162조건, 기본 강화 상한 +10 장비로 저레벨 24조건, 얼음 나무 적정 4성 공략 준비 추가 6조건이다. 엔진 오류 0이며 성공만 추려 발표하지 않는다.

얼음 나무는 바바라의 물 부착이 빙결 위험을 만드는 기본 편성 실패를 지우지 않았다. **Lv22 엠버·향릉·베넷 C0, 서리막이 망토+6, 특성4, 수호진형, 주인공 후열**로 추가 측정한 6조건은 공략 3/3·KO0(8/11/12라운드, 최종 HP63.3/44.6/67.1%), 반복 3/3이지만 1조건 KO1이었다. 서리막이 망토 제작법은 자연어가 조건문에 섞여 영구 잠겨 있던 기존 버그를 한 건만 정규화했고 Lv4 차단/Lv5 실제 재료·모라 소비 제작을 별도 확인한다. 자기 필드 보스 재료를 먼저 요구하지 않는다.

폭염 나무 명함 공략은 8–9라운드·KO0·최종 HP61–65%, 바위 용 명함 공략은 9–11라운드·KO0·최종 HP46–53%, 뱀 명함 공략은 16–29라운드·KO0·최종 HP65–73%였다. 같은 준비 반복이 각각 1/3패배, 2/3패배, 3/3패배라 공략 이익이 생긴다.

**동레벨 풀돌 4성·명함 5성 준비 편성은 여전히 전부 이긴다.** 이것을 숨기거나 모든 필드가 수동 필수라고 결론내리지 않는다. 5성 불 나무는 모든 조건에서 전투불능 1명이 발생했고, 뱀 반복은 9/20/29라운드·최소 HP85.7–96.1%·1조건 KO1, 공략은 8/17/17라운드·최소 HP94.5–97.8%·KO0였다. 반면 적절한 종려·진 보호막/치유 조합은 무상의 얼음에서 최소 HP약96%, 바위 용에서 약93–96%를 유지한다. 개별 보스가 이 조합에 쉬운 부분은 남아 있다. 전 조합·전 원소·최적 성유물까지 어렵다는 증거가 아니다.

강한 장비를 제외해서 저레벨 문제를 가리지 않았다. 기본 강화 상한 +10의 합법 착용 장비(전용·보스 장비를 계정 전승한 경우도 포함), 각자 자연 60회 성유물 추첨에서 하나 선택해 +5, 종려·다이루크·진 C0, 최대 합법 특성을 넣었다. 바위 용은 바위 여행자, 뱀은 이세계인이다. 별도의 장비 수급 시간을 포함하지 않는다.

| 강한 저레벨 편성 → 보스 | 반복/공략, 3seed씩 | 실제 결과 |
|---|---|---|
| Lv25 → 바위 용48 |0/3 · 0/3|19–30R 패배|
| Lv25 → 뱀56 |0/3 · 0/3|26–32R 패배|
| Lv35 → 뱀56 |0/3 · 0/3|56–68R 패배|
| Lv35 → 바위 용48 |3/3 · 3/3|14–20R 승리. 반복 2조건 KO1, 공략 1조건 KO1|

Lv35 기본 상한 +10 편성이 상위 보스를 절대 못 깨게 하지는 않았다. 기존 7–8R에서 14–20R로 늘고 손실이 생겼으며, Lv25의 큰 격차는 막혔다. 이 효과는 숨은 입장/희귀도 제한이 아니라 공개 전투 수치와 기존 반사 공략에서 나온다.

주인공이 먼저 죽은 반복 실패에서는 남은 동료 AI가 계속 싸워 300R 이상 뒤 패배하기도 한다. 모든 아군이 죽고도 계속 싸웠다는 결과는 아니며, 사람이 수백 번 입력했다는 뜻도 아니다. 최대 주인공 입력은 80회다.

## 원시 기록과 재현

- `raw_192_rows.json.gz`: 192조건 전체 준비·배우·실제 입력·로그·피해계량·결과.
- `summary.json`: 192조건을 읽기 쉽게 축약한 실제 장비·특성·배우 수치 포함 표.
- `selected_numbers.json`: 선택한 후보 원시 HP/ATK/DEF(DEF의 후단 K 보정 전)·공격/보호막/소환체 숫자.
- `manifest.json`: 원격 DB SHA, 실제 입력 엔진 hash, 조건 수·분할 실행·난수 재현·한계.
- `engine_snapshot/`: 실제 필드 실험에 사용한 필드/성장/규칙/경제 원천. 이후 EXP 보상 및 Frost 제작 조건 정규화가 들어갔지만 필드 전투 source/rules는 동일하고 필드9종 수치도 같다.
- `public_craft_receipts_before/after.json`, `preparation_contracts.json`: 접근 불가능했던 제작법을 숨기지 않고 전후 공개 행동을 기록.

두 큰 최초 프로세스가 메모리 압력으로 exit137되어 44/54,86/108 완료 prefix를 남겼다. 그 prefix 자체를 완료로 세지 않았다. 같은 동결 입력으로 꼬리 12·24조건을 정상 완료했고 겹친 4조건의 시작 배우·전 로그·피해계량·결과가 완전히 같음을 확인해 unique186조건으로 병합했다. 이후 얼음 나무 추가6조건을 더했다. `*_incomplete_prefix.json.gz`는 이 불완료 사실을 확인할 별도 기록이다.

재현 도구는 `tools/audit_field_balance_v01627.cjs`다. 현재 제품을 순정 관리자 설정으로 로드한다. 메모리가 큰 전체 격자는 보스 1–2종씩 나눠 실행한다.

```sh
node --max-old-space-size=640 --expose-gc tools/audit_field_balance_v01627.cjs --out reports/field_geo_serpent --bosses FB_GEO_HYPOSTASIS,FB_RUIN_SERPENT --investments FOUR_C0,FOUR_C6,FIVE_C0 --seeds 717,19,43 --talent 10 --prepared yes
node --max-old-space-size=640 --expose-gc tools/audit_field_balance_v01627.cjs --out reports/field_cryo_prepared --bosses FB_CRYO_REGISVINE --investments FOUR_C0 --seeds 717,19,43 --talent 10 --prepared yes --enhance 6 --cryo-fire-prep yes --formation DIAMOND --order LIYUE_XIANGLING,MOND_BENNETT,MOND_AMBER,PLAYER_CUSTOM
node --max-old-space-size=640 --expose-gc tools/audit_field_balance_v01627.cjs --out reports/field_gap25 --bosses FB_PRIMO_GEOVISHAP,FB_RUIN_SERPENT --investments FIVE_C0 --seeds 717,19,43 --talent 10 --prepared yes --best-gear yes --enhance 10 --art 60 --level 25
```

3seed는 균형의 전 범위를 증명하지 않는다. C1/C2/5성 풀돌, 최적 세팅·모든 조합·식사 회복·전체 수급 비용/제작 이동 시간은 이 필드 격자에서 직접 검증하지 않았다. 현재 CI의 공략 가능 검사는 난이도 상한 검사를 대신하지 않는다. 남은 강한 보호막/치유 편성은 일일보스·나선 및 경제 자료와 함께 판단해야 한다.

연결 회귀 검사: `tools/test_boss_boundaries_v01619.cjs` 31/31, `tests/test_abyss_fixes_v01626.cjs` 35/35, `tests/test_field_preparation_v01627.cjs` 6/6, `tests/test_field_boss_strategy_v01623.cjs` 55/55, 합계127/127 통과. 과거 기믹을 현재 수치 fixture에서 격리하는 검사와 실제 봉인0.26 세이브 재생은 다른 검사로 유지한다. 전체 CI 판정은 릴리스 종합 기록을 참조한다.

## 후속 회귀 검사의 의미

추가한 세 CI 프로그램은 최종 EXP60=24,000 / TALENT60 v4=90 기준으로 **26/26** 통과했다. `test_ascension_efficiency_v01613.cjs` 6/6, `test_material_rewards_v01616.cjs` 13/13, `test_balance_v0152.cjs` 7/7이다. 과거 EXP=10,000 및 TALENT v3=80은 과거 표/저장 보상으로 따로 보존하며, 새 보상만으로 과거 저장 지급량을 덮지 않는다.

기존의 회복·장비 변경 전 공격형 4성 편성 승리를 현재의 무조건 승리 계약으로 쓰지 않았다. 현재 타르탈리아 진단은 향릉·피슬·노엘 C6, 야타용왕은 종려·다이루크·진 C0 등 공개 지원/공격 역할과 후열 주인공을 선언하고, 같은 기존 전용/성유물 강화 투자로 실제 승리를 검증한다. 옛 공격형 C0 자동 패배, 이야기에 대한 기존 난도·레벨 계약, 오염된 저장 밸런스 거절은 유지한다. 현행 드발린은 엠버·피슬·디오나 C6의 원거리 공략과 바람길 부재를 확인하고, 봉인된 진짜 0.16.26 엔진에서 옛 바람길 실제 사용·승리를 별도 확인한다.

일일보스 CI의 +12·전용·성유물 준비는 소유권을 지급한 강한 계정의 회귀 진단이다. 최초 자연 입장에 이 장비를 모두 마련했다는 증거로 쓰지 않는다. 해당 최신 회귀의 원자료는 `balance_contracts.json`이다.
