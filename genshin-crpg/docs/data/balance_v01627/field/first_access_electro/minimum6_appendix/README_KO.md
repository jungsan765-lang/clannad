# 일반 장비 +6과 몬드 장신구 보완 검사

**브로치를 빼도 Lv20 명함 편성의 +6 장비로 무상의 뇌전 첫 재료를 얻는 경로가 있다.** 향릉·중운·바바라 + 이세계인, 일반 제작 무기·철제 수호갑·매의 눈 장식 모두 +6으로 3건 중 2건 승리했다. 실패 1건도 포함했다. 실제 기본 특성 2, 별자리 0, 성유물/음식/전용/보스 장비 없이 기존 공개 공략과 동료 AI를 그대로 사용했다.

기존 24건 원장과 별도로 6건을 추가했다. 이번 장비 지급·원소 캐릭터 소유권·제작 재료·모라·지역 접근은 준비용이다. 자연 수급 시간을 재현하거나 모든 초보 편성의 승리를 보장한 검사는 아니다. 브로치 +6 편성은 투자 비교로만 남겼다.

치유사의 브로치는 착용 Lv5지만 상점 stock이 없고, 제작 Lv8·**수메르성** 조건이다. 재료 에테르 실3·공명 보석1은 다른 지역에서 얻을 수 있어도 제작 장소가 별도이므로 몬드 첫 접근 장비로 지급하면 준비 수준을 과대평가한다. 회복/보호막 +10%가 있어 기존 +10의 3/3 결과 또한 자연 몬드 접근 보장으로 부르지 않는다.

매의 눈 장식은 몬드에서 공개 구매/제작 가능한 장신구다. 기존 공개 공급 검사에서 바그너 구매와 몬드 제작 성공을 확인했다. 착용/구매 Lv3, 제작 Lv5·수정2·에테르 실2·150모라이며, 기존 native 구매 영수증 단가는 520모라다. 원시 stock 행의 1,800모라·Lv5는 runtime 적용값과 다르므로 구매 접근은 공개 영수증으로 구분해 확인했다. 이번 3건은 준비 지급 후 실제 공개 `EQUIP`으로 장착했고 브로치를 인벤토리에서도 제거했다. 무기·수호갑·장신구 12개 모두 +6이다.

진형은 `DIAMOND`, 향릉→중운→바바라→이세계인 후열 순서이며 향릉·중운 공격 우선, 바바라 지원 우선이다. 원래 주인공 공략 함수, 실제 동료 AI, 재생/프리즘 기믹을 바꾸지 않았다. seed19 실패는 프리즘 재생 7회를 허용한 제한된 수동 정책의 결과이며 보스 수치를 낮춰 성공시키지 않았다. 바바라 초기 실제 HP는 진형 보정 뒤 약95.24%, 나머지100%이다.

6건 모두 공개 개시 저장과 실제 종료 저장을 다시 native 생성자로 읽어 전투 상태와 PRNG가 보존되는지 확인했다. **저장 경계12/12 정상, 엔진 예외0·80입력 한도0·관리자 revision0.** 몬드 장신구 3건이 전패하지 않아 요청의 조건부 옛 버전 재측정은 추가하지 않았다. 구·신 동일 준비 9쌍 비교는 상위 원장에 그대로 남아 있다.

`summary.json`은 6건과 저장 검증·실제 장비/특성·초기 배우를 분리 기록한다. 각 디렉터리 `rows.json.gz`는 전체 공개 입력/로그/결과이며 `runner.cjs`가 측정 코드다. `accessory_region_proof.json`에는 원시 장비/레시피/stock 행과 기존 공개 매의 눈 장식 공급 영수증을 담았다. 전투 수치 변경은 없으며 관측 wrapper는 원래 피해/회복/종료 함수를 호출한다.
