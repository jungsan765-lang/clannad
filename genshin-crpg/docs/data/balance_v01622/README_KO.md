반복 회복 검사는 같은 저장과 난수를 이어 사용하며 음식·숙박·강제 회복·HP 초기화를 하지 않는다. 고정4인, 명함/풀돌, 장비·특성·시드를 원문에서 확인한다. 표시2배속의 실제 연출 시간에 조작3초와 결과/재입장6초를 더했다. 네트워크·사람의 반응·재료 획득과 해금 전체 시간까지 측정했다는 뜻은 아니다.

돌파 최고4성25/5성50기본승과 리월3특성 최고63기본승을 유지했다. 초기1/2/3보상·첫3/6요구도 유지한다. 선택한 새 표의4성 전체 돌파 보석 요구141,004,5성282,008과 최종 단계 요구135,000/270,000은 다른 값이다. 이전 표B는140,718/281,436이었다. 같은20승+추가6~9회분 보너스 공급은140,400~156,600개로4성 최종 요구104~116%지만 모든 계정의 주간 획득을 보장하지 않는다.
