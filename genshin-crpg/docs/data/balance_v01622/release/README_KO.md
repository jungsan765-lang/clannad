# 0.16.22 선별 회귀 검사

최종 제품에서 선정한 35개 프로그램의 최초 실행은 완료됐다. 결과는 32 PASS / 3 FAIL이며, 원 결과·압축 원출력·해시는 보존한다. 실패는 한운 신규 정책의 옛 기대값, 불 돌파 비경의 불리한 기본 편성 필승 가정, 이세계인 오셀 전투의 필승 가정이다. 후속 교정·재검증과 실제 전투 진단은 진행 중이므로 현재 전체 통과로 표시하지 않는다.

서버·브라우저 빌드와 엔진 식별자 검사는 통과했다. 실제 소스·빌드 브라우저·import한 서버의 3엔진 대조는 218/218 PASS다. 동시에 실행하는 무거운 작업은 팀 전체 3개 이하, 회귀 worker는 최대 2개로 제한했다.

제품·QA DB는 최초 실행 중 바뀌지 않았다. 승인된 QA 변경 2건은 성장 검사 4→5계약 추가 및 한운 신규 정책 기대값 1250/600→850/400이다. 원문과 최종문·diff·승인 사유는 `qa_corrections`에 따로 보관한다. 옛 저장의 회복값 검사는 유지한다.

원자료는 `per_gate`·`logs/*.gz`, 최초 결과는 `results.json`·`summary.json`이다. 후속 재검증은 이 원장을 덮어쓰지 않고 별도로 기록한다. 실제 오셀 전투의 초기 저장·행동·KO·기지 HP와 통제 비교는 `osial_diagnostic` 및 `osial_medicine_diagnostic`에 보관한다. 방어만 반복한 경우와 응급치료만 추가한 경우도 모든 표본을 이기지는 못했으며, 성공으로 바꾸지 않는다.

기존 0.16.21 봉인 증거는 변경하지 않았다. 정확한 옛 DB가 없는 저장 검사와 원본 서술행이 없는 편집 분리 검사 2건은 재실행하지 않은 미해결 입력 부족으로 별도 유지한다. 이 폴더는 전체 180개 검사의 재실행 결과가 아니다.
