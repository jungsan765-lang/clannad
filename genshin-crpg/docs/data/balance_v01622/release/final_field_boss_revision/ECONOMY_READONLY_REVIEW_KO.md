# 필드보스 revision3 경제 연결 읽기 점검

이 점검은 소스 계약을 읽은 결과다. 필드보스 수정의 실제 승패·공략 가능성은 별도 전투 검증을 따른다. 기존 경제11개 원장과 문서는 편집하지 않았다. 부모가 최종 제품 동결을 확정했으며, 필드보스 소스 SHA `dab1e585bf696116d05affbcc1ceb58420d5fc23144ca0ad85d7742f1dd4b04b`가 읽기 스냅샷과 같음을 확인했다. `economy_readonly_review.json`에 입력SHA를 보존했다.

| 연결 | 코드 근거와 영향 |
|---|---|
| 반복 부활 보상 | 보상은 최종 승리 때 한 번 정산한다. 성장 `mondRewardPlan`은 `!fbSummon`만 합산하므로 프리즘·기둥 재생성으로 XP·모라가 늘지 않는다. 소환체의 loot ID는 비어 있고 실제 loot DB에 빈 ID 행이 없어 아이템도 없다. 전투영수증은 같은 battleId 재정산을 거절한다. |
| 토벌 상한 | 모든 필드보스 합계 현실12시간3승, 한국시간0시·12시 갱신은 그대로다. 실패는 차감하지 않는다. 한 전투 안의 부활은 새 승리·새 토벌횟수가 아니다. |
| 돌파 고유재료 | Lv50/55 돌파의 요구는 4성2+3개, 5성4+6개 그대로다. 보스 정상드롭2~3개·최초승리 추가1개도 그대로다. 무상4종 부활 저지 실패를 되풀이할 때 실제재료 수집의 전투시간·부상은 늘 수 있다. 숫자가 같다는 이유로 실제육성시간도 같다고 보장하지 않는다. |
| 임무·호감도 | 마지막 승리영수증에서 전투1승·필드보스1승만 집계한다. 부활/소환체 처치는 추가목표가 아니다. 낚시·사냥 등 생활목표는 실제 `LIFE_FINISH` 산출물이 필요하며 보스전으로 우회하지 못한다. 호감도는 battleId별 대상+1, 필드보스 승리기록도 마지막 승리 한 번이다. |
| 협동 정산 | 게스트 battleId 재수령 차단과 본인 토벌상한을 유지한다. 상한 뒤 XP만 받는 기존정책은 그대로며, 부활 자체가 새 협동보상을 만들지 않는다. |
| 비경·회복·시장 | 비경 보상/돌파요구/재료첫3승/XP/숙박/요리/장비/상점 수치는 바뀌지 않았다. 보스 공략 실패의 실제휴식·소모품 비용은 늘 수 있으므로 기존 비경1,876쌍 효율산술을 보스고유재료까지 포함한 전체육성 완주시간으로 확장하지 않는다. |

현재 얼음 돌파의 고유재료는 얼음 나무의 서리의 핵으로 연결되어 있으며 무상의 얼음의 응결의 꽃은 일반돌파 요구에 쓰이지 않는다. 이 기존매핑은 revision3가 만든 문제가 아니다. 별도 성장용도·개별캐릭터 설계 검토가 필요한 항목으로만 남겼다.

주간 필드보스10승은 기존 토벌상한의 주간총량 안에 있으나, 실제공략 가능한 편성·해금·접속시간을 보장하는 판정은 아니다. 이번 읽기점검에서 재료·보상·임무를 부활로 무한증식하는 경로는 발견하지 않았다. 새공략의 성공률·전체육성 소요시간·음식/모라수급 완주는 측정하지 않았다.
