# 0.16.22 최종 연결 수정 후 회복 재검증

오셀의 기지 보호 전투(`PROTECT_FORMATION`)에 기존 방어 상수100을 보존하고, 이세계인 성장 이야기 잠금·성유물 연결·감사 helper 검증을 마친 최종 제품을 별도 복제하여 회복 반복을 다시 실행했다. 앞선 `../healing/`의36파일 원장은 고치거나 다시 봉인하지 않았다.

## 결과

| 관측 | 직전 pivot35 | 최종 연결 수정 후 |
|---|---:|---:|
| 조건/실제 전투 |56/202|56/202|
| 승/패 |182/20|182/20|
| 오류/진행 정지 |0/0|0/0|
| 4승·전사 없음 |32|32|
| 4승·전원 완치 |4|4|

직전 pivot35의56조건 배열과 최종56조건 배열이 **전체 동일**하다. 개별 전투의 승패·HP·회복 이벤트·전투 로그·시간·회복 견적까지 달라진 조건0이다. 추가 연결 수정이 이 회복 조건에 새로운 영향을 만들지 않았음을 확인한다. 오셀 기지 공격 자체와 이세계인 이야기 잠금은 root의 별도 회귀 자료를 읽는다.

시드717/925, Lv25/Lv60, 한 명 지원과 공격 편성, 세 명 지원 풀돌을 실제 런타임에서 최대4회 연속 실행한다. 음식·숙박·체력/난수 강제 재설정 없이 패배 시 중단한다. 모든 조건의 첫 전투 승리와 전사 수는 앞선 보고와 같으며, Lv60 진·바바라·백출·한운 단일 지원은 상처가 누적된다. 세 지원 풀돌의 완치 이익과 느린 반복 시간도 그대로 남는다. 구체적인 투자·수치·시간과 숙박 견적의 한계는 `../healing/README_KO.md`를 함께 읽는다.

## 저장·기술 설명 계약

진·바바라6검사, 한운5검사를 최종 제품에서 다시 실행하여11검사 모두 통과했다. 신규 한운850/400, 표시 없는 기존 전투1250/600, 이미 저장된 대나무별600, 진 영역의 저장된 수치와 옛 집중 회복3%+60, 원본 DB 불변과 기술 정보 일치를 확인한다. 이 계약 검사는 회복량·대상을 분리하려고 시험 경기장의 적 HP와 난수를 통제한다. 승률 증거는 위의 별도56조건 native 반복이다.

## 입력·원자료

- `input_manifest.json`: 최종 제품에서 별도 복사한 실파일121개. 모든 입력SHA와 심볼릭 링크0을 기록한다.
- `input_verification.json`: 실행 전 지문, 실행 후 동결 지문, 현재 제품 지문이 동일하다. 동결121개와 제품121개 SHA 변경0.
- `repeated.json.gz`·`repeated.summary.json`:56조건202전 원자료와 native 요약. 원gzip의 최종 집계 footer는 없는 상태로 보존했으며, 전체 전투 행에서 독립 재집계한 값이 native 요약과 일치한다.
- `comparison_since_pivot35.json`: 전체 조건 동일과 재집계 결과. 입력 지문은 소스 변경 때문에 달라지며 관측값이 동일한 것과 구분한다.
- `jean_barbara_contract.json`·`xianyun_contract.json` 및 로그: 실제11계약 검사 결과.
- `contracts_summary.json`·`tool_inputs_before.json`: helper와 계약 테스트의 원문SHA·검사 수·종료0. 원문 파일도 함께 저장했으며 재실행은 repo의 기존 상대 경로에서 한다.
- `changes_since_pivot35.patch`·`changes_since_pivot35.json`: 직전 동결 입력과의4개 native 소스 변경. 전체 배포본은 root가 생성한다.
- `earlier_seal_before.json`·`earlier_seal_after.json`: 앞선36파일 원장의SHA 변경0과 기존 MANIFEST SHA 보존.

최종 native 로드 지문: `88b8d478b7370208f7a325e4d1a42735e0b5a1668e00181438afda5801fde3b9`. 이 지문은 helper가 실행 순서대로 결합한 런타임 소스와 DB이며, presentation/index까지 포함한121개 입력은 별도 파일SHA로 확인한다.
