# 0.16.22 K5 및 한운 변경의 특수 전투 범위 읽기 검토

- 검사일: 2026-10-10 UTC.
- 범위: 현재 runtime_rules / runtime_combat / runtime_liyue_cards 및 나선·협동·레이드 wrapper, 기존 0.16.22 검증 자료. 제품 코드 수정 없음. 새 대규모 시뮬레이션 실행 없음.
- 이 문서는 정적 코드 검토 및 기존 실측 증거의 해석이다. 모든 나선층·레이드·협동을 실제 완주했다는 뜻이 아니다.

## 판정

K5는 `runtime_rules.js:73,88`의 ENEMY→ALLY 직접 공격 방어 분수 한 곳에만 적용된다. `100+5*max(0,enemyLevel-25)`가 같은 피해에 두 번 곱해지는 경로는 발견하지 못했다. 아군의 원래 DEF 값, DEF 기반 공격·보호막·회복 계수, 아군 화력은 직접 변경하지 않는다. 실제 흡수해야 할 적 공격이 커지므로 보호막 지속은 짧아질 수 있다.

## 4성 C6 / 5성 C0 해석

K5는 운명의 자리나 희귀도별 배율을 직접 변경하지 않는다. 다만 방어 상수가 커지면 높은 DEF가 주는 상대 생존 우위는 작아지고, 보호막·피해 감소·힐이 있는 편성이 여전히 더 오래 버틴다. 따라서 전체 후보가 5성 방어 편성으로 승리했다는 결과를 일반 C0 4성 편성의 안전성으로 대신할 수 없다. 4성 C6와 5성 C0의 가치 우열도 이 정적 검토만으로 단정할 수 없다.

기존 `pressure_boss_candidate.json` 14조건에는 PREPARED_C0(노엘·행추·피슬) Lv.30 무상의 얼음, Lv.45 무상의 바위, Lv.48 고대 바위 용 도마뱀 모두 전멸이 있다. Lv.56 유적의 뱀은 승리하되 최종 HP 합계 비율 약 59.7%이다. 같은 레벨 FIVE_DEFENSIVE(종려·다이루크·진)는 해당 네 보스 모두 승리하며 최종 HP 합계 100%였다. 이것만으로 K5가 새로 실패를 만들었다고 주장할 수는 없다. 같은 seed/장비/조작의 이전 정책과 비교한 결과가 필요하다.

한운 선별 비교 자료 `pressure_k5_xianyun850_comparison.json`의 Lv.60 seed 717/925는 각각 4연승을 유지하면서 HP 합계 비율이 1.000→0.898, 0.984→0.869로 내려갔다. 이는 해당 편성·비경의 결과이며 전체 특수 콘텐츠 안전성 증명은 아니다. Lv.25는 K5 방어 상수가 옛값과 같아 비교 차이는 한운 회복 조정에서 발생한다.

## 추가로 필요한 선별 실측(최대 4조건)

1. 나선 10층의 기존 입장 가능한 C0 reference 편성으로 정책 마커 없음/1을 같은 seed에 비교: 3방 클리어·방별 KO·최종 HP·음식 사용량·시간초과. 옛 저장 방1→새 방2의 전환도 짧게 확인한다.
2. Lv.60 동일 enemy packet을 host 및 같은 유효 DEF의 guest에 각각 1회 적용: 과거/신규 피해 비가 같은지, 기록상의 원래 DEF/guest 스냅샷 변화가 없는지. 필드·나선 방어 공식 검사와 함께 분수 한 번 적용을 검증한다.
3. 현재 열린 토벌전 보스 1종에서 기존 일반 C0 편성으로 8라운드 전/후 비교: 적중 당 기여 1, REACTION_DOT 제외, 조기 KO 및 총 hits. 공격당 뜻과 생존 때문에 달라지는 총량을 구분한다.
4. 후반 일반 C0 편성(노엘·행추·피슬)의 입장 레벨에 맞는 비경 1종을 같은 seed 2개에서 이전/신규 정책으로 비교: 식사·숙박 없이 첫 전투 KO와 3연전 HP를 확인. 5성 방어팀으로 이 조건을 대체하지 않는다.
