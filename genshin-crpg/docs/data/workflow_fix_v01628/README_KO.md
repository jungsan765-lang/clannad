## 수정 계약

원본 runtime.js는 과거 게시 blob `550200e4582fe620966c8f76ebb96b53288193ed`, SHA256 `da3479d514fbcc6edf5c3be64d8cbb5ff9e6533b84a045711e27b3d0325c3ec7`이다. 기존0.16.23 전체 게시 원장과0.16.26 전체 모듈 원장에서 확인하고0.16.24의 기록된 전체 source closure 지문도 다시 통과했다. 세 historical overlay에 같은 진짜 원본을 추가했으며 원래 원장 파일은 수정하지 않았다. 현재 source/runtime.js는 최적화 후 원문 그대로다.

기존 검사에서 현재 엔진과 과거 엔진을 섞어 쓰던 fallback을 실제 검사 자료 추가로 차단한다. 향후 공통 소스가 바뀌면 과거 재현이 참조하던 원본도 함께 보관해야 한다. 기대 해시를 현재 해시로 바꾸거나 검사를 빼지 않는다.

버전0.16.28, 엔진 `engine3-58331e639a984025612c388c2f4479d2d69cb59771b903939070895382e35003`, 서버 빌드 `server-862ceb36200a8bfb6a64`는 같다. 새 배포에는 복구 커밋 전체40자리 SHA를 사용한다. 실제 VPS 설치·본서버 승격·main 병합·워크플로 완료 대기는 실행하지 않았다.
