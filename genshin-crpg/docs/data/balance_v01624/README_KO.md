## 입력·저장·재현

최종 native 지문은 `840ef8955b08346d086de5b39ab87d918123ab4ce2dc0c292f080827fc4bafdc`다. 생성 엔진 지문은 `engine3-fb60daa8a1c8d1e8eda9e7932189f4d54b17fa7908fa4dacde54e393c4a3d422`로 소스/브라우저/서버가 일치한다. 두 지문은 서로 다른 해시 방식이며 같아야 하는 값이 아니다.

[source_before](source_before/published_source_manifest.json)는 공개0.16.23 커밋`1bf0ee5fb35f5fba371466e2e29f01ef7fa4ed59`의 출처235항목 중233 source blob을 검증한다. 변한 모듈은 그때의 파일 덮개로 구엔진을 재구성하고 나머지는 공개 원본과 같음을 검사한다. 로컬 git HEAD를 공개 릴리스의 출처로 사용하지 않는다.

기록된 QA DB 원문SHA256은`254c9294c7787b421f38c84b3ad8fed9f00c207a8ef74855868c0cda48dc0962`다. 재현용 압축QA DB는 검증 폴더에만 있으며 **운영 content/db.json을 대체하지 않는다**. 원격 authored DB·assets는 선별 게시에서 그대로 보존한다. 로컬QA DB가 운영 편집 원문 전체와 같다는 증명은 아니다.

scope 검사 기본은 구/신 엔진의 같은 실행DB와 실행 전후 불변을 확인한다. `--require-recorded-qa`를 쓰면 위 기록된SHA까지 강제한다. 최종 로컬 보고서는 이 엄격옵션으로 실행했다. 자세한 재현CLI·도구 및 개별input SHA는 각 원장을 따른다.

## 실패와 기각 보존

[field 후보/초기제품/같은준비구수치](field/README_KO.md)는 최종 제품162와 분리한다. 일일 후보에서는 보호막3배를 일괄 적용하면 늑대·야타의4성 경로가 막혀 보스별 배율을 선택했다. 전역 종려 방패25% 후보는 일반Lv20특성2회차의 주인공KO를 만들어 기각했다.
