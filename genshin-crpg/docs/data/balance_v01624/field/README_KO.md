# 0.16.24 필드보스 최종 수치·공개 공략 실측

최종 release source freeze 이후 [release_final](release_final/README_KO.md) 복제본에서 **162조건을 새로 실행**했다. 일일 추가 전의 별도162와 결과 드리프트는0이며 각 원장은 합산하지 않는다. 빈 공식 운영자 profile revision0, 신규 field behavior5, 동레벨 고정4인, 실제 균형 동료AI와 공개 주인공 조작이다. 기존 후보156조건과 합산하지 않았다.

**준비한 4성 명함 수동 편성의 첫 재료 수급 경로는 27/27승리로 확인했다. 모든 4성 풀돌·5성 명함이 필드에서 수동 공략을 반드시 해야 하는 목표는 달성하지 못했다.** 적절한 동료AI가 기존 원소·갑주·보호막 공략을 수행한다. 이 한계를 숨기거나 일일보스 결과로 바꿔 말하지 않는다.

## 준비와 보존 범위

- Lv35 미만 전원 일반 제작장비+3, 이후+6. 실제 기본특성 합법상한이며 전용·성유물·보스장비·+12·음식·전투치료품은 없다. 보스 own-material을 미리 요구하지 않는다.
- 나무·뇌전은 제작 철제 수호갑과 공개 후열 주인공 대열. 나머지6종은 강화 가죽갑옷과 주인공 선두다. 반복/수동 쌍의 준비는 항상 같고, 보스별 최적 준비가 같다고 주장하지 않는다.
- 철제 수호갑 REC_ARMOR_IRON은 몬드 대장장이, Lv5, 백철4+정제 가죽2+모라220이다. early-shop 판매라는 설명 대신 제작으로 기록한다.
- 주인공은 보스별 이세계인 또는 고대 바위 용의 바위 여행자다. 이세계인 무기 선택과 여행자 바위 공명·동료C6해금·대열·장비·입장·전투는 공개 API로 실행했다. 동료를 수동 조작하거나 전투 중HP/공격력/주사위를 바꾸지 않았다.
- 4성 편성은 보유한 적절한 카운터 동료를 전제로 한다. 소유·해금·강화자금·최초 완전회복은 진단fixture다. 자연 획득 시간·모든 조합·서버 경제 전체를 증명하지 않는다.
- 일반5성 비교는 종려/다이루크/진이다. 폭염 나무는 물·얼음 결정막 대응이 가능한 감우/모나/진을 써 부적절한 원소 편성을 등급 차이로 오해하지 않는다.
- 종려·전역 캐릭터·회복·음식·숙박·드롭·경제 수치는 이 필드 조정에서 바꾸지 않았다. 이세계인·여행자와 4성C6의 실제 투자 차이를 숨은 희귀도 통과 조건으로 바꾸지 않았다.
- 신규behavior5의 수치·소환값·시간창이며 saved4 이하 진행전투는 부모 저장회귀의 별도 검증 범위다. 본162 전투를 저장회귀·세 엔진 검증으로 부르지 않는다.

## 남은 한계

C6의 반복도27/27승리·전투불능0이고 일부3–6R에 끝난다. 5성 종려/진 편성의 다수 필드는HP100%로 끝난다. 수치만 더 올려 이를 모두 막는 후보는 C0 첫 재료 경로를 차단하여 폐기했다. 특히 뱀HP100000+충전계수1.8은C0 수동3시드 모두 전멸했다. 실제 공개 수동1명+AI3명 구조에서 모든 보스의 수동 필수화를 끝냈다는 결론은 내리지 않는다. 일일보스·5성1/2/6돌·자연 연속수급은 부모의 별도 결과를 확인해야 한다.
