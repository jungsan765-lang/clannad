# 보스 보호막·치유 압력 확인 (0.16.23)

제품 파일 수정 없이 실제 런타임의 보스 입장과 기술 실행을 사용했다. 아래 값은 선언한 경계에서의 회복·보호막·중립 피해 한 건 측정이며, 전체 전투 승률이나 공략 성공 증거가 아니다.

공통 조건: 여행자 + 종려·다이루크·진 C0, 동레벨·합법 돌파, 제작 장비 +10/상한10, 합법 기본 특성상한, 성유물·전용무기·보스 장비 없음. 초기 HP 회복은 편성 준비에만 실시했다. 피해 한 건은 ATK×1, 치명타·원소부착 없음, 명중 확정, die50/random0.5를 선언했다. R1/R5는 비교 경계 설정이다. 자동 엄호가 이 주사위에서 발동하지 않으므로 실제 난수 전투에서는 보호가 더 클 수 있다.

종려 E의 실제 재사용 대기는 본인 차례 2턴이고 방패 지속은 2라운드다. 생성 라운드 END에는 지속시간이 줄지 않으며, 같은 출처 갱신은 남은 값과 새 값 중 큰 값을 사용한다. 진 Q는 5턴이다. 레벨 50·60 특성/돌파 투자로 방패 절대량이 크게 커진다.

종려의 자체 생존 보정은 R1 완전 무피해, R2 50%, R3 70%, R4 90%, R5부터100%다. DEF, 진형, 수신 장비와 독립적으로 곱해진다. 전체 방패는 인접 단일 공격의 자동 엄호 30%도 켜므로 첫 라운드 종려에게 공격이 옮겨가면 실제 피해와 방패 소모가 둘 다 없다.

수호 진형 + 지원 역할은 방패 생성1.344배와 받는 피해0.88배를 동시에 제공한다. 이 조합의 방패 유지력은 연계 진형 대비 약1.527배다. 두 캐릭터를 함께 넣으면 단순히 회복량만 낮추는 조정으로는 무손상 방패 순환이 해소되지 않는다.

공략 압력 후보는 기존 보스의 공격·페이즈·동일 대상 연속 공격을 먼저 검토해야 한다. HP만 늘리면 방패 재사용과 치유 재사용 횟수도 늘어난다. 전역 치유·방어 너프는 일반 비경의 음식·숙박 비용을 바꾸므로 이번 보스 개선에서 분리해야 한다. 공격력의 일괄 큰 배수는 방패가 없는 4성 편성부터 전멸시킬 수 있어, 실제 동일 투자 비교와 공략 행동으로 피할 수 있는 압력이 함께 필요하다.

4성 풀돌 일반 편성이 약하다는 결론을 전체 4성 편성으로 확장하면 안 된다. 디오나 C2, 달리아 전체 방패/재생성/C6, 북두 C1·Q, 행추 Q의 지속 피해감소 조합은 별도 확인해야 한다.

진행중 전투에는 기존 HP·ATK·방패·장판·쿨다운·난수를 보존해야 한다. 변경된 보스 한정 지원 배율을 검토한다면 최초 행동 전 신규 표시/수치 스냅샷과 구저장 중립 처리부터 설계해야 한다. 기존 healingBalanceRevision은1만 허용하므로 임의로2로 승격하면 저장검증이 깨진다.
