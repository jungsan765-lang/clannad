# 0.16.23 필드·일일보스 난도 위계 — 동일 장비 작은 비교

제목의 0.16.23은 점검 작업명이며 제품 버전 변경을 뜻하지 않는다.

읽기 전용 추가 2조건. Lv30 필드 보스, 주인공 명함+4성 동료 셋 풀돌 및+5성 동료 셋 명함을 실제 PLACE_ENTER→BOSS_ROUTE DIRECT로 입장해 실행했다. 제품·기존 필드18조건 폴더·기존 일일8조건 폴더는 편집하지 않았다.

|현재 소스 표본|4성 풀돌 · 라운드/HP/가정시간|5성 명함 · 라운드/HP/가정시간|
|---|---|---|
|필드 FB_CRYO_HYPOSTASIS Lv30|6R / 90.55% / 125.24초|6R / 100% / 86.72초|
|일일 BOSS_ANDRIUS Lv25|3R / 79.06% / 44.22초|4R / 87.61% / 64.13초|

이 세 행은 같은 동료 편성(4성 향릉/피슬/바바라, 5성 종려/다이루크/진), 제작 무기·가죽 갑옷+10·상한10, 회복 장신구+0, 성유물/전용무기/보스장비/음식0, 기본 특성 상한(풀돌 C3/C5 추가는 실제 해금), seed717, 처음 한 번만 HP100%, 같은 주인공 Q/E/기본 우선 정책과 원래 균형 동료AI다. 일일 Dvalin의 실제 공중길 행동만 그 보스에 고유하게 사용했다. 배우 능력치나 원소 면역·기믹을 직접 바꾸지 않았다.

필드 추가 2전 모두 승리·KO0·패배0·입력상한0·오류0. 실제 입력122개 변경0이며 일일8조건의122개 입력SHA와 차이0이다. 실제 필드 적 Lv30 HP25,550/ATK1,509/DEF294, behaviorRevision3, 냉기핵4/4 파괴와 최종 정산을 로그로 확인했다. 현실12시간 토벌상한은 입장시0승, 승리후1승/잔여2로 정상 소모했다.

최초 실행에서는 PLACE_ENTER 단계를 누락하여 2조건 모두 기존 장소 진입 규칙으로 거절됐다. 전투를 시작하지 않았고 이를 승리나 패배로 세지 않는다. 원자료를 sibling `field_daily_hierarchy_entry_required_attempt/`에 그대로 보존한 뒤, 공개 PLACE_ENTER 행동만 추가하고 동일 2조건을 다시 실행했다. 제품 변경이나 입장 검증 완화가 아니다.

현재 이 준비 표본은 필드 보스가 일일 중 두 보스보다 라운드·입력 가정시간이 길다. 일일이 모든 필드보다 어렵다는 기대를 이 결과가 뒷받침하지는 않는다. 하지만 종과 고정레벨이 다르고(25/28/30), 보스 기믹·공중길·부활 마무리·피해분포도 다르므로 정확히 같은 적을 비교한 난도비율, 모든 동레벨 편성 승률 또는 전체 일일보스의 난도 결론으로 확대하지 않는다. 이전 필드+3/+6 결과와 이번 일일+10 결과를 직접 비교하지 않았다.

동료 자동공격으로 냉기핵을 처리했고 플레이어는 보스 전용 최적 수동 대응을 하지 않았다. 소유·육성·진단자금·이야기 해금 준비물로 만든 계정이며 자연 신규 계정 획득 완주나 수동 공략의 즐거움 검증이 아니다. 표시시간은 연출2배속ms/1000+조작3초+정산6초, 실제 CPU 실행은 두 조건 각각약0.22초/0.13초이며 사람/네트워크 지연을 제외한다.

사용자의 최종 목표는 동레벨 4성 풀돌·5성 명함도 일일보스를 공략에 맞춰 깨야 한다는 것이다. 일일 보상 수급이 가능하다는 결과는 그 공략 요구 난도를 달성했다는 증거가 아니다. 이번 표본에서는 단순 우선 행동과 균형 동료AI로 일일 승리가 났으므로 필수 수동 공략이 성립했다고 판단할 수 없다. 5성 C1·C2·풀돌 편성은 실행하지 않았으므로 해당 투자 단계의 격차와 적절한 보상감도 미측정이다.
