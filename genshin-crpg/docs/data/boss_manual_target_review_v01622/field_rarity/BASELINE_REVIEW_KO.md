# 0.16.22 네이티브 동레벨 보스·운명의 자리 기준선

제품 소스·기존 봉인 근거는 수정하지 않았다. 두 네이티브 프로세스를 순차 실행했고 12조건에 오류 0, 실행 전후 실제 입력파일 SHA 차이 0이다.

## 비교 조건

- 여행자 C0 + 동료 3인, 보스와 같은 레벨. 4성은 향릉·케이아·바바라, 5성은 종려·다이루크·진.
- 같은 정식 돌파, 제작 무기·강화 가죽 갑옷·회복 브로치, Lv20 +3 / Lv30 +6, 기본 특성65%cap(Lv20 1 / Lv30 2), 성유물·음식·전술도구 없음.
- C6는 실제 운명의 별 지급→CONSTELLATION_UNLOCK 6회. C2도 같은 공개 해금. 주인공은 C0 고정.
- 같은 팀 C0/C6 사이에서 실제 초기 HP·ATK·DEF와 장비가 동일하다. 실제 운명의 자리 기술+3와 네이티브 효과가 적용된다. 다른 등급의 팀끼리는 캐릭터 구성 자체가 다르므로 등급 하나의 독립 효과로 해석하지 않는다.
- initial full HP는 지속 상태에서 한 번만 적용. 전투 3번 자리의 최대HP +5%는 현재 엔진에서 현재HP를 함께 늘리지 않으므로 초기 최소HP95.24%가 생길 수 있다. 이는 적 공격으로 잃은HP가 아니다.
- GENERIC은 공개 주인공 Q→E→평타, 동료 네이티브 AI. GUARD_ONLY는 주인공이 계속 방어만 해 동료 AI의 완료 여부를 보는 조건. 입력 없이 돌아가는 AFK 검사는 아니다.
- 80개 공개 입력 한도에서 종료하지 않으면 INPUT_LIMIT이다. 실제 패배와 합산하지 않는다.

## 판단에 도움이 되는 원인

1. 4성 C0는 두 준비된 동레벨 조건에서도 generic 실제 패배. 이것만으로 올바른 수동 공략이 가능하다는 증명은 아니다. 특히 이 팀의 얼음 보스는 면역인 케이아가 포함돼 있고 특성65%·무성유물이다.
2. 4성 C6는 얼음 보스 11라운드 generic 승리·76.22%HP. C6 향릉의 실제 지속 공격이 냉기 핵 4히트 조건을 자동 수행했다. 요구된 ‘4성 풀돌도 수동 대응 필요’ 목표의 반례다.
3. 4성 C6 바바라 포함은 뇌전에서 81라운드까지 회복과 피해가 거의 상쇄되지만 핵을 제때 끝내지 못해 정체. 생존이 편해지는 문제와 핵 공략 실패가 별도다.
4. 5성 종려·다이루크·진 C0 얼음 조건은 적→아군 HP 피해 0 / 방패 흡수39,626, 회복427이며 HP100%로18라운드 완료. 이 조건의 무숙박 원인은 힐보다 지속 보호막이다.
5. 5성 C2/C6는 실제 같은 팀·장비 조건에서 C0보다 크게 빨라진다. 얼음18→6→5라운드, 뇌전guard 정체81→승리28→승리10라운드. 운명의 자리 값은 나오지만 수동 핵 대응을 요구한다고는 말할 수 없다.
6. 단순 돌파 재료 효율 축소는 승리 후 장기 수급 속도만 줄인다. 현재 한 전투 안에서 핵이 자동 수행되는 구조·보호막 상쇄는 고치지 못한다.

## 한계와 다음 단계

- 모든 레벨·모든 보스·최적 편성·수동 숙련도를 대표하지 않는다. 시드717 단일 샘플이며 다른 시드는 미실행.
- manual policy로 캐릭터 기술을 직접 executeCard 호출하는 조작은 사용하지 않았다. 주인공만 조작 가능한 현재 공개 입력에서 여행자는 핵에 맞는 원소를 공급하기 어려운 조건이 있고 이세계인 합동 공격의 수동 타이밍은 아직 측정하지 않았다.
- 결과를 직접 난이도 숫자 목표로 삼기 전에 적정 특성cap/유리한 4성 편성, 이세계인·여행자의 실제 공개 수동 입력으로 핵·예고·노출 대응을 따로 비교해야 한다.
- 모델 2배속 시간은 presentation ms/1000 + 주인공 입력3초 + 종료6초 가정이며 CPU벽시계와 다르다. 상세 summary에 둘을 분리 기록했다.
- 적발 피해는 applyDamage에서 ENEMY→ALLY로 관찰한 패킷의 실제 HP/방패 감소이다. 자해·초기 자리HP 차이를 적 피해로 합산하지 않았다.
