# 원소별돌파·주인공·성급읽기근거

[사용자화면과설계검토](../../../ASCENSION_ELEMENT_REVIEW_V01620_KO.md)를먼저읽는다. 읽기전용실험이며제품보상/요구량/DB/UI를변경하지않았다. 실제견적210개·보상96개·주인공결제/재로드/동일요청12개는`native_quotes.json`,요약은`summary.json`이다.

Lv25번개6/불21은기존원소별고정보상표이고캐릭터성급과무관하다. 요구량을같이늘려최고단계기본승수의일부기준을맞췄지만전체소요시간공정성은입증하지못한다. 같은등급수량의직관이깨지며불Lv25의21→Lv30의18로표시량이줄어드는문제도있다. 이화면은출력버그가아닌설계검토사항이다.

`minimal_verification.json`:235baseline파일바이트/Gitblob복원검증,구/신4정책함수/상수의문자일치,보존견적/보상/결제수의검증,화면수량과역전을확인했다. 전체210견적을또실행한기록이아니며0.19이후전투시간은다시측정하지않았다.

포터블`audit.cjs`는`--source-root`/`--out`를지원한다. 원래실행코드와기존helper는`original_*.cjs.gz`로정확한원문보존하며변경포터블도구와별도SHA를기록한다. 비용정책만확인하려면`verify_read_only.py`의인자안내를따른다. `provenance.json`의기존실행과포터블변환시점을구분한다.
