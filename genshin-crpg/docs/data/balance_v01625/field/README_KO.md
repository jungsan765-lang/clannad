# 0.16.25 보호막·치유 후보의 필드보스 검증

이 폴더는 제품 반영 전 후보 비교다. 최종 적용 수치와 새 기술 시전자 귀속 수정 검증으로 읽으면 안 된다. 원점은0.16.24 최종162조건의 같은 시드717을 골랐다. 각 후보는9보스×4성 명함/5성 명함×반복/수동=36조건이다. 각 전투는 고정4인·동레벨, 합법 돌파 단계·기본 특성상한, Lv35 미만 제작+3/이후+6·상한10, 성유물/보스장비/전용/음식0이며 실제 균형 동료AI를 사용한다. 해금·소유·돈을 지급한 진단 표본으로 자연 계정 획득 완료 보장이 아니다.

약 후보는 대부분98~100%로 끝나 회복 부담을 충분히 만들지 못했다. 강 후보에서도 바위·얼음 나무·유적의 뱀 같은 일부 표본은 여전히 거의 완치다. 이 결과를 모든 보스에서5성명함 수동 공략이 강제됐다고 해석할 수 없다. 원점 4성 명함은 수동9승(KO1), 반복6승3패(KO11)이고 모든 후보에서 그대로다.

무상의 바람은 근접 종려/다이루크/진과 활 이세계인 편성의 공중 핵2라운드에 Q 재사용 대기·명중 타이밍이 겹치면 부활이 반복된다. N15/N12 기존 수동은81라운드 입력상한, N3E25는55라운드 승리였다. `anemo_core_save/`는 부활 핵 우선 및 HP40% 아래 주인공Q 저장이라는 별도 공개 행동 정책이며 기존 MANUAL과 합산하지 않는다. 원점31/53/45라운드 승리, N3E25는34승/시드19의456라운드 주인공KO 패배/14승이었다. 새 정책은 원점에서도 좋지 않았으므로 선택안의 수동 대응 성공 증명으로 쓰지 않는다. 적합한 원거리 편성의 추가 검증이 필요하다. 보스 기한이나 소환체 수치는 이 실험에서 바꾸지 않았다.

`CANDIDATE_INPUTS.json`은430개 입력의 해시와 후보별 변경2파일을 기록한다. `CANDIDATE_COMPARISON.json`은 원점과 같은 조건별 차이다. 압축 native 원장은 당시 행동·상태·최종HP·KO·로그를 보존한다. 5성 불 나무는 물/얼음 대응을 위해 감우/모나/진 편성이다. 다른 대부분5성 표본의 종려/다이루크/진과 섞어 종려 너프의 인과로 해석하지 않는다. 기존0.16.24 원장은 수정하지 않았다.

`anemo_ganyu/`는 적합 원거리 편성의 별도3시드 대조다. 종려/감우/진과 활 이세계인의 같은 준비를 원점/N3E25에서 각각3시드×반복/수동6조건으로 비교했다. 양쪽6승·KO0, 원점8~13라운드/N3E25도8~13라운드였고 N3E25 수동 종료HP92.3~100%, 반복98.9~99.2%였다. 이는 강 후보가 무상의 바람5성 명함 전체의 수급을 막지는 않음을 보여 준다. 근접 다이루크 편성과 결합해 수동 정책만의 효과나 모든 조합의 통과를 주장하지 않는다.
