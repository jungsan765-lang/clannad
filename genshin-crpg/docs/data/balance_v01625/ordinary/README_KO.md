# 0.16.25 보호막·치유 후보의 일반비경 연전 검증

제품 반영 전 후보이며 최종 시전자 귀속 오류 수정은 아직 포함하지 않았다. Lv10/20/30/40/50/60에서 실제 공개 DOMAIN_START→COMBAT_BEGIN→여행자Q/E HOLD/평타와 균형 동료AI로 EXP·TALENT 각각2회 연속한다. 처음만 만피이며 중간 음식/숙박/HP 초기화를 하지 않았다.5성 명함은 종려/다이루크/진,4성 명함 대조는 노엘/향릉/북두다. 장비는 제작·상한10, 기본 특성은 합법 단계 상한, 성유물·전용·보스장비·음식·별자리0이다. 해금·소유·모라를 지급한 진단이며 자연 진행 완주 증명은 아니다.

`BASELINE/N3E25/N3E30`은 전원+10으로 이전 회복 검토를 반복했다. 각24조건46전투이며5성 명함24/24승리·KO0, 오류0·입력변화0이다. `AUTO_BASELINE/AUTO_N3E25`는 Lv35 미만+3/이후+6으로 같은24조건46전투를 비교했다.5성 명함24/24승리이며 N3E25의 Lv20특성 두번째에서 주인공만KO가1회 있었다. 첫12전투는 모두 승리·KO0이다.

Lv20 두번째 KO는 첫 비경 진입 불가나 전원 패배가 아니다. 이전0.16.24 강 폐기후보에서도52전투는 전승이었고 두번째 연전의 주인공KO만 있었다. 이번 N3E25 +3 표본도 첫회 승리 후 회복 없이 재도전하면 주인공KO가 생겼지만 동료가 전투를 마쳐 승리했다. 이 연전 위험은 음식/숙박 압력으로 볼 수 있으며 그것만으로 너프를 기각할 수 없다. 전투 직전·보상 전 native KO와 전투 후 자동10% 부활 저장HP를 각각 기록했다.

4성 명함 대조의 모든 전투/HP/실제회복량은 원점과 완전 동일하다. 단 원점부터20특성·60EXP의 첫패배, 다른 일부 연전 패배가 있다. 이는 이 비힐 편성이 모든 일반비경을 보장하지 못한다는 제한이며5성계수 너프가 새로 만든 장애가 아니다. 일반 모든4성 조합의 진입 가능을 주장하지 않는다.

회복량 합계만 보면 보호막이 약해져 실제 손실HP가 늘면서 실현 회복량이 증가할 수 있다. 계수·실제HP·KO·승리·숙박 견적을 함께 확인한다. `innQuote`는 그때 실제 대상별 레벨과 손실 비율로 구한 기존 견적이며 실행한 숙박 지출이 아니다. 전원 만피에서도 서비스 최저20Mora 견적이 나오지만 숙박을 이용할 필요는0이다. 숙박 가격·음식 효율·보상/요구량·적수치는 후보에서 변경하지 않았다.
