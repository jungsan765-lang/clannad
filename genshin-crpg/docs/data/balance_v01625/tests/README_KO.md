- 백출 E: 신규 전투 기본 MAX_HP 계수 3%, 무표시 구전투 8%. Lv10/30/60에서 실제 아군 4명에게 회복하고 기존 특성·리듬·편성 효과를 한 번씩 적용한다.
- 관리자 카드 배율: 종려 보호막/Q 피해, 진 즉시/저장 영역 회복, 백출 신규·구전투 E 회복에 2배가 한 번만 적용된다.
- 실제 0.16.24 공개 안드리우스 입장의 C0/C2/C6 PENDING/WAIT 저장, 종려·진 기존 효과 저장 및 다음 영역 회복을 보존한다.
- 실제 0.16.24 공개 Lv60 야타 입장의 PENDING, WAIT_PLAYER, 백출 AI가 실제 E를 사용한 뒤 WAIT_PLAYER 저장을 신규 엔진에서 불러온다. 전체 전투·전체 저장·RNG·쿨다운·다음 실제 공개 행동 결과를 구버전과 비교한다. 마지막 사례에서는 자연 발생한 다이루크 HP 결손 1,640을 실제로 회복했다.
- 바바라/디오나/노엘 자체 회복·보호막·쿨다운이 유지된다. 노엘 E 리듬이 결정 보호막에 잘못 붙던 누수의 제거는 별도로 표시하고 동일하다고 주장하지 않는다.

## 구버전과 생산 환경의 비교 방법

`../source_before/manifest.json`의 원본 7파일을 현재와 동일한 나머지 모듈에 덮어 읽는다. 엄격 검사에서 이 전체 구버전 소스/DB 지문이 기록된 0.16.24 엔진 `840ef8955b08346d086de5b39ab87d918123ab4ce2dc0c292f080827fc4bafdc`와 같음을 확인했다. 현재 최종 엔진 지문은 `aeb110f1cb71c11b2d515e71c1a8f24189463d09eb26fd9959afe10b576aadd1`이다.

소스·브라우저 테스트 로더에는 서버 생성기의 기존 `CRPGRelationships.install` 생산 부트스트랩을 똑같이 적용한다. 구버전 로더에도 동일하게 적용한다. 이전 3엔진 실행에서 서버에만 `relationshipSchemaVersion:1`이 생긴 차이가 있었으므로 이 테스트 로더 차이를 바로잡았으며, 전체 상태 비교 assert는 유지했다. 제품 관계 코드나 저장을 임의 수정하지 않았다.

`character_contracts_final.json`의 39개 결과는 백출 추가 조정 전 중간 동결 결과다. 초기 실패와 준비 수정 결과 역시 덮어쓰지 않고 보존한다. 현재 최종 판단은 `character_contracts_final2.json`을 사용한다.

## 재현

저장소 루트에서 실행한다.

```sh
node --max-old-space-size=512 tests/test_character_balance_v01625.cjs --out /tmp/character_contracts_v01625.json
```

기본 검사는 실행 환경의 동일한 실제 DB로 구/신규 엔진을 비교하며 DB를 대체하지 않는다. 기록된 QA DB/구버전 전체 지문까지 강제하려면 `--require-recorded-qa`를 추가한다. 최종 QA는 이 엄격 옵션으로 실행했다. QA DB SHA256: `254c9294c7787b421f38c84b3ad8fed9f00c207a8ef74855868c0cda48dc0962`.

테스트 SHA256: `1f17e24e6cdab263a4f33b6729e4ab3e01f0f51264b6fe6c19b87fb3dcc565db`.

이 검사는 수치/효과/저장 호환 계약이다. 직접 `executeCard`를 쓰는 계수 검사에는 공개 턴 순서가 적용되지 않으며 승리를 강제하지 않는다. 공개 후반 저장 검사는 일반 제작 장비 +6만 선언하고 전투 행동은 기존 공개 API로 실행했다. 자연 육성에 드는 시간·재료 수급·보스 조합별 승률은 다른 전투/경제 원장으로 판단해야 한다.
