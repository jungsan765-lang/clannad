# 0.16.19 확정 반응 오류 수정 · 구현 증거

기준: 보존한 0.16.18 소스(`/tmp/crpg_v01619_baseline/source`)와 현재 전체 런타임 로드 순서. 배포·버전·DB·경제·화면은 이 담당자가 수정하지 않았다.

## 수정 구간

| 파일 | 수정 |
|---|---|
| `source/runtime_rules.js` | 제어 적용 거부의 반환값, 확정 둔중 판정, 빙결 소비, 촉진·발산 가산 위치, 초전도 피해 면역과 약화 분리, 물로 연소 소화, 물 확산의 인접 피해 예외, 결정의 같은 원소 흡수 효율, 원핵 5개 상한 |
| `source/runtime_premium_v0148.js` | 공통 배율 중 특성 배율만 선택적으로 건너뛰는 내부 옵션 한 줄 |
| `source/runtime_mond_cards.js` | 유라 E의 두 스택 추가타에 `blunt:false` 명시 한 줄 |
| `tests/test_reaction_fixes_v01619.cjs` | 실제 원작 카드·기존 몬스터·실제 장비·적법한 특성/돌파 단계·저장된 다인 스냅샷을 사용하는 반응 회귀 검사 |
| `tests/test_control_grace_v01619.cjs` | 정상 제어는 충전을 즉시 끊고 거부된 제어는 충전을 보존하는 회귀 검사 |

`runtime_rules.js`의 진 Q 치유 구간은 다른 담당자가 동시에 소유한다. 파일 전체 재작성은 하지 않았고, 공유 파일을 문맥 패치로 수정했다.

## 실제로 바뀌는 동작

- 일반 적의 빙결, 보스의 기존 약한 제어, 공중 부양 상태가 실제로 등록되지 않으면 제어 실패를 반환한다. 이를 성공으로 오인하여 충전을 끊거나 다음 행동을 늦추던 오류를 막는다. 성공한 제어의 기존 수명·보스 규칙·두 번의 자유 행동 보호는 유지한다.
- 불로 융해한 적은 `STATUS_FREEZE`에서 벗어난다. 다시 얼리지 못하는 제어 보호 기록은 유지한다.
- 빙결 적의 쇄빙은 공격의 둔중 여부로 판정한다. 장착한 양손검의 일반 공격, 원소 부여된 동일 공격, 클레 일반 공격·E, 다이루크 E, 가명 E, 유라 E 본타·Q 최초/빛의 검, 바위 공격, 토끼 백작 폭발을 확인했다. 모든 강공·`HEAVY` 태그나 모든 양손검 E/Q를 같은 공격으로 취급하지 않는다. 가명 Q, 유라 E 스택 추가타, 일반 활·법구·한손검 강공 태그만으로 쇄빙하지 않는다. 다인 동료는 방장의 무기 대신 자기 무기 스냅샷을 쓴다.
- 기존 한 번에 반응 하나를 고르는 구조에서 확정 둔중의 쇄빙을 증폭 반응보다 먼저 선택한다. 실제 원작의 게이지별 쇄빙+융해/증발 복합 사례까지 새로 모델링하지 않았다.
- 촉진·발산은 `직접 피해 × 직접 피해의 특성 배율 + 레벨 기반 반응 가산` 이후 공통 치명·피해 보너스·방어 계산을 적용한다. 반응 가산에는 직접 피해의 특성 배율이나 `SKILL_COEFF`가 다시 붙지 않는다. 직접 피해의 정상 특성 성장은 유지한다.
- 초전도의 얼음 피해가 면역이어도 살아있는 대상에 물리 취약을 적용한다. 기존 게임의 25% 물리 피해 증가 수치는 유지했다. 이것을 원작의 물리 내성 -40%와 같은 수치라고 설명해서는 안 된다.
- 물 확산은 직접 확산을 일으킨 대상에 물 반응 피해를 준다. 인접 대상에는 물 부착·후속 반응만 전달한다. 다른 원소 확산의 인접 피해는 유지한다.
- 물이 연소 상태를 제거하므로 이미 등록된 연소 피해가 계속 틱하지 않는다. 해당 물 공격이 원래 일으키던 증발 등은 유지한다.
- 일반 결정 보호막은 같은 원소 공격에 보호막 자원을 0.4배 사용하여 2.5배 흡수한다. 다른 속성에는 기존 1배를 사용한다. 신규 보호막에 기존 `damageMultipliers` 메타데이터를 전달하고 저장된 예전 보호막을 일괄 재작성하지 않는다.
- 활성 원핵은 모든 소유자 합계 5개다. 여섯 번째 생성 시 기존 객체 배열에서 가장 먼저 만들어진 원핵을 기존 `detonateCombatObject`로 폭발시키며, 원래 소유자·생성 당시 반응 기준값을 유지한다. 오래된 6개 저장은 로드 시 바꾸지 않고 다음 생성 시 상한을 맞춘다. 토끼 백작·클레 지뢰 등 다른 객체의 상한을 바꾸지 않는다.

## 검증 범위와 수치

1. 반응 회귀 기본 42개 전부 통과 (`results.json`, `run.log`). 여기에 실제 유라 HOLD 본타/두 추가타의 둔중 분리를 단독 검사한 1개를 추가했다 (`eula_followup.json`, `eula_followup.log`). 최종 테스트 파일에는 합계 43개가 들어 있다.
2. 촉진·발산은 Lv.30/50/60에서 허용되는 기본 특성 1/4/7/10을 모두 비교한다. 직접 피해는 특성에 따라 늘어나며, 같은 레벨의 반응 가산분은 특성과 무관하다. 적법한 C3/C5로 상승한 유효 특성 13과 실제 다인 스냅샷 저장 복구도 검사했다.
3. 별도 C6 치명·방어력 감소·캐릭터 피해 보너스 검사가 정상 공통 배율의 보존을 확인한다. 일반 치유·장비/적 공격 수치 조정에 관한 검사는 해당 담당자의 자료를 함께 봐야 한다.
4. 기존 원소 면역 회귀 41개와 기존 반응/운명의 자리·다인 검사 14개는 전부 통과 (`immunity.log`, `control_reactions.log`). 제어 전용 신규 10개와 기존 몬스터 13개 통과 결과는 `/tmp/crpg_reaction_plan/control_grace_v01619/results.json` 및 기존 검사 로그에 있다.
5. 이전 소스를 읽기 전용으로 주입하는 반례에서 Lv.60·기본 특성 4의 촉진 피해는 기대 3,601에 실제 4,452로 실패한다 (`counterfactual_additive.log`). 수정 후 직접 피해 특성 성장을 보존하면서 가산분의 중복 배율만 빠진다. 기대식은 신규 `skipTalentMultiplier` 옵션에 의존하지 않고 정상 공통 배율에서 특성 배율을 나누어 독립 계산한다.
6. 제품 세 파일·검사 파일의 구문 및 문맥 diff 공백 검사가 통과했다. 파일별 SHA-256은 `sourcehash.json`에 남겼다. 다른 담당자의 변경 또는 최종 빌드 뒤에는 root가 최종 소스 해시를 다시 남긴다.

## 의도적으로 하지 않은 것

감전 선지급·주기·총량을 바꾸지 않았다. 과부하 2, 감전 1.2, 초전도 0.5, 쇄빙 3 등 이 게임의 현재 기본 반응 계수를 그대로 두었다. 원작의 최신 변환 계수 표를 전부 교체하지 않았다. 풀원핵 자해/초 단위 피해 상한·복합 원소 게이지·원소 마스터리·새 달/별 캐릭터·새 반응 시스템도 추가하지 않았다. 이 작업은 확정한 동작 오류 수정이지 모든 캐릭터/모든 조합의 승률이 같다는 증명이 아니다.
