# 0.16.19 — 치치·한운·요요·디오나 회복 검증

이번 조정은 후반 공격력·최대 HP에 비례해 과도하게 커지던 기존 회복식을 낮은 비례 계수와 고정량으로 바꾼 것이다. 한운과 디오나의 지속 회복은 HP 비율이 가장 낮은 살아 있는 아군 한 명에게 집중한다. 피해·특성 비용·보상·숙박 요금은 이 회복 조정으로 변경하지 않았다.

## 적용 수치

아래는 특성·치유 보너스·실제 잃은 HP를 적용하기 전 회복 기본값이다. 로그의 `requested`와 실제 회복된 `applied`를 구분한다.

| 동료·기술 | 이전 | 0.16.19 | 대상·발동 |

| 치치 원소전투 스킬 | ATK × 0.55 | ATK × 0.13 + 350 | 라운드 종료에 가장 부상한 아군 1명. 치치가 그 라운드에 직접 피해를 주면 기존 25% 증가 유지 |
| 치치 원소폭발의 부적 | ATK × 0.45 | ATK × 0.10 + 295 | 부적이 붙은 적을 직접 공격한 아군 자신. 각 아군의 라운드당 1회 제한 유지 |
| 한운 원소폭발 즉시 회복 | ATK × 0.80 | ATK × 0.03 + 1,250 | 살아 있는 아군 전체 |

소환·상태·영역에 새 회복 계수와 고정량을 저장한다. **이미 진행 중이던 옛 저장의 효과에 새 메타데이터가 없으면 이전 회복식과 이전 대상 수를 유지한다.** 기술 정보는 기존 행을 복사해 현재 수치로 표시하며 원본 DB와 서명 검증은 보존한다. 지속 회복 대상은 사망한 아군을 포함하지 않는다.

## 최종 제품에서 확인한 결과

여행자·향릉·피슬·검사 대상 동료의 고정 4인, 모두 C0, 단조 무기·강화 가죽 갑옷·치유 장신구 +6, 성유물과 전용 무기 없음. 네 명의 레벨을 동일하게 25/50/60으로 설정하고 합법적인 돌파 단계와 특성 4/5/6을 적용했다. 동료는 기존 균형 AI, 여행자는 실제 `COMBAT` 행동을 사용한다.

한 번만 완전 회복한 뒤 숙박·음식·레벨/HP 초기화 없이 실제 전투와 보상을 이어 간다. 패배하면 중단한다. 레벨업·전투 중 능력치·승리 시 주인공의 기존 10% 부활·난수의 소모는 원래 처리대로 진행한다.

### 한운의 어려운 경험치 비경

특성 비경의 짧은 전투에서는 한운이 여전히 전원 HP 100%를 유지하는 조건이 있다. 이를 조정 실패로 숨기거나 모든 전투에 숙박을 강제하지 않고, 실제 다른 적 편성의 경험치 비경에서 최대 8연전도 확인했다.

`current_final_exp`는 **Lv50/60 × 시드 717/925 = 4조건**이다. Lv50은 `DOMAIN_OF_GUYUN:50`, Lv60은 `LOST_VALLEY:60`의 기존 편성이다. 최종 실제 **25전 23승 2패**, 오류 0. 0.16.18의 `cloud_exp_base`는 **4조건 32전 32승**이었다.

| 레벨·시드 | 이전 최대 8연전 | 최종 최대 8연전 | 최종 저장 HP / 완료 후 가상 숙박 견적 |

| 60·925 | 8승 | 3승 뒤 4번째 전투에서 패배 | 실패 조건이므로 효율 견적에서 제외 |

첫 전투는 네 조건 모두 이전·최종 승리다. 최종 Lv60 결과는 음식·숙박 없이 계속 누적시킨 결과이며, 이 조건에서 적정 회복 없이 8연전을 보장하지 않는다. 반대로 쉬운 특성 비경에서는 좋은 조합과 회복으로 숙박이 필요 없는 경우가 남는다.

### Lv25 요요 패배의 분리 확인

최종 엔진의 원소 반응·적·AI·장비를 그대로 두고 **요요의 회복식만** 이전 Q 10%·월계 5%로 되돌린 격리 VM을 추가 확인했다. `current_legacy_yaoyao_only`의 **2조건 6전은 4승 2패**로 새 회복식과 똑같이 세 번째 연전에서 패배했다.

이 조건의 요요 최대 HP 5,021에서 Q의 기본 회복은 이전 502.1 → 현재 505.525, 월계는 이전 251.05 → 현재 255.315다. 이 레벨에서는 기본 회복량이 소폭 증가했다. 따라서 해당 두 패배를 **요요 회복량 하향 때문에 발생했다고 쓰면 안 된다.** 0.16.18 전체 엔진과의 비교에는 원소 반응 오류 수정도 포함되어 있다. 어느 반응 수정이 전체 승패 차이를 만들었는지까지 하나씩 분리한 결과는 아니다.

## 분모와 한계

- 최종 네 동료 특성 비경 24조건·72전과 한운 경험치 비경 4조건·25전은 서로 다른 내용이다. 합치면 최종 제품 28조건·97전·92승5패지만, 그 합계로 특정 동료의 승률이나 하향률을 계산하지 않는다.
- 같은 시작 HP·장비·특성·시드와 첫 전투 적 능력치는 공통 24조건 모두 같았다. 반응과 전투 길이가 바뀌면 이후 난수와 다음 전투의 실제 적 추첨은 달라질 수 있다. 매 공격의 난수를 강제로 고정한 비교가 아니다.
- 한 조건 안의 전투는 이전 HP를 이어 받는다. 각각 독립적으로 완전 회복한 72개의 전투가 아니다.
- `koBattles`는 전투 종료 직전 한 명 이상 HP 0인 **전투 수**다. 사망한 캐릭터 수가 아니다. 승리 영수증 뒤의 주인공 10% 부활과도 구분한다.
- 치유 장신구 +6을 모두 장착한 진단 편성이다. 확보·강화 과정의 비용을 무료로 얻는 실제 경제 조건으로 해석하지 않는다. 시작 모라는 검사 재원이며 수익이 아니다.
- 측정 시간은 2배속 연출 시간과 수동 전투 입력 3초·결과/재입장 6초의 가정이다. 회복 왕복·재료 획득·네트워크·사람의 판단 시간을 포함하지 않는다.
- 백출·미카는 최초 36조건 참고군에만 포함한다. 이번 회복 수치 조정 대상과 최종 24조건의 분모에 넣지 않는다.
- 후보 자료의 `fingerprint`는 VM 치환 **전** 소스와 DB의 해시다. `substitutions`가 후보 수치를 구분한다. 이를 최종 제품과 같은 엔진이라고 쓰지 않는다.

## 저장된 파일과 재현

`manifest.json`에는 원본 gzip·요약·소스 관측 해시·역할과 조건/전투/승패 수를 기록했다. 기존 완료한 자료는 그대로 복사해 보존했다. `paired_talent_summary.json`은 공통 24조건을 비교하며 `yaoyao_legacy_isolation.json`은 위 분리 확인 결과다. 각 `native.json.gz`에 실제 시작 적 능력치, 행동 로그, 회복 함수 반환값, 저장 HP와 가상 숙박 견적이 들어 있다.

`native_checks.json`의 **14/14 검사**는 새 효과 저장 후 복구, 옛 효과의 회복량·대상 유지, 부적/추가 회복 횟수, 현재 기술 숫자, DB 원본 유지, 서명 위변조 차단과 종려 표시/실행 이중 축소 방지를 확인했다. 이 숫자는 연전 조건 수와 합산하지 않는다.

현재 소스에서 최종 제품 조건을 재현하는 명령이다. 새 출력은 기존 증거를 덮지 않도록 `/tmp`에 쓴다.

```bash
node tools/audit_other_healers_v01619.cjs --supports LIYUE_XIANYUN,LIYUE_QIQI,LIYUE_YAOYAO,MOND_DIONA --levels 25,50,60 --seeds 717,925 --runs 3 --out /tmp/crpg-other-healers-final-talent
node tools/audit_other_healers_v01619.cjs --supports LIYUE_XIANYUN --levels 50,60 --seeds 717,925 --runs 8 --domain-kind EXP --out /tmp/crpg-other-healers-final-exp
node tools/audit_other_healers_v01619.cjs --supports LIYUE_YAOYAO --levels 25 --seeds 717,925 --runs 3 --legacy-yaoyao-healing --out /tmp/crpg-other-healers-legacy-yaoyao
node tools/test_other_healers_v01619.cjs /tmp/crpg-other-healers-native-checks.json
```

0.16.18 재현은 고정 커밋 `1e1b2442b53d42873d29556898f5f612d52d0c7a`의 **별도 체크아웃**을 `--root`로 사용한다. 실제 빌드에 쓰인 DB를 맞추려면 그 별도 체크아웃에서 아래 전처리를 한다. 현재 작업 소스나 운영 DB에서 실행할 명령이 아니다.

```python
from pathlib import Path
import json, sys
baseline = Path('/tmp/crpg-0.16.18-evidence/genshin-crpg')
sys.path.insert(0, str(baseline / 'tools'))
from runtime_data import clean_runtime_db
p = baseline / 'content/db.json'
data, removed = clean_runtime_db(json.loads(p.read_text()))
p.write_text(json.dumps(data, ensure_ascii=False, separators=(',', ':')) + '\n')
```

현재 도구를 기준으로 같은 네 명을 실행하면 이전 공통 24조건을 새 디렉터리에 재현할 수 있다.

```bash
node tools/audit_other_healers_v01619.cjs --root /tmp/crpg-0.16.18-evidence/genshin-crpg --supports LIYUE_XIANYUN,LIYUE_QIQI,LIYUE_YAOYAO,MOND_DIONA --levels 25,50,60 --seeds 717,925 --runs 3 --out /tmp/crpg-other-healers-baseline
```

`--candidate-hybrid`, `--cloud-strong`, `--cloud-focused`, `--diona-hybrid`, `--diona-focused`는 이전 소스의 정확한 식을 VM에서만 치환하는 **보존된 후보 검사 모드**다. 최종 제품 소스에 이 모드를 실행하면 대응하는 이전 식을 찾을 수 없어 종료되는 것이 정상이다. 후보의 정확한 치환은 각 원본 `native.json.gz`와 `manifest.json`에 남겼다. 새 제품 수치를 탐색하거나 적용하는 도구가 아니다.
