## 원본·중간 기록·최종 빌드

`input_baseline.json`은 게시 기준0.16.25의 원격118런타임과 로컬 입력을 대조한 기록이다. `baseline/`에는 승인 네 소스의 실제 원본과 SHA, 수정 전 읽기 점검의 네 문서 헤더를 별도로 보존했다. 나머지114런타임은 변경하지 않았다. QA DB64테이블은 보호 원격 authoredDB와 의미가 동일하며 QA 원문을 운영 DB로 게시하지 않는다.

`engines/`는 별도 작업 폴더에서 만든 실제 정적 배포 스크립트와 서버 ESM 검증이다. 브라우저 배포 스크립트를 VM에서 실행하므로 화면 배치 검사가 아니다. 빌드 입력·출력 해시와 재현 스크립트는 해당 README를 따른다. 원본 작업 폴더에서 초기에 만든 두 소스 배포본은 최종 적용 파일로 사용하지 않는다.

`QA_ITERATIONS.json`은 최초 실패와 검사 입력 교정을 남긴다. `contracts_interim_run_6.json`, `review/INDEPENDENT_REVIEW_FINAL2.json`, `engines/preliminary2source/`, `native/final2/`는 중간 기록이며 최종 통과 수와 실제42회에 합산하지 않는다. 최종 제품 네 SHA와 최종 테스트 SHA가 일치하는 실행만 최종 근거로 센다. 과거0.16.24/0.16.25 검증은 이번 전체 밸런스 검사로 재사용하지 않는다.

## 남은 별도 사항

앱에서 호출하지 않는 옛 `TUTORIAL_DRILL` API는 시작 후 적 SPD를20으로 덮어 첫 점수와 불일치하는 기존 문제가 남는다. 수정 전후가 같고 현재 강제 이야기 튜토리얼 경로와 다르다. `review/OPTIONAL_LEGACY_DRILL.json`에 재현했으며 이번 네 소스 패치 밖의 후속 항목이다. 현재 화면에서 재현되는 튜토리얼 문제까지 모두 고쳤다는 뜻이 아니다.

이번 수정은 원래 잘못 집계된 연전 승리를 막고 기존 속도를 첫 순서에 반영한다. 모든 편성의 난도·수동 공략 재미·자연 계정의 장비/음식 수급 또는 실제 시장 경제가 완성됐다는 결론으로 확대하지 않는다. 게시 파일은 `tools/prepare_abyss_publication_v01626.py`의 명시 목록과 최종 원장으로 선별하며 DB·assets·UI 및 다른 AI 변경을 보존한다.
