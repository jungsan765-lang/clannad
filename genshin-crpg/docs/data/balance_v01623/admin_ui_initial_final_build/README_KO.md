# 최종 빌드의 운영자 화면·실제 API 검사

새로 생성한 **0.16.23 서버 엔진**과 실제 운영자 API·`:memory:` SQLite에 Chromium 운영자 화면을 연결했다. 별도 소스 모듈을 적재하지 않았으며, QA가 generated 소스를 고치지 않았다. `NATIVE_RESULT.json`의 13검사가 모두 통과했고 브라우저 예외는 0개다.

실제 로그인, 한국어 미리보기의 기본 HP244→1337 표시, 숫자 적용·운영자 메모 기록, 동시 변경의 실제 HTTP409와 초안 보존·재반영, 비경 재료 보상77의 실제 설정, 기록0 복구의 실제 SQL 저장 및 복구 원본 번호를 검사했다. 390×844 휴대폰에서도 HP1551 적용과 기록0 복구를 버튼으로 실행했다. 마지막 설정은 모두 기본값으로 되돌렸다.

`native_desktop.png`, `native_phone.png`의 실제 브라우저 화면을 직접 확인했다. 한글 글꼴은 캡처 환경에만 적재했고 제품의 글꼴·의존성·게임 화면은 바꾸지 않았다. UI 소스 SHA256와 실행된 최종 엔진 지문은 결과 파일에 있다.

이 검사는 로컬 메모리 SQLite 서버다. 실제 운영 서버 설치나 디스크 재시작 복구를 증명하지 않는다. 앞선 UI30검사 및 이전 엔진조건의 API13검사는 옆 `admin-ui/`에서 보존하며 서로 다른 원장으로 구분한다.
