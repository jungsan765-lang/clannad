## 휴대폰: 설치해서, 가로로 (`source/app_install_v01524.js`)

휴대폰(터치·호버 없음, 화면 짧은 변 600px 미만)만 해당한다. 태블릿과 PC 브라우저는 그대로 브라우저에서 한다.

**브라우저 탭으로 열면 게임 대신 설치 안내 화면**이 화면 전체를 덮는다(최상위 레이어, 뒤 화면 `inert`). 브라우저마다 실제로 가능한 방법만 보여 준다.

| 브라우저 | 실제 제약 | 안내 |
|---|---|---|
| 안드로이드 Chrome·Edge·삼성 인터넷 등 | 설치 가능 조건이면 `beforeinstallprompt`로 페이지에서 설치 창을 띄울 수 있다 | 「설치하기」 버튼 → 수락하면 「홈 화면의 아이콘으로 실행」 안내로 바뀜. 설치 창을 주지 않는 경우(이미 설치됨 등) ⋮ / ≡ 메뉴 단계 |
| 아이폰 Safari·Chrome·Edge | 페이지용 설치 API가 없다. 공유 메뉴의 홈 화면에 추가만 가능(iOS 16.4부터 다른 브라우저도) | 공유 버튼 → 홈 화면에 추가 → 「웹 앱으로 열기」 켠 채 추가. 홈 화면 앱은 저장 공간이 따로라 처음 한 번 로그인 |
| 카카오톡·인스타그램·페이스북·LINE·네이버 앱 등의 내장 브라우저 | 설치 불가 | 카카오톡 `kakaotalk://web/openExternal?url=`, LINE `openExternalBrowser=1`, 안드로이드 기타 앱은 Chrome intent로 「Chrome으로 열기」. 아이폰 기타 앱은 메뉴의 「Safari로 열기」 안내와 주소 복사 |

**설치한 앱(홈 화면 아이콘)으로 열면**

- `manifest.webmanifest`에 `"orientation":"landscape"`. 안드로이드 설치 앱은 가로로 열린다. 이미 설치된 앱은 Chrome이 매니페스트 변경을 반영할 때까지 이전 설정일 수 있다.
- 페이지가 `screen.orientation.lock('landscape')`를 요청한다. 안드로이드의 설치 앱·전체 화면에서만 허용되고, 거절되면 무시한다.
- 세로로 들면 「가로로 돌려 주세요」 화면(돌아가는 휴대폰 그림). 아이폰 웹 앱은 방향을 잠글 수 없어(매니페스트 방향 무시, `lock()` 미지원) 제어 센터의 화면 세로 방향 고정을 끄라는 안내, 안드로이드는 자동 회전 안내를 붙인다.
- 홈 화면에서 처음 열면 한 번 「설치한 앱으로 열었습니다 …」 문구.

**시험용:** 주소에 `?display=app`을 붙이면 브라우저 탭에서도 설치 앱처럼 동작한다(설치 안내 대신 회전 안내/게임). 플레이어 안내 문구에는 쓰지 않는다. 0.15.7의 제목 화면 「앱으로 설치」 버튼(태블릿용)은 이 시험 모드에서 숨는다.

## 가로 휴대폰 화면 (`source/landscape_v01524.css`)

`@media (orientation:landscape) and (max-height:500px)` 한 덩어리. 마지막에 읽는 스타일시트다.

- **세로 휴대폰 규칙 분리:** `shell.css`·`style.css`·`growth_v01522.css`의 `max-width ≤ 780px` 미디어 쿼리 69개에 `and (min-height:501px)`를 붙였다. `app_shell.js`의 `isMobile()`도 같은 조건(`MOBILE_QUERY`). 폭 640~760px 가로 휴대폰이 세로용 아래쪽 메뉴·접힌 지도를 쓰지 않고, 모든 가로 휴대폰이 같은 배치를 쓴다.
- **위쪽 막대 한 줄(44px):** 장소, 레벨 고리·HP 막대, 모라, 원석, 도구. 태블릿용 두 줄 막대 규칙을 덮는다.
- **메뉴는 왼쪽 세로 줄(54px):** 아이콘 + 짧은 이름. 높이 380px 이하에서 칸을 줄인다. 전투 중에는 세로 줄을 숨기고 화면 전체를 쓴다(전투 중엔 어차피 열 수 없다. 파이몬 메뉴는 위쪽에 남음).
- **메인 화면:** 왼쪽 장소·임무·시설(한 줄 목록)·대기, 가운데 지도, 오른쪽 목적지 한 줄 목록, 지도 아래 선택 목적지 + 이동 버튼(항상 보임). 첫 이동 화면의 「목록이 잘리고 이동 버튼을 찾기 어렵다」 제보 해결.
- **메뉴 화면:** 머리글 한 줄(설명 문단·영문 머리말 숨김, 하위 탭 같은 줄), 열은 옆으로 나란히. 편성 4칸 한 줄, 캐릭터 목록 칸 폭 조정.
- **이야기:** 인물 그림 뒤, 대사·계속 읽기·읽은 이야기·자동 재생이 한 화면.
- **결과 화면, 파이몬 메뉴(5열 작은 칸 + 아래 한 줄 버튼), 기원 화면(원작처럼 위 한 줄·배너·아래 버튼), 로그인 창, 일반 창**을 줄였다.
- 손보지 않은 화면은 아래 「남은 것」.

## 전투: 0.15.21 구도

- 0.15.22의 고정 1180×700 판 확대·축소를 없앴다(`app_battle_layout_v01522.js` 재작성, `growth_v01522.css`의 battle-fit 삭제). 0.15.21의 적 그림 중심 구도(적 가운데, 아군 오른쪽, 명령 아래)로 돌아간다.
- 적 1~4명 한 줄, 5~8명 두 줄. 실제 수에 맞춰 카드 크기를 나눈다(`data-count`·`data-rows`·`--cols`). 빈 8칸·빈 소환체 칸 예약 없음. 소환체 칸은 있을 때만 「아군 소환체 / 적 소환체」.
- 전투 중 페이지 스크롤 없음. 전투 기록·전투 정보는 머리글 버튼으로 창을 연다.
- **행동 순서는 얼굴 + 이름.** 그림 없는 이세계 주인공은 ✦ 표시. 라운드 재생이 목록을 다시 그릴 때(`followRound`)도 같다.
- 가로 휴대폰: 명령은 한 줄(누구 차례 · 기술 · 실행). 기술의 「효과」는 기술 칸 오른쪽 끝 작은 i. 대상은 적을 눌러 고른다(대상 목록 칸 숨김). 시작 전 줄도 한 줄. 재생 띠는 명령 줄 높이 안의 두 줄이라 적 이름·체력을 가리지 않는다. 두 줄 전투는 「정보」·「부착」을 둥근 배지로 줄인다.

## 튜토리얼: 엠버가 이끈다 (`app_tutorial.js`, `tutorial_v01523.css`)

- 강제 스포트라이트는 그대로. 안내문을 **얼굴이 있는 말풍선**으로 바꿨다. 여행자는 첫 이동~도착까지 페이몬, 엠버를 만난 뒤와 이세계인은 엠버. 얼굴은 공식 아이콘 `UI_AvatarIcon_Paimon` / `UI_AvatarIcon_Ambor`(enka.network/ui, 사용자 승인 「둘 다 받기」, `CREDITS.md`·`genshin-ui-assets.json` avatars).
- 단계마다 엠버의 대사: 편성 「슬라임이 길을 막았어! 나도 같이 싸울게…」, 장비 「아차, 나 활을 안 들었어!…」, 전투 「먼저 일반 공격!…」 등. 이야기 원고·사건은 바꾸지 않았다(튜토리얼 말풍선 대사만). 말투는 `VOICE_BIBLE.md`(엠버 밝은 반말, 페이몬 「~라구」).
- **위치(「위치를 잘 보고 해주고」):** 대상의 위/아래/좌/우 중 화면에 들어가고 지도 장소 이름·버튼·전투 카드를 가장 적게 가리는 쪽에 붙고, 꼬리로 대상을 가리킨다. 위쪽 막대와 가로 휴대폰의 메뉴 줄은 덮지 않는다. 대화 화면의 `.speaker` 금색 줄이 말풍선에 붙던 문제 수정(클래스 분리).
