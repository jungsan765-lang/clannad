# 0.16.21 전투·회복 재점검

전투에서 확정한 새 오류는 **노엘 C1/C6의 중복 회복과 호심경 없이 발동하는 회복**이다. 같은 타격이 두 번 회복하던 부분과 보호막 조건을 고쳤다. 성장 수정과 함께 레벨업으로 전사자가 부활하거나 생존자가 전부 회복되던 경로도 실제 전투로 다시 확인했다. 적 수치·반응 배율·다른 치유 계수는 이번 수정에서 바꾸지 않았다.

## 실제 바뀐 행동

노엘의 기존 DEF 25% 회복량과 라운드당 1회 규칙은 유지했다. 공식 원소폭발과 원소전투스킬의 동시 적용 조건을 확인했고, 기본 회복 훅과 C1의 라운드 가드를 공유하게 했다. 같은 라운드 재시전, 보호막 파괴, 타인의 보호막, 폭발 종료, 동료 전사, 저장 복원 등의 **새 회귀 7항목이 통과**했다. 기준본에서는 오류를 드러내는 5항목이 실패하고 정상 경계 2항목이 통과한다.

## 다른 시스템에 끼치는 영향

**회복 편성의 이익은 남는다.** 같은 레벨 특성 비경을 음식·숙박·HP 초기화 없이 최대 4회 반복했을 때 56조건 중 33조건은 전투 중 전사자 없이 4연승했고, 6조건은 마지막에 전원 최대 HP였다. 이는 선언한 편성·장비·별자리·시드의 결과이며 모든 힐러의 무조건 무한 승리를 뜻하지 않는다. 노엘을 포함한 공격 편성에서도 전멸 조건이 있었다. 실제 적용 회복과 초과 회복, 보호막으로 막은 피해를 분리했으며 숙박을 강제하려고 적 전체를 강화하지 않았다.

**레벨업 무료 회복은 육성 속도·음식·숙박을 함께 우회했다.** 새 규칙은 전투 승리 XP, 경험치 책 사용과 돌파 모두 같은 결손 HP 보존을 적용한다. 전투 영수증·XP·책 소비는 유지했고, KO 부활만 제거했다. 기존 주인공 승리 후 10% 부활과 패배 회복 경로는 별개로 유지했다.

**승률만 보고 적을 약화하지 않았다.** 돌파·특성 비경은 실제 전투 시간과 회복 비용을 포함한 성장 담당의 전후 비교로 보상과 요구량을 함께 조정했다. 고단계 원소 면역을 우회하지 않고 맞는 원소 편성을 사용했으며, 전투 수치가 같다는 사실을 별도로 검증했다. 음식·숙박·장비·수입 비교는 [경제 보고서](ECONOMY_AUDIT_V01621_KO.md), 연속 육성 시간과 재료 요구량은 [성장 보고서](GROWTH_AUDIT_V01621_KO.md)에 연결한다.

**5성 방어·회복 편성의 고레벨 적 생존 돌파는 일부 남아 있다.** 동일한 시드717·준비 장비 조건에서 4성 C0는 적 +20/+30의 12조건 전패였다. 추가 비교에서 4성 C6는 +20의 7조건 중 2승, +30의 5조건 전패였다. 종려·다이루크·진 C0 편성은 +20의 7조건 중 5승, +30의 5조건 중 1승이었다. +30 승리는 Lv26→Lv56 유적의 뱀, 40라운드·주인공 전사·최종 파티 HP 72.5%였다. Lv10→Lv30 무상의 얼음은 95라운드였다. 높은 적을 못 잡는다고 단정하거나 이 결과를 짧은 시간 무손실 파밍으로 설명하지 않는다. 원소·보호막·보스 기믹이 다른 편성을 비교한 것이므로 4성 풀돌과 5성 명함의 순수 등급 격차를 분리한 실험도 아니다. 고레벨 보스의 장시간 생존 편성은 후속 실제 세이브 관찰 대상으로 남긴다.

## 남겨 둔 한계와 인수인계

414카드 중 104종은 직접 실행, 6종은 단계·패시브 로그만 확인, 87종은 지원 판정이지만 직접 미실행, **217종은 현재 엔진에서 정적 미지원**이다. 미지원 카드를 사용하는 해당 그룹은 입장 전에 거절되거나 현재 합법 AI 참조에 없다. 원문 `READY`만으로 구현 완료라 판단하지 않았다. 75몬스터 행은 현재 초기 그룹·멤버 참조가 없어 동적 검증에 포함되지 않는다. 각 이름·ID·사유·근거는 전수표에 남겼다.

준비된 고정 4인 편성의 진단 결과다. 신규 계정의 자연 해금·획득, 모든 이야기 갈래, 나선 12층 전 층, 모든 캐릭터 조합을 완주한 결과는 아니다. 실제 사용자 세이브가 없어 그 파티의 승률이나 숙박비를 보증하지 않는다. 미지원 원본 콘텐츠를 이번 밸런스 패치에 섞어 새로 구현하지 않았다.

처음 고정 회귀에 서버 보조 입력을 빠뜨린 두 ENOENT는 원본 실패 로그를 보존하고 해당 검사만 다시 실행했다. 최종 고정 16개가 통과했다. 고정본 이후 경험치 책 표시 대상의 `joinedCompanions()` 수정은 별도 UI 11항목과 브라우저 빌드로 확인한다. 네이티브 엔진 입력 119파일 중 118파일과 로컬 DB는 전투 고정본과 최종본이 같다. 성장 파일의 추가 차이는 공통 돌파 보상 표 1줄이며, 이 줄을 제외한 전체 파일이 바이트 단위로 같다는 독립 재확인 결과를 `data/full_balance_v01621/combat_source_review_v01621.json`에 기록했다. 기존 `combat/final_scope.json`과 봉인된 전투 증거 272개는 그대로 보존했다. 따라서 XP·HP·적 수치·치유·AI가 같은 전투 관측은 재사용하고 최종 재료 지급은 별도 실제 지급 검사로 검증한다.

이야기 임시 동행의 오래된 성장 정산 코드에는 전량 회복 문장이 남아 있지만, 현재 `runtime_journey.js`가 임시 동행 목록을 비우고 정식 합류하지 않은 참가자를 거절한다. 옛 파티 정책의 저장도 체크포인트 또는 전투 준비로 이관한다. raw 작성 데이터의 임시 동행 목록만 보고 실행 가능한 오류라고 단정했던 첫 QA 시도는 현재 목록이 비어 있다는 조건에서 전투 생성 전에 실패했다. 이 경로를 새로 켜거나 제품 코드를 변경하지 않았으며, 임시 동행 성장의 실제 정산 검증을 통과 수에 넣지 않는다. 읽은 코드·실패한 QA 원본·판단 근거는 `data/full_balance_v01621/guest_dormant_review.json`에 따로 남겼다.

처음 48보스와 추가 24보스는 서로 다른 저장된 입력 fingerprint다. 첫 48의 성장 해시는 실제 HP 정책 수정 후 8조건 증거와 연결했고, 두 실행 사이 성장·주간 임무 파일 이외의 source 해시는 같다. 이를 하나의 동일 빌드에서 실행한 72조건으로 주장하지 않는다. 동일 입력으로 첫 48을 추가 재실행하려던 선택 검사는 26조건 로그 후 프로세스가 종료 코드137로 중단됐다. 원인을 단정하지 않고 미완료 로그를 보존했으며 성공 검증 수에 포함하지 않는다.
