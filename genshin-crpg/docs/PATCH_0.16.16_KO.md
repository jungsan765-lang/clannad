# 0.16.16 · 전투 복원, 보상·요구량으로 효율 정정

## 변경 범위

0.16.15에서 전투를 약하게 만들어 높은 단계의 효율을 맞춘 판단을 사용자가 거절했다. **신규 특성·돌파 전투는 0.16.14의 고정 4인 적 수치로 복원했다.** 적 편성·HP·공격력·방어·속도·보호막·기술·행동을 바꾸지 않고 기존 원소 선택/단계의 보상과 돌파 보석·특성책 수요를 조정한다. 숙박 없이 파밍하는 결과를 목표로 삼지 않는다.

대상별 숙박비, XP 곡선·보상, 모라·다른 육성 재료, 임무·화면·이야기는 유지한다. 새 재료·입장 제한·시스템을 만들지 않았다.

## 전투와 숙박 증거

독립 원본 0.16.14 엔진으로 만든 216조건의 적 수치·보호막과 신규 전투를 대조했다. 카드·AI 코드는 변경하지 않았다. `tuneGrowthEnemy`와 `startBattle` 경로를 복원했다. Lv.60 물 돌파 적 합계 HP는 거절된 패치의21,545에서 원본182,413으로 돌아간다. 이는216조건 시작 검사이고216조건 완주라고 주장하지 않는다.

0.16.15 진행 중 전투는 저장 HP·공격력·보호막·순서와 옛 보상으로 마무리한다. 옛 약한 전투 마커에 신규 보상 마커만 붙이는 조합은 거절한다. 신규 입장에만 복원된 난이도와 새 보상을 적용한다.

숙박은 `ceil(20×지역요율) + Σceil(4×각 대상 레벨×그 대상 손실HP비율×지역요율)`이다. 합계 레벨을 기본료로 쓰지 않으며 숫자 표시·BUY·회복·영수증의 견적을 유지한다.

## 측정 조건과 해석

고정4인·제작장비+3/+6·합법 중간 특성,두 경로, 실제HP/난수 이월이다. 시작 때만 완전 회복하고 레벨 상한이라 레벨업 회복을 끼우지 않는다. 사망자 또는HP50%미만이 있으면 실제 이동→숙박BUY→복귀하며 이동 조우도 싸운다. 동일 레벨/경로/시드는 같은SAVE_ID·실제 날짜를 사용해 돌발상황을 공정하게 비교한다.

표시2배속은 내부1이므로 연출ms `/1000` +입력3초 +결과/재입장6초와 실제 이동/시설 입력 시간이다. CPU 시간을 플레이 시간으로 쓰지 않는다. 소유·해금·장비와 준비금20만모라는 선언한 검사 조건이고 게임에서 주는 보상이 아니다. 원재료/장비/모라 마련·사람/네트워크 지연은 별도다.

기초226조건:2,669비경전투/2,665승·4패/실제숙박275회/이동전투213회. 실패4개는Lv20+3중간특성의 상위 특성 단계다. 추가 조기56조건:382비경전투/378승·4패/숙박109회/이동전투101회(별도2패). 실패를 파밍 성공 시간으로 외삽하지 않았다.

확정 설계는364개 성공 가능한 비교에서 후기 인접·자기 레벨 조기·최고 대 최적 하위를 검증했다. 후기 최고는 두 경로·8원소의 기본 시간 효율 최소20%를 **설계 목표**로 삼았다. 유한한 기초 승수와 실제 목표 완주의 차이는 아래 최종 결과를 따른다. 장비가 부족해 한 판을 못 이기면 보상만으로 해결할 수 없으며 전투를 다시 약하게 만들지 않는다. 관측하지 않은 모든 편성·시드의 보장은 아니다.

이전 전구간XP 평균8.8/30.1/65.4/194.3/222.1/289.8분은 XP자료이며 이번 재료 완성 시간으로 둔갑시키지 않는다. 재료 직접XP는 남은XP에서 한 번만 빼고 두 번 계산하지 않는다.

기존 주간 `3종 각20승=60승` 자료는 하위 목표 각20승 수급의 부분 모델이다. 현재 보고/활성 순서의 주간 전체 갈래는 최소140비경승이다. 임무 갈래·횟수·보상은 이번 변경 밖이다. 보석/책은 거래 불가·NPC매각0·상점/합성공급 없음이다. 실시간 시장 시세 안정까지 검증했다고 쓰지 않는다.
