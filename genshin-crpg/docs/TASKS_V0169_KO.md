# 0.16.9 임무 목록과 보상

기존 캐서린 의뢰·일일/주간 임무판을 사용한다. 일회성 **29계열288개**, 반복 후보 **일일12종·주간31종**이다. 실제 배정은 일일4개, 주간은 열린 목표 최대20개다. 후속 의뢰는 선행 의뢰 보고 후 공개한다. 고유 특별 보상은 추후 사용자와 별도 합의하며 현재 원석을 사용한다.

## 보상과 수락 규칙

- 일일 모두 달성20원석은 유지한다. 주간 전체 완료200원석을 새로 구분한다. 기존 주간70원석은 보스30+일일 보너스5회40이었으며 전체 완료 보너스는 없었다.
- 의뢰 동시 수락은 진행 중·보고 대기 합계5개. 기존5개 초과는 삭제하지 않고 보고 후 새로 받는다.
- 새 일회성 보상은 고정 금액이다. 예전 캐릭터 레벨/10 배율을 다시 곱하지 않는다. 반복 보상은 배정 당시 계정 레벨로 고정한다.
- 같은 기간 배정된 일일과 기존 주간4개는 목표·보상·진도를 보존한다. 기존 사과 목표는 오늘만 유지하고 다음 한국 날짜 갱신부터 일반 채집3회다. 기존 주간에는 새 목표를 덧붙이고 다음 주부터 새 핵심 목표 수치를 전부 적용한다.
- 이미 받은 보상은 차액을 다시 지급하지 않는다. 이미 수락한 일회성 의뢰는 수락 당시 정의를 보존하고 다음 새 의뢰부터 새 보상이다.
- 물품 납품만 보고 시 실물을 소비한다. 일반 요리·제작 목표는 결과물을 유지한다. 납품 실패는 소비·지급을 함께 취소하고 장착·잠금·강화·돌파·성유물은 보호한다.
- 성공한 실제 활동만 집계한다. 빈손·메뉴 열기·거절·전투 시작은 완료가 아니다. 일일·주간·수락 중 의뢰는 한 활동으로 함께 진행할 수 있다.
- 원소 일일은 계정 보유·생존 동료로 가능한 조건을 매일 바꾼다. 비소유·대여 동료는 원소·지정 동료 조건을 대신 채우지 않는다. 일반 승리는 유지한다. 꽃·특성·돌파 일일에는 별도의 단계·지역·원소 편성 조건을 두지 않는다. 활동 자체의 기존 해금은 유지한다.
- 실제 모두 열린 Lv60의 생존 보유 원소를 활용하는 새 일일4개는15,000~21,400모라, 새 주간20개는385,400~477,000모라다. 일회성288개 총액은2,671,660모라·17,875원석이다. 전체 일일 후보를 자유 조합한15,000~23,600은 원소를 활용하는 실제 배정 범위와 구분한다.
