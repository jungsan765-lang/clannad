## 검증과 증거 구분

- 서버 회귀는 격리된 SQLite 저장과 실제 런타임을 사용한다. 거래 취소·내용 변경·확정 해제 경쟁, 동시 확정과 등록 제한의 저장 횟수·물품 수를 확인한다.
- 용량 회귀는 실제 Node 쓰기 스트림으로 느린 소비자·drain·UTF-8 바이트·시간 초과·다른 연결의 진행을 확인한다. 500명의 실제 네트워크 부하 시험은 아니다.
- 설치기는 임시 경로·모의 네트워크·모의 systemd로 전체 스크립트를 실행한다. 재시작/설정/디스크/웹 링크/표시 파일 실패, 잘못된 엔진·같은 엔진의 옛 서버 빌드/앱 버전, 비정상 health, 첫 설치, 재설치, 동시 실행을 확인한다. 이 결과가 실제 VPS 설치 증명은 아니다.
- 자산 검사: 이미지 1,077개 무결성 오류 0, 카탈로그 local media 1,230항목의 누락·검사 가능한 해시 불일치 0, 코드 고정 미디어 경로 17개 빌드 누락 0. 영입 43명의 기본 초상 존재를 확인했다. 파일 존재가 전 장면 배치/화자 일치를 증명하지는 않는다.
- UI 회귀는 실제 소스를 지연 응답·DOM 대역에서 실행한다. 전 화면의 렌더링·물리 클릭·실기기 키보드 검증을 대신하지 않는다.
- GitHub 전체 회귀와 기존 소스/배포물 브라우저 CI 통과 및 테스트 묶음 게시 결과는 해당 커밋의 PR 기록에서 별도로 확인한다.

## 실제 서버에서 읽기만 하여 확인한 것

2026-10-03 후속 작업 중 테스트 사이트의 `release.json`, `/api/health`, `test-source-sha.txt`는 **0.15.10 / 7b9d2c1**로 일치했다. API는 `ok:true`였다. 0.15.11을 실제 VPS에 설치했다는 뜻이 아니다.

같은 작업 환경에서 공개 파일을 `Accept-Encoding:gzip`으로 각각 한 번 읽은 결과:

| 파일 | 실제 응답 본문 바이트 | 압축 해제 후 바이트 | 첫 응답 / 전체 수신 |
|---|---:|---:|---:|
| app.js | 14,213 | 40,120 | 887 / 1,067ms |
| data.js | 4,232,479 | 23,086,429 | 854 / 2,387ms |

gzip 응답과 `Vary: Accept-Encoding`을 확인했다. 이는 서버→점검 환경 전송의 단일 관측이며 휴대폰 체감·업로드 트래픽·브라우저 파싱 시간·평균 지연으로 일반화하지 않는다. data.js의 큰 해제 크기는 저사양 기기의 초기 파싱·메모리 후속 측정 대상이다.
