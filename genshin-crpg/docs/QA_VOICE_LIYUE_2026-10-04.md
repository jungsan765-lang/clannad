# 리월 말투 표본 대조 — 2026-10-04

사용자 최신 지시: Claude 쪽 이야기 작업과 겹치지 않도록 **제품·원고·스토리 문구는 수정하지 않는다.** 이 문서는 읽기 전용 감사 결과다. 말투의 취향 차이를 치명적 오류로 확대하지 않는다.

## 결론

- 행추·연비·각청을 우선 대조했고 감우·소는 대표 장면만 추가 확인했다. 이번 표본에서 **공식 한국판과 명백히 모순되는 어미를 확정한 인물은 없다.** 전 인물·전 대사 검증 완료라는 뜻은 아니다.
- 다만 각청의 `미정 자원`, 행추의 `남의 독서 순서를 훔치지 않고`, 감우의 `규칙을 건너뛸 권한` 등은 일상적인 상대의 말에 반응하기보다 원칙을 평가하는 문장으로 반복된다. **말투·대화 자연스러움 편집 후보**로 알리고 그대로 둔다.
- 연비가 법을 설명하거나 각청이 업무를 지휘하거나 감우가 존댓말을 쓰는 것 자체는 오류가 아니다. 행추의 문어적 표현, 소의 짧고 단호한 명령도 어미만으로 배제하지 않는다. 공식의 사적인 생일 대화와 게임의 공적 업무 장면은 같은 기준으로 기계적으로 비교할 수 없다.
- 원신 공식 한국 계정 게시물의 **검색 인덱스에 노출된 실제 한국어 문장**을 읽었다. 원문 페이지 직접 열기는 동적 빈 본문/403으로 제한됐다. 영상 전체를 보거나 한국어 음성을 청취한 것으로 계산하지 않는다.

## 현재 게임에서 추린 편집 후보 — 모두 미수정

현재 `tests/helpers_v011.cjs`의 `fresh()` → `installMarketContent()` → `storyIndex()`로 최종 합성 노드를 가져와 `storyDisplayText(row)`를 다시 확인했다. 아래 10개 노드는 전부 실제 해당 인물의 `DIALOGUE`다. 주인공 선택문이나 서술자의 설명을 그 인물의 말로 잘못 세지 않았다. 별도로 이전 정독의 `/tmp/narrative-LIYUE_*-ROUTE_*.compact.txt`에서 앞뒤 상황을 읽었다. 이는 브라우저 실제 플레이 검증이 아니다.

### 각청: 농담에 규범 설명으로 대답하는 구간

- `AFF_ISK_LIYUE_KEQING_H02_BODY_04`: `농담할 시간은 있어. 다만 실제 조명 계획은 따로 세워. 팔이 아플 때 멈추는 건 네 권리야.`
- 앞에서는 주인공이 자신이 팔을 들고 임시 등불이 되겠다는 농담을 한다. 각청이 현실적인 대책을 요구하는 것은 자연스럽지만, 마지막의 권리 설명은 이 장면에 새로운 정보나 개인적인 반응을 거의 더하지 않는다.

## 이번 결과의 사용 방법

1. 위 표본을 Claude에게 전달하더라도 전부 자동 교체하지 않는다. 현재 작업 중인 원고에서 이미 다뤘다면 중복 작업하지 않는다.
2. 사용자에게 알릴 때는 `각청의 미정 자원 같은 표현이 유독 딱딱하다`처럼 실제 문장을 근거로 말한다. `각청은 ~군을 안 쓴다`, `행추는 자네라고 하면 안 된다`, `감우는 합쇼체를 쓰면 안 된다`로 과장하지 않는다.
3. 응광의 `~하네/라네` 여부는 이 문서의 조사 범위가 아니다. 별도 응광 공식 발화 확인 결과를 따른다.
4. 확인된 잘못된 캐릭터 이름, 내부 제작 문구 노출, 진행 불능 같은 치명적 문제와 문체 취향 후보를 분리한다. 이 감사에서는 제품 파일을 변경하지 않았다.
