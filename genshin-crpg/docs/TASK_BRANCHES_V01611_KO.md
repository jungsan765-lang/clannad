# 0.16.11 임무 갈래

시작은 **의뢰 접수 연습 수락 → 캐서린에게 보고**다. 후속 임무는 선행 임무의 보상을 실제로 받은 뒤 열린다. 연결이 둘 이상이면 모두 완료·수령해야 한다. 기존 임무판과 쪽 넘기기를 사용한다.

## 삭제한 네 항목

- `D_V168_HILI`: 전투 5번 이기기
- `W_V168_MOND_PATROL`: 몬드 초원·숲·바람이 시작되는 곳에서 전투 40번 승리
- `W_V169_REPORT`: 현장 의뢰 6번 보고
- `W_V168_CRYO_VINE`: 얼음 나무 3번 토벌

다른 ID는 유지한다. 일일 정의 11개·주간 정의 28개·일회성 288개다. 이는 한 화면에 한꺼번에 표시되는 수가 아니다. 해당 기간에 수행 가능한 갈래를 고정하고 그중 지금 열린 미수령 목표만 표시한다. 미해금 활동은 기간 계획에 넣지 않는다. 개별 목표 횟수와 보상은 이번에 바꾸지 않았다.

## 집계와 저장

- 후속 해금 이전에 시작한 전투·생활 활동은 후속 목표에 소급하지 않는다. 지금 열린 서로 다른 목표는 같은 실제 성공 활동을 공유할 수 있다.
- 수령한 반복 목표는 목록에서 빠지고 다음 목표가 나타난다. 메인 완료 숫자는 숨겨진 후속과 수령 기록까지 포함한 전체 기간 계획 기준이다.
- 기존 168/169 수락 중 의뢰는 해당 정의·보상·진척으로 계속 마칠 수 있다. 새로 수락하는 의뢰부터 현재 연결을 적용한다. 삭제한 네 목표의 과거 보상은 회수·차액 지급하지 않는다.
- 기간 안의 계획과 보상은 고정이다. 레벨·보유 캐릭터·지역이 늘어도 이미 받은 전체 완료 보상을 재계산하거나 추가 지급하지 않는다.
