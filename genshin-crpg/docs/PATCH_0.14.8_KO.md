# 0.14.8 패치 노트 (테스트 서버 후보)

0.14.7을 테스트 서버에서 해 본 사용자의 의견을 반영한 첫 묶음입니다. 승인 전에는 main 병합과 운영 반영을 하지 않습니다.

## 바뀐 점

- **PC 화면 크기** (`source/index.html` 맨 앞 스크립트)
  - 0.14.7은 1280×720 화면을 창에 맞게 통째로 키워서 글자와 칸이 지나치게 커졌습니다(「컴퓨터 화면이 너무 커」).
  - 이제 틀 안의 화면 크기가 창 크기를 따라갑니다. 크기 = 창 크기 ÷ 배율이고, 배율은 설정 → 표시 설정 → 「화면 크기」에서 고릅니다(작게 0.85, 보통 1, 크게 1.2). 값은 `settings.uiScale`에 저장되고, 틀은 `window.CRPGFrameFit()`으로 바로 다시 맞춥니다.
  - 화면은 1280×720보다 작아지지 않고, 높이는 1200을 넘지 않으며, 가로는 세로의 1.92배까지만 넓어집니다. 이 범위를 벗어나는 창에서만 비율을 지킨 채 화면 전체를 줄이거나 키웁니다.
- **들판 화면 겹침**: 숨은 눈동자가 있는 장소(몬드 외곽 초원)에서 `app_discovery.js`의 가로 풍경 띠가 화면 위쪽을 차지해 지도와 목적지 칸을 밀어내던 문제를 고쳤습니다.
- **풍경 보기** (`app_shell.js` `toggleScenery`, HUD 눈 아이콘·V 키)
  - 들판과 마을 어디서나 화면을 치우고 장소 그림을 좌우로 둘러봅니다(끌기·휠·화살표, Esc로 닫기).
  - 숨겨진 눈동자(`method:'HIDDEN'`: `ANEMO_PLAINS_CART`, `GEO_HARBOR_CRATES`)는 이 풍경 속에서만 작게 반짝입니다. 처음에는 가운데를 보여 주므로 오른쪽으로 둘러봐야 보입니다.
  - 버튼이 모든 장소에 있어서, 버튼이 있다는 것만으로 숨은 눈동자가 있다는 사실이 드러나지 않습니다. 예전 풍경 띠와 「주변 살펴보기」 버튼은 셸에서 숨깁니다.
  - 바위 눈동자 탐사 목록의 부두 힌트에서 찾는 방법 설명을 뺐습니다.
- **마을 시설**: 시설 카드를 아이콘과 이름만 있는 두 줄 타일(`.shell-place-tile`)로 바꿨습니다. 타일 전체가 들어가기 버튼이라 몬드성 시설 9곳이 1920×1000에서 한 화면에 다 보입니다.
- **이야기 선택지 번호**: 예전 스타일이 번호 동그라미에 남긴 오른쪽 여백(13px)과 위쪽 여백(2px) 때문에 01·02가 동그라미 왼쪽 아래로 밀려 있었습니다. 여백을 없앴습니다.
- **마우스를 올렸을 때 깨지던 칸** (`app_motion.js`)
  - 의뢰처럼 넓은 구역(`.journal-section`, `.main-objective`, `.next-chapter`)이 기울고 커지면서 패널 밖으로 잘렸습니다.
  - 이 구역들을 기울기 대상에서 뺐고, 가로 520px나 세로 320px를 넘는 칸은 기울지 않습니다.
- **스크롤바**: 게임 화면에서는 문서 전체가 스크롤되지 않게 했고(`html:has(>body.teyvat)`, `#root`), 페이몬 메뉴 상자의 스크롤바를 숨겼습니다.
- **필드 보스 토벌 횟수** (`runtime_field_boss_limits.js`)
  - 모든 필드 보스를 합쳐 현실 시간 12시간마다 3번까지 토벌할 수 있습니다. 한국 시간 0시와 12시에 다시 셉니다.
  - 온라인에서는 서버의 행동 시각(`actionStartedAt`)을 기준으로 합니다. 기록은 `s.fieldBossWindow = {window, wins}`이며, window는 `floor((now + 9h) / 12h)`입니다.
  - 보스마다 게임 내 하루를 기다리던 규칙(`fieldBossCooldown`)은 없앴습니다. 패배는 횟수에 들어가지 않습니다.
  - 예전 `s.fieldBossDaily`는 그대로 검증만 하고 읽지 않습니다.
- **이름**: 「이틀 주기 보스」를 「일일 보스」로 부릅니다. 규칙은 0.14.5 그대로입니다(보스마다 현실 시간 하루 1회, 한국 시간 0시).
- **나선 각인**
  - 모험가 핸드북의 나선비경 제목이 「나선비경 · 나선 각인」이라 뜻을 알 수 없었습니다. 제목을 「나선비경 기록」으로 바꾸고 각인 규칙을 설명에 넣었습니다.
  - 나선비경 화면의 각인 목록에도 설명 한 줄을 붙였습니다.
  - 공략 방법은 적지 않습니다.
