# 0.16.26 나선 진행·첫 행동 순서 오류 수정

사용자가 승인한 **종려·진 고정 편성, 층별 각인과 장비·성유물 조건은 유지**했다. 캐릭터·보스·적의 체력/공격력/속도 수치, 치유량, 음식·숙박비, 성장 요구량·보상·시장·임무 보상은 조정하지 않았다. 기존 전투 규칙이 계산과 정산에서 빠지던 부분을 고쳤다.

## 바뀐 동작

| 문제 | 수정 후 |
|---|---|
| 나선 1·2번 방에서 주인공 KO 후 동료가 이기면 승리 정산의 10% 회복 때문에 다음 방으로 진행 | 정산 전 실제 주인공 HP를 확인하여 그 층 도전을 `DOWNED`로 종료. 다음 방·층 정복·각인을 얻지 못한다 |
| 나선 적의 첫 순서가 템플릿 SPD28을 쓰고, 이후 SPD는 층별 최종값을 사용 | 첫 순서에도 최종 유효 속도를 반영. 12층 SPD50이라면 기존 0~9 난수에 50을 더한다 |
| 일반 적의 성장·변종·지맥 속도 보정이 첫 순서 뒤에 적용 | 첫 주사위에 실제 사용한 속도를 임시로 기록하고 최종 성장 속도와의 차이를 보정. 변종의 속도와 관리자 덮어쓰기까지 중복 없이 계산 |
| 기동 진형의 아군 속도+6이 첫 순서에 누락 | 새 전투의 첫 순서에 기존 진형 보너스를 반영. 음식 속도 효과와 함께 계산 |
| 관리자 속도 설정 후 공개 시작 결과가 이전 순서를 반환하거나 매우 빠른 적이 미리보기에서 주인공보다 먼저 표시 | 최종 저장 순서·미리보기·시작 결과를 동기화. 기존 ‘주인공이 첫 행동’ 정책을 실제 실행과 일치시킨다 |
| 방 사이에서는 전투 치료품을 허용한다고 판정하지만 실제 사용은 실패 | 음식만 허용하는 기존 실제 사용 규칙에 판정을 맞춤. 전투 치료품은 기존 전투 행동에서 사용 |

첫 행동 순서를 다시 뽑지 않는다. 기존 난수·선제 우선권·속도 점수 페널티를 유지하고 누락된 속도만 반영한다. 성장 보정에 사용하는 임시 기록은 저장 파일에 들어가지 않으며 시작 처리가 끝나면 제거한다.

## 기존 진행과 연결 영향

- **진행 중인 옛 저장 전투는 저장한 순서와 정산대로 이어진다.** 새 나선 방에 `rulesRevision:1`을 기록하여 새 KO 판정을 적용한다. 옛 전투를 불러오는 순간 순서를 바꾸거나 규칙 표식을 소급 추가하지 않는다.
- 일반 전투에서 동료가 이겼을 때 주인공이 HP10%로 일어나는 기존 퇴장 회복은 유지한다. 새 나선의 1·2번 방에서도 퇴장 회복은 남지만, 이미 끝난 층 도전을 이어갈 수는 없다.
- 세 번째 방은 동료가 마지막 적을 처치하면 기존대로 정복을 인정한다. 마지막 방 KO 승리를 연전 오류로 취급하지 않는다.
- 실제 적을 전멸시킨 방의 승리 횟수는 기존 임무/업적에 집계된다. 층 정복 보상·각인·다음 층·나선 순위는 정복 기록이 없으면 열리지 않는다. 기존 화면의 `DOWNED` 실패 분기를 그대로 사용했다.
- 층별 편성 계획과 최종 장비 조건은 사용자가 의도한 설계다. 0.16.25 읽기 점검의 고정 편성 비판을 추가 너프나 개편 지시로 넘기지 않는다.

## 소스와 적용

실제 전투를 같은21조건씩 비교한42회·87방에서 주인공 KO 뒤 다음 방으로 넘어가던13건은0건이 됐다. 기존 무KO 클리어6회는 유지했다. 정산·저장·순서35조건, 독립 검토13조건, 실제 전투 시작 경로39조건이 통과했다. 전투 입력과 중간 실패·재검사 내역은 원장에 별도로 남겼다.

최종 소스·실제 브라우저 배포 스크립트·서버 ESM에서 각각127개, 합계381개 계약이 전부 통과했다. 새 오류35개 조건과 기존 캐릭터·효과 귀속·일일 전투·평타 사거리92개 조건을 같은 엔진으로 실행했다. 화면 배치나 자연 계정의 전체 육성·등반 검증을 뜻하지 않는다.

앱에서 호출하지 않는 옛 `TUTORIAL_DRILL` API의 시작 후 SPD 덮어쓰기 문제는 별도 잔존 항목으로 재현했다. 현재 이야기 튜토리얼과 구분하여 인수인계했으며 이번 패치에서 다른 소스를 추가 변경하지 않았다.

제품 수정은 네 파일이다: `runtime_abyss.js`, `runtime_formations.js`, `runtime_growth_v01522.js`, `runtime_balance_admin_v01623.js`. 버전 메타3개, 관련 검사·원장·인수인계 문서를 함께 게시한다. 원격0.16.25 트리에 선별 반영하며 DB·assets·UI·다른 AI의 코드를 덮지 않는다.
