## 이전 계산이 틀린 이유

1. **매 판 새 저장을 만들고 체력을 가득 채웠다.** 단발 승리 여부는 확인했지만, 다음 판의 잃은 체력·사망한 동료·딜 감소를 지워 버렸다.
2. **숙박·마을 왕복·이동 중 전투·실패 손실을 제외했다.** 낮은 단계에서 계속 싸울 수 있는 이점을 비교하지 않았다. 초기 지갑 0인 표본은 패배의 10% 모라 손실도 없앴다.
3. **표시 2배속을 잘못 환산했다.** UI의 표시 속도는 내부 속도의 두 배다. 표시 2×는 내부 1이므로 연출 ms를 `/1000` 해야 한다. 0.16.13/14 문서의 `/2000`은 실제 허용 속도보다 빠르게 계산한 오류였다. 기존 `audit_balance_v0161.cjs`의 `/1000`이 맞았다.
4. **마지막 요구량 800/1,600개를 맞춘 것을 단계 효율 해결과 혼동했다.** 기본 25/50승 복원은 사실이지만, 요구량은 모든 단계에 같은 배수다. 낮은 단계가 유리한 순서를 바꾸지 못한다.

따라서 과거 문서의 평균 15.09/30.17분, 최고 단계 일반 우위, 과거 분당 효율 표는 현재 판단 근거로 사용하지 않는다. 이미 완료한 돌파와 실제 지급량의 역사까지 바꾸는 것은 아니다.

## 이번 비교 방법

- 고정 4인: 주인공·엠버·케이아·리사, 별자리 0. 특성 핵심 비교는 Lv.20/돌파 1단계·제작 장비 +3·중간 특성, 돌파 완주 비교는 Lv.55/돌파 5단계·제작 장비 +6·중간 특성이다. 모두 시작 때만 완전 회복한다. 장비·소유·이야기 해금은 선언한 합성 조건이다.
- 캠페인마다 난수 시드 한 번만 설정하고 다음 판에 HP·사망·난수를 그대로 넘긴다. 적 HP·승패를 강제로 바꾸지 않는다. 실제 스킬·동료 AI·정산을 사용한다.
- 일일 재료 2배는 시작 전에 공유 3승을 소진한 기본 반복 조건이다. 몬드/리월 특성책은 별개 재료이므로 같은 지역의 책끼리만 비교한다.
- 표시 2배속 시간 모델은 **기다리는 연출 ms / 1000 + 전투 입력당 3초 + 결과 확인·재입장 6초**다. 클라이언트가 기다리지 않는 `state && silent` 프레임은 0초로 센다. CPU 실행 시간을 플레이 시간으로 쓰지 않는다. 실물 폰·네트워크에서 측정한 시간은 아니다.
- 돌파 완주 캠페인은 준비금 10,000모라로 시작한다. 파티원 중 누군가 쓰러졌거나 HP가 50% 미만이면 실제 숙박 왕복을 수행한다. 준비금은 수익에 더하지 않는다. 이동 조우의 시간·체력·수입을 포함한다. 완주 비교의 시드는 717이며 특성은 717/4242를 비교했다.
- 첫 패배에서 멈춘 특성/돌파 파일럿은 달성 시간으로 외삽하지 않는다. 패배 뒤 실제 60초 행동 잠금은 별도로 표시하고, 지갑의 실제 10% 손실을 기록한다.

특성 파일럿의 초기 지갑은 기존 준비 도구 기본값인 0모라라 패배 모라 손실도 0이다. 특성의 시간·HP 반례에 이 제한을 숨기지 않고, 일반 플레이어의 실제 지갑 손실을 추정한 경제 표로 사용하지 않는다. 위 10,000모라 준비금은 돌파 완주 비교에만 적용한다.

일반 승리 후 체력은 누적되지만 주인공만 죽고 동료가 승리하면 주인공이 HP 10%로 부활하는 예외가 있다. 동료 사망은 유지된다. 새 전투의 재사용 대기·보호막은 초기화되며 별도 숫자 에너지는 없다. 정상 레벨업·돌파의 완전 회복은 네이티브 규칙 그대로다. 핵심 비교 조건은 레벨 상한에 도달해 전투 XP로 레벨업 회복이 발생하지 않는다.

### 실제 리월 숙박 경로

천둥 연산 밀궁 → 명온 마을 → 귀리 평원 → 리월항 북문 → 리월항, 귀환은 역순이다. 네이티브 `MOVE` 8회 + 시설 입장 + 숙박 구매로 **10입력**이다. 순수 연출 12초 + 선언한 입력 시간 30초 = **왕복당 42초**, 이동 중 전투는 추가한다. 숙박비는 140모라이고 전원 부활·완전 회복 후 시설을 자동 퇴장한다.

이동 160분+숙박 480분=640분은 게임 내 시계 변화이며 실제 640분 대기가 아니다. Lv.30~60 돌파는 모두 같은 입구이므로 그 자리에서 낮은 단계로 바꾸는 이동 비용은 없다. 숙박으로 게임 날짜가 바뀌어도 실제 한국 날짜 기준의 첫 3회 보너스가 다시 생기지 않는다.

## 후속 수치 조정에서 지킬 기준

**돌파와 특성 모두 전 단계의 같은 재료 효율을 조정해야 한다.** 최고 단계 보상 하나와 최종 요구량 하나만 고치는 방식으로 끝내지 않는다.

1. 우선 기존 돌파 보상 32개·최종 800/1,600개, 특성책 요구량(세 특성 1→8 몬드 168/리월 336권, 1→10 몬드 270/리월 540권)을 기준으로 삼는다. 요구량만 다시 늘리거나 하위 보상을 줄여 해결하지 않는다.
2. 필드·스토리·지맥의 전역 성장 곡선을 바꾸지 않고 **돌파·특성 비경의 단계/등장 편성별 고정 총 HP·공격 위협 예산**을 좁게 보정한다. 원소별 편성·기술·보호막 규칙은 유지하고 보호막 수치도 함께 검토한다. 모든 고단계에 같은 배수를 적용하는 안도 원소 편성 차이를 놓칠 수 있다.
3. 높은 단계가 최적 하위 단계보다 실제 지속 재료/시간이 충분히 좋아지는지, 회복 횟수·순모라·전투불능·입력 부담도 함께 검사한다. 보상/HP 비율만으로 수정값을 확정하지 않는다.
4. 첫 다섯 돌파와 저단계 접근성·보상을 막지 않는다. 4성 고정 4인에서 검증한 뒤 5성 편성은 같은 적을 더 빠르고 안전하게 잡는 장점을 확인한다. 5성을 뽑았다고 적을 강화하지 않는다.
5. 반복이 빨라지면 실제 육성 시간도 달라진다. 주간 승수가 같다는 이유로 시간이 보존됐다고 쓰지 않고, 최종 돌파·특성·XP·모라·장비의 전체 육성 경로를 다시 합산한다. 진행 중 전투의 약속된 보상·완료한 육성·구버전 저장을 보존한다.

힐러 보유·고강화·다른 전술·음식·실제 클릭 속도에 따라 결과는 달라질 수 있다. 이번 결과는 모든 편성의 승률이나 경제 시세를 뜻하지 않지만, 높은 단계의 일반 우위가 성립하지 않는 반례로는 충분하다.
