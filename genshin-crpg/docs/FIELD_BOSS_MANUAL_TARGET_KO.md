# 필드보스 수동 공략의 기반 — 0.16.22 추가 점검

사용자 기준은 옳다. 공략 조건이 존재하는 것과, 명함·풀돌·5성 투자의 차이를 살리면서 수동 대응이 필요한 것은 다르다. 현재 0.16.22는 뒤의 기준까지 완성했다고 볼 수 없다. 이번에는 현재 소스의 28조건을 더 측정하고 목표·제약·주변 영향을 기록했다. **이 추가 점검은 제품 수치를 변경한 0.16.23 패치가 아니다.**

## 목표를 이렇게 나눈다

| 투자 | 동레벨 필드보스의 목표 | 일일보스·성장 목표 |
|---|---|---|
| 4성 명함 | 대응 원소·장비·편성을 준비하고 대상·방어·폭발 시점을 제대로 선택하면 승리 가능. 공략을 무시한 반복은 큰 손실이나 실패 | 최초 장비 재료를 얻기 전에 그 재료로 만든 장비를 선행 요구하지 않음 |
| 4성 풀돌 | 화력·생존·실수 허용량이 분명히 좋아지되 핵심 공략을 생략하는 일반 반복이 쉬운 정답은 아니어야 함 | 동레벨 일일보스도 예고·대응·공격 기회를 제대로 활용해야 승리. 장비·특성을 준비했다는 이유만으로 일반 기술 반복이 쉬운 정답이 되면 미달 |
| 5성 명함·1/2돌 | 조합과 투자에 따라 더 빠른 처치와 넓은 대응 여유. 돌 차이는 실제 기술 효과로 확인 | 명함 편성도 동레벨 일일보스를 공략해야 승리. 1/2돌의 여유는 실제 기술 가치로 주되 면역·필수 공략 무시는 허용하지 않음 |
| 5성 풀돌 | 고투자 화력·편의 가치를 충분히 인정 | 낮은 단계는 빠르게 수급 가능하되 최종 보스의 필수 승리 조건은 유지 |

이는 사용자가 지정한 후속 조정의 통과 기준이며 현재 달성한 수치표가 아니다. 등급에 따른 숨은 입장·핵 타격 제한이나 고정 패배를 만들지 않는다. 최적 조합의 동료 AI가 실제 공략을 수행하는 것을 모두 금지하는 목표와도 구별해야 한다.

추가 정정: **일일보스는 같은 수준의 육성·준비 기준에서 필드보스보다 더 많은 준비와 대응을 요구해야 한다. 4성 풀돌·5성 명함이 동레벨 일일보스를 ‘공략을 토대로’ 이기는 것이 목표다.** 앞선 ‘수급 가능’이나 ‘빠르게 파밍 가능’은 난도 목표가 아니며, 입장 소모·낮은 드롭률·모라 부담으로 전투의 공략 난도를 대신하지 않는다.

## 실제 추가 측정

필드 12조건 + 공개 수동 후보 6조건, 일일 8조건과 같은 장비 비교용 필드 2조건을 수행했다. 제품·기존 봉인 증거 수정 0, 각 실행 입력 변경 0, 완료 실행 오류 0이다. 비교용 최초 진입 2건은 장소 진입 누락으로 차단됐고 전투 결과와 별도로 보존했다. 18조건은 시드717·무성유물·특성65%상한·제작 장비+3/+6이며 최적 편성 전체를 대표하지 않는다. 일일8조건과 비교용 필드2조건은 같은 시드·장비+10상한10·기본 특성상한·무성유물이다. 동료는 실제 AI, 주인공만 공개 COMBAT로 조작했다.

실측 입력은 앞선 검증과 동일한 로컬 검사 DB다(SHA256 `254c9294c7787b421f38c84b3ad8fed9f00c207a8ef74855868c0cda48dc0962`). 원격 authored DB 전체 원문으로 다시 실행한 결과는 아니며, 각 원장의 입력 해시로 범위를 추적한다. 원격 DB는 교체하지 않았고 운영 환경의 모든 편성·보스 승률을 확정한 결과로 쓰지 않는다.

| 확인한 반례·경계 | 실제 결과 | 판단 |
|---|---|---|
| 얼음계 필드 Lv30, 여행자+4성 동료3명 | 명함 일반 반복22라운드 패배 / 풀돌11라운드 승리·HP76.22% | 명함의 정상 수동 성공 가능성과 풀돌의 공략 의존성을 아직 증명하지 못함 |
| 같은 필드, 이세계인+4성 동료3명 | 명함 일반 반복16라운드 승리·HP23.47% / 풀돌7라운드·86.00% | 명함도 일반 반복으로 성공 가능한 좁은 반례. 주인공 두 경로를 합쳐 판단하면 안 됨 |
| 같은 필드, 5성 방어·치유 동료3명 | 명함18라운드·HP100%, 적 HP피해0·보호막흡수39,626. 2돌6라운드, 풀돌5라운드 | 투자 효과는 있으나 이 조건의 무숙박 원인은 힐보다 보호막 |
| 뇌전계 필드 Lv20, 4성 동료3명 | 명함63라운드 실제패배 / 풀돌81라운드 입력 한도까지 정체 | 회복으로 생존하는 것과 제시간에 공략을 푸는 것이 별개. 정체를 패배나 승리로 세지 않음 |
| 일일4종 각각 동레벨, 4성 풀돌·5성 명함 준비 편성 | 8조건 전부2~4라운드 승리, KO0 | 보스 장비·성유물·+12 없이 수급 경로는 존재. 그러나 ‘일일 > 필드’, ‘공략을 해야 승리’ 목표 충족의 증거는 아님 |

수동 후보는 폭발을 지나치게 오래 아껴 화력·치유 리듬을 망친 사례가 있다. 그 실패를 숙련자가 최선을 다한 난도로 쓰지 않는다. 일일보스는 선행 이야기/클리어 기록·소유·레벨·자금이 준비된 검사 계정이다. 최종 보스 최초 클리어 자체와 새 계정 자연 육성 완주를 증명한 것은 아니다.

필드18조건의 +3/+6과 일일8조건의 +10은 장비 강화도가 다르므로 위 라운드를 그대로 빼서 난도 순서를 확정할 수 없다. 다만 실제 일일 단계 전환이 기록되어도 2~4라운드에 끝나면 지형 소진·누적 분노·후반 원소의 지속 압박을 충분히 겪기 전에 승리할 수 있다. 단계가 구현되어 있다는 사실과 대응이 승패에 필요하다는 사실을 분리한다. 동일 장비 조건의 추가 비교는 원래 봉인과 분리해 기록한다.

같은 동료·+10 장비·기본 특성 상한으로 추가 측정한 Lv30 얼음계 필드는 4성 풀돌과 5성 명함 모두 6라운드, 잔여 HP90.55%/100%로 승리했다. 같은 준비의 일일 Lv25·28 표본은 3/4라운드와 2/2라운드였다. 이 비교는 ‘일일이 더 어렵다’를 뒷받침하지 않는다. 각 보스와 캐릭터는 해당 고정 레벨로 맞췄으므로 25/28/30의 종별 차이가 남고, 전체 난도 비율로 확대하지 않는다. 추가 필드에서도 동료 AI가 핵4/4를 처리했으며 최적 수동 대응을 수행한 사례가 아니다.

## 왜 적 공격력만 올리면 안 되는가

현재 조작 가능한 것은 주인공1명이며 동료3명은 AI다. 대응 동료를 편성하면 AI가 공략을 자동 수행하고, 일부 여행자 장비/편성에서는 주인공이 핵에 직접 유효타를 넣을 수 없다. 이런 상태에서 공격력만 올리면 명함은 먼저 죽고 풀돌·보호막 편성은 버티거나 정체하는 격차가 커진다. 수동의 이득을 만든 것으로 볼 수 없다.

우선 후보는 기존 핵의 공격 실행 중복 집계, 영구 유지되는 최초 갑주 개방/반사를 기존 노출 창과 연결하는 처리, 예고 실패 손실과 성공 노출의 이득이다. 명함의 공개 수동 승리 경로를 확인한 뒤 필요한 보스별 최종 수치를 맞춘다. 새 화면·수동 명령 시스템·캐릭터 등급별 암호 조건을 이번 점검에서 만들지 않았다.

일일보스4종의 후보는 반복 입장 원점(`MATERIAL_CHALLENGE:`)에만 보스별 생존 시간과 기존 단계 피해의 예산을 맞추는 것이다. 최종 성장 보정이 앞선 보스/반복도전 HP·ATK·DEF를 덮어쓰므로 초기 배율만 올려 효과가 있다고 선언하지 않는다. 초기 일일2종에는 최종 HP에 0.45/0.55 감산까지 적용된다. 수치 적용 시에는 현재의 이야기 최초전투·필드보스·보상·진행 중 전투를 함께 바꾸지 않는 경계가 필요하다. **이 후보는 아직 제품에 적용하지 않았다.**

냉기 핵은 현재 다단·추가타도 패킷마다 횟수를 더하며 명중 계산 전 집계한다. 실행 단위 중복 제거 후보는 투자와 편성의 실제 가치도 바꾸므로 별도 저장 버전·지연 공격·합동 공격·단일 정산 검증이 필요하다. 불 동료1명만 있는 일부 여행자 편성은 중복 제거 후 기한 안에 필요한 공격 실행 수를 공급할 수 없다. 단순히 집계를 바꿔놓고 명함 수동 가능이라고 선언하지 않는다.

## 성장·경제 경계

- 최대Lv60만으로 모든 보스 처치를 보장하지 않는다. 최종 일일보스도60이라 초과 레벨로 넘기는 탈출구가 없다. 준비된60레벨 편성의 실제 승리와 모든 계정의 가능성을 구분한다.
- 첫 +12 장비에 필요한 핵·정수를 주는 보스를 +12 기준으로만 맞추거나, 성유물 강화재료 보스를 완성 성유물 기준으로만 맞추면 최초 수급이 막힌다.
- 일일보스 패배는 당일 입장도 소모한다. 필드보스 재료·정수·핵은 거래 불가이므로 시장 구매를 탈출구로 가정하지 않는다.
- 보스가 어려워지면 승리당 음식·숙박·이동·모라 비용과 실패 시간이 함께 늘어난다. 돌파 재료 드롭까지 바로 줄이면 육성 병목을 중복해서 늘린다.
- ‘돌파 효율 감소’는 능력치 상승폭과 재료 수급량을 구분해야 한다. 전자는 일반 전투·치유·보호막·장비·음식·숙박까지 흔들고, 후자는 현재 전투의 자동 공략을 해결하지 못한다. 이번에는 둘 다 임의 변경하지 않았다.
