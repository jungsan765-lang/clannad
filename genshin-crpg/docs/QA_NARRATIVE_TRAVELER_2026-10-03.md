# 여행자 본편 직접 읽기 검수 — 몬드 1·2장 / 리월 1장

> **2026-10-04 00:29 KST 사용자 지시 우선:** 스토리는 즉시 바꾸지 않고 먼저 예시를 보여 달라는 요청에 따라 엠버·소·백출·벤티·여행자 M017 문구/서사 변경을 미적용 후보 패치 `docs/story-proposals/v01514-unapplied-story.patch`로 보존한 뒤 제품에서 되돌렸다. 아래의 ‘승인 수정/반영/통과’는 그 전 작업본의 이력이며 현재 배포 적용 상태가 아니다. 최종 기술 검사 등록은 해당 이야기 전용 2개를 제외한 96개다. 그림 연결, 이름 표시·조사, 적 기술의 내부 변수 표시, 서버 캐시 수정은 별도 기술 범위로 유지한다.

기준: v0.15.13, 검수 시작 HEAD `5e05a75`, 2026-10-03. 대상은 `ROUTE_TRAVELER`이며 이세계인 K·모름 갈래와 구분했다.

**실제 읽은 범위는 825노드다.** 몬드 1장 168노드, 몬드 2장 443노드, 리월 1장 214노드의 본문·선택지·조건·연결을 모두 읽었다. 리월 2–4장 611노드는 별도 담당자의 [여행자 리월 검수](QA_NARRATIVE_TRAVELER_LIYUE_2026-10-03.md) 범위다. 이 보고서만으로 여행자 6장 전체 정독을 마쳤다고 주장하지 않는다.

확인된 문제는 제작 지침 문장이 지문으로 표시되는 것, 선택과 반대되는 회상, 보여 주지 않은 정보 공개를 이미 했다고 말하는 것, 귀환 후 다시 귀환하라고 안내하는 것이다. 또한 인물 대부분이 직접 본 사실과 추측을 구분하자는 같은 설명을 반복하여 성격과 갈등이 약해진다.

승인에 따라 `TRV_M01_M017`의 마지막 제작 지시문 한 문장만 **최종 화면 표시에서 제외했다**. 최종 구현은 `source/runtime_quality_fixes.js`의 `STORY_TEXT` 표시 대체이며, `content/db.json`의 원문 셀은 복원·보존했다. 다른 여행자 본문·조건·효과·연결은 이 검수에서 변경하지 않았다.

## 1. 읽기 방법과 적용 확인

`tests/helpers_v011.cjs`의 `fresh()` → `installMarketContent()` → `storyIndex().nodes` 순서로 현재 설치된 내용을 추출했다. `new Runtime(db)`만 호출한 미설치 상태를 검사 자료로 쓰지 않았다. 메인 원고 설치 실패는 0이었다.

`ROUTE_TRAVELER` 중 퀘스트 ID가 `Q_TRV`로 시작하는 1,436노드를 목록화했다. 장별 정렬은 읽기 편의를 위한 것이며 실제 재생 순서는 `NEXT`, `GROUP`, `COND`를 따라 대조했다. 뒤에 정렬되는 `JOIN_*`, `LX_*`, `REV02_*` 삽입 노드도 연결 위치를 확인하고 실제로 읽었다. 자동 분기 통과를 정독의 대체물로 쓰지 않았다.

또한 **전체 1,436노드의 `storyDisplayText()` 결과를 원본 셀과 비교**했다. 최초 정독 때의 표시 대체는 몬드 `TRV_M02_N300`, `TRV_M02_N302` 두 곳이었고, 실제 대체문까지 읽어 raw DB만 봤을 때처럼 신의 정체에 대한 반응이 없다고 오판하지 않았다. 승인 교정의 최종 구현을 표시 패치로 옮긴 뒤 다시 비교한 결과, 현재는 **`TRV_M01_M017`, `TRV_M02_N300`, `TRV_M02_N302` 세 곳**이다. 세 대체문 모두 `source/runtime_quality_fixes.js`에 있으며 M017은 `STORY_TEXT`, N300/N302는 `VENTI_REVEAL_TEXT` 항목이다.

## 2. 확정 문제

### TRV-01 — 휴식 뒤 제작 지시문이 지문으로 표시됨 [승인 교정 완료]

- 원문 위치: `content/db.json`, `55_MAIN_STORY_DB`, `TRV_M01_M017`, 본문 셀 9.
- 최종 교정 위치: `source/runtime_quality_fixes.js`, `const STORY_TEXT`의 `TRV_M01_M017` 항목과 이를 읽는 `P.storyDisplayText`.
- 종류: `NARRATION`. 최초 확인 시 `storyDisplayText()`도 원문을 반환했으나, 최종 구현에서는 승인된 두 문장만 표시한다.
- 교정 전 마지막 문장: `보고를 미룬 시간만큼 어떤 사건이 더 진행됐다고 가정하지 않는다.`

선행 경로는 `TRV_M01_M007`의 요기 선택 → M014의 가판 방문 → M015의 식사 → M016의 기사단 방문 제안이다. 문제 문장은 등장인물이 보는 사건이 아니라 시간 진행을 다루는 제작 지침이다.

교정 후 **표시 본문**은 앞의 두 문장만 남는다. DB 원문을 삭제한 상태로 배포하는 방식이 아니다.

> 휴식은 길지 않다. 여행자와 페이몬은 엠버와 함께 가판을 떠나 기사단 본부로 향한다.

최초에는 해당 DB 셀만 치환했으나, 최종 배포 구성에서는 DB를 원본으로 복원하고 기존 런타임 표시 대체 방식으로 이행했다. `STORY_TEXT`가 승인된 두 문장을 반환하므로 최종 화면 문구는 같다. 노드 ID·종류·원문·조건·효과·다음 연결 `TRV_M01_K001`과 저장 형식은 보존한다. 자산 24셀의 런타임 이행은 별도 담당 범위이며 이 문서의 서사 교정 범위로 합산하지 않는다.

최종 집중 확인 결과(2026-10-03): 정상 초기화 `fresh()` → `installMarketContent()` → `storyIndex()`에서 설치 실패 0, 여행자 본편 1,436노드를 확인했다. M017의 원문에는 삭제 대상 문장이 그대로 있고, 실제 `storyDisplayText(M017)`는 위 승인 문구와 정확히 일치한다. 반복 표시 호출 3회와 1,436노드 표시문 비교 전후에 M017 전체 배열, 원본 DB 행, 전체 인덱스 행, `JSON.stringify(r.s)`, `r.serialize()`가 모두 동일했다. 따라서 표시 조회가 저장 상태나 노드의 조건·효과·연결을 변경하지 않음을 확인했다. 원본 DB는 19열, 합성 노드는 빈 NOTE 열을 추가한 20열이므로 원문 대조는 원본 19열의 완전 일치와 추가 열의 빈 값 여부를 각각 확인했다. 노드/저장 불변 비교는 합성 완료 상태를 기준으로 전체 값을 비교했다.

검증 증거: M017 전체 노드의 표시 전후 SHA-256은 `d64435551199e30416346f456c8ff1ab44326aee9c2bc47226799ecc5884af26`로 같았고, 해당 초기화 저장의 직렬화 전후 SHA-256은 `e1bfd6e4656d9df5c08d754a07741a8e820c70bc5ac485e4ad32f965dd5bf45b`로 같았다. 후자는 검증 실행의 초기화 시간/저장 ID에 따른 값이며 고정 배포 해시가 아니다. 이 확인은 로컬 읽기 전용 표시 검증으로, `STORY_NEXT`나 실서버 요청은 실행하지 않았다.

`source/db_planned.json`에도 구문이 있지만 현재 `tools/build.py`·`tools/build_server.py`의 DB 원천은 `content/db.json`이다. 전자는 구형 `source/build_ui.py`·`source/test_runtime.js`의 참조이므로 수정하지 않았다. 최종 `content/db.json` 역시 원문을 보존하며, 현재 화면에 적용되는 교정은 위 런타임 표시 패치다. 빌드·배포 전체 검증은 부모 담당 범위다.

### TRV-02 — 결정이 재화·소모품으로 자동 변하지 않는다는 제작 설명 노출 [미해결]

- 위치: `TRV_M02_N193`, 지문, 조건 없음.
- 실제 표시: `숲의 결정은 이전 선택에 따른 위치에 그대로 있다.` / `그것은 여행자의 수중 재화나 즉시 사용 가능한 소모품으로 자동 바뀌지 않는다.`

이 장면은 바람이 시작되는 곳에서 벤티가 하프를 설명하고 결정을 보관하는 대화다. ‘이전 선택에 따른 위치’, ‘수중 재화’, ‘소모품으로 자동 바뀌지 않는다’는 상태 관리 설명이 서술자로 노출되어 있다. 바로 앞에 벤티가 보관한다고 이미 쓰여 있으므로 같은 사실을 장면 언어로 전달할 수 있다.

사실과 추측을 나누자는 인물의 대사 취향과 달리, 이 항목은 플레이어에게 불필요한 제작 규칙이 실제 표시된 것이 확인된 경우다. 수정하지 않았다.

### TRV-03 — 요기를 선택했는데 요기하지 않은 것처럼 회상함 [미해결]

- 위치: `TRV_M02_N019`, 페이몬 대사.
- 조건: `FLAG_TRV_CITY_PRIORITY=REST_FIRST`.
- 짧은 원문: `조금 전에 음식을 사며 시간을 벌었더라면` / `그때 고른 일을 되돌릴 수 없으니까`.

이 조건은 1장에서 실제로 가판에 들러 음식을 먹은 `TRV_M01_M007 → M014 → M015 → M016 → M017` 선택에서만 성립한다. 그런데 같은 선택을 하지 않았을 때의 후회처럼 회상한다. ‘더 오래 머물렀더라면’이라는 뜻인지도 현 문장에는 나타나지 않는다.

후속 편집에서는 REST_FIRST 경로에서 실제로 본 가판과 먹은 음식을 기억하도록 맞춘다. 다른 두 조건의 N020·N021도 각각 선택 이력을 대조하되, 현재 오류를 고치기 위해 선택 효과를 바꾸지 않는다.

### TRV-04 — 결정 위치를 말하지 않은 경로에도 ‘기사단에 위치는 전했다’고 말함 [미해결]

- 위치: `TRV_M02_N182`, 페이몬 대사.
- 현재 조건: `FLAG_TRV_CRYSTAL_STATE=MARKED_LEFT`만 검사.
- 원문: `기사단에 위치는 전했지만 누가 회수했는지는 아직 확인 못 했지.`

재현 가능한 선행 선택:

1. `TRV_M01_C003` — 숲의 결정은 건드리지 않고 위치만 표시한다.
2. `TRV_M01_J009` — 기사단에서 물건 이야기는 나중에 한다. `FLAG_TRV_JEAN_EVIDENCE=DEFER`.
3. `TRV_M01_L006` — 도서관 기록부터 본다. 엠버에게 현장 위치를 추가로 설명하는 L007 경로를 고르지 않는다.

J016은 물건 관련 설명을 하지 않았다고 명시한다. 2장 N073도 설명 보류를 기억한다. 이 조합에서는 결정 위치를 전한 일이 없는데 N182는 MARKED_LEFT 하나만 보고 이미 전달했다고 말한다. 위치를 실제 전달하는 경로는 J008 → J013 등으로 따로 있다.

후속 편집: 위치 표시와 위치 전달은 다른 사실이다. 해당 조건을 구분하거나, 전달하지 않은 경로에서도 맞는 회상으로 조정한다.

### TRV-05 — 두고 온 결정을 모든 경로에서 ‘숲에서 주웠던 눈물’이라 부름 [미해결]

- 위치: `TRV_M02_N367`, 페이몬 대사, 조건 없음.
- 원문: `숲에서 주웠던 눈물과 같은 색이야.`

`TRV_M01_C003`을 고르면 결정을 건드리지 않고 표식만 남긴다. 해당 경로의 C007–C009가 이를 분명히 말한다. 그런데 드발린 전투 직전에는 공통 대사가 ‘주웠다’고 기억한다. 다른 곳에서 회수한 눈물을 말하려는 것이라면 발견 장소도 맞지 않는다.

후속 편집: ‘숲에서 본’처럼 두 경로에서 공통으로 사실인 관찰인지, 소지·수거 이력에 따라 달라져야 할 회상인지 정한다. 설정을 소급하여 모두 주운 것으로 만들지 않는다.

### TRV-06 — 페이몬이 함께 겪은 선택을 모르고 두 갈래를 동시에 나열함 [미해결]

- 위치: `TRV_M02_N179`, 페이몬 대사, 조건 없음.
- 원문: `숲의 물건은 여행자가 가지고 있을 수도 있고 아직 숲에 있을 수도 있는데`.

페이몬은 1장의 두 선택 모두에서 곁에 있었다. 결정을 감싼 경로에서는 C005, 두고 간 경로에서는 C008이 각각 그 일을 확인한다. 따라서 이 시점에 페이몬이 플레이어의 현재 갈래를 모르는 듯 두 가능성을 나열하면 인물의 기억이 사라진다. 뒤 N180–N182에 조건별 대사가 이미 따로 있다는 점도 공통 N179의 부자연스러움을 키운다.

앞서 주운 뒤 기사단에 건넨 SHOW_CRYSTAL 경로도 있어, ‘여행자 소지 또는 숲’ 두 가지만을 현재 상태로 말하는 것도 정확하지 않다. 후속 편집은 세 결정의 발견 경위와 현재 보관자를 따로 정리한 뒤, 인물에게 필요한 말만 남기는 방식이 적절하다.

### TRV-07 — 리월항에 돌아와 일을 마친 뒤 다시 돌아가라고 장 종료가 안내함 [미해결]

- 위치: `TRV_LY1_N166`, `CHAPTER_END`, 현재 맵 `MAP_LIYUE_HARBOR`.
- 원문 마지막 문장: `이제 리월항으로 돌아가 다음 단서를 찾아야 한다.`

N148에서 이미 리월항으로 돌아온다. N150–N153에서 천암군에게 증언하고, N157–N164에서 타르탈리아를 다시 만나 종려를 소개받을 계획까지 세운다. N165는 항구에서 묵을 곳을 알아보는 장면이다. 장 종료 안내만 이전 시점에 남아 있어 현재 위치와 다음 목적을 잘못 말한다.

후속 편집: 귀환 안내 대신 이미 정한 다음 만남과 남은 질문을 요약해야 한다. 장소 이동이나 퀘스트 효과 자체를 바꿀 문제는 아니다.

## 3. 조건별 동행과 정보 연결의 추가 검토

### TRV-E01 — 동행을 거절해도 바로 함께 행동하는 장면으로 합류함

| 선택 | 거절 응답과 다음 연결 | 이어지는 본문 |
|---|---|---|
| `TRV_M02_JOIN_AMBER_DEFER` — ‘이번엔 우리끼리 먼저’ | 엠버는 나중에 성에서 다시 부르라고 답함 → N114 | 사당 입구에 엠버가 있고 N115에서 앞을 맡고 N119에서 불꽃을 피우며 N127–128에서 계속 현장을 확인 |
| `TRV_M02_JOIN_KAEYA_DEFER` — ‘같이 가는 건 다음에’ | 케이아는 마음이 바뀌면 기사단에서 기록을 찾으라고 답함 → N130 | N131의 초대, N136의 얼음길, N142의 ‘여행자와 케이아가’ 장치 중단 |
| `TRV_M02_JOIN_LISA_DEFER` — ‘같이 싸우는 건 나중에’ | 리사는 나중에 도서관으로 오라고 답함 → N150 | N156에서 직접 문을 열고 N157은 ‘리사와 힘을 합쳐 적을 쓰러뜨리고’라고 안내 |

카드 획득 거절과 임무 현장의 NPC 지원을 분리하는 설계는 가능하다. 다만 현재 선택 문구는 실제 동행·함께 싸우기를 거절하는 말이고, 응답도 나중의 재회를 제안한다. 바로 다음 본문이 이미 동행 중이어서 선택의 의미가 흐려진다.

이 검수는 해당 전투에서 거절한 캐릭터가 실제 파티 슬롯에 들어가는지까지 실행 확인한 것이 아니다. 무료 카드 지급 버그로 보고하지 않는다. 후속 편집은 ‘카드는 거절했어도 왜 NPC는 같은 현장에 있는가’를 자연스럽게 이어 주거나, 선택 문구와 의도된 지원 범위를 맞추어야 한다.

다이루크의 `TRV_M02_JOIN_DILUC_DEFER`는 ‘바깥길만 맡아 줘’이고 그는 부하들의 바깥길 수비를 말한다. 이후 N243에서 출입로 문서를 챙기는 것 자체는 가능한 역할이므로 같은 확정 오류로 묶지 않았다.

### TRV-E02 — 첫 인사를 넣은 인물과 생략한 인물의 차이가 큼

엠버는 `TRV_M01_A002`에서 이름·소속을 밝힌다. 벤티는 G022에서 페이몬이 이름을 물은 뒤 답한다. 진은 J002에서 직함·이름을 밝힌다. 타르탈리아도 `TRV_LY1_N069–N070`의 이름 질문과 신분 공개가 있다. 이 부분은 잘 연결된다.

반면 케이아는 M01_K002부터 길게 질문하지만 자기소개가 없다. 리사도 J001의 서술자 이름 표기 뒤 곧바로 본론으로 들어간다. 다이루크 역시 사당에서 처음 보고 N206의 술집에서 다시 만난 뒤 서로 아는 관계를 설명하지만, 페이몬이 N211에서 이미 이름을 쓴다. 적어도 이름을 어디서 들었는지나 엠버·벤티가 소개해 주는 연결이 필요하다.

리월에서는 소월축양진군이 이름·역할을 밝히기 전에 긴 사실 확인을 요구하고, 다음에는 ‘항마대성’을 전하라는 말만 듣고 페이몬이 바로 ‘소’라고 부른다(`TRV_LY1_N115–N118`). 단순히 NPC 이름표가 화면에 뜨는 것과 등장인물들이 서로를 아는 것은 구분해야 한다. 개인 임무 선행 만남이 가능한 경우라면 실제 만남 이력을 확인한 뒤 첫 만남 경로만 다듬는다.

### TRV-E03 — 리월에서 도망쳐야 하는 이유가 장면의 증거와 약하게 연결됨

`TRV_LY1_N047`의 병사는 ‘당신을 범인으로 정한 건 아니다’라고 말하고, N055는 이름과 머물 곳부터 알려 달라고 한다. N054도 병사들이 특정인을 공격하지 않는다고 명시한다. 그런데 페이몬과 여행자는 이미 끌려가면 설명할 상대가 사라지고 조사 기회도 없어진다고 판단하며 도망친다. 선인에게는 ‘누명을 쓰고 있다’고 호소하는 선택까지 이어진다(N112).

원작을 따라 도주 사건을 유지하는 것은 가능하다. 현재 원고는 천암군의 대응을 공정하고 신중한 조사로 자세히 풀면서, 주인공이 도주해야 할 절박한 장애는 보여 주지 않는다. 그래서 탈출을 도운 타르탈리아를 따라가야 하는 필요도 약해진다. 천암군을 무조건 악인으로 만들 필요는 없다. 군중의 실제 오해, 통제의 위험, 놓치면 사라질 구체적 단서 등 인물이 도주를 택한 이유를 장면으로 납득시켜야 한다.

### TRV-E04 — 타르탈리아가 알려 주기 전에 페이몬이 ‘선인?’이라고 받음

`TRV_LY1_N077`은 ‘제군의 일은 … 계약을 맺은 자들 모두에게 닿아’와 ‘항구의 명령만으로 닿지 않는 이들’이라고만 말한다. N078의 페이몬은 ‘선인?’이라고 정확히 받는다. 행상에게 절운간 이야기를 들었다는 짧은 설명은 있으므로 불가능한 추론은 아니다. 다만 처음 듣는 플레이어에게는 이름을 알려 줄 단계가 빠져 대화가 정답을 미리 아는 듯 흐른다. 정보 제공과 이해·반응의 순서를 확인한다.

## 4. 대화·목적·장면 호흡에 관한 편집 판단

### TRV-E05 — 대부분의 인물이 같은 ‘사실과 추측 구분’ 강의를 반복함

몬드에서는 엠버·케이아·리사·진·벤티·페이몬, 리월 1장에서는 타르탈리아·천암군·소·세 선인까지 비슷한 논리와 길이로 말한다. 다음은 일부 대표 위치다.

| 인물·장면 | 대표 노드 | 반복되는 내용 |
|---|---|---|
| 엠버의 첫 보고 | M01_A009, M012 | 실제 본 것과 소문 구분 |
| 리사의 도서관 | M01_L004, L009 | 책·기억과 현장의 상태 구분 |
| 케이아의 사당 | M02_N135, N141 | 적·함정·바람을 각각 기록, 그럴듯한 범인 만들지 않기 |
| 진의 의뢰 설명 | M02_N247 | 사당 조사와 눈물 수집을 한 임무로 기록하지 않기 |
| 페이몬의 결정 관리 | M02_N070, N179–182, N219, N245, N267, N278 | 물건의 발견 경위·위치·개수를 섞지 않기 |
| 리월의 접촉과 보고 | LY1_N075, N095, N104, N121, N133, N138, N151, N159 | 같은 사건을 같은 주의사항과 함께 재진술 |

확인하지 않은 사실을 단정하지 않는 인물은 설득력이 있을 수 있다. 그러나 그 원칙을 매 장면 대사로 길게 반복하면 인물의 욕심·실수·농담·갈등이 그 뒤로 밀린다. 페이몬조차 바로 다음 대사를 말하기 전에 자기 발언의 한계를 설명하는 경우가 많아, 갑작스러운 놀람이나 기쁨이 약해진다.

후속 편집은 ‘기록’이라는 단어를 일괄 삭제하는 방식이 아니다. 한 장면에서 새로 알아야 할 사실은 무엇인지, 누가 무엇을 원해서 상대의 말을 막거나 받아들이는지 먼저 정한다. 이미 행동으로 지킨 원칙을 매번 설명하지 않는다. 소·타르탈리아·리사가 같은 증언 교육을 반복할 필요도 없다.

### TRV-E06 — 제약을 존중한다는 말이 많지만 실제 선택은 바로 고정 진행됨

`TRV_M02_N082`는 위험한 결정을 조사할 의무가 없다고 길게 말하지만 N083에서 바로 손을 뻗는다. N202의 벤티는 계획을 멈추고 싶다면 그 말을 들어야 한다고 말하지만 N203에서 바로 밤의 성당 지하에 들어간다. 주인공이 그 제안을 어떻게 받아들였는지 드러내는 대답이 없다.

선형 메인 이야기라서 모든 행동에 거절 갈래가 필요한 것은 아니다. 다만 거절권·판단권을 계속 강조한 뒤 선택도 수락 대사도 없이 강한 결정을 넘기면 말과 연출이 충돌한다. 한 줄의 실제 결심이 반복되는 배려 설명보다 유용할 수 있다. 특히 절도 계획은 보고·허가를 중시하던 앞 장면과도 대비되므로 왜 이 방법을 택했는지 주인공의 판단이 필요하다.

### TRV-E07 — 인물의 이름을 계속 반복하는 대사가 부자연스러움

예: 벤티 `TRV_M01_G002`, `TRV_M02_N285`, N289의 ‘드발린’ 반복, 페이몬 전반의 ‘여행자/여행자의’ 반복, 시뇨라 N401과 벤티 N402의 상대 이름 반복이다. 바로 눈앞의 상대를 두고 계속 고유명사를 말해 상대에게 이야기하는 느낌보다 설명문을 읽는 느낌이 생긴다.

한국어 공식 말투를 확인하지 않은 상태에서 ‘너’를 일괄 치환하자는 뜻은 아니다. 같은 상대와 같은 장면 안에서 생략해도 뜻이 분명한 주어까지 계속 쓰는지 점검한다. 호칭은 관계·거리·감정이 바뀌는 곳에서 의미 있게 남긴다.

### TRV-E08 — 관계 설정을 지문이 직접 검사하는 듯한 문장

`TRV_M02_N146`의 ‘서로를 알아보지만 처음 만나는 사이처럼 인사하지 않는다’, N214의 ‘여행자와 페이몬이 그들 사이의 과거를 안다는 뜻은 아니다’, N322의 ‘선택은 달라도 갈 곳은 같구나’가 대표적이다.

관계의 사실관계는 맞출 필요가 있다. 다만 플레이어는 ‘처음 만나는 사이가 아닌지’를 검사한 설명보다 익숙한 호칭, 짧은 불평, 끊긴 대화, 상대가 미리 내놓은 물건을 통해 그 사실을 느끼는 편이 자연스럽다. 여러 선택이 합류한다는 것도 등장인물이 직접 알리는 문장으로 처리할 필요는 없다.

### TRV-E09 — 사당·결정의 구분을 너무 자주 다시 설명해 목표가 업무 목록처럼 느껴짐

M02_N247–N251에서 세 사당과 새 눈물 세 곳을 구분한 뒤 N253, N260–N261, N267, N275, N278에서 계속 이름·분류·개수를 확인한다. 플레이어가 길과 목적을 헷갈리지 않게 하는 장점은 있으나, 각 장소의 새 갈등보다 목록 관리가 대화의 중심이 된다.

목적 자체는 이어진다. 사당의 바람을 끊어 공습을 약화하고, 눈물의 정화 능력을 확인하여 하프를 고치고, 첫 재회의 실패 때문에 폐허로 갈 새 방법을 찾는다. 문제는 이 목적을 한 번 정한 뒤 행동하면서 드러내기보다 같은 차이를 여러 인물이 거듭 설명하는 호흡이다.

### TRV-E10 — 보관고의 위치 설명과 지명이 어긋나는 후보

N228은 ‘바람숲 쪽 오래된 보관고’, N233은 성 밖으로 직접 움직이겠다고 하고 N235에서 보관고에 도착한다. 그런데 N236의 벤티는 하프가 ‘아직 성 밖으로’ 나가지 않았다고 말한다. 지도 데이터는 부모 맵이 `MAP_MOND_PLAINS`이지만 환경 분류는 ‘도시/실내’여서 자료 자체도 한 방향으로 명확하지 않다.

성 바깥의 보관고인지, 성 안의 숲 쪽 창고인지 먼저 결정해야 한다. 외부 지도나 현장 화면까지 확인하지 않았으므로 확정 공간 오류로 세지 않았다. ‘아직 몬드 지역을 떠나지 않았다’라는 의도와 ‘성 밖’을 혼동한 것인지도 확인 대상이다.

### TRV-E11 — 성당 습격 뒤 함께 옮긴 벤티를 다시 찾아 나오는 전환

M02_N405는 여행자가 벤티를 안전한 곳으로 옮기고 페이몬도 뒤따른다고 한다. N406은 곧바로 바람이 시작되는 곳이며, N407은 페이몬의 ‘찾았다! …중간에 안 보이면 걱정되잖아’다. 일행이 언제 헤어졌고 벤티가 언제 혼자 먼저 떠났는지가 없다.

그 사이에 회복·이동 시간을 생략할 수는 있지만, 같이 데려가던 상태에서 찾는 상태로 바뀌는 최소 연결은 필요하다. 새로운 사건을 추가할 문제라기보다 장면 전환을 명확히 할 문제다.

### TRV-E12 — 같은 장소의 한글 표기가 다름

`TRV_M02_N248`, N249, N269는 ‘다다우파 협곡’, N270·N277은 ‘타타우파 협곡’이다. 같은 탐색 목표가 두 표기로 나온다는 것은 내부에서 확인된다. 어느 표기가 한국판 공식 명칭인지는 공식 한국어 지명 자료를 확보한 뒤 맞춰야 한다. 이번 검수에서는 임의로 일괄 치환하지 않았다.

## 5. 오류로 세지 않은 점과 유지할 부분

- **진·다이루크의 신 정체 반응은 실제 표시본에 있다.** M02_N300/N302의 raw 셀만 보면 화자 없는 말처럼 보이지만 `storyDisplayText()`는 놀람·침묵·호칭 변화가 있는 지문을 반환한다. 이 둘을 결함으로 세지 않았다.
- **첫 결정의 두 처리 경로는 상당 부분 지켜진다.** M01_J007/J008 선택 조건과 M02_N071–N075는 전달·보류·숲에 남김을 구분한다. 문제는 그 이후의 N179/N182/N367 회상이다.
- **주인공 능력에는 선행 연결이 있다.** M01_E002가 신상과 공명해 바람을 얻은 일을 명시한다. M02_N005–N009가 날개를 배우는 장면이고 공습에서는 난간에서 떨어져 반사적으로 펴게 된다. 아무 준비 없이 곧바로 비행 능력을 쓰는 구조는 아니다.
- **동료 획득 제안과 수락은 존재한다.** 엠버·케이아·리사에 각각 제안·선택·획득 노드가 있다. 카드만 갑자기 지급된다고 일반화하지 않는다. 다만 거절 경로의 동행 문구는 E01 문제다.
- **퍼즐에는 장면 차이가 있다.** 폐허 중앙 장치로 주변 세 잠금이 드러나고, 북쪽은 발판·바람, 서쪽은 적과 돌문, 동쪽은 높이가 다른 기둥이라는 장애를 제시한다. 모두 단순히 같은 버튼을 누르라는 원고로 묶지 않는다. 실제 조작과 연출의 품질은 별도 화면 검증이 필요하다.
- **드발린은 죽은 것으로 마감되지 않는다.** 마지막 가시 제거 뒤 일행을 스스로 받아 주고, 재방문 여부를 자신이 정하도록 한다. 승리와 치료·관계 회복을 구분한 의도는 분명하다.
- **리월의 다리 구조 장면은 행동 선택으로 나뉜다.** `REV02_TRV_BRIDGE_*`는 옆 바위 접근, 수레 고정, 화물 하역에 따라 실제 구조 방법을 다르게 보여 준다. 구한 상인을 이번 장에서 갑자기 원신 주요 인물로 정체 변경하지 않는다.
- **류운차풍진군과는 실제 의견 충돌이 있다.** LY1_N139의 도시 징벌 의사와 두 설득 선택, 힘을 거두는 N147까지 이어진다. 다만 다른 선인들과 같은 사실 확인 설명은 여전히 많다.

## 6. 공식 한국어 대조의 한계

공식 한국어 자료의 확보 상태는 [몬드 정독 보고서 6절](QA_NARRATIVE_MOND_2026-10-03.md#6-공식-한국어-참고-자료와-판정-보류)에 기록했다. 공식 사이트와 HoYoLAB은 대사 본문이 비어 있는 동적 페이지, X 일부는 403으로 반환됐다. 팬 재게시를 공식 원문을 직접 읽은 것으로 취급하지 않았다.

따라서 이 보고서는 진의 반말, 다이루크의 하오체, 선인들의 어미가 공식 한국어와 일치하거나 어긋난다고 확정하지 않는다. ‘원작이라면 이 인물은 절대 이렇게 행동하지 않는다’는 판정도 하지 않았다. 2절은 본 원고 내부의 선택·사실·장소와 실제 표시문을 대조한 결과이고, 3·4절은 현재 대화의 자연스러움과 장면 설득력에 관한 편집 판단이다.

## 7. 후속 작업 단위

1. TRV-01의 현재 빌드 반영을 확인한다. 같은 노드 ID·타입·조건·효과·연결을 유지한다.
2. 결정 이력을 ‘발견 장소 / 현재 보관자 / 기사단에 전달한 정보’로 나눠 TRV-04~06을 한 묶음으로 교정한다. 최소한 HELD+SHOW, HELD+DEFER, LEFT+LOCATION, LEFT+DEFER+RECORD_FIRST를 각각 읽는다.
3. REST_FIRST 회상 TRV-03과 리월 귀환 안내 TRV-07을 선행 장면에 맞춘다.
4. TRV-02와 E08의 제작 설명을 우선 걷어 낸다. 없애는 정보가 실제 조작에 필요한 경우에는 장면 밖의 안내로 전달할지 판단한다.
5. 엠버·케이아·리사의 수락·거절을 한 인물씩 읽어 카드 획득, 이야기 동행, 전투 지원의 의미를 맞춘다. 실제 획득 효과는 서사 편집과 분리해 검증한다.
6. 첫 만남을 한 인물씩 확인한다. 이름표와 서술자의 지식을 인물 간 소개의 대체물로 쓰지 않는다.
7. 리월의 도주 목적과 몬드의 하프 회수 결심을 각각 한 장면으로 검토한다. 인물이 자기 목적 때문에 결정을 내린 근거를 남긴다.
8. 긴 대화는 한 장씩 정리한다. 캐릭터마다 같은 원칙을 설명하는 문장부터 줄이고, 실제 반응·행동·의견 차이가 남는지 읽는다.
9. 공식 한국어 원문은 인물별로 확보한다. 호칭·친밀도·위기 상황이 같은 장면끼리 비교하고, 출처 없이 한국어 어미만 일괄 치환하지 않는다.
10. 각 작업이 끝나면 바꾼 장면의 실제 출력 일부를 제시하고, 어떤 선택 조합에서 읽었는지 기록한다. 자동 노드 통과만으로 완료 처리하지 않는다.
