# 0.15.22 상태 이름·설명과 실제 효과

0.15.21 조사표의 ‘설명 없음’, ‘알 수 없는 항목’과 동작하지 않던 격려·기절을 후속 수정했다. 기존 전체 조사 내용은 `STATUS_EFFECTS_KO.md`에 보존한다.

## 구현한 변경

- `runtime_status_catalog_v01522.js`: 101개 상태의 표시 이름·설명. 캐릭터 전용 부여, 혈매향, 단류, 단화인, 운명의 자리 등 공통 상태 DB 밖의 효과도 조회한다.
- `app_revision.js`와 `app_experience.js`: 공통 DB·전용 목록·실제 능력치 수정값을 함께 설명한다. 상태 칩을 누르면 현재 표시 중인 효과 목록을 읽는다. 전투 재생 중 새로 붙은 칩도 설명을 열 수 있다.
- `runtime_status_v01522.js` → `presentation.js` → `app_battle_fx_v01521.js`: 실제로 성공한 상태 부여만 `statusApplied` 사건으로 기록한다. 기술 이름을 보고 상태가 붙었다고 추정하지 않는다. 빙결·연소·감전 등도 해당 대상에게 붙는 순간 표시한다.

| 효과 | 0.15.22에서 실제 하는 일 |
|---|---|
| 베넷 · 격려의 영역 | 아군 HP가 70% 이하이면 라운드 끝에 베넷 최대 HP의 6% 회복. 70% 초과이면 베넷 기초 공격력의 40%를 공격력에 가산. 영역 안의 아군에 불 원소를 부착한다. |
| 베넷 · 모험 동경(C1) | 공격 증가의 70% HP 조건을 없애고 계수를 60%로 높인다. 과거 별도 파티 공격력 +20% 배율을 중복해서 더하지 않는다. 겹친 영역은 가장 큰 공격 보너스 한 개만 적용한다. |
| 베넷 기초 공격력 | 캐릭터 기본 공격력의 레벨·돌파 성장 + 장착 무기의 공격력. 음식·장신구·성유물·전투 버프를 다시 포함하지 않는다. |
| 기절 | `STATUS_STUN`이 살아 있는 동안 행동 잠금과 기술 선택 사유에 반영한다. 유적의 뱀의 기존 기절 부여 기믹이 실제 행동 정지로 이어진다. |
| 무상의 바람 | 고유 바람 부착을 유지한다. 불·물·얼음·번개 공격은 확산을 일으키지만 외부 원소가 지속 부착된 상태로 바뀌지 않는다. |
| 무상의 뇌전·얼음, 물의 정령·물 형상 | 고유 원소를 유지하며 외부 지속 부착으로 덮어쓰지 않는다. 반응·피해·고유 면역은 전투 규칙으로 처리한다. |
| 무상의 바위 | 고유 바위 표시는 유지하되 외부 원소와 공존할 수 있다. 고유 바위를 역방향 결정 반응의 반응물로 사용하지 않는다. |

회복 6%, 공격 증가 40%/60%, 라운드 지속시간은 **이 턴제 게임의 밸런스 계수**다. 원신의 실시간 초 단위 지속시간이나 특성 레벨별 계수와 같은 숫자라고 설명하지 않는다. 원작의 조건 구조(HP 70%, 기초 공격력, C1의 제한 해제)를 따른다. 바바라 원소폭발 재사용은 6, 베넷은 5라운드로 조정했고 각성 원소폭발의 공격 배율은 1.5다.
