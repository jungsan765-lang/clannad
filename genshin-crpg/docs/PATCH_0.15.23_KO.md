# 0.15.23 · 튜토리얼 수정과 전체 밸런스 점검

## 이번에 바뀐 것

- 튜토리얼의 큰 안내 카드를 제거했다. 실제 조작 대상 주변에만 밝은 구멍과 테두리를 두고, 다른 곳은 어둡게 하며 클릭·키보드 입력을 막는다. 안내 문장은 화면 위에 떠 있으므로 게임판에 별도 칸을 만들지 않는다.
- 새 안내를 쓰는 저장에서는 예전 자동 장비 설명 팝업도 띄우지 않는다. 조작 안내나 통신 재시도 버튼 위에 다른 설명 창이 끼어들지 않게 했다. 도움말에서 장비 설명을 직접 여는 기능은 유지한다.
- 실제 첫 지도 목적지 → 이동 → 도착한 이야기로 이어진다. 이야기 대화는 원래 장면을 사용한다.
- 여행자 첫 슬라임 전투 준비에서 **편성 → 엠버 선택 → 엠버 장비 → 활 장착 → 전투 준비 → 시작 → 기본 공격 → 적 선택 → 실행**을 직접 한다. 무기를 자동으로 입혀 장착 조작을 건너뛰지 않는다.
- 엠버를 미소유한 경우 이 첫 전투에만 동행한다. 승리 후 임시 편성과 대여 활만 회수한다. 이미 기원으로 소유했다면 그대로 남는다. 이 처리는 '기원 전용 캐릭터 소유' 규칙의 영구 무료 지급 예외가 아니다.
- 방어와 원소전투 스킬은 아직 배우지 않았고 해당 조작이 가능한 실제 전투 차례에 안내한다. 첫 전투가 빨리 끝나면 다음 실제 전투에서 이어진다. 별도 훈련실로 보내지 않는다.
- 비경·기원·책·강화·첫 돌파를 차례대로 강제하던 긴 실습 경로를 제거했다. 채집·채광·사냥은 처음 해당 작업을 이용할 때 안내한다.
- 예전 '나중에 계속'으로 꺼 둔 0.15.22 안내 기록은 새 방식으로 이어진다. 이미 끝낸 구형 전투 훈련은 배운 것으로 보존한다. 저장/패배/재도전/중복 요청에서 장비나 보상을 반복 지급하지 않는다.
- 전투 용어는 **아군 소환체 / 적 소환체**로 정리했다.
- 주인공 사망 후 회복 AI와 무적 보스가 교착하면 기존 자동 처리 한도(2,000회)에서 후퇴 결과를 저장한다. 이전처럼 `COMBAT_LOOP` 오류가 나고 마지막 행동이 되돌아가지 않는다. 살아 있는 주인공의 보스 전투 라운드 제한을 신설하지 않았다.

## 점검했지만 아직 해결하지 않은 것

**밸런스는 아직 맞았다고 할 수 없다.** `BALANCE_AUDIT_V01523_KO.md`에 실제 수치와 재현 코드를 정리했다.

- 4인 파티 필드 344회/비경 96회 전승, 비경 평균 1.21라운드. 같은 장비 비경을 혼자 하면 7~11라운드 또는 패배한다.
- 높은 비경 단계의 적 편성이 더 단순해지는 역전이 있다.
- 상시 기원 20회 단차와 10연속 두 번의 동료 보장 규칙이 다르다.
- 초반 리월 캐릭터의 돌파 특산물 공급과 비경·고정 정예의 조건부 전리품이 성장 경로를 불편하게 한다.
- 보스/치유는 조합 및 기믹 대응에 따라 편차가 크다. 합성 자동 조작의 승패를 실제 사용자 승률이라고 제시하지 않는다.

이번 판에서 모든 성장 수치를 다시 맞췄다는 뜻이 아니다. 캐릭터 레벨·비용·보스 능력치를 일괄 변경하지 않았다.
