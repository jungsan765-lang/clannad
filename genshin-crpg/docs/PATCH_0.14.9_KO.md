# 0.14.9 패치 노트 (테스트 서버 후보)

0.14.7~0.14.8 테스트에서 받은 의견의 두 번째 묶음입니다. 승인 전에는 main 병합과 운영 반영을 하지 않습니다.

## 전투 (`source/runtime_combat_v0148.js`, `source/app_combat_fx.js`)

- **원소 부착**
  - 원소는 원래 맞으면 항상 붙습니다(`runtime_rules.js`의 `damage`).
  - 다만 공격 자체가 명중 판정(명중−회피+10, 65~98%)으로 6~16% 빗나가서, 원소 스킬이 가끔 원소를 못 남겼습니다.
  - 이제 아군의 `_E`·`_Q` 카드(주인공 포함)는 `sureHit`로 빗나가지 않습니다. 일반 공격·적 공격은 그대로입니다.
- **피해 숫자**
  - 숫자는 `app_av.js`가 그립니다(손대지 않는 파일). `app_combat_fx.js`의 MutationObserver가 붙는 순간 글자만 바꿉니다.
    - 「HP -123」 → 「123」
    - 보호막은 작은 줄로 따로 표시
    - 치명타는 글자 대신 큰 크기로 표시
  - 원소 색 그라데이션과 튀어 오르는 움직임은 `shell.css`에 있습니다.
  - 원소 반응 이름은 가운데 배너 대신 그 대상의 숫자 위에 붙습니다(`CombatFX.reactionTags`).
- **이세계인 직업 재설계**
  - 기본 능력치: HP 560·공격력 62·방어력 30·속도 63(이전 480/40/30/55).
  - 방어력을 그대로 둔 이유: 나선비경 6층부터 적이 방어력이 가장 낮은 아군을 노리는데, 기준 공략이 이세계인이 공격을 받아 주는 데 기대고 있습니다. 방어 42로 올리면 10층 클리어율이 3/16 → 0/16로 떨어졌고, 30으로 두면 11/16이었습니다.
  - 이전 저장은 불러올 때 한 번만 차이를 더합니다(`PROTAGONIST_ISEKAI_V2`). 그동안 얻은 능력치 증가는 유지합니다.
  - E 「약점 간파」: 공격력×1.5 물리 피해 + `STATUS_ISEKAI_EXPOSED` 2라운드(파티가 주는 피해 +20%, 보스 +12%, `combatDamageMultiplier`). 재사용 2.
  - 예전 E(일시 최대 HP 감소)는 진행 중이던 전투 저장의 복원용으로만 남습니다.
  - Q 「함께하는 일격」: 동료는 자기 원소(전투원의 `[불]` 같은 태그)로, 주인공은 물리로 함께 공격합니다. 추가 배율 20 + 공격력×0.1 + (레벨−1)×1.5%, 최대 60%. 재사용 3.
- **나선비경 확인**: 기준 파티, 시드 8개씩. 1층 6→8, 3층 4→8, 11층 6→8 클리어로 조금 쉬워졌고, 나머지 층은 같았습니다. 10층은 위와 같습니다.

## 경제·제작 (`source/runtime_economy_v0148.js`, `source/app_forge_v0148.js`)

- 리월항의 공용 대장장이(`MRC_BLACKSMITH_COMMON`)를 몬드처럼 리월 장비점에 합쳤습니다(`placeMergedInto`, `placeStockMerchants`). 대장장이용 제작법도 리월 장비점에서 됩니다.
- 리월 잡화점·장비점에 몬드에 있던 품목을 리월 물가로 들였습니다(`STK_V0148_LY_*`).
  - 리월의 약재·치료품 상점은 원래 비운 상회 거리의 「불복려」에 있습니다.
- **4성·5성 무기는 제작으로만 얻습니다.**
  - 어떤 상점 재고도 팔지 않습니다(`SYSTEM_DISABLED`, 장비 표 구매 가능 = N).
  - 기사단 장비 보급(페보니우스 5종)과 나선비경 첫 정복(이나즈마 4성 6종)은 무기 대신 `BP_<무기 ID>` 단조 도면을 줍니다(제작 도면 분류라 교환 불가).
  - 도면 제작법 `REC_BP_<무기 ID>`: 도면 1·수정덩이 4·원소 가공목 2·모라 400~500, 몬드성/리월항 `MRC_BLACKSMITH_COMMON`, Lv.4 이상.
  - 이미 가진 무기와 시험용으로 지급되는 무기에는 영향이 없습니다.
- 제작 화면
  - 제작법 카드를 그대로 두고 등급 색 타일 목록과 상세 칸으로 다시 배치합니다(카드를 옮길 뿐 다시 만들지 않음).
  - 상세 칸은 장비 표의 기본 능력치·고유 효과를 보여 줍니다.
  - 강화 패널이 있으면 「제작 / 강화·돌파」 탭으로 나눕니다.

## 엠버 개인 임무 (`source/runtime_personal_v0148.js`)

- 엠버는 본편에서 합류해 「동료 획득」 소개 목록에 나오지 않았습니다. 그래서 개인 임무(`LEG_MOND_AMBER` / `LEG_ISK_MOND_AMBER`)를 찾을 곳이 없었습니다.
- 합류 깃발과 몬드 도입부 깃발이 서면, 다음 행동 때 소개 기록(`guildLegends[id] = {day, auto:true}`)을 남깁니다.
- 여행 안내에 「동료의 개인 임무」 단계를 넣고, 한 번 알림을 띄웁니다(`app_tutorial.js`).
- 임무 내용, 비용, 첫 완료 시 호감도 +10, 전투 호감도 규칙은 바뀌지 않았습니다.

## 원석·특성·운명의 자리 (`source/runtime_premium_v0148.js`, `source/app_premium_v0148.js`)

- **재화**: `PRIMOGEM`, `STARGLITTER`, `STARDUST`(전역, 0 이상 정수). 얻을 방법은 아직 없습니다(사용자 결정). 비영리이므로 현금 결제는 없습니다.
- **상점**: `PREMIUM_BUY`
  - 원석: 운명의 별 1600, 스타더스트 75개 160
  - 스타라이트: 운명의 별 34
  - 스타더스트: 영웅의 경험 20, 수정덩이 2개 10, 10,000 모라 10
- **운명의 자리**: `CONSTELLATION_UNLOCK`이 `STELLA_<캐릭터>`를 하나 써서 한 칸 엽니다(최대 6).
  - 1: E +15%
  - 2: Q +15%
  - 3: E 특성 +3
  - 4: 공격력 +10%
  - 5: Q 특성 +3
  - 6: 모든 피해 +15%
- **특성**: `s.talents[id] = {na, e, q}`(1~10, 기본 1). 레벨 1 초과분마다 해당 공격 +7.5%. 올리는 방법은 아직 없습니다.
- **서버**: 새 행동 두 개를 `server/game-core.mjs`의 허용 목록에 넣었습니다. `server/worker.mjs`(Cloudflare, 비상 복구용)는 손대지 않았습니다.
- **화면**: HUD의 원석(누르면 상점), 페이몬 메뉴 「상점」, 장비·성장 화면의 특성·운명의 자리.

## 이동 지도 경로 (`source/terrain_map.js` `roads`, `source/app_navigation.js`, `tools/trace_terrain_roads.py`)

- 연결된 두 지점 사이 길을 지도 그림에서 찾아 경로점으로 저장했습니다(54개).
  - 길 색 픽셀은 싸게, 땅은 7배, 물은 45배로 쳐서 가장 싼 길을 찾고, 2.2px 기준으로 줄였습니다.
  - 지점이나 연결, 지도 그림을 바꾸면 `python tools/trace_terrain_roads.py`를 다시 돌려 `roads`를 갈아 끼우면 됩니다.
- 이동 지도는 현재 위치에서 나가는 길을 모두 점선으로 그리고, 다른 길과 갈라진 지점에 목적지 번호를 붙입니다.
- 카드에 마우스를 올리거나 목적지를 고르면 그 길이 금색으로 강조됩니다. 여러 구역을 거치는 목적지는 남은 구역의 길까지 이어 그립니다.
