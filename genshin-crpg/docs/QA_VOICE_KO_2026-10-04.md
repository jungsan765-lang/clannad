# 한국판 말투 확인 — 스토리 무수정

사용자 요청(2026-10-04 00:49 KST): Claude가 스토리를 작업 중이므로 일반 대사·사건·말투는 그대로 둔다. 책 속 ‘주인공’을 ‘클라나드’로 바꾸는 것처럼 문장의 대상을 망가뜨리는 표시 결함만 고친다. 말투는 한국어 대사와 대조하여 이상 후보를 보고한다.

**이번 말투 검사로 수정한 제품 대사·원고는 0건이다.** 응광·행추·연비·각청·케이아·다이루크·캐서린을 우선 대조했다. 모든 43인·모든 상대·공식 음성을 전수 검증했다는 뜻은 아니다. 감우·소·진·리사·벤티의 추가 표본은 각 담당 보고서의 제한 범위를 따른다.

## 우선 결론

- 응광의 `~하네/~네`만 보고 잘못된 말투로 판단하지 않는다. 한국어 생일 편지 전재에 “어떤 빛을 발하게 될지 궁금하네.”가 있고, 음성 대사 전재도 편한 반말과 `~네/~군`이 혼용된다. 공식 직접 확보와 전재를 구별한다.
- 반대로 그 한 어미가 확인됐다고 `자네/~라네/~하겠네`를 응광의 기본형으로 지정하지 않는다. 이전 채팅의 “누가 자네를 탓하기라도 했나?”는 공식 검증을 마친 교정안이 아니며 사용하지 않는다.
- 각청도 공식 한국 계정 글에서 “마음 쓰게 했네”라고 한다. `~네`를 남성적/연장자 말투라는 인상만으로 지우지 않는다.
- 캐서린의 반말, 다이루크의 `자네`도 한국어 대사 전재에서 확인되는 표현이다. 각각 ‘접수원은 항상 존댓말’, ‘다이루크는 너/네만’이라는 규칙으로 바꾸지 않는다.
- **이번 표본에서 어미 때문에 긴급 수정해야 할 명백한 원작 말투 위반은 확정하지 못했다.** 아래는 문체·맥락 검토 후보이며 자동 교정 목록이 아니다.
