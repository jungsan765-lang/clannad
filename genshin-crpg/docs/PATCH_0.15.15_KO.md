# 0.15.15 패치 노트 (알파 테스트) — 틀린 그림 찾기 휴식, 화면 검사

기준: 0.15.14(`d068307`, PR #20의 감사 후속). 이야기 · 대사는 바꾸지 않았다.

- 「이제보니 틀린그림찾기 기회 다 닳으면 30초 기다리는거도 추가하자. 해보니까 그게 없으니까 그냥 체력이 있나 없나 똑같은 것 같아.」
- 「PR#20 체크하고 검사한거 고칠만한거 있으면 고치고 테섭에 올려. 그리고 화면 검사... 해야될 것 같으니까 화면 검사도 하고.」

## 바뀐 내용
- **틀린 그림 찾기 휴식**(`app_chests_v01415.js`의 `spotGame`): 기회(몬드 5 · 리월 3)를 다 쓰면 찾은 곳이 지워지고 30초 쉰다. 쉬는 동안 하트가 비고 그림이 어두워지며, 남은 초가 보이고, 눌러도 기회가 줄지 않고, 힌트는 이유와 함께 잠긴다. 휴식은 퍼즐(다른 곳들의 위치)마다 기억해서(`crpg-spot-rest`, 브라우저 저장소) 창을 닫았다 열거나 새로 고쳐도 이어진다. 지역 사건의 같은 퍼즐에도 적용된다.
- **다인 모드 구석 버튼**(`app_coop_v0153.js`의 `roaming`/`pill`): 필드 화면(LOCATION, 시설 밖)에서만 보인다. 호감도 · 캐릭터 · 가방 같은 메뉴 화면에서는 숨긴다(PR #20: 관계 · 생활 마지막 버튼을 가릴 위험). 보이는 동안 `body.cp-world-on`이 필드 목록 끝에 여백을 둔다(휴대폰 탭 86px, PC 좌우 열 64px).
- **창 머리**(`shell.css`): 내용이 화면보다 길 때 창 머리가 줄어들지 않는다(`flex-shrink:0`). 320px 휴대폰에서 상자 창 머리가 25px로 눌려 두 줄 제목의 윗줄이 창 위로 밀리던 것을 고쳤다.

## 화면 검사 (로컬 미리보기, 계정 둘, 실제 클릭)
- 관계(호감도) 화면: 동료 10명, 마지막 카드의 호감도 임무를 펼쳐 끝까지 내렸을 때 마지막 행(5단계)이 보이고 눌림 — 320×640, 375×812, 759 · 760 · 761×900(휴대폰/PC 배치 경계), 812×375(가로), PC 틀 1280×800 · 1440×1000 · 1920×1080 · 2560×1440 · 3840×2160. 가로 휴대폰에서는 열린 학습 안내 카드가 가리지만 「안내 잠시 숨기기」로 닫힌다.
- 생활: 몬드 외곽 초원에서 채집 버튼을 실제로 눌러 채집 완료 창까지 확인. 목록 끝까지 내려도 구석 버튼과 겹치지 않음.
- 필드 이동 탭: 끝의 「지도 보는 법」을 실제로 눌러 펼침. 구석 버튼이 펼쳐졌을 때 · 접혔을 때 모두 겹침 없음. 글자 150%에서도 같음.
- 다인 모드 창: PR #20의 포커스 가두기와 함께 대화 입력 중 상대 말이 와도 글 · 커서 유지, Tab은 창 안에서만 돎, Esc로 닫히고 뒤 화면이 풀림, 쓰던 글은 다음에 열 때 남음. 글자 150%에서 넘침 · 한두 글자 줄바꿈 없음.
- 틀린 그림 찾기: 375 · 320px에서 다섯 번 틀려 휴식 → 창 닫고 다시 열기 → 휴식 중 누르기 → 30초 뒤 하트 복구 · 힌트 다시 켜짐.
- 하지 않은 것: 실제 iOS · Android 기기, 설치형 PWA, OS 화면 배율, 가상 키보드, 장시간 VPS 부하.
