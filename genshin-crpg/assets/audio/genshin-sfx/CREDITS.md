# v0.12 효과음 조사 결과

`ready/`의 MP3 26종은 총 827,436 bytes다. 모든 파일은 ffprobe 형식·길이 확인, ffmpeg 전체 디코딩 검사를 통과했다. 내려받은 ZIP도 CRC 검사를 통과했다. 원본 전체 길이를 유지하고 메타데이터를 제거했으며, 원본 peak가 -6 dBFS를 넘으면 감쇄했다. 청각 입력을 지원하지 않는 실행 환경이므로 사람이 실제로 들어본 음질 검증은 수행하지 못했다.

파일별 출처·해시·용도는 `integration-manifest.json`에 있다. 원본 게임 제작사와 녹음 모음 제작자를 함께 표기해야 한다.

## 연결을 보류할 후보

- `dendro`: 파일명은 해당 풀 캐릭터 스킬이나, 모음의 변경 기록이 2022년 출시 전 녹음이라고 명시한다. 출시된 본편과 동일한 소리인지 비교하지 못해 권장하지 않는다.
- `rock`: 본편 바위 원소폭발 녹음. 음성 혼입 여부를 직접 청취하지 못했으므로 기본 연결은 보류한다.
- `water_ambience`: 수영 소리이며 물 원소 전투음이 아니다.
- `pot_break`: 도자기 파괴음이며 바위 원소 고유 효과가 아니다.
- `slime_land`: 공식 웹 이벤트 슬라임 착지음이며 일반 타격음으로 증명되지 않았다.
- `event_success`/`event_fail`: 공식 웹 이벤트 결과음. 본편 성공·실패 녹음도 확보했으므로 결과에는 본편 쪽을 우선 제안한다.

## 확인하지 못한 요청

본편 일반 물리 타격·방어·물 원소 공격·융해/증발/과부하/빙결 전용 원본과 공식 새·멧돼지 소리는 이번 제한된 조사에서 용도와 소리를 모두 확인한 파일을 찾지 못했다. 현재 자체 제작음이나 자연 녹음을 그대로 유지한다면 최종 보고에서도 미완료로 구분한다. 기존 자연 녹음을 원신 공식 소리로 이름만 바꿔서는 안 된다.

## 0.14.7: 효과음을 원신 녹음으로 교체

합성음을 없애고, 위 녹음 모음(같은 ZIP, SHA-256 `d922980840c5bc78…fd0f45100` 일치 확인)에서 고른 소리를 `ig_*.mp3`로 넣었다. 파일마다 원본 파일명, 잘라낸 구간, 적용한 음량, 해시는 `catalog.json`에 있다.

- 손질: 원본 앞에 붙은 약 0.1초 무음을 잘라 바로 들리게 했고, 여러 번 나는 소리(수영, 활 공격 등)는 한 번만, 긴 소리(신상 회복 등)는 필요한 부분만 잘라냈다. 모든 파일을 같은 크기(150 Hz 위 가장 큰 50 ms가 -24 dBFS)로 맞춘 뒤 Windows 내장 인코더로 MP3 128 kbps로 변환했다.
- 사용자가 직접 들어 보고 고른 것(2라운드): 메뉴는 본편 클릭·초점 이동·탭·대화 넘김·알림·삐빅·페이몬 메뉴 열기/닫기·책장 넘김·임무 일지 열기·순간이동, 보상은 기행 레벨업과 기존 본편 녹음, 장착은 장비(`equip`, ItemArm 1)와 성유물(`ig_item_arm2`, ItemArm 2)을 나눠 씀, 방어는 나무 상자 부서짐, 회복은 신상 HP 회복 후반부(2.04–4.2초), 물은 빠른 수영 물보라, 번개는 번개 구체, 과부하는 번개 구체의 두 번째 소리, 증발은 다른 물보라, 불·바람·얼음·융해·빙결은 공식 웹 이벤트 소리, 활 사용자의 물리 공격은 활 일반 공격 첫 발, 츄츄족 공격은 본편 츄츄족 공격.
- 3라운드: 바위는 비경 문이 솟는 소리의 앞부분만(DoorComeout 0.06–0.95초, 끝 0.2초 페이드) 써서 1.04–1.19초의 「츠컹」이 들어가지 않게 했다. 타격 후보는 이전 타격음과 무기 넣기(ItemUnarm 2), 전투 시작 후보는 이전 전투 시작음과 나선비경 진입·비경 입장·카운트다운.
- `made_dendro_slice.mp3`, `made_dendro_slice2.mp3`, `made_dendro_whirl.mp3`: **원작 소리가 아니다.** 녹음 모음에 풀로 베는 소리가 없어 사용자가 「아예 새 SE를 만들자」고 해서 이 게임에서 만든 소리다. 빠르게 스치는 잎 소리(서)와 줄기가 아삭하게 잘리는 소리(걱), 흩어지는 잎을 합쳤고, 한 번 베기·두 번 베기·휘익 후 베기 세 가지다.
- `prev_battle_start.mp3`, `prev_hit.mp3`: **원작 소리가 아니다.** 사용자가 「전투 시작은 이전 것이 나을지도」라고 해서, 0.14.7 중간 버전(커밋 `bcaf42e`)에서 이 게임이 브라우저로 합성하던 전투 시작음과 타격음을 그대로 한 번 녹음해 파일로 남겼다.
- 호두 원소폭발은 스펙트로그램에 말소리 무늬(휘어지는 배음 줄)가 보여 처음부터 넣지 않았다.
- 바위·풀·한손검류 타격·물 원소 공격·원소 반응 전용 원작 녹음은 이 모음에 없다. 공식 웹 이벤트 페이지 몇 곳과 공개 자료도 찾아봤지만 쓸 만한 것을 찾지 못했다(게임 파일을 통째로 뽑은 공개 저장소는 이름 없는 파일 수만 개라 고르지 않았다).

1라운드에서 넣었다가 사용자가 고르지 않은 후보 41개, 승리 OST 후보 4개, 웹 이벤트 성공·실패음, 패배 OST 후보 2개는 파일과 목록에서 뺐다. 버튼 클릭 예비로 기존 `audio/official-review-click.mp3`(공식 웹 이벤트 클릭음)는 그대로 있다.
