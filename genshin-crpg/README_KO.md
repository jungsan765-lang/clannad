# 원신 CRPG · 몬드 개발 검증판

2026-09-24 최신61개탭을 고정된 콘텐츠로 가져와 기존 실행기에 공통 노드·관계·저장·게임 화면을 연결한 버전입니다. **몬드 전체 완성본은 아닙니다.** 원본 시트·원고·운영 SAVE는 수정하지 않았습니다.

## 실행

- 배포 주소에서는 이름과 출발점을 고르면 시작합니다.
- 내려받은 묶음은 Python3이 있는 환경에서 Windows `start-game.bat`, macOS/Linux `./start-game.sh`로 실행한 뒤 브라우저에서 `http://localhost:8765/`를 엽니다.
- `dist/index.html` 더블클릭은 권장하지 않습니다. 브라우저 저장·오프라인 기능을 위해 위 로컬 서버 또는 HTTPS 주소를 사용하세요.
- 개발: `npm ci` → `npm run dev`. 빌드: `python3 tools/build.py`. 이미지 재인코딩이 필요하면 `python3 -m pip install -r requirements.txt`.
- Windows 설치형 실행 파일은 이번 묶음에 포함하지 않습니다.

## 이번에 연결한 것

편성·아이템·임무·호감도를 별도 메뉴로 분리했습니다. 상점·제작·보스의 고정 메뉴는 없애고 현재 지도에서 해당 장소에 들어가도록 연결했습니다. 상점별 상품, 시설별 제작·강화, 영업시간을 실행 규칙에서도 검증합니다. 두 시설이 필요한 공동 제작은 각 시설에서 준비한 뒤 완성하며, 비용과 제작 시간은 완료할 때 한 번 적용합니다.

현재 파티만 장비·성장책·음식을 사용할 수 있으며, 편성 해제·교체·동행 종료 시 장비가 공용 소지품으로 돌아옵니다. 0.5의 대기 동료 장비 허용은 이번 요구에 따라 폐지했습니다. 기존 저장도 같은 규칙으로 정규화합니다.

캐서린 인물·원고 이미지 코드의 별칭을 복구했습니다. 아이템은 사각 아이콘, 마우스/키보드 툴팁, 터치 선택 상세와 현재 파티 대상 선택으로 제공합니다. 실제 성우 음성은 적합한 공식 재사용 출처를 확인하지 못해 추가하지 않았습니다.

전투는 실제 행동 순서를 저장한 시작 대기 화면에서 직접 시작합니다. 적 대표 이미지 한 장과 개별 체력·대상 선택을 유지하고 공격 조작부를 위로 옮겼습니다. 첫 자동 행동부터 타격·이동 연출이 표시됩니다. 완료 보스의 신규 반복 도전과 이야기 보스의 독립 진입은 차단하며, 기존 진행 중 도전의 재시도/계속하기는 현장에서 허용합니다.

## 콘텐츠/저장 업데이트
