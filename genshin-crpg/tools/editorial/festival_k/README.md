# 축제 이야기 원고 (0.16.67)

정기 축제(설날·추석)의 이야기다. 축제 창의 「이야기」 탭에서 1·3·5·7일째에 한 편씩 열리고, 처음 보면 원석 160과 축제 점수 100을 받는다.
1편은 같은 만남을 두 갈래에서 보고(`EVT_<축제>_ISK_1`, `EVT_<축제>_TRV_1`), 2~4편은 두 갈래 공통이다(`EVT_<축제>_2~4`, 사용자: 「중간부터는 아예 같은 길로 가게」).
눈꽃 축제(크리스마스)는 사용자 답(「이야기 없이」)대로 이야기가 없다.

| 파일 | 체인 | 내용 |
| --- | --- | --- |
| `seollal.md` | `EVT_SEOLLAL_ISK_1` | 이세계인: 만민당에서 향릉·행추에게 설날을 알려 주다가 하늘에서 여행자와 페이몬이 떨어짐, 인사 |
| `seollal.md` | `EVT_SEOLLAL_TRV_1` | 여행자: 길에서 빛에 휩쓸려 그 리월로, 향릉·행추가 여행자를 모름, 이세계인과 인사 |
| `seollal.md` | `EVT_SEOLLAL_2~4` | 공통: 쌀로 떡 만들기(중운) → 왕생당 세배와 덕담(호두·종려) → 설날 떡국과 윷놀이, 빛과 작별(복주머니) |
| `chuseok.md` | `EVT_CHUSEOK_ISK_1` | 이세계인: 왕생당에서 호두·종려에게 추석·차례를 알려 주다가 부두의 달빛에서 여행자를 다시 만남 |
| `chuseok.md` | `EVT_CHUSEOK_TRV_1` | 여행자: 달빛에 휩쓸려 다시 그 리월 부두로, 이세계인과 인사, 왕생당으로 |
| `chuseok.md` | `EVT_CHUSEOK_2~4` | 공통: 차례상에 올릴 것(들판) → 차례상과 빈 자리 → 송편과 보름달 소원, 작별(송편 꾸러미) |

## 고치는 순서 — 이야기 작업대가 먼저다
사용자 지시(2026-10-18): 「스토리 관련은 전부 다 작업대가 필수야」.

1. 사용자가 이야기 작업대(https://claude.ai/artifact/2pKp3oqfozGeJaad5X4Lqu)의 「축제 · 설날」 「축제 · 추석」에서 줄을 고친다.
2. 고친 내용(작업대 db `edits`, 줄 이름 `EVT_<축제>_<루트>_<편>_<번호>`)을 이 원고에 옮긴다.
3. `node tools/editorial/compile_festival_story.cjs` → `source/app_feststory_v01667.js`(게임이 읽는 글).
4. `node tools/editorial/export_story_workbench.cjs <작업대 폴더>/story.json` 으로 작업대 이야기 파일을 다시 만들어 올린다.
5. `node tests/test_festival_v01667.cjs`, `node tests/test_glossary_v01647.cjs`.

## 문법
메인스토리 원고(`../main_story_k/README.md`)의 일부다.

```
# chain EVT_SEOLLAL_ISK_1      편 하나 (축제 · 루트 · 1~3편)
# title 설날이 뭐야?            제목
@map MAP_LY_DETAIL_CHIHU        뒤에 보이는 장소 (바꾸면 장소 이름이 뜬다)
## 만민당 앞                    장면
이야기: …                       지문
향릉: …                         대사 (페이몬, 이세계인, 게임 인물은 이름 그대로)
?? …                            내 말(그 갈래의 주인공). 같은 들여쓰기에 여러 줄이면 선택지, 그 밑에 두 칸 들여 쓴 줄이 그 선택의 결과
이세계인: … / 여행자: …         (2~4편) 두 주인공의 말. 자기 갈래에서는 내 말이 된다
@for isk / @for trv / @for all  (2~4편) 다음 줄들을 한 갈래에서만 / 다시 두 갈래 모두
@know / @unknown / @any         (이세계인 1편) 원신을 아는 주인공(몬드를 앎)일 때만 / 모를 때만 / 둘 다
{이세계인}                       (2~4편) 이세계인 갈래에서는 주인공 이름, 여행자 갈래에서는 「이세계인」
// 메모
```

- 주인공의 말은 전부 `??`다(`나:` 금지). `{PLAYER_NAME}` 뒤의 조사(이/가, 은/는…)는 화면이 이름에 맞춘다.
- 선택지는 결과만 다르고 이야기는 다시 합쳐진다(기록되는 선택은 없다).
- 말투는 `../personal_k/VOICE_BIBLE.md`, 고유명사는 사전 `../glossary_ko.json`(`tests/test_glossary_v01647.cjs`가 이 폴더도 검사한다).
- 본편 시점과 상관없는 축제 이야기다. 본편 사건(누가 죽었는지, 누구의 정체 등)은 말하지 않는다.
