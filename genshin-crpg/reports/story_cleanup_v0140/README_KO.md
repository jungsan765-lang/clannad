# v0.14.0: 이야기 정리 · 리월 대화 복원 · 설명 문구 정리 (리뷰 18)

## 1. 이야기 문장 정리 (`content/revisions/v0.14.0-story.json`, `v0.14.0-paimon.json`, `v0.14.0-story-system.json`)

원고(`content/db.json`)는 수정 파일을 `tools/apply_v0140_revisions.py`로 적용해 만든다. 같은 수정을 여러 번 적용해도 결과가 같다.

- 주인공 선택지는 실제로 말하는 대사로 바꿨다. 「상자를 옮긴다」처럼 행동을 설명하던 선택지는 없앴다. 행동이 필요한 곳은 선택 뒤에 서술 줄을 따로 넣어 무엇을 했는지 적었다(추가한 줄 262개).
- 페이몬이 항상 「페이몬은」으로 자기를 부르던 말투를 고치고, 인물별로 어색한 말투를 다듬었다.
- 대사·서술에 섞여 있던 작업 메모(내부 코드명, 규칙 설명, 「~는 아니다」 식의 확인 문장), 반복 문장, 설정 오류를 정리했다.
- 이세계인 시점 서술에서 주인공을 「자신」으로 부르던 318줄을 「나/내」로 고쳤다. 다른 인물을 가리키는 「자신」은 그대로 두었다.
- 사건을 보고서처럼 요약하던 서술(「확보했다」, 「확정되지 않았다」, 「·」 나열)은 장면 서술로 다시 썼다.
- 개인 임무·호감도 이야기의 끝맺음 문장과 호감도 칭호를 정리했다.

## 2. 리월 이세계인 대화 복원

0.13.39에서 리월 이세계인 본편은 긴 대화를 한 문단 서술로 줄이고, 주인공의 한 줄 응답을 서술로 바꿔 두었다. 그래서 몬드와 달리 초상화도, 선택지 대사도 거의 나오지 않았다.

- 한 문단으로 줄였던 장면 791곳을 원래의 한 줄씩 대화로 되돌렸다. 말하는 인물의 초상화가 함께 나온다.
- 서술로 바꿨던 한 줄 응답 615곳은 다시 주인공이 고르는 대사가 되었다. 서술 대체 줄(`R39_PROSE_*`)은 어떤 경로에서도 이어지지 않는다.
- 되살아난 대사도 1장과 같은 기준으로 다시 읽고 고쳤다.
- `tests/test_liyue_rework_flow.cjs`의 10개 경로(이세계인 8, 여행자 2)가 모두 끝까지 진행된다.

## 3. 화면 설명 문구 (`content/revisions/v0.14.0-ui-text.json`, `source/readable_text.js`)

- 전투 카드 설명 53개: 「~를 환산」, 「비전투 패시브」, 「폭딜」, 「초자연 능력 또는 서사 기술이 아님」 같은 설계 메모를 실제 효과 설명으로 바꿨다. 방어 태세는 「다음 내 차례까지 받는 피해를 절반으로 줄인다」고 정확히 적는다.
- 적 카드 69개: 오셀·야타용왕·타르탈리아 등 보스 기술의 내부 코드명과 규칙 번호를 지우고, 단계 조건을 「1단계, 우리 파티가 2명 이상 살아 있을 때」처럼 말로 풀었다.
- 가방·장비·상태·상점: 「TRPG 환산」, 「CRPG 성유물」, 「원작 효과 구조는 재검증 대상」, `EQUIP_ID` 같은 문구를 정리했다. 코드에서 만드는 성유물·여행자 바위 Q 문구도 고쳤다.
- 적 정보 창의 「CRPG 전용 명칭·수치」 안내를 지웠다.
- 화면에 보이는 글자는 `readable_text.js`를 거친다. 능력치 약어(EM, ER, ACTION_SCORE 등)를 한국어로 바꾸고, 캐릭터 이름 뒤의 조사(이/가, 을/를, (으)로)를 이름에 맞춘다.
- 신상 카드는 장면 묘사로 바꾸고, 이세계인은 신상과 공명할 수 없다는 점을 한 줄로 안내한다.

## 4. 관계와 성장 규칙

- 일상 「교류 활동」을 없앴다(`runtime_relationships.js`). 호감도는 개인 임무 완료 20, 호감도 이야기(H01~H04) 하나마다 20씩 올라 다음 이야기가 열린다(`runtime_nodes.js`). 하루를 두고 이어지도록 쓰인 이야기(2~5단계 344개 중 82개)는 날이 바뀐 뒤 열리고, 나머지는 앞 이야기를 마치면 바로 열린다. 기존 저장의 호감도는 줄어들지 않는다.
- 모험가 길드의 「무술 숙련」(일반 공격 단계당 +30%)을 없앴다(`runtime_world.js`, `runtime_journey.js`, `app_journey.js`). 이미 배운 저장은 불러올 때 들인 모라와 철광석을 돌려받는다.
- 캐서린 화면의 「개인 임무 소개」란을 없앴다(`app_adventure.js`). 소개받지 않은 개인 임무는 어디서 소개받는지 알려 준다.

## 5. 현장 의뢰 장면 · 요리 화면 · 이름

- 탐험 의뢰는 짧은 현장 장면으로 진행한다(`runtime_field_scenes.js`, `app_field_scenes.js`). 선택지는 주인공의 말이고, 무엇을 했는지는 뒤의 서술로 보여 준다. 실수하면 잃은 시간, 체력, 망가진 물자 값을 정확히 알려 준다.
- 요리 화면은 요리 계통별로 묶고 효과별로 거를 수 있다. 재료 준비 상태와 모자란 재료를 구하는 곳을 함께 보여 준다(`app_cooking.js`, `v0.14.0-cooking.json`).
- 몬스터·장소·아이템 이름을 한국어판 명칭에 맞췄다(`v0.14.0-names.json`, `runtime_mond_encounters.js`, `runtime_life.js`).
