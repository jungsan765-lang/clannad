# v0.13.23 — 리월 적 기술·경제·의뢰·시설 UI·이동 흐름

## 전투
- 바위 용 도마뱀 새끼는 기존 MON_VISHAP의 「용 도마뱀 돌진」「꼬리 휩쓸기」를 리월 필드에서 상속한다.
- 유적 가디언 변종은 리월 RANDOM/QUEST 필드전에서만 기존 Lv.14 프로토타입 게이트를 해제해 「회전 강타」를 실제 사용한다.
- 기존 약점 코어 노출 자동 기믹은 그대로 유지한다.

## 몬드 몬스터 소재 판매가
전투 승리 모라와 별도로 소재 판매가가 두 번째 주수입이 되지 않도록 조정했다.
- 슬라임 응축액/분비물/원액: 6 / 18 / 54
- 부서진/오염된/불길한 가면: 6 / 18 / 54
- 구라구라꽃 꿀/미광/원소 꽃꿀: 7 / 21 / 63
- 신병/사관/위관 휘장: 8 / 24 / 72
- 혼돈의 장치/회로/노심: 12 / 36 / 108
- 안개꽃 가루/풀/심지: 12 / 36 / 108
- 지맥의 낡은 가지/마른 잎: 15 / 45

## 리월항 의뢰
기존 의뢰에 새 10개를 더해 리월 일반 의뢰가 약 15개가 되도록 맞췄다. 새 의뢰 레벨은 Lv.4~13.
장부 대조, 보물 사냥단 휘장 수거, 경책 산장 식량, 산길 전투, 절운간 이정표 조사, 유적 부품 감정, 리월 야외 순찰 3회, 유적 기계 정리, 층암거연 교대조 구조, 심층 재측량을 포함한다.
소재 납품은 실제 아이템을 한 번 소비하고, 3회 순찰은 의뢰 수락 이후의 리월 RANDOM 전투 승리만 센다.

## 시설 UI
새 외부 이미지를 추가하지 않았다. 프로젝트에 이미 포함된 원신 원본 게임 텍스처 추출 자산의 조리·제작·치료·임무·장비·도구 아이콘 6종을 시설 카드에 재사용한다.
몬드 시설은 파란 계열 지역선, 리월 시설은 금빛 계열 지역선과 지역명으로 구분한다.

## 이동 UI
- 메인 화면의 「다른 구역으로 이동」 중복 목록 삭제.
- 여행 지도 오른쪽 「어디로 갈까?」의 잠금 해제 목적지 카드는 누르면 즉시 MOVE.
- 지도 위 번호/위치점은 기존 미리보기·경로 확인 기능 유지.

## 검증
새 기능 전용 8/8, 통합 18/18, 층암 40/40, 상점 14/14, 기존 5번 7/7을 확인했다.
기존 전체 QA의 오래된 economy 기대값 1건과 시설 개수 고정 기대값은 v0.13.22 구조에서도 이미 어긋나는 픽스처라 이번 회귀 판정에는 사용하지 않았다.
Google Sheet는 읽기만 했고 수정하지 않았다.
