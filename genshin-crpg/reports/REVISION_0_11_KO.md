# v0.11.0 수정 내역

- 상점 구매·판매 탭, 아이콘 격자와 상세 패널, 지금 구매 가능한 상품 필터, 장비 장착 후 능력치 비교를 추가했다. 1개·여러 개 판매와 완료 안내를 지원하며 장착·준비 중인 장비와 핵심 물품은 보호한다.
- 초급 장비 6종, 판매 재고 46행을 보강하고 기존 재고 35행의 가격·조건을 조정했다. 구매·장착 레벨 제한은 붉게 표시한다.
- 일반 필드 적 HP는 이전 보정을 유지하고 공격력만 현재값 대비 1인 1.35배, 2인 1.30배, 3~4인 1.15배 조정했다. 저장 재개 시 재적용하지 않는다.
- 정식 합류한 동료만 전투에 참가한다. 이전 임시동행 전투의 저장은 준비 단계로 복원한다. 전투 준비에서 물러나 훈련·장비·회복 후 재도전할 수 있다.
- 누락된 이세계인 사당 전투 5곳을 연결했다. 사당·결전 전투는 보유 파티 규모에 맞춰 따로 조정했다. 길드 훈련과 주인공 무술 숙련을 추가했다.
- 본편 휴식 지점 11곳과 실제 지도 이동을 거치는 이야기 재개를 추가했다. 모든 설산 이야기가 새 구역을 경유하는 것은 아니며 신규 구역은 탐험에 연결된다.
- 몬드·설산·폐허의 세부 탐험 지도 18곳을 추가했다. 눈동자 12개의 동일한 획득 기록을 유지하면서 현장 조사, 퍼즐, 상점 거래, 호감도, 원소·시간·방문 조건 등으로 접근 방법을 나눴다. 이미 획득한 눈동자는 다시 얻지 못한다.
- 편지 의뢰는 10초 수집, 8초 정리, 길드 전달의 세 단계로 진행한다. 작업 취소·저장 재개와 중복 보상 방지를 적용했다.
- 장소별 공식 공개 음원 목록을 보완하고 지도·시설이 바뀌면 새 곡을 처음부터 재생한다. 같은 전투 중 화면 갱신은 재생을 끊지 않는다.
- 실제 메뉴를 강조하는 7단계 UI 안내와 도움말을 추가했다.
- 2026-09-24 17:52 UTC 원본 시트 스냅샷의 이름·대사 변경을 반영했다. 새 리월 확장 자료는 원본과 함께 보관하고 엔진이 아직 지원하지 않는 노드를 현재 본편에서 제외했다. 리월 전체가 플레이 가능한 상태라는 의미는 아니다.

## 검증

기존 회귀 검사 38묶음과 전체 모듈을 함께 로드하는 v0.11 검사 1묶음(핵심 8사례)이 통과했다. 임시동행을 허용하던 이전 기대값은 새 규칙으로 교체했다. 실제 화면에서 구매, 3개 판매, 수량·모라·완료 안내, 붉은 제한, 장비 비교와 390px 모바일 배치를 확인했다.

여행자와 이세계인 지식 공개 분기에서 실제 이야기 선택·지도 이동·재개·저장 복원을 거쳐 첫 사당 전투 준비까지 확인했다. 전체 본편 모든 분기 완주 및 사용자 개인 저장의 모든 상태는 검증하지 않았다. 기존 자동 검사 일부는 개별 기능만 로드하므로 새 세계·여정·상점 통합 동작은 test_release_v011.cjs와 별도 경로 점검에서 확인했다.
