# 0.8.1 · 접속 오류 긴급 수정

실제 배포 상태 active/succeeded, 접근 정책 revision1 소유자 전용 유지, 서버 오류 로그 없음. 사용자 Chrome ERR_FAILED 확인. 승인된 사이트 진단에서 /index.html은 / 로 리다이렉트 후 HTTP200이며 실제 게임 HTML인 것을 확인했습니다.

기존 SW는 리다이렉트를 따라 저장된 index.html Response를 navigation에 그대로 반환하여 브라우저의 manual redirect 요청과 충돌할 수 있었습니다. 새 SW는 앱 marker 및 빌드를 검증한 HTML을 새로운 Response로 재구성해 반환합니다. 인증 등 앱 진입 외 navigation은 가로채지 않습니다. 인증 페이지를 게임 HTML로 캐시하지 않습니다.

접속 불가 상태에서도 복구되도록 정상 코어 파일 준비 후 새 워커를 활성화합니다. 열린 게임을 강제로 새로고침하거나 기존 저장/슬롯을 삭제하지 않습니다. 소유자 접근 범위를 유지합니다.

검증: redirect/manual navigation·인증 경로·캐시 검증 8/8, 오프라인 계약433, 버전/업데이트19개 검사. 실제 사용자의 브라우저 캐시 상태를 직접 확인한 것은 아니며, 첫 재접속에 이전 워커가 남으면 새 워커 설치 후 새로고침이 한 번 필요할 수 있습니다.
