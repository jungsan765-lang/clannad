# v0.13.25 — 허브 UI·공식 아이콘·바위 눈동자 정리·야타용왕

## 주변 시설
- 몬드성/리월항에서는 주변 시설이 여행 지도보다 먼저 나온다.
- 시설 카드는 58px 아이콘 / 유동 텍스트 / 고정 버튼 구조로 바꿔 한글이 한 글자씩 세로로 찢어지지 않는다.
- 같은 도시명은 카드 하단에 반복하지 않는다.
- 1200px 이상은 3열, 모바일은 1열로 정리한다.

## 시설 공식 텍스처
원신 원본 게임 UI 텍스처를 저장소 내부에 번들한다.
대장간, 식당, 공용 조리시설, 잡화·보급, 연금, 모험가 길드, 숙박, 일반 상점, 이야기/소개 장소가 서로 다른 아이콘을 사용한다.

## 입문 무기
CRPG 입문 장비 5종에 무기군별 원신 원본 1성 무기 텍스처를 연결했다.
낡은 연습검=UI_EquipIcon_Sword_Blunt, 연습용 양손검=Claymore_Tin, 연습용 창=Pole_Gewalt, 연습용 사냥활=Bow_Hunters, 견습자의 마도서=Catalyst_Apprentice.
이는 CRPG 장비명 자체가 원작 정식 명칭이라는 뜻이 아니라 공식 무기군 시각 자산 대응이다.

## 임무 화면
모든 임무 탭의 아래에 무조건 붙던 「리월의 바위 눈동자」 카드를 제거한다.
눈동자 진행은 실제 리월 탐험 장소, 절운간 공양, 종려 획득 조건에서 확인한다.

## 8번 — 야타용왕
기존 DB 정의를 구현했다.
- 전투 시작: 불/물/얼음/번개 중 서로 다른 2종 선택.
- HP 70%: 첫 원소 주입, 전원 ATK×0.75 전환 충격.
- HP 40%: 두 번째 원소로 교체, 전원 ATK×0.75 전환 충격.
- 주입 중 현재 원소의 직접·지속 피해 완전면역.
- 주입 중 라운드 종료마다 전원 ATK×0.35 현재 원소 피해.
- 산하 진동: 전원 바위 피해 + 중심 대상 추가타.
- 원소 지맥 분출: 현재 원소 2연속 광역, 두 번째 중심타 강화.
- 용왕의 지맥 폭주: HP 60% 이하 광역 필살.
- 종려가 전투 시작 시 존재하면 야타용왕 ATK/DEF 15% 감소가 전투 끝까지 유지되고, 종려 생존 중 모든 광역 중심타는 종려 고정.
- 원소 공명 변환기: 플레이어 직접 공격 기준 라운드당 1회, 면역 원소 공격을 물리/중성 70%로 변환하며 오라·반응 없음.

## 검증
- 야타용왕 런타임 단위 검사: 원소 선택, 종려 공/방 감소, 중심타 고정, 면역, 변환기 1회 우회, 2회차 면역, 40% 전환 충격, 산하 진동 중심 추가타 확인.
- 수정 JS 문법 검사.
- 시설 레이아웃에 keep-all/최소 폭/3열·모바일 1열 규칙 확인.
- 임무 화면의 전역 바위 눈동자 wrapper 제거 확인.
- 14개 공식 텍스처를 외부 핫링크 없이 source/dist에 포함하고 오프라인 패키지에 기록.
