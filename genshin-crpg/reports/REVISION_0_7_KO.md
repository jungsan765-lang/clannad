# 0.7 버전 표시·회복·생활·임무 정리

2026-09-24. 콘텐츠 DB 61개 탭과 저장 호환키 schema2-4d2a266ee290을 유지합니다. 아래 수치들은 이 CRPG의 사용자 지정 규칙이며 원작 전투 규칙을 뜻하지 않습니다.

## 배포 확인과 실행 버전

- 직전 0.6의 배포 성공 기록, 원격 소스 커밋 021a849150e052a882baa4c8c3b6be11e15595c1, 업로드 아카이브 SHA-256 d20a1b1d07ed671c564d05aec125accf1740ff821c9c7662524079b359cd045d를 대조했습니다. 0.6의 장소·편성·아이템·전투 시작 모듈과 해당 index 연결이 들어 있습니다. 0.6 자체가 누락 배포됐다는 증거는 없습니다.
- 기존 서비스 워커는 열린 게임 탭이 있으면 새 워커 활성화를 기다릴 수 있습니다. 당시 실행 버전 표시·갱신 안내가 없어 이 상태를 구별하기 어려웠습니다. 사용자 기기에서 실제 어떤 캐시가 실행되었는지는 직접 확인하지 않았습니다.
- 우측 하단에 로드된 묶음의 v0.7.0을 표시합니다. 클릭하면 전체 빌드 번호와 최신 배포 여부를 봅니다. release.json 확인은 캐시를 거치지 않습니다.
- HTML의 스크립트와 스타일 주소에 빌드 번호를 붙입니다. 워커가 없는 환경에서도 새 버전 HTML 주소로 이동하여 이전 HTTP 캐시 스크립트를 재사용하지 않습니다. 워커의 초기 오프라인 캐시도 같은 주소를 준비합니다.
- 명시적으로 '저장 후 새 버전 적용'을 누를 때 대기 중 쓰기를 마치고 현재 진행을 저장한 뒤 워커를 활성화합니다. 저장 실패, 자동저장 일시중지, 설치 실패, 시간 초과, 활성 워커 버전 불일치는 새로고침을 막습니다.
- 처음 0.6에서 넘어올 때 배지가 없다면 저장하고 모든 게임 탭을 닫은 뒤 다시 열어야 합니다. 저장 데이터 삭제나 브라우저 데이터 초기화는 필요하지 않습니다.

## 회복·전투·이동

- 일반 패배나 과거 저장의 HP 0은 전투불능으로 처리합니다. 이동·대기·소비·생활 행동을 막고 명시적 회복으로 현재 파티 HP를 복구합니다. 자유행동 중에는 마지막 안전 거점으로 돌아가며 게임 시간 1시간이 지납니다.
- 이야기 전투 패배는 기존 전투 직전 재도전을 유지합니다. 전투불능 회복으로 대화나 전투를 건너뛰지 않습니다. 안전지대에는 1시간 휴식을 추가했습니다.
- 일반 무작위/의뢰 조우에서 1~2인 파티의 적 수를 생존 파티원 수로 제한하고 체력·공격력을 낮췄습니다. 3~4인, 고정전, 보스 및 이미 시작한 전투는 유지합니다. 조우 난수와 확정된 첫 순서는 재추첨하지 않습니다.
- '매번 이동하면 전투'는 지도 확률 자체가 100%라서 생긴 현상이 아니었습니다. HP 0 이동이 조우를 만들다가 실패하면 원자적 롤백으로 같은 난수가 복구되는 경로가 있었습니다. 이제 전투불능에서 이동을 먼저 차단합니다.
- 야외에서 1시간 기다리면 해당 지도 확률로 한 번 조우 판정합니다. 안전지대와 전투 직후 보호 1회는 조우하지 않습니다. 첫 공격은 여전히 전투 시작 버튼 뒤에 진행합니다.
- 지도·시설 출입·회복 이동과 이야기의 실제 지도 전환에 1초 진행 연출과 입력 잠금을 둡니다. 현재는 별 문양과 게이지이며 새 페이몬 달리기 그림은 추가하지 않았습니다.
- 장소 메뉴는 색을 구별한 메인 화면으로 바꾸고 목적지 권장 레벨을 표시합니다. 전투 상세의 위치 확인 패널은 제거했습니다.

## 생활 행동

- 광맥이 있는 구역에서 채광: 실제 10초 진행, 게임 시간 10분 소비, 광석 1개 지급. 철광 65%, 백철 30%, 수정덩이 5%입니다.
- 구역당 하루 6회. 해당 구역 자원이 고갈되면 게임 내 다음 날 다시 생성됩니다. 다른 구역 잔량은 독립적입니다.
- 기존 콘텐츠에 자원 풀이 있는 곳에서는 채집·낚시·사냥도 같은 10초 작업으로 제공합니다. 각각 구역당 하루 4회이며 결과물은 기존 데이터의 가중치를 사용합니다.
- 작업 도중 이동·전투·중복 시작을 막습니다. 조기 완료/잘못된 작업 ID/중복 지급을 거절합니다. 취소는 보상과 잔량 소비가 없습니다. 저장 후 복귀한 작업은 한 번만 완료합니다.

## 임무와 보상

- 실제 캐서린 방문에서 일반 의뢰 37개를 지역별로 접수합니다. 원거리 의뢰도 임무 목록에 남고 실제 목표 지도·권장 레벨·다음 이동을 표시합니다. 이미 진행하던 과거 저장의 의뢰는 재접수하지 않습니다.
- 개인 임무 소개도 캐서린에서 받습니다. 소개 등록은 비용·시간·호감·원고 진행을 변경하지 않으며, 실제 무료 도입부와 명시 수락은 원래 이야기 규칙을 따릅니다.
- 임무 → 개인 임무에 실제 제목·준비물·보유량·판매처·가격을 표시합니다. 이세계인 엠버의 질긴 직물은 몬드 잡화 상인에서 75모라에 구매하고 명시 수락 시 1개만 소비합니다. 실행 가능한 제작법이 없는 직물 가공을 획득 방법으로 안내하지 않습니다.
- 메인 화면과 임무창의 메인 이야기 계속으로 현재 대화/자유행동 뒤 장면을 이어갑니다. 진행 중인 장을 처음부터 재시작하지 않습니다.
- 완료한 개인 임무는 진행 목록에서 빠지고 완료 탭에 표시합니다. 본편 연동 조사 의뢰는 기존 명시 수락 사건과 미해결 상태를 보존하여 별도 보상이나 반복 수락을 만들지 않습니다.
- 의뢰 완료는 실제 새로 지급된 아이템/장비·수량·모라·경험치·호감 변화만 표시하고 메인 화면으로 돌아갑니다. 이전 전투 보상을 잘못 재표시하지 않습니다.
- 선택 보상에 없는 장비를 직접 요청하는 경로도 거절합니다. 중복 수령은 추가 지급되지 않습니다.

## 저장

자동 저장과 수동 저장을 탭으로 나누고 목록 높이를 제한했습니다. 이야기 시작 전 자동 체크포인트는 활성 여정별 한 슬롯을 갱신합니다. 기존 기록을 임의로 지우지 않으며 개별 삭제는 기존 두 번째 확인을 유지합니다. 현재 슬롯 삭제 후 불러오기가 실패해도 자동저장 일시중지 상태를 풀지 않습니다.
