# v0.10.0 변경·검증 기록

- 한 구역에서는 채광·채집·사냥·낚시 중 한 종류만 가능합니다. 몬드 동쪽 광산, 속삭임의 숲 사냥터와 시드르 호수·와이너리 강변·샘물 연못·리월항 방파제 낚시터를 추가했습니다. 기존 구역에서 소모한 해당 자원은 이전 저장 이행 때 새 구역에도 반영합니다.
- 채집·사냥을 마칠 때 적 조우 확률은 5%입니다. 기존 전투 직후 보호 규칙을 유지하며, 조우 후에는 전투 시작 화면에서 기다립니다. 채광·낚시 완료는 전투를 만들지 않습니다.
- 채집은 두 묶음, 채집·사냥 재료는 묶음당 3–5개, 낚시는 성공 시 2–4개를 얻습니다. 몬드 채집에 새알을 추가했습니다. 몬드 광맥은 기본 광석 65%·백철 30%·수정 5%이며 설산 기본 광석은 성은 광석을 유지합니다.
- 낚싯대와 과일 미끼를 갖추고 낚싯줄을 던집니다. 2초 입질 대기 후 버튼·Space·Enter를 눌렀다 놓으며 장력을 금색 구간 안에 유지합니다. 한 시도는 최대 20초입니다. 낚싯대는 유지하고 미끼 1개는 던질 때 소모합니다. 실패와 취소도 미끼를 돌려주지 않습니다. 미끼는 낚싯대 판매 상점에서 구입하거나 조리시설에서 10개씩 만듭니다.
- 낚시 결과는 시간과 조작 기록을 실행기가 다시 계산합니다. 새로고침이나 임의의 성공 값으로 물고기를 얻지 못하며, 중복 완료도 차단합니다.
- 새·활·돼지 녹음 효과음을 생활 활동에 연결했습니다. 공식 원신 SE는 아니며 출처·라이선스를 소리 설정에서 확인할 수 있습니다.
- 몬드 전투는 《City of Winds and Idylls》 Disc 3의 1번 Photon of Fluctuation과 2번 His Resolution만 사용합니다. 전투마다 무작위 선택하고 같은 전투의 화면 갱신은 곡을 바꾸지 않습니다. 탐험 복귀 시 이전 탐험곡 위치를 유지합니다. 두 파일은 공개 보관본이며 공식 Apple 청음과 PCM 상관계수 0.9998/0.99976으로 동일 녹음을 확인했습니다. 공식 CDN에서 직접 받은 파일이라고 표기하지 않습니다. 전투 선택 난수는 게임 저장 난수와 별개입니다.
- 레벨이 오른 주인공과 동료의 HP를 새 최대치까지 회복합니다. 성장책·전투·보상으로 오른 레벨과 회복 알림을 획득 창에 표시합니다. 이야기 전투의 임시 참가자도 포함합니다.
- 1시간 기다리기는 3초 진행바 후 게임 시간과 조우를 한 번 반영합니다.
- 아이템 상세와 툴팁에 요리·제작 용도를 표시합니다. 현재 마을의 해당 시설로 바로 들어가 관련 제작법을 강조합니다. 시설·영업·재료·제작법 조건은 그대로 검사합니다.
- 호감도에서 다음 만남 장소 또는 실제 시설·현장 대화 구역과 이동 방향을 안내합니다. 현재 동행 중인 인물은 함께 이동 중으로 표시합니다.
- 제목·설정의 저장 목록은 ‘게임 불러오기’, 외부 JSON 가져오기는 ‘백업 파일 가져오기’로 구분합니다. 새 생활 구역에서 저장한 장소 이름이 비던 문제를 고쳤습니다.
- 사라와 새 장소 ‘천사의 몫 · 찰스’에서 현재 루트에 맞는 기존 개인 임무를 소개합니다. 기존 이야기·선택·준비물·해금·최초 완료 규칙으로 이어집니다. 일반 의뢰 접수는 길드에 남습니다. 완료한 개인 임무는 다시 소개하지 않습니다.
- 몬드 밖 구역에서 메인 임무의 복귀 조건이 있는 경우, 본편을 마쳤다는 잘못된 문구 대신 몬드성 복귀를 안내합니다.

## 검증

전체 회귀 검사 38개 스위트가 통과했습니다. 생활 검사에는 구역 분리, 양방향 이동, 원본 데이터 불변, 이전 작업·자원 이행, 5% 경계, 낚시 도구·미끼·입력 검증·성공·재개·중복 완료, 레벨업 회복, 루트별 개인 임무 소개와 이야기 중 우회 차단을 포함합니다.

브라우저의 격리된 시험 저장으로 다음을 확인했습니다.

- Lv.1 HP 1/660에서 성장책 사용 후 Lv.2 HP 684/684와 레벨업 창.
- 새알 사용처 → 공용 조리시설 → 달걀 프라이 제작·획득 창.
- 사라에게 베넷 임무 소개 → 개인 임무 목록 → 기존 원고 장면.
- 천사의 몫에서 다이루크·케이아 개인 임무 소개.
- 1시간 기다리기 게이지와 08:00 → 09:00 반영.
- 낚시 장력 화면·이동 잠금·미끼 소모·시간 초과 실패 처리.
- 390px 모바일에서도 낚시 장력·성공 게이지와 당기기·취소 버튼을 한 화면에서 확인했습니다.
- 호감도 만남 위치와 새 생활 구역 저장 이름.

낚시의 성공 조작은 결정적 시뮬레이션 검사로 검증했으며, 브라우저에서 손으로 성공까지 조작했다는 의미는 아닙니다. 두 루트 전체를 끝까지 플레이한 검증은 아닙니다. 원본 콘텐츠 시트와 사용자의 저장 데이터는 수정하지 않았습니다.
