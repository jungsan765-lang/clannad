# v0.13.21 — 리월 동료 영입 단계 개방

## 범위
우선순위 4번만 처리했다. 리월 개인 임무 원고·비용·합류 결과는 유지하고, 모든 비집정관 개인 임무가 리월 최종 완료까지 묶여 있던 입구 조건을 장별 진행으로 분산했다.

## 개방 단계
- 1장 완료: 향릉, 행추, 중운, 요요, 가명, 신염, 연비, 운근, 남연, 소, 북두, 호두
- 2장 완료: 각청, 치치, 야란, 감우
- 3장 완료: 타르탈리아
- 4장 완료: 응광, 백출, 신학, 한운, 자백
- 종려: 기존 바위 눈동자 전량 수집 → 공양 → 본편 완료 뒤 최종 공양의 동행 규칙 유지

응광·백출 원고는 오셀 이후 맥락, 타르탈리아 원고는 황금옥 이후 맥락을 직접 포함하므로 해당 시점보다 앞당기지 않았다. 자백은 4장 외에 기존 세계 귀환 확인 플래그도 계속 필요하다.

## 지역 간섭 수정
이세계인 리월의 activeQuest가 존재한다는 이유만으로 몬드 개인 임무 소개까지 막던 전역 차단을 제거했다. 리월항에서는 완료한 장과 다음 장 수락 사이에 모험가 길드 개인 임무 소개를 허용하고, 다음 장을 수락해 진행 중일 때는 기존 도시 활동 제한을 유지한다.

## 검증
- 단계/게이트/재회/세이브 전용 검사: 10/10 (source, dist)
- 대표 개인 임무 완주: 여행자·이세계인 각 단계 표본 8/8
- 통합 검사: 18/18
- 리월 본편 대표 루트: K1, B2, TRV_A 통과
- 기존 UI 읽기 전용 검사의 4개 실패는 DOM mock의 Element.after/ResizeObserver 미구현으로 재현되는 화면 시험 인프라 한계이며 이번 런타임 수정 경로와 무관하다.
- 전체 85개 개인 임무 검사는 기존 NAV_LIYUE_VISITED fixture 불일치가 남아 있어 전체 통과 근거로 사용하지 않았다. 변경 대상 단계 표본은 별도 8개 완주 검사로 검증했다.
