# v0.13.19 — 리월 일반전 모라 정산

점검 목록 2번만 처리한다. 리월 지역의 `RANDOM` 일반 전투 승리에 파티 공용 모라를 지급한다. 스토리전·의뢰전·보스전은 기존 보상 체계를 유지한다.

모라는 적별로 `(8 + 5 × 실제 적 레벨) × 등급 배율 × 지역 위험 배율`을 반올림해 합산한다. 등급 배율은 일반 1, 정예 2, 강적 4이며 지역 위험도는 현재 리월 맵의 권장 최소·최대 레벨 평균에서 1~6단계로 환산하여 몬드의 기존 위험 배율 `1 / 1.05 / 1.10 / 1.20 / 1.30 / 1.40`을 재사용한다.

이 변경은 전투 종료 시 계산되므로 새 저장 필드를 만들지 않는다. 진행 중인 v0.13.18 리월 랜덤 전투 저장을 불러와 승리해도 새 정산을 받을 수 있다.

전용 검사: `node tools/test_liyue_mora_step2.cjs`. 3번 소재 드롭 조건 수정은 포함하지 않는다.
