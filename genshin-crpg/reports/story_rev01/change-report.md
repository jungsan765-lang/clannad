## 바뀐 장면

### 1. 진에게 벤티의 정체를 말하는 장면

두 정체 고지 선택을 유지하되, 직설적으로 말했을 때와 조심스럽게 전했을 때의 동요를 다르게 썼다. 펜이 멎고 자세가 변하는 반응, 말의 근거를 되묻는 확인, 믿고 싶은 마음을 드러냈다가 단장으로서 판단을 수습하는 과정이 이어진다. 놀라지 않은 채 비밀 처리만 하던 대사를 대체했다. 주인공의 고지를 듣는 것과 진이 직접 사실을 확인한 것을 구별한다.

후속 대답에도 각각 대안을 하나씩 추가했다. 기존 1개 버튼이던 두 묶음이 2개씩 되며, 고르지 않은 답변은 발화하지 않는다. 문밖의 엠버에게 비밀을 전달하지 않는 기존 구조는 보존했다.

### 2. 사당 수색 뒤의 퇴로 위기

하프 수색 결과를 듣고 바로 떠나던 구간에 낡은 측랑 철문·금이 간 문틀의 위기를 넣었다. 진은 회수조의 퇴로를 확보하고, 엠버와 주인공은 다른 쪽에서 탈출 방법을 찾는다. 진의 전력을 억지로 없애거나 주인공에게 전투 능력을 주지는 않는다.

세 선택은 다음과 같다.

| 선택 | 현장 결과 | 귀환 반응 |
|---|---|---|
| 걸린 추와 나무 조각을 관찰한다 | 엠버가 막힌 부분을 제거해 출구 확보 | 진이 구체적인 관찰의 도움을 기억 |
| 후미 대피 여부를 확인해 신호한다 | 대원들이 빠진 뒤 진이 문을 들어 올림 | 진이 자신이 못 본 곳을 확인해 준 일을 기억 |
| 손잡이에 먼저 힘을 준다 | 문이 기울고 엠버가 제지; 협력으로 구조 | 엠버가 잘못된 시도와 멈춘 행동을 함께 기억 |

실패 선택도 진행 불능·강제 재시작으로 만들지 않았다. 선택은 실제 저장값으로 남지만, 이번 묶음에서는 HP·모라·별도 시간·전투 보상을 증감시키지 않는다. 이는 별도 조작 화면이 있는 퍼즐이 아니라 **본문의 단서를 읽고 선택하는 짧은 상황 퍼즐**이다.

### 3. 정화 실패 이후

정화되지 않았다는 결과는 그대로다. 주인공의 실망을 보고 엠버가 말을 고르는 순간과, 진도 기대했다는 사실을 인정하는 대사를 넣었다. 실패를 업무 보고로 바로 정리하지 않고, 안전을 확인하고 쉬게 하는 장면으로 연결했다. 사당을 실제로 겪은 저장에서만 해당 선택이 후속 대사에 등장한다.

## 10개 루트 추적표

현재 데이터에서 이세계인 말단 8개와 여행자 A/B를 구별했다. 아래 표는 **수정 진행표이지 10개 전체 독해·검수 완료표가 아니다.**

| 말단 | 계승 조건 | 이번 상태 |
|---|---|---|
| K1 | 세계를 알고 온 K계열 → 리월 K1 | 몬드 공통 초반 1차만 반영; 이후·리월 미수정 |
| K2 | 세계를 알고 온 K계열 → 리월 K2 | 위와 동일한 공통 구간; 별도 루트 완료 아님 |
| AA1 | 세계 지식 없음 → 원정 → 동승 → 리월 AA1 | 후속 검토 대기 |
| AA2 | 세계 지식 없음 → 원정 → 동승 → 리월 AA2 | 후속 검토 대기 |
| AB1 | 세계 지식 없음 → 원정 → 귀환 → 리월 AB1 | 후속 검토 대기 |
| AB2 | 세계 지식 없음 → 원정 → 귀환 → 리월 AB2 | 후속 검토 대기 |
| B1 | 세계 지식 없음 → 길드 → 리월 B1 | 후속 검토 대기 |
| B2 | 세계 지식 없음 → 길드 → 리월 B2 | 후속 검토 대기 |
| 여행자 A | 황금옥에서 타르탈리아를 막아섬 | 후속 검토 대기 |
| 여행자 B | 교전 대신 증거·경보 확보 우선 | 후속 검토 대기 |

다음 이어갈 지점은 K계열 몬드의 `ISK_M03_K_001` 이후다. 다음 묶음에서는 실제 벤티 대면 때의 반응과 앞 장면의 정보·감정 연속성을 확인한다. 리월의 병사 대화, 봉쇄·기억 이상·각 말단의 독립 위기는 해당 원고를 읽은 뒤 개별 수정한다. 층암거연 감금은 제안 후보이며, 이번에 넣었다고 주장하지 않는다.

## 검사 결과와 한계

빌드 성공. 기본 통합 검사 18개와 이번 스토리용 검사 15개를 통과했다. 스토리 검사는 세 퇴로, 네 정체 고지/응답 조합, 미경험 저장 두 경우, 다른 계열의 선택 접근 차단, 선택 대기 중 저장·복원, 같은 선택 재실행 차단, 새 참조 연결, 기존 저장 버전 허용 및 실제 SaveAdapter 가져오기를 확인했다.

기존 노드의 효과·보상·주요 게이트를 바꾸지 않았고, 이번 수정 이외의 데이터와 다른 루트 본문이 동일함을 프로그램으로 비교했다. 이는 전 루트 완주 검사가 아니다. 이번에는 PC/모바일 화면을 새로 촬영하거나 전체 전투 조합을 검증하지 않았다. 새 글의 재미와 감정 강도는 사용자 플레이 평가가 남아 있다.

## 적용 방법

이 파일은 **v0.13.15 전체 프로젝트에 적용하는 증분 패치**다. v0.13.0에 바로 적용하거나 `dist` 폴더만 대상으로 삼지 않는다. 기존 게임 저장을 먼저 내보내 백업한다.

```bash
python apply_patch.py "기존 v0.13.15 프로젝트 폴더" --check
python apply_patch.py "기존 v0.13.15 프로젝트 폴더"
```

패치 도구는 대상이 검증한 기준과 다르면 덮어쓰지 않고 중단한다. 변경 전 파일은 대상의 `.patch-backups`에 보존한다. 반영 후 `start-game.bat` 또는 기존 실행 방법을 사용한다. 직접 빌드는 `python tools/build.py`, 이번 테스트는 `node tools/test_story_rev01.js`다. 운영 배포는 별도이며 이 작업에서 수행하지 않았다.

이미 지나간 장면을 강제로 되감지 않는다. 새 장면을 보려면 정체 고지/사당 수색 이전 저장에서 진행한다. v0.13.16의 새 노드에서 만든 저장을 v0.13.15로 역으로 불러오는 것은 보장하지 않는다.
