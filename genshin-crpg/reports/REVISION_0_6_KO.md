# 0.6 장소 방문·아이템·전투 화면

2026-09-24. 콘텐츠 원본과 저장 호환 버전은 유지했습니다.

## 장소에서 이용하는 서비스

- 고정 상점·제작·보스 메뉴를 제거했습니다. 현재 지도에서 시설에 들어가고, 밖으로 나가는 흐름으로 연결했습니다.
- 들어간 상점의 상품만 구입합니다. 지도·영업시간·방문 시설·화면을 실제 행동에서도 검증하여 다른 상점 구매나 원격 제작을 차단합니다.
- 대장간·연금·조리시설의 제작법을 분리했습니다. 두 시설이 필요한 제작법 4개는 각 시설에서 준비한 뒤 완성합니다. 준비 상태는 저장되며, 비용·재료·총 제작 시간은 완료할 때 한 번 소비합니다.
- 제작에 필요한 재료·보유량·모라·시간과 부족한 레벨을 표시합니다. 강화 허용값이 불리언인 장비를 화면에서 잘못 막던 오류를 수정했습니다.
- 보스는 지도상의 해당 입구에서 도전합니다. 완료한 보스의 새로운 반복 도전과 이야기 전용 보스의 독립 진입을 차단했습니다. 이미 시작한 도전의 재시도와 다음 전투는 해당 장소에서 계속할 수 있습니다.

## 메뉴·편성·아이템

- 편성, 아이템, 임무, 호감도를 분리했습니다. 시설 방문 중 메뉴를 열어도 돌아가기 버튼으로 같은 시설에 복귀합니다.
- 현재 파티만 장비·음식·성장책의 대상이 됩니다. 편성 해제·교체·이야기 동행 종료 시 해당 캐릭터의 장비가 모두 공용 소지품으로 돌아옵니다.
- 기존 저장의 파티 밖 장비도 같은 규칙으로 정리합니다. 진행 중 전투의 능력치 스냅샷을 다시 계산하지 않습니다.
- 아이템은 정사각 격자와 종류 아이콘으로 표시합니다. 마우스와 키보드 초점의 효과 설명, 클릭·터치 상세, 편성의 장착 화면 연결을 제공합니다. 새 아이템 그림은 추가하지 않았으며 현재 아이콘은 종류별 기호입니다.
- 캐서린 이미지의 두 코드(KSR/KTH)를 연결했습니다. 실제 화면에서 캐서린 그림이 로드되는 것을 확인했습니다.

## 저장과 전투

- 자동·수동 저장에 삭제 버튼과 두 번째 확인창을 추가했습니다. 취소하면 유지됩니다. 동시에 다른 탭에서 바뀐 저장은 오래된 화면의 삭제로 지워지지 않습니다.
- 현재 슬롯을 삭제하면 자동저장을 일시중지하여 즉시 재생성되지 않습니다. 새 자동저장 시작은 별도 슬롯을 만듭니다.
- 첫 라운드의 실제 행동 순서를 확정·저장하고 전투 시작 버튼을 누를 때까지 공격을 진행하지 않습니다. 저장 복원이나 중복 클릭으로 순서가 다시 뽑히지 않습니다.
- 전투 조작부를 위로 옮겼습니다. 적 대표 그림 한 장과 각 적의 개별 체력·상태·대상 선택을 제공합니다. 같은 이름의 적은 번호로 구별합니다.
- 첫 자동 행동부터 공격자 움직임, 타격, 원소 반응과 피격 연출을 표시합니다. 기존 오리지널 BGM 2곡·SE 18종과 음량·움직임 감소 설정을 유지했습니다.
- 실제 원신 성우 추임새는 적합한 공식 재사용 출처를 확인하지 못하여 추가하지 않았습니다.

## 검증 기록

- `python3 tools/test_all.py`의 범위가 정해진 회귀 검사 23개가 모두 통과했습니다. 최종 결과는 `suite-results.json`에 기록합니다.
- 이번 추가·갱신 범위: 장소 28그룹, 공동 제작 12그룹, 전투 시작 11그룹, 편성 19그룹, 아이템 표현 7그룹.
- 실제 브라우저의 격리된 IndexedDB에서 삭제·취소 관련 저장 어댑터 검사 6개를 통과했습니다. 최신 리비전 보존·다른 슬롯 및 설정 보존·삭제 알림 실패도 확인했습니다.
- 합성 검증 저장을 사용해 캐서린 그림, 메뉴 분리, 파티 대상 제한, 사각 아이템과 설명, 저장 삭제 취소·확인·자동저장 중지·재시작을 확인했습니다.
- 전투는 시작 전 순서와 자동 공격 대기, 시작 후 연출, 대표 이미지 한 장, 개별 대상 선택을 확인했습니다. 390px 모바일 프레임에서 가로 넘침이 없고 공격 실행 버튼은 화면 상단에서 약 561~610px에 위치했습니다.
- 대장간→밖으로→연금시설→공동 제작 완료를 실행하여 만국 항해용해도 1개, 220모라·재료 차감, 2시간 경과를 확인했습니다. 별도 저장에서는 여행자 외투 +3 강화, 120모라·철광 3개 차감, 30분 경과를 확인했습니다.
- QA 페이지와 합성 저장은 배포 묶음에 넣지 않습니다. 실제 사용자 저장을 시험 데이터로 수정하지 않았습니다.

## 남은 범위

정상 육성 파티의 두 루트 종단 완주와 전체 밸런스, 실제 PWA 설치 후 네트워크 차단 재실행은 미검증입니다. 원고에만 적힌 일부 고급 제작 해금 조건과 실행기가 아직 지원하지 않는 장비 고유 강화 효과는 기존처럼 비용 소모 없이 잠깁니다. 이번 수정이 모든 콘텐츠의 완성을 뜻하지는 않습니다.
