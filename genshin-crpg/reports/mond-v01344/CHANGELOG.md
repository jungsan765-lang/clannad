# v0.13.44 · 몬드 점검 및 시작 화면 개편

배포 대상: https://clannad.shop/genshin-crpg/dist/

## 화면과 계정

- 전용 게임 시작 화면을 만들었습니다. 몬드 풍경, 중앙 로고와 게임 시작 버튼, 계정·랭킹·설정 메뉴를 배치했습니다.
- 새로고침하면 시작 화면으로 돌아옵니다. 로그인 정보는 유지하고, 게임 시작을 누를 때 서버의 최신 자동저장을 엽니다. 로그인 만료 시에만 로그인을 요청합니다.
- 시작 화면에서 이어서 모험하기와 저장 슬롯 목록을 없앴습니다. 기존 기기 저장은 설정 아래에 보존했습니다.
- 인게임 메뉴와 자동저장·계정 화면에 로그아웃을 추가했습니다. 게임 시작 화면으로 돌아가는 버튼도 추가했습니다.
- 서버 행동을 처리할 때마다 대화 기록이 초기화되던 문제를 수정했습니다.

## 몬드 이야기와 표시

- 이세계인 AA 분기의 출발 전 연속 인물 소개·작별 순회를 정리했습니다. 알베도에게 구슬 기록을 맡기는 방문은 선택으로 바꿨습니다.
- 기사단에서 출발 준비 → 선택한 경우 공방 방문 → 성문과 다리에서 핵심 동료들과 작별하는 흐름으로 줄였습니다. 나머지 인물의 개인 임무와 자유 만남은 유지합니다.
- 핵심 사건, 기존 분기, 보상과 기존 장면 번호를 유지해 순회 도중의 저장도 불러올 수 있게 했습니다.
- 몬드 완료 후 아직 리월이 준비되지 않았다는 잘못된 안내를 실제 메인 임무 안내로 바꿨습니다.
- 개인 임무 종료 대사에 노출되던 내부 기획 문장을 제거했습니다.
- 대사와 화면의 ‘주인공’을 설정한 닉네임으로 표시하고 받침에 맞춰 조사를 처리합니다.
- DEX·ATK·DEF·HP 등 약어, 상태 코드와 회복 계산식을 민첩·공격력·방어력·체력 등 쉬운 말로 바꿨습니다. 데이터 식별자와 계산 규칙은 보존합니다.
- 성유물 품질을 퍼센트로 표시합니다.

## 업데이트와 저장 보호

- 새 저장을 읽고 검증한 다음에만 현재 게임을 교체합니다. 읽기 실패가 기존 계정 저장을 덮어쓰지 않습니다.
- 서버와 화면 버전이 다르면 행동을 막고 업데이트를 안내합니다.
- 응답 유실 중인 행동을 계정별로 보관합니다. 로그아웃이나 다른 계정 로그인으로 섞이지 않고, 업데이트 후에도 같은 요청 번호로 확인해 중복 보상을 방지합니다.
- 서버의 최근 저장 원본 3개를 자동 보관합니다. 운영 복구용이며 플레이어가 이전 시점으로 되돌릴 수 있는 기능은 없습니다. 계정 삭제 시 함께 삭제됩니다.
- 이미 확정한 행동은 정리 작업이 실패하더라도 실패로 오인하지 않도록 했습니다.
- 운영자 권한은 기존 서버 계정 설정을 유지합니다.

## 검증 결과와 범위

- 몬드 주요 7경로: 이세계인 K·AA·AA 바로 출발·AB·B, 여행자 남녀 경로가 최종 장면에 도달했습니다. 실제 이동·대화·선택·전투·기믹 행동과 중간 저장 복원을 사용했습니다.
- 이 검사는 이야기 진행 검증을 위해 전투 능력을 높인 시험 저장을 사용했습니다. 일반 파티로 난이도를 평가한 결과는 아니며 이번 작업에서 전투 난이도를 낮추지 않았습니다.
- 몬드 활성 대사 7,039개, 선택지 1,675개, 아이템·장비 정의 383개: 연결·명령 문법·표시 검사 통과.
- 확장 개인 임무 15종 × 양쪽 선택 2개, 보급과 우편물 의뢰, 탄궁 등 장비 장착·비교, 생활·탐색 작업 검증 통과.
- 실제 v0.13.43 엔진이 만든 8개 저장: 대화·출발 구간·전투·시간제 작업의 호환성 통과.
- 계정 가입·로그인·삭제, 위조 행동 거부, 중복 요청, 버전 충돌, 원본 보관, 잘못된 저장 보호, 랭킹·운영자 제한 검사 통과.
- 시작 화면·로그인 만료·새로고침·로그아웃·계정별 재시도 검사 통과.
- 과거 v0.12 저장 검사와 v0.11의 일부 런타임만 불러오는 비교 검사는 현재 저장소 이력·모듈 구성과 맞지 않았습니다. 그 결과를 성공으로 계산하지 않았으며, 현재 배포본을 기준으로 호환성 검사를 새로 작성했습니다.

모든 가능한 선택 조합과 모든 기기에서 무오류를 보증하는 결과는 아닙니다. 이번 스토리 검토 범위는 몬드이며 리월·나선비경의 전면 재검토는 포함하지 않습니다.
