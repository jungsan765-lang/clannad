# 0.8.0 · 전투 가시성 및 시설·임무 오류 수정

2026-09-24, 기존 소유자 전용 Site 업데이트. 콘텐츠 DB 원본과 저장 호환 버전은 유지.

- 전투 속도 0.5~2배 슬라이더, 기본 타격당 1.4초. 진행 도중 변경·정지·다음 한 건·결과 바로 보기. 움직임 줄이기에서도 읽는 시간은 동일.
- 판정과 저장은 한 번 확정하고 화면만 이전 상태부터 순서대로 재생. 피해마다 해당 대상의 HP 전후를 표시. 마지막 타격 후 승패 화면 전환. 같은 이름의 적은 번호 및 고유 ID로 구분. 반응 연쇄·모나 버블의 실제 대상/스킬명 수정.
- 적 선택 버튼이 글을 한 글자 폭으로 누르던 CSS 수정. 대표 이미지 1개 유지, 이미지 끔에서도 팀 영역 전체 폭 사용. 전투 기록 전체를 펼친 스크롤 영역에 표시.
- 합성 BGM 두 곡 및 UI 소리 제거. 공식 폰타인 OST 웹이벤트 음악, 공식 3.2 PV 음원, 공식 회고 이벤트 클릭음 원본 파일로 교체. 전투에 쓰는 음악은 PV 음원이며 공식 전투 OST라고 주장하지 않음. 기존 전투 SE 16종은 프로젝트 제작음. 공식 성우 음성·공식 폰트는 미포함. 시작 음악 음량을 실제 재생 18%/13%로 낮춤, 음소거 유지.
- 이미 읽은 전설임무 도입부는 기존 완료 기록으로 판별하고 준비 선택부터 재개. 최초 진입은 도입부 유지. 24개 전설 준비 지점 검증, 비용 중복 지불 방지 및 본편 커서 유지.
- 여관의 상품 형식을 숙박하기로 변경. 120모라·8시간·활성 파티 전원 HP 회복. 무상 REST 우회 차단.
- 실제 입장 상태로 연금·의료시설/스네즈나야 접근 조건을 평가. 상점 밖·다른 상인·다른 도시 구매 차단 유지. 레벨 제한은 요구/현재 레벨로 안내. 확인하지 않은 조건은 차단 유지.
- 아이템 수식 및 상태 코드를 한국어 효과 설명으로 변환. 강화 고유 효과 설명도 현재 단계 수치로 표시.
- 우측 하단 v0.8.0 및 캐시를 갱신하는 기존 버전 갱신 흐름 유지.

## 검증

- 회귀 스크립트 29/29 통과: reports/suite-results.json. 기존 이름 확정, 행동 잠금, HP0 회복, 메뉴, 저장, 오프라인 캐시, 제작, 퀘스트/전투 규칙 포함.
- 시설 조건 84/84, 전설·숙박 12/12(공개 행동228회), 전투 메타데이터 11/11, 가상 시계 재생8/8.
- 전투 규칙/난수 상태는 메타데이터 없는 엔진과 비교하여 일치. 비교는 전투 로그의 추가 표시 필드만 제외하며 게임 HP·라운드 등 변경은 감지.
- 실제 Chrome 미리보기: 슬라임3개/아군3명, HP 순차 감소, 정지 중 속도0.5→2배 변경·다음 표시·결과 건너뛰기. 390px iframe에서도 조절버튼 작동. 전체 몬드 본편을 수동으로 완주한 것은 아님.
- 연금 상점 Lv.5에서 재료/의료 상품 구매 가능, Lv.7상품은 구체 제한. 여관에서1000→880모라,08:00→16:00,HP100→600 확인.
- 업로드 이미지4장 확인. v0.6 UI가 찍힌 HP0 이미지는 기존0.7 DOWNED 회복 동선 회귀 검사로 확인.
- 브라우저 확장프로그램의 메타데이터 전송 오류 외 제품 콘솔 오류 없음.
