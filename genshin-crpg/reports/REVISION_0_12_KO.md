# v0.12.0 수정 내역

이번 버전은 v0.11.0을 바탕으로 전투의 진입 이유와 연출을 보강하고, 남아 있던 아이콘·효과음·숨은 탐색·세부 지도 연결을 적용했다. 오른쪽 아래 **v0.12.0** 버튼에서도 이번 수정 내역을 확인할 수 있다.

## 전투

- 이동 중 조우, 자원 탐색 중 조우, 의뢰 대상, 이야기 전투, 눈동자 조사 중 전투, 강적 도전을 구분해 전투에 들어온 이유와 현재 장소를 먼저 표시한다. 이야기 전투는 실제 원고의 해당 장면을 사용한다.
- 등장 적 종류와 수, 행동 순서를 확인한 뒤 **전투 시작**을 직접 누른다. 시작 전에는 공격·피해가 발생하지 않으며, 저장을 불러와도 시작 대기 상태와 처음 정한 행동 순서를 유지한다.
- 공격 준비 → 빛의 궤적 → 타격·피해 수치의 순서로 재생한다. 불·물·얼음·번개·바람·바위·풀 색상, 충격 입자, 회복·보호막 고리, 원소 반응 문구, 치명타와 격파 표시를 추가했다.
- 전투원 이미지와 HP를 같은 줄에 배치하고, 재생 중에는 전투판을 위로 올린다. 다중 대상과 연속 타격은 행동별 합계 및 실제 HP 변화로 확인할 수 있다.
- 속도 조절, 일시정지, 다음 표시, 결과 바로 보기를 유지한다. 준비 동작이 끝난 시점에 HP를 표시하며, 일시정지·생략 시 추적 중인 애니메이션도 정리한다. 움직임 줄이기에서는 입자·흔들림을 끈다.
- 연출은 이미 확정한 결과를 재생한다. HP·난수·전리품·보상을 다시 계산하거나 저장을 반복 실행하지 않는다. 이번 연출 변경으로 전투 수치를 추가 조정하지 않았다.

## 아이콘·글꼴·소리

- 개별 아이템·장비 아이콘 **127개**를 연결했다. 공식 CDN 42개와 공개 보관본의 원본 게임 텍스처 85개이며, 파일별 출처·이름 매핑·해시를 기록했다. HTTP 200으로 내려오던 공통 깨진 그림은 제외했다.
- 자체 제작품 또는 원본을 확보하지 못한 품목에는 **6종의 분류 아이콘**을 적용했다. 개별 정식 그림으로 가장하지 않는다. 현재 데이터의 나머지 145개 품목은 이 대체 표시 범위다.
- 공식 웹 이벤트가 사용하는 Default_SC-85W의 원래 숫자 글리프를 담은 **2.3KB 숫자 폰트**를 피해·회복 수치에 적용했다. 게임 전체 글꼴을 교체한 것은 아니다.
- 용도가 확인된 효과음 **19종**을 포함했다. 불·얼음·번개·바람 및 해제음은 공식 웹 이벤트 원본이다. 회복·승패·장착·활·아이템 획득·요리·단조·합성·임무·의뢰와 해당 적 효과음은 제작자가 직접 본편에서 녹음했다고 밝힌 공개 자료다. 공식 CDN 배포본과 제3자 녹음본을 구분했다.
- 공식 웹 이벤트 원소음이 본편 전투음과 동일하다고 확인한 것은 아니다. 일반 물리 타격·방어·물·바위·풀·일부 반응음은 기존 제작음을 유지한다. 새·멧돼지는 기존 자연 녹음이다. 이 부분은 원신 원본으로 모두 교체했다고 보고하지 않는다.
- 음원 전체 디코딩·길이·해시와 녹음 모음 ZIP 무결성을 확인했다. 직접 청취에 의한 음질·음성 혼입 검증은 수행하지 못했다. 게임 설정에서 출처 문서를 열 수 있다.

## 탐색·이야기 지도

- 몬드 외곽 초원의 숨은 단서를 기존 상시 목록에서 빼고 **좌우로 살펴볼 수 있는 실제 풍경의 가장자리**에 배치했다. 미세한 빛을 클릭하면 8초 조사 후 5초 회수로 이어진다. 키보드·모바일에서는 주변 살펴보기 버튼으로 같은 지점에 접근할 수 있다. 기존 수집 기록은 유지하며 보상은 한 번만 지급한다.
- 새로 만든 18개 세부 지도를 기존 이야기의 실제 위치와 연결했다. 여행자 폐허 장치, 이세계인 K/B의 설산·폐허, 유라 개인 임무 등 **노드 471개의 장소**를 정확한 분기별로 갱신했다.
- 연동 이벤트 11건, 유라 개인 임무 시작 위치, 장 진입 지도 조건과 휴식 지점 정보를 함께 맞췄다. 전투가 새 지도에서 시작될 때 기존 대구역 조건에 걸려 막히지 않는다.
- 대사에는 설산 순찰·난방 복구가 나오지만 장소가 몬드성으로 되어 있던 유라 개인 임무 위치를 수정했다. 유라의 별도 도시 교류와 알베도의 도시·숲 실험은 원문대로 유지했다.
- 실제 지도에서 걸어 올라간 뒤 다시 120분을 더하는 등산 사건 2건의 중복 시간을 제거했다. 설산 세부 경로를 건너뛰던 지름길 4개를 비활성화했다. 옛 드래곤 스파인 지도 저장은 야영지를 통해 나올 수 있다.
- AA의 드발린 탑승 이동과 AB의 성문 전투, 분기별 물품·사건·보상은 유지했다. 모든 선택 탐험 지역을 관계없는 본편의 필수 경유지로 만들지는 않았다.
- 원고 2곳의 다다우파/타타우파 표기를 타타우파로 맞췄다. 노드 ID·선택지 연결·완료 영수증은 변경하지 않았다.

## 확인하고 수정한 문제

1. **개인 임무 이동 중 채집·조사 실패:** 실행 가능한 버튼을 누르면 LIFE_SAVE 또는 WORLD_SAVE 검증 오류로 취소되던 문제를 수정했다. 작업 전 실제 자유행동 상태를 검사하며, 전투·대화·다른 작업 중에는 계속 차단한다.
2. **개인 임무를 메인 임무로 표시:** 개인 이야기 이동 목표의 구분을 바로잡았다.
3. **구버전 장 종료 저장의 이동 잠금:** 새 목적지까지 이동한 뒤 STORY_WAITING이 사라져 다음 장으로 넘어가지 못하던 이관 문제를 수정했다. 완료한 사건을 다시 실행하지 않는다.
4. **이전 대구역 저장과 새 전투 장소 불일치:** 실제 현재 위치를 유지하고 필요한 이동 목표를 만든다. 진행 중 전투의 HP·설정은 보존하며, 패배 후 재도전은 올바른 새 장소로 이어진다.
5. **오프라인 기본 파일 누락:** 새 전투·탐색·지도 모듈 4개를 서비스 워커 기본 캐시에 추가했다. 새 빌드가 이전 파일과 섞이지 않게 전체 팩을 다시 구성했다.
6. **숨은 풍경의 명암 경계:** 가로 이동 시 그라데이션이 끊기던 화면 경계를 수정했다.

## 최신 시트와 이전 요청

- 원본 확인 시각은 **2026-09-24 18:50:00.487 UTC (한국시간 9월 25일 03:50)**이며 다운로드 전후·최종 조회가 일치했다.
- 이전 배포 이후 활성 몬드 스토리 변경은 0행이었다. 새 변경은 리월 본편·개인 장면 등으로, 추가 504행을 준비 데이터에 보관했다. 총 준비 단계 제외 데이터는 13,266행이다. 미지원 리월 구문을 현재 게임에 무조건 활성화하지 않았다.
- v0.11.0의 상점 구매·판매, 가격·초급 장비, 정식 동료만 참가, 사당 전투 5곳, 길드 훈련·무술 숙련, 본편 휴식, 눈동자 조건 12곳, 편지 작업, 지역 BGM과 UI 안내는 유지한다. 이전 상세 기록은 `REVISION_0_11_KO.md`에 있다.

## 검증과 범위

- 기존 및 추가 **42개 회귀 검사 묶음 최종 통과**. 초기 검사의 기존 아이콘·재생 기대값은 새 동작을 검증하도록 갱신했고, 확인된 오프라인 누락도 수정한 뒤 재검사했다.
- 전체 런타임을 함께 로드한 작업 검증 7사례, 전투 설명의 난수·HP·순서 불변성 5사례, 구버전 지도·장 종료·진행 중 보스·재도전 이관 9사례를 포함한다.
- 별도 감사에서 개인 임무 22개 경로의 장면별 저장 복원을 점검했고, 사당 전투 5곳의 시작 대기·정식 파티 조건을 확인했다.
- 실제 PC 미리보기에서 전투 진입, 공격 재생·일시정지·생략 후 조작 복귀, 다중 대상 피해와 글꼴, 상점 아이콘, 숨은 단서의 조사 완료를 확인했다. 390px 모바일 화면에서 진입 설명·재생 조작·수정 내역 표시를 점검했다.
- 오프라인 검사는 서비스 워커와 캐시·네트워크 계약 검사다. 실제 기기에서 설치 후 완전 오프라인 재시작, 전체 본편 모든 분기 완주, 사용자 개인 저장의 모든 상태를 검증한 것은 아니다.
