# v0.13.26 — 전투/대장간 핫픽스 + 9번

## 전투 정보 UI
- 적 행의 **정보** 버튼은 데스크톱·모바일 모두 즉시 「적 정보」 모달을 연다.
- 적 이름 클릭에 의존하던 숨은 조작을 제거했다.
- 전투 행동 영역의 별도 「적 기술 정보」 블록과 「최근 적 기술 다시 보기」 블록을 제거했다.
- 몬드 적 정보에 공통으로 붙던 토끼 백작 설명을 제거했다. 토끼 백작의 실제 도발 규칙은 유지한다.

## E/Q 카드
E/Q 키 표식을 절대 위치에서 카드 내부 2열 그리드로 옮겼다.
한글 기술명은 글자 단위로 쪼개지 않으며 E/Q 배지와 겹치지 않는다.
선택 기술 아래에 반복되던 장문 E/Q/여행자 E 설명은 삭제하고 「효과」 버튼에서만 확인한다.

## 상점 충돌
runtime_enemy_skills가 이미 12_ENEMY_CARD_DB에 통합된 적 기술을 다시 추가하면서 ENEMY_CARD_COLLISION을 내던 설치 오류를 수정했다.
같은 ID가 존재하면 DB를 우선하고 중복 삽입하지 않는다. 실행 스크립트 호환성은 실제 기술 사용 때 cardSupport에서 검사한다.

## 대장간 상점
필터 순서를 기본 무기 / 단조 무기 / 방어구 / 법구·장신구 / 제작 재료 등으로 고정하고 각 버튼에 실제 상품 개수를 표시한다.
실제 시트 기준 MRC_MOND_EQUIP에는 기본 무기 3, 법구·장신구 5, 방어구 2가 있으며 런타임 추가 재고가 더해진다.
MRC_LIYUE_EQUIP에는 기본 무기 1, 방어구 1, 법구·장신구 1, 재료 1이 있다.
따라서 빈 필터가 표시되는 것이 아니라 실제 재고가 있는 분류만 노출한다.

## 제작 아이콘
제작법 카드의 결과 아이템/장비를 ItemPresenter로 해석하고 기존 공식/분류 아이콘을 표시한다.
v0.13.25에서 추가한 입문 무기 5종 공식 원본 텍스처 매핑도 그대로 사용한다.

## 9번 — 강화 체계 통합
기존 신형 강화는 MAP_MOND_CITY를 직접 검사하고 있었기 때문에 리월 대장간에서는 구형 강화 경로로 떨어졌다.
이 지도 하드코딩을 제거하고 **현재 들어간 시설이 대장간 + CRAFT 화면인지**만 검증한다.

- ENHANCE_ALLOWED = TRUE/Y/boolean true 장비: 신형 확률 강화·+10/+12 돌파
- NO_ENHANCE_REASON이 있는 입문 장비: 명시적 강화 불가
- 사용자 화면의 구형 「+3/+6/+9 기존 방식 강화」 버튼 제거
- 기존 CRPG_MOND_ENHANCEMENT_V1 프로필은 재변환하지 않고 legacy_profile을 읽어 새 CRPG_REGIONAL_ENHANCEMENT_V2로 안전하게 승계
- 저장용 enhancementVersion은 유지해 기존 저장 호환을 깨지 않는다.
