# v0.9.0 변경·검증 기록

- 대사 없는 EVENT/META/NOTE 노드는 자동 진행합니다. v0.8.1에서 멈춘 이세계인 5개 장면의 저장을 복구합니다.
- 전설임무 완료 판정과 보상 영수증을 통합했습니다. 24개 전설임무의 최초 완료 호감도 +10, 중복 진입·중복 보상 방지, 이전 완료 저장 이행을 검사했습니다. 기존 호감도는 유지하고 중복으로 더하지 않습니다.
- 전설임무를 완료한 동료가 실제 전투의 2번 자리에서 동행하면 승리당 +1을 지급합니다. 일상 대화는 더 이상 호감도를 올리지 않습니다. 편성·호감도 화면에 규칙을 표시합니다.
- 몬드의 중복 공용 대장간을 바그너 시설로 합쳤습니다. 기존 시설/제작 기록을 이행합니다. 상품 종류별 정렬, 구매·장착 레벨과 능력치 표시, 1개/여러 개 구매 및 아이콘 포함 구매 완료 창을 추가했습니다.
- 사라를 완성된 음식 3종을 파는 디어 헌터 식당으로 연결했습니다. 요리는 별도 조리시설에서 진행합니다.
- 임무 재료 설명에 연결된 임무 이름을 표시합니다.
- 몬드 의뢰 10개를 추가하고 레벨별 수락·노출을 제한합니다. 다른 지역은 실제 방문 기록이 있어야 임무가 보입니다. 단순 이동 허가만으로 리월 임무가 보이지 않습니다.
- 몬드 7개 구역에 고정 탐험 눈동자 12개를 배치했습니다. 회수·공양·보상은 각각 한 번이며 모험 진행에 따라 숨겨진 동행을 해금합니다.
- 공식 공개 원신 음악 14개를 지역·장면별 재생 목록으로 연결했습니다. 곡이 끝나면 다음 곡으로 바뀌고 전투가 끝나면 탐험 음악의 이전 위치로 돌아갑니다. 기존 PV 배경음은 제거했습니다. 일부 곡은 공식 웹이벤트용 편집본입니다. 몬드 고유 전투/보스 녹음은 확보하지 못해 리월 전투 녹음을 공유합니다. 출처·해시는 음원 목록과 공식 음원 안내 파일에 기록했습니다. 공식 성우 추임새는 추가하지 않았습니다.
- 엠버 Q의 5연타를 한 행동으로 표시하고 대상별 합계·치명타 포함·최종 HP를 보여줍니다. 지속 피해와 원소 반응을 추가 행동으로 표시하지 않습니다. 원래 전투 판정과 저장 난수는 변경하지 않습니다.
- 3인 초반 파티의 일반 무작위/의뢰 전투 난이도 보정을 확장했습니다. 보스·고정 스토리 전투·진행 중인 저장 전투는 기존 수치를 유지합니다.
- 데이터 개정 전 v0.8 저장 호환 식별자를 보존했습니다. 접속 복구와 자동 저장 이행도 검사했습니다.

## 검증

자동 회귀 검사 36개 스위트가 모두 통과했습니다. 전투 표시 검사는 다단히트 합계, 반응, 보호막, 빗나감, 치명타, 최종 HP, 일시정지·속도·다음 표시를 포함합니다. 기존 전투 시뮬레이션 1,152건에서 동일 라운드의 중복 캐릭터 턴은 없었습니다. 보정 후보 비교 192건과 순서·보스 보존 검사를 수행했습니다.

브라우저에서 기존 저장 불러오기, 바그너 백철 3개 구매(225모라·재고 3개 감소·결과 창), 단일 대장간, 사라 음식 판매, Lv.1 캐서린의 몬드 의뢰만 표시, 전투 시작 순서·엠버 5연타 합산·치명타·정지 조작을 확인했습니다. 공식 몬드 음원의 실제 media 재생을 확인했습니다. 390px 모바일 편성 화면의 2번 자리 안내와 장비 선택을 확인했습니다.

범위: 몬드 전체 루트를 끝까지 플레이하거나 모든 조합의 난이도를 보증하는 검사는 아닙니다. 공식 음원 전체 앨범을 수록한 것도 아닙니다. 원본 Google Sheets와 운영 저장은 변경하지 않았습니다.
