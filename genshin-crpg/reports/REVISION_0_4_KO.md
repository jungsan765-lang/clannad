# 0.4 진행 제한·성장·몬드 전투 보완

2026-09-24. 원본 시트와 원고를 바꾸지 않고 코드에 반영했습니다. 전체 몬드 완성 또는 전체 루트 밸런스 합격을 뜻하지 않습니다.

## 수정

- 진행 단계를 이야기 / 선택 / 전투 준비 / 전투 대화 / 전투 / 재도전 / 자유행동으로 판정합니다. 화면 버튼과 트랜잭션 진입에서 동일하게 검사합니다.
- 이야기 중 이동·상점·제작·의뢰·상자·보상·제목 화면을 잠급니다. 저장·불러오기는 유지합니다. 소지품과 임무는 열람만 가능하며 원고가 SAVE_LOAD_ONLY인 장면은 그 제한을 우선합니다.
- 이름은 새 게임에서 한 번 정합니다. 엠버와의 이름 장면은 정한 이름을 전달하는 버튼이며, 다른 이름 제출과 일반 NEXT 우회를 거절합니다.
- 메뉴 복귀가 이전 대사나 맵을 복원하던 문제를 제거했습니다. 개인 이야기 복귀에는 대기/후속 장면 정보도 저장합니다. 전투 컷인은 실제 대사·선택을 마쳐야 돌아갑니다.
- 경험치 숫자·진행 막대·다음 레벨까지 수치, 성장·능력치 화면과 소유 동료의 경험치 책 사용을 제공합니다. 소유했지만 비편성인 동료도 성장시킬 수 있습니다.
- 모든 스토리 전투에 편성 준비를 제공합니다. 패배 후 전투 직전 상태를 복원하는 재도전은 HP만 채우는 기능이 아니라 아이템·성장·난수·깃발 등 전투 전 전체 상태를 복원합니다. 저장 행동 번호는 증가하여 중복 처리되지 않습니다.
- 자유행동에서 이야기에 들어갈 때 별도의 ‘이야기 시작 전’ 저장을 남깁니다. 준비를 다시 해야 한다면 저장 메뉴에서 불러올 수 있습니다.
- 팩의 코드 해시와 저장 호환 버전을 분리했습니다. 직전 배포 팩을 호환 대상으로 유지하고 업그레이드 전 원본을 보관합니다. 지원하지 않는 저장도 원본 파일로 내보낼 수 있습니다.

## 확정한 코드 측 규칙

`HOUSE_RULE_V1`이며 원본에 있던 수치로 오인하지 않도록 게임의 저장·설정 → 전투 규칙에도 표시합니다.

| 항목 | 규칙 |
|---|---|
| 위치 | 6열×4행, 동일 구역·상하좌우 1구역 인접. 기존 사거리와 대공 접근은 유지 |
| 이동 | 밀치기·당기기 1구역. 경계에 멈추며 추가 충돌 피해 없음 |
| 크기 | 일반 소형, 정예 중형, 강적 대형, 보스. 츄츄 폭도는 대형 |
| 띄우기 | 1라운드 이동 잠금과 다음 행동점수 −10. 보스는 원본 제어 대체 규칙 우선 |
| 벤티 E | 아군 부양과 적 바람 피해 취약 5%는 1라운드 |
| 모나 E | 허영 HP는 시전자 최대HP의 25%, DEF는 시전 시점 값. 파괴·만료 시 한 번 폭발 |
| 설탕 Q | 흡수 추가타는 공격력의 20%, 흡수한 다음 펄스부터 적용 |
| 설치물 | 접촉·파괴·만료를 별도 처리, 소비 표시를 먼저 기록하여 중복 폭발 방지 |
| 선택 보스 경로 | 초원↔북풍의 왕랑 도전 구역 각30분 왕복 경로. 원본 지도 행은 수정하지 않음 |

기존 카드 피해·회복 계수, 생성 라운드 수명 예외, 소유자 턴의 쿨다운, 대상별 다단 부착 한 번을 유지했습니다. 기존 원본 규칙인 일반 오라2라운드, 변환 반응, 감전 전이, 풀 원핵, 활성·촉진·발산을 연결했습니다. 달/별 반응은 현재 몬드 범위에서 임의로 개방하지 않습니다.

몬드 활성 카드40개를 실행기로 연결했습니다. 기존 차단8개와 일반 대상 제한3개를 해제했고, 모나 포영/성이를 독립 반응 피해에도 적용합니다. 알베도의 스킬 강화는 기본공격을 강화하지 않습니다. 설산 얼음 폭도2개 카드와 안드리우스8개 카드·면역·페이즈·추가 행동·소환 효과도 연결했습니다.

## 검증과 한계

드발린 원본 능력치·공중·8라운드 지형 제한과 임시 동료의 기본 능력치는 그대로입니다. 해당 전략의 패배를 모든 전략의 불가능으로 해석하지 않습니다. 두 루트 종단 밸런스는 아직 검증되지 않았습니다. 생활 채집 패시브 일부, 몬드 밖 특수 전투, 일반 장비 발동 효과 전부, 실제 네트워크 차단 후 PWA재실행은 남은 범위입니다.
