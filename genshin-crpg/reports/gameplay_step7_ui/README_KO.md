# v0.13.24 — 토끼 백작 공용 도발·다단히트·전투 UI

## 7번: 토끼 백작 도발
기존에는 몬드 필드에만 광역/지원 기술 예외가 있고 리월 등에서는 토끼 백작이 있으면 적이 사실상 단일 공격만 하게 되는 차이가 있었다.

이제 전 지역 공통 규칙:
- 단일 대상 공격: 토끼 백작을 우선 공격.
- 광역 공격: 토끼 백작 때문에 봉쇄되지 않음.
- 회복/보호막/소환/자기 강화: 정상 사용.
- 적에게 사용 가능한 위 행동이 없으면 기존대로 토끼 백작을 공격.

사용자 노출 이름은 모두 「토끼 백작」으로 통일한다. 내부 BUNNY/BARON_BUNNY ID는 저장 호환 때문에 유지한다.

## 다단 공격 연출
한 행동으로 묶이는 규칙은 그대로다.
한 대상에 실제 피해 로그가 여러 개 있으면 각 피해 숫자와 HP 표시를 전투 속도 1배 기준 50ms 간격으로 순차 재생한다.
5연타라면 약 0/50/100/150/200ms에 차례로 숫자가 뜬다. 전투 계산값과 저장값은 건드리지 않는다.

## 전투 조작 UI
- 행동/공격 카드가 적 목록보다 먼저 보인다.
- 카드에는 기술명과 사용 가능/재사용/사용 불가 상태만 표시한다.
- 각 카드 옆 「효과」 버튼에서 기존 상세 설명을 확인한다.
- 이세계인 E는 현재 대상의 최대 HP 감소량, Q는 현재 추가 배율과 참가/불참 동료를 효과 창에서 추가 표시한다.
- 적 기술의 긴 상시 패널을 제거한다.
- 적 행의 「정보」 또는 행동 영역의 「적 기술 정보」 버튼으로 모달을 연다.
- 전투 기록은 기본 접힘.

## 검증
- 수정 JS 7개 문법 검사 통과.
- 공용 도발 함수 단위 검사: 광역 기술 보유 적은 광역기를 사용하고 단일기만 있는 적은 토끼 백작 우선 규칙으로 되돌아감.
- 사용자 노출 파일에서 폭탄 인형/도발 인형 제거 및 토끼 백작 표기 확인.
- 효과 버튼/행동 영역 상단 배치/적 상시 패널 제거/전투 기록 접힘/50ms 다단 표시 정적 검사 통과.
