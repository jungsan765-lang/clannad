# ⛔⛔ ChatGPT 작업 금지 — 게임 화면(UI)과 비경·성장 구조 ⛔⛔

**사용자 지시 (2026-10-06): ChatGPT는 아래 영역을 만들거나 고치지 않는다. 이 영역은 Claude가 맡는다.**

## 1. 드롭다운 절대 금지

- **`v`(▾)를 눌러 목록을 펼쳐서 고르는 방식(`<select>`, 드롭다운, 콤보 상자)을 게임 어디에도 쓰지 않는다.**
- 고를 것은 그림·아이콘·버튼 칸으로 한눈에 보여 주고, 바로 눌러서 고르게 한다.
- 「찾아서 누르는」 화면(목록을 펼쳐 찾고, 또 다른 목록을 펼쳐 고르는 화면)을 만들지 않는다.

## 2. 게임 화면(UI)을 만들거나 고치지 않는다

- 화면 배치, 창, 메뉴, 버튼, 안내 문구, 튜토리얼 화면.
- **글로 때우지 않는다.** 설명 문단을 늘어놓는 화면을 만들지 않는다. 그림·아이콘·숫자로 보여 준다.
- 사용자가 일부러 뺀 단계(예: 비경 입장 전 편성 확인)를 다시 넣지 않는다.

## 3. 비경·지맥·성장 재료·보상 구조를 만들거나 고치지 않는다

- 비경은 지도 위 정해진 장소에 있다. 아무 데서나 들어가는 비경, 종류·단계를 목록에서 고르는 「성장 비경 준비」 창을 다시 만들지 않는다.
- 경험치 책은 지맥(계시의 꽃)에서 나온다. 비경이 지맥의 역할을 빼앗는 보상을 만들지 않는다.
