## 주요 교정

옥경대와 흘호암을 서로 다른 도시 구역으로 분리했습니다. 옥경대는 서쪽 높은 대의 광장, 흘호암은 남동쪽 생활 거리의 기준점으로 표시합니다. 경책 산장 밭길은 남쪽 산기슭 도로 대신 지도 상단의 계단식 밭으로 옮겼습니다. 성법 관문은 연못 안쪽에서 동쪽 지상 바깥길로, 녹화 연못과 망서 객잔은 수면·건물과 구분되는 기슭·마당 기준점으로 교정했습니다.

명온 마을 폐광·남천문 고목·층암거연 관문처럼 원본에서 개별 입구를 식별할 수 없는 대상은 인근 지상 접근 지역이나 길의 대표점으로 표시합니다. 장소 이름은 기존 저장·활동과의 호환을 위해 그대로 두고 지도 설명에 미확정 범위를 적었습니다. 남천문의 점은 고목 줄기 좌표가 아닙니다.

브라우저 검사는 빌드 파일을 Chromium에 로드하고 외부 통신을 차단한 환경에서 수행했습니다. 게임 원본 로직은 그대로 실행했고 화면 검사에 필요한 지도·글꼴은 테스트 중 로컬 데이터로 주입했습니다. 배포 서버, Service Worker 업데이트, 실사용자 세이브 또는 전체 본편 완주를 시험한 것은 아닙니다.

## 설치 및 실행

이 ZIP은 전체 게임이 아닌 **누적 패치**입니다. 제공된 v0.13.0 전체 소스 또는 그 위에 적용한 제공 패치 v0.13.1~v0.13.14가 필요합니다. 변경 없는 에셋은 기존 전체 소스를 사용합니다. 예전 패치를 하나씩 다시 설치할 필요는 없습니다. 다른 세션의 독립 수정이 있으면 덮어쓰지 말고 먼저 병합해야 합니다.

압축을 풀고 `package.json`이 있는 기존 프로젝트 폴더를 대상으로 먼저 확인합니다.

```text
python apply_patch.py "기존 프로젝트 폴더" --check
python apply_patch.py "기존 프로젝트 폴더"
```

Windows에서는 `apply-patch.bat`을 이용할 수도 있습니다. 설치기는 변경 대상과 주요 소스의 해시를 확인하여 예상치 못한 수정이 있으면 중단하며, 실제 적용 전에 `.patch-backups`에 이전 파일을 보존합니다. 개인 저장은 별도 보관하세요.

프로젝트 안에서 `start-game.bat` 또는 `start-game.sh`로 실행합니다. 다시 빌드할 때는 프로젝트에서 `python -m pip install -r requirements.txt` 후 `python tools/build.py`를 실행합니다. 이미 빌드된 결과는 `dist/`에 있습니다.

추가 좌표 검사 재실행은 Python Playwright와 Chromium이 필요합니다. `python -m pip install playwright`, `python -m playwright install chromium` 후 프로젝트에서 `python tests/v01315_coordinates.py`를 실행합니다. 시스템 Chromium을 사용하려면 `CRPG_CHROMIUM` 환경 변수로 실행 경로를 지정합니다. 테스트 fixture는 프로젝트의 기존 합성 QA 상태이며 개인 세이브가 아닙니다.
