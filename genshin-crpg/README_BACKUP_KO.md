## 실행

Python 3이 설치된 환경에서 ZIP을 풀고 폴더 안에서 Windows는 `start-game.bat`, macOS/Linux는 `sh start-game.sh`를 실행합니다. 브라우저에서 `http://localhost:8765/`에 접속합니다. `dist/index.html`을 파일로 직접 열면 저장·오프라인 동작이 제한될 수 있습니다. 이미 만들어 둔 `dist/`만으로 로컬 실행할 수 있으며 Google 계정이나 시트 접근 권한은 필요하지 않습니다.

## 개발과 빌드

1. Python 3에 필요한 이미지 라이브러리를 설치합니다: `python3 -m pip install -r requirements.txt` (Windows에서는 `py -m pip install -r requirements.txt`).
2. 원본과 데이터를 수정한 뒤 `python3 tools/build.py`를 실행합니다 (Windows에서는 `py tools/build.py`). `dist/`가 새 결과물로 덮어써집니다. 빌드가 기존 `dist/audio` 디렉터리 충돌로 멈추면 **추출한 백업 사본의 `dist/`만 삭제한 뒤** 다시 실행합니다. 이 ZIP을 다시 풀면 백업 당시 배포본 `dist/`를 복원할 수 있습니다.
3. 개발 서버가 필요하면 Node.js와 npm을 설치하고 `npm ci` 후 `npm run dev`를 실행합니다. `npm run build`도 Python 빌드를 실행합니다.
4. 기본 자동 검사: `python3 tools/test_all.py`; 일부 브라우저 검사에는 추가로 Playwright·Chromium이 필요합니다. 자세한 제한은 `README_KO.md`와 `reports/REVISION_0_13_KO.md`를 참조합니다.

원고를 다시 편입하는 `tools/integrate_liyue.py`는 백업에서 운영 상태를 제거한 `content/archive/`의 기준 원고와 이전 버전 기초 DB를 읽도록 조정했습니다. 현재 버전을 단순히 고쳐 다시 빌드할 때는 편입기를 다시 실행할 필요가 없습니다. 편입기만으로 모든 후속 수작업 패치가 재현되지는 않으며 현재의 완성된 원본은 `content/db.json`입니다.
