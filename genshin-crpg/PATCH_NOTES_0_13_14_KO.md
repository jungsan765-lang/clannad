# CRPG v0.13.14 — 리월 세부 지역 확장 패치 기록

기준: 제공된 v0.13.13 개발 소스. 기존 스토리 거점 13개를 유지하고 세부 탐방 구역 26개를 더해 리월 구역은 39개가 됩니다. 왕복 경로 39쌍(방향별 78행)을 추가합니다.

## 변경 내용

- 지형 지도 위 대표 위치점, 기존 번호·연결선·큰 목적지 카드에 새 구역을 연결했습니다. 새 구역은 지역별 목록에서 찾아 선택할 수도 있습니다.
- 각 장소에 풍경 설명과 무료 둘러보기를 추가했습니다. 생활 자원이 있는 20개 구역에는 기존 채집·채광·낚시 행동을 연결했습니다. 별도의 새로운 NPC 임무를 완성한 것은 아닙니다.
- 세부 구역의 적 편성·권장 레벨은 기존 상위 지역 데이터를 계승합니다. 원본 몬스터 능력치와 전투 시스템은 변경하지 않았습니다.
- 항구의 기존 상점·길드·본편 재개는 원래 리월항 거점을 사용합니다. 새 골목을 통해 출입 통제를 우회하지 않도록 같은 통행 조건을 적용합니다.
- 고운각은 부두의 배편으로 왕복하며 이동 시간이 지납니다. 섬 사이 순간이동이나 바다 위 도보 경로로 처리하지 않습니다.
- 선택·경로 조회·풍경 설명 열기는 이동하지 않습니다. 실제 이동 버튼으로 기존 MOVE를 한 번 실행합니다.
- 기존 구역·본편 경로·보상·대사·귀환로는 삭제하지 않았고, 복제 구역에 원래의 일회성 상자·눈동자·보급 보상을 복사하지 않았습니다.

## 위치 표시 및 보존

좌표 원점은 승인된 리월 PNG(880×786)의 왼쪽 위입니다. 건물·유적·모래톱·산길 등의 지상 대표점입니다. 개별 NPC, 특정 자원이나 비경 입구의 정밀 좌표를 의미하지 않으며 지형의 높낮이는 표현하지 않습니다. 흐림 영역에는 새 핀을 넣지 않았습니다.
승인된 몬드·리월 PNG와 기존 몬드 좌표는 그대로입니다. 새 이미지·AI 그림을 추가하지 않았습니다. 새로운 풍경 문구는 이 CRPG용 창작 문구이며 원작 대사 인용이 아닙니다.
상위 구역에서 이어받는 조우 구성, 생활 자원의 수량·확률·이동 시간은 기존 규칙 또는 CRPG 설계값입니다. 원작의 모든 출현 좌표와 드롭을 복제한 것이 아닙니다.

## 적용

이 ZIP은 v0.13.0~v0.13.13 제공 소스를 v0.13.14로 올리는 누적 변경본입니다. 원래 전체 소스와 변경 없는 에셋이 필요하며 이전 패치를 순서대로 다시 설치하지 않습니다. 패치 폴더의 `apply-patch.bat`을 실행하거나 다음 명령을 사용합니다.

```text
python apply_patch.py "기존 프로젝트 폴더"
```

설치기는 기존 파일이 다른 작업으로 변경된 경우 덮어쓰지 않고 중단하며, 변경 전 파일은 `.patch-backups`에 보존합니다. 이 해시 확인은 설치 안전장치이며 별도의 게임 재검증 작업을 실행하지 않습니다.
패치에는 현재 개발 소스와 생성된 실행본을 포함합니다. 과거 테스트 묶음·화면 검증 보고서·재검증 체크리스트는 이번 배포 묶음에 다시 넣지 않았습니다. 기존 프로젝트 안의 그런 파일을 삭제하는 것은 아닙니다.
새 구역 ID가 저장되므로 저장 호환 키에 `-liyueareas1`을 추가했습니다. 이전 제공 저장은 읽는 방향으로 유지하고, 새 구역 저장을 구버전에 넣지 않도록 구분합니다. 업데이트 전 개인 세이브는 별도 보관합니다.
로컬 개발 원본 빌드는 완료했습니다. 전체 본편·전체 지점 플레이 검증이나 운영 사이트 배포를 완료했다고 표시하지 않습니다. 운영 사이트·원본 시트·Drive·개인 세이브는 수정하지 않았습니다.
같은 기존 Sites 프로젝트에 적용할 대상이며 새 사이트를 만들지 않습니다. 프로젝트 ID: `appgprj_6ab50ad27a50819192e6d8c961bda4ed`.
