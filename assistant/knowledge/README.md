# 게임 지식 (다니카의 사전)

- 공개된 게임 정보만 둔다 (캐릭터 성격·유출 정보는 character/ 쪽, git 제외).
- 파일 하나에 '## 제목' 마다 항목 하나, 바로 다음 줄은 '키워드: 이름, 용어, …'.
  대화·화면 판단에 키워드가 나오면 그 항목만 다니카에게 보여 준다 (`lorebook.py`).
- '판단 기준과 이유' 중심으로 적는다. 다니카는 그대로 읽지 않고 필요한 것만 골라 자기 말로 쓴다.
- 업데이트로 그대로 배달된다. 다니카가 받아 둔 최신 소식은 data/knowledge/ 에 따로 쌓인다.
- 파일 맨 위(첫 '## ' 앞)에 `게임: 붉은사막, Crimson Desert` 처럼 적으면, 그 파일 항목은 대화·화면에 그 이름이 보일 때만 꺼낸다
  (게임 중이면 모드 이름이 늘 함께 들어간다). '심연'·'흔적' 같은 흔한 말이 다른 게임 얘기에 끼어드는 것을 막는다.
- 스토리 전개·반전이 드러나는 항목은 제목 끝에 `(스포일러)`. 꺼낼 때 '묻기 전엔 먼저 말하지 않기' 안내가 붙는다.
