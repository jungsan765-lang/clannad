## 판정 시스템 (MAX %·BREAK·RATE)
키워드: 판정, MAX 100%, MAX 90%, MAX 1%, BREAK, 브레이크, RATE, 레이트, PERFECT PLAY, 퍼펙트 플레이, MAX COMBO, 맥스 콤보, 하드판정, 맥스판정, HARD 판정, MAX 판정, NORMAL 판정
- 판정은 MAX 100% ~ MAX 1%의 퍼센트 방식(DJMAX Online/Portable 계열 전통). 못 친 노트는 BREAK.
- MAX 1%도 콤보는 이어짐. BREAK만 콤보가 끊김.
- RATE = 전체 노트 판정 퍼센트의 평균. 전 노트 MAX 100% = PERFECT PLAY, BREAK 0 = MAX COMBO.
- 판정 모드: NORMAL / HARD / MAX. HARD·MAX는 판정 폭이 더 좁음(정확한 ms 값은 공식 미공개, 확인 못 함).
- 2.0 이후 래더에서 HARD/MAX 판정 기록을 NORMAL 기록과 분리 집계하며, 대기 화면·인게임에 판정 모드가 표시됨.
- 판정 타이밍 조절 기능이 있음(패치노트 'judgment timing adjustment'). 입력 지연이 느껴지면 먼저 이걸로 오프셋을 맞출 것.

## 난이도 (NM·HD·MX·SC)
키워드: NM, HD, MX, SC, NORMAL, HARD, MAXIMUM, SC 패턴, 난이도, 레벨, 별, 서열
- 채보 난이도는 쉬운 순서로 NM(NORMAL) → HD(HARD) → MX(MAXIMUM) → SC.
- SC는 별도 표기 체계를 쓰는 고난도 채보이며, 키보드 플레이를 전제로 설계된 패턴(패드로 치기 어려운 배치 포함).
- 레벨은 곡 선택 화면의 별(★) 수로 표시. 커뮤니티에선 SC는 같은 레벨 안에서도 체감 난이도 편차가 크다는 평이 많음.
- 공식 버그 수정 예: 'Good Bye 8B SC' 레벨 표시가 10 → 8로 수정(2025-11-06).
- 정확한 레벨 상한·SC 레벨 범위는 (확인 못 함).
- 실력 기준이 필요하면 팬 사이트 V-ARCHIVE의 '서열표'(유저 체감 난이도표)를 참고.

- 아래는 공식 가이드가 아닌 리듬게임 일반 연습 원칙 + 게임 내 기능 활용법.
- 먼저 판정 타이밍 조절로 싱크를 맞추고, 사운드 출력은 지연이 적은 장치(WASAPI/ASIO 표시 확인)로.
- 배속은 '노트 간격이 읽히는 가장 빠른 값'에 고정. 자주 바꾸면 손이 적응을 못 함. 밀집 구간이 뭉쳐 보이면 0.1~0.3씩 올려 볼 것.
- 목표 순서: BREAK 없애기(MAX COMBO) → RATE 올리기. RATE 90% 이상이어야 DJ POWER가 생기므로 무리한 고레벨보다 90%+가 나오는 레벨을 반복.
- 어려운 구간은 FREESTYLE에서 REWIND로 구간 반복(기록엔 페널티), 기록 도전은 F5 재시작.
- 같은 버튼 모드·같은 기어를 꾸준히 쓰고, V-ARCHIVE 서열표로 비슷한 체감 난이도 곡을 묶어 연습.
