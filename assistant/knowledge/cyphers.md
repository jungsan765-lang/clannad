## 사이퍼즈 기록 API 응답 구조
키워드: API 응답, playInfo, matchId, rows, matches 응답, 매치 상세, JSON
- /cy/players/{playerId}/matches (2019년 실제 응답 샘플로 확인): matches.rows[] 각 원소 = {date: "YYYY-MM-DD HH:MM", matchId, playInfo: {result("win"/"lose"), random, partyUserCount, characterId, characterName, level, killCount, deathCount, assistCount, attackPoint, damagePoint, battlePoint, sightPoint, …}}.
- 같은 응답에 플레이어 정보(playerId, nickname, grade, clanName, ratingPoint, maxRatingPoint, tierName, records[]{gameTypeId, winCount, loseCount, stopCount})도 들어 있음(2019 샘플).
- date에는 시간대 표기가 없고 KST로 해석됨(2026년 비공식 구현 근거).
- /cy/matches/{matchId} (2026년 비공식 구현 기준, 공식 확인 못 함):
  - date, gameTypeId, map{mapId, name}
  - teams[]{result, players[]}: players는 playerId 문자열 배열
  - players[]{playerId, nickname, playInfo{…}, items[]{itemId, itemName, slotCode, rarityCode, …}, itemPurchase[] (itemId 배열)}
- 확인 못 함: next 토큰 위치(최상위인지 matches 안인지), multiKillCount 내부 키, position·attribute 필드가 지금도 있는지(포지션 삭제 2025-05-15 이후).

## 사이퍼즈 공식 API 엔드포인트
키워드: 네오플 API, Neople API, 오픈 API, api.neople.co.kr, 전적 검색, apikey
- 기본 URL은 https://api.neople.co.kr이고, 모든 요청에 apikey 쿼리가 필요.
- 엔드포인트:
  - GET /cy/players?nickname=&wordType=(match|full): 닉네임으로 playerId 검색(limit 최대 200).
  - GET /cy/players/{playerId}: 플레이어 정보.
  - GET /cy/players/{playerId}/matches?gameTypeId=(기본 rating|normal)&startDate=&endDate=&limit=(기본 10, 최대 100)&next=
  - GET /cy/matches/{matchId}: 매칭 상세.
  - 그 외: /cy/ranking/ratingpoint, /cy/ranking/characters/{characterId}/{winCount|winRate|killCount|assistCount|exp}, /cy/ranking/tsj/{melee|ranged}, /cy/battleitems, /cy/battleitems/{itemId}, /cy/multi/battleitems?itemIds=, /cy/characters.
- matches 조회 규칙:
  - 기본 기간은 최근 30일, 최대 90일.
  - startDate·endDate는 둘 다 넣어야 함. 예: 20180901T0000.
  - next를 쓰면 첫 조회의 조건이 그대로 적용됨.
  - 기록은 1시간마다 갱신.
- 이미지 URL: img-api.neople.co.kr/cy/characters/{characterId}, /cy/items/{itemId}.
- slotCode:
  - 장비: 101 손, 102 머리, 103 가슴, 104 허리, 105 다리, 106 발, 107 목.
  - 장신구: 201 장신구ALL, 202~205 장신구1~4.
  - 킷: 301~305 회복·가속·공격·방어·특수킷.
