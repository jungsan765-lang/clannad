# 캐릭터 비서

혼자 쓰는 Windows 바탕화면 캐릭터 비서. 배포하지 않음. 계획은 Claude 문서 "캐릭터 비서 개발 계획".

## 실행하기 (1단계: 대화)

1. Python 3.12 설치 후 이 폴더에서 `pip install -r requirements.txt`
2. API 키 설정 (둘 중 하나, 코드·설정 파일에는 쓰지 않음)
   - 환경 변수: `setx ANTHROPIC_API_KEY "키"` 후 새 터미널
   - Windows 자격 증명 관리자: `pip install keyring` 후
     `python -c "import keyring; keyring.set_password('danika-assistant', 'anthropic', '키')"`
3. `python main.py` (콘솔 창 없이: `pythonw main.py`)

- 캐릭터 클릭 → 입력창, Enter 로 보내면 말풍선으로 답한다. 드래그로 이동(위치 기억).
- 오른쪽 클릭·트레이 메뉴: 오늘/이번 달 사용 금액, 기억 보기, 기억 지금 정리하기, 최근 대화 잊기, 종료.
- 설정은 `config.toml`, 내 설정은 같은 키로 `config.local.toml` 에 (git 제외).
- 성격 파일: `config.toml` 의 `character.persona` (기본 `character/danika/persona.md`). 없으면 기본 말투.
- 캐릭터 그림: `character.folder` 의 `manifest.json` (make_character.py / make_rig.py 결과). 없으면 임시 원형 캐릭터.
- 기록은 `data/` 에만 저장 (git 제외): `usage.json` 비용, `memory.json` 장기기억, `recent.json` 최근 대화,
  `logs/날짜.jsonl` 대화 원문, `logs/app.log` 오류 기록.

### 화면 보기 (2단계)
- `screen.interval_seconds`(기본 30초)마다 `screen.monitor`(기본 왼쪽 모니터)를 캡처한다. 다니카는 오른쪽 모니터에 두면 된다.
- 화면이 거의 그대로면 판단 없이 건너뛴다(비용 0). 바뀌었으면 Haiku 가 말 걸지 판단(생각 끔),
  말하기로 했을 때만 Opus 가 화면을 보고 다니카 말투로 한마디 한다. 최소 간격은 `screen.cooldown_seconds`.
- 켜고 끄기: `screen.enabled`, 메뉴 체크, F9. 메뉴에서 바꾼 값은 다음에 켤 때도 유지된다(`data/state.json`).
- F8: 판단·간격 없이 지금 화면을 보고 말하게 한다. 먼저 건넨 말에 대답하면 그 말을 기억한 채 이어서 대화한다.
- 화면은 DXGI 화면 복제(`watch/dxgi.py`, dxcam)로 찍는다. 기존 GDI 방식(mss)은 게임이 포커스를 가지면 멈춘 화면·검은 화면이
  찍혀서 '화면이 그대로'로 판단을 건너뛰었다. DXGI 를 쓸 수 없으면 자동으로 mss. 새까맣게 찍히면 기록에 남긴다.
- 설정 창의 '화면 확인 간격'·'쉬는 시간'이 게임 모드 값보다 짧으면 설정 창 값을 쓴다.
- 스크린샷 크기 `screen.max_width`(기본 1920, 설정 창 '화면 선명도'). 1024 처럼 작으면 작은 글씨를 못 읽는다.
- 스크린샷은 디스크에 저장하지 않는다. 월 예산을 넘으면 화면 보기만 멈춘다(`screen.stop_when_over_budget`).

### 분석 모드
- 평소 화면 말은 '보이는 걸 읊지 말고, 주인님이 모를 정보·판단·조언·생각 중 하나'가 없으면 말하지 않는다.
- 분석 모드(메뉴 체크, 설정 창): 판단 담당이 '분석할 만한 순간'(결과·정산 화면, 판이 끝난 직후, 파티·장비 화면, 실수·오류)만
  고르고, 그때 최근 장면 최대 3장(15초 넘게 떨어진 것)을 함께 보내 Opus 가 생각 깊이 `ai.analysis_effort`(기본 medium)로 분석한다.
  상황 · 짚을 점(근거) · 지금 할 일은 캐릭터 옆 '분석 창'에, 요약은 말풍선에. 원신이면 계정 정보·배경지식 사전도 함께 쓴다.
- F10(`hotkeys.analyze`)·메뉴·대화("지금 화면 분석해 줘")로 언제든 바로 분석. 한 번에 대략 50~150원.

### 게임 모드 (`modes/*.toml`, 파일 하나 = 게임 하나)
- 맨 앞 창의 실행 파일 이름(`processes`)이나 창 제목에 든 단어(`titles`)로 자동 전환. 다니카가 있는 모니터의 창은 무시한다.
- 지금 모드와 맨 앞 프로그램 이름은 메뉴 맨 위와 트레이 아이콘 툴팁에 나온다. 인식이 안 되면 그 이름을 `processes` 에 넣는다.
- 들어 있는 모드: 사이퍼즈(20초, 판 끝나면 총평), 붉은사막(30초, 컷신 중 조용, 스포일러 금지),
  디맥(15초, 플레이 중엔 절대 말 안 함, 결과 화면에서만), 칸코레(10초, 大破 상태로 진격하려 하면 대기 없이 바로 철수 경고).
- 게임 중에 본 장면과 한 말은 '이번 판 기록'으로 모아서, 판 총평과 "방금 판 어땠어?" 같은 대화에 쓴다.
  게임 창이 3분 넘게 안 보이면 기록을 마치고, 다음 기억 정리 때 '최근 있었던 일'로 남긴다.
- 키: `name`, `processes`, `titles`, `interval_seconds`, `cooldown_seconds`, `knowledge`(게임 설명·코칭 기준),
  `quiet_during_play`, `review_on_result`, `urgent`(대기 무시하고 바로 말할 상황).

### 다니카가 스스로 늘리는 것
- 인터넷 검색: 모르는 이름·사실이 나오면 "찾아보겠습니다" 하고 Haiku 가 웹 검색(`ai.search_model`) → 다니카가 이어서 답한다.
  찾은 내용은 `data/knowledge.json` 에 남아 다음부터는 검색 없이 안다. 설정 창에서 끌 수 있다. 검색 1번 0.01달러 + 토큰.
- 화면에 이름이 글자로 보이는데 모르는 인물·장소면 말 대신 조용히 찾아본 뒤 말한다(`screen.searches_per_hour`, 기본 6번).
  인물은 얼굴만으로 단정하지 않고 이름표(파티 목록, 대화창 이름)로 알아본다.
- 게임 모드 자동 생성: 평소 모드에서 같은 프로그램이 게임 화면으로 8번쯤 보이면 그 게임을 찾아보고 모드를 만든다
  (`data/modes/auto_*.toml`, 업데이트가 건드리지 않음. 지우면 다시 자동으로 만들지 않는다). 대화로 "이 게임 모드 만들어줘",
  메뉴 '지금 하는 게임 모드 만들기'로도 만든다.
- 개선 요청 메모: 못 하는 일을 부탁받거나 "이런 기능 있었으면" 하면 `data/requests.json` 에 적는다.
  메뉴 '개선 요청 메모…'에서 보고, 직접 적고, '복사하기'로 개발 채팅에 붙여넣는다. 다니카가 자기 코드를 직접 고치지는 않는다.
- 고정 기억: 설정 창 '주인님 → 아이디·닉네임'(여러 개면 쉼표)과, 대화로 "고정해" 한 사실(`data/pinned.json`)은
  장기기억 정리와 상관없이 항상 프롬프트에 들어간다. 화면에 그 아이디가 보이면 주인님 본인으로 본다. 둘 다 이 PC 에만 저장.
- 배경지식 사전(`lorebook.py`): 성격 파일이 있는 폴더(또는 `character.lore_dir`)의 다른 *.md 를 '## 제목'마다 나눠 두고,
  대화·화면 판단에 그 항목 이름('키워드:' 줄)이 나오면 그 항목만 넣는다. 늘 아는 핵심(lore.md)은 캐시되는 앞부분에.
- 배경지식: `character.lore`(기본 `character/danika/lore.md`, git 제외)를 프롬프트의 캐시되는 부분에 넣는다.

### 원신 계정 정보 (게임 프로그램은 건드리지 않음)
- 게임 메모리·파일은 읽지 않는다(안티치트·약관). 공식·공개 통로만 쓴다 (`gamedata/genshin_data.py`).
- 진열장: 설정 창 '원신 연결 → UID' 만 있으면 Enka.Network 에서 진열장 캐릭터의 무기·성유물·스탯을 받는다(ttl 지킴).
- 실시간 메모: 설정 창 'HoYoLAB → 로그인…'(앱 안 브라우저, 기록 안 남김. 안 되면 쿠키 붙여넣기). 로그인 정보는
  `data/secrets.bin` 에 윈도우 DPAPI 로 암호화. 10분마다 레진·일일 의뢰·탐사 파견·주전자 동전을 받고, 레진이 넘치기 직전 등은
  다니카가 먼저 알린다. HoYoLAB 계정 설정은 바꾸지 않는다(실시간 메모 공개가 꺼져 있으면 켜는 방법만 안내).
- 기원 기록: 게임 안에서 기원 기록을 한 번 열면 남는 주소로 공식 기록을 받는다(게임을 끌 때·메뉴 '원신 → 새로고침').
  공식 기록은 6개월치라 `data/genshin/wishes.json` 에 계속 쌓고, 배너별로 마지막 5성 뒤 몇 번째인지 알려 준다.
- 원신 모드이거나 대화에 레진·기원·성유물 같은 말이 나오면 이 정보를 함께 넘긴다. 메뉴 '원신 → 받은 원신 정보 보기'.

### 목소리로 말 걸기
- `voice.mode`: `always`(항상 듣기) | `push`(F7·메뉴로 그때만 듣기) | `off`. 메뉴의 "목소리로 말 걸기"에서도 바꾼다.
- 음성은 PC 안에서 Whisper(`voice.model`)로 글자가 된 뒤 일반 대화처럼 보내진다. 처음 쓸 때 모델을 내려받는다.
- 항상 듣기는 게임 음성 채팅 같은 말에도 반응한다. `voice.wake_word = "다니카"` 로 하면 이름을 부른 말에만 반응한다.

### 하고 있는 일 표시
- 캐릭터 아래 작은 글씨로 지금 하는 일을 보여준다: 생각 중, 화면 확인 중, 할 말 고르는 중, 듣는 중, 알아듣는 중,
  음성 인식 준비 중, 기억 정리 중, 업데이트 확인 중, 파일 목록 읽는 중, 정리안 만드는 중, 파일 옮기는 중 3/40 등 (몇 초째인지 함께).
- 말풍선과 따로라 대사를 가리지 않고, 클릭은 뒤로 통과한다. 설정 창 '대답·표시'에서 끌 수 있다.
- 대답은 받는 대로 말풍선에 바로 나온다(다 받을 때까지 기다리지 않음). 영어로 나오기 시작하면 보여주지 않고 한국어로 다시 받는다.
- '빠르게 대답'(설정 창): Opus 빠른 모드. 답이 2배쯤 빨리 오지만 요금도 2배. 막히면 보통 속도로 다시 보낸다.

### 파일 정리
- 대화로 "다운로드 정리해줘" 라고 하거나 메뉴 '파일 정리'에서 폴더를 고른다 (다운로드·바탕화면·문서·사진·동영상·음악·다른 폴더).
- 폴더 맨 위 칸 파일(최근 500개)의 이름·크기·날짜만 보고 다니카가 하위 폴더로 나누는 정리안을 만든다. 파일 내용은 보내지 않는다.
- 미리보기 창에서 체크한 것만 옮긴다. 새 폴더 이름은 칸을 두 번 눌러 바꿀 수 있다. 지우지 않고, 같은 이름이 있으면 '이름 (2)'.
- 바로가기(.lnk)·받는 중인 파일·숨김 파일은 건드리지 않는다. 윈도우·프로그램 폴더, 드라이브 맨 위, 사용자 폴더 자체는 거절한다.
- 옮긴 기록은 `data/organize_log.jsonl`. 메뉴 '파일 정리 → 마지막 정리 되돌리기'로 원래 자리로 돌린다.
- 다니카가 할 수 있는 일은 프롬프트에 적혀 있고, 못 하는 일(프로그램 실행, 삭제, 알람 등)은 했다고 하지 않고 못 한다고 말한다.

### 단축키
- `hotkeys` 의 F7(듣기)·F8(지금 화면)·F9(화면 보기 켜고 끄기). 등록한 키는 다른 프로그램으로 전달되지 않으니 게임 키와 겹치면 바꾼다.

### 업데이트·설정
- `run.bat` 은 `launcher.py` 로 켠다. 업데이트한 버전이 켜지지 않으면 이전 버전으로 되돌리고 다시 켠다(그 버전은 다시 안 받음).
  받은 파일은 바꾸기 전에 문법 검사를 하고, 이상하면 아무것도 바꾸지 않는다. 그래도 안 켜지면 이유를 한국어 창으로 알려준다.
- 켤 때와 `update.check_hours`(기본 6시간)마다 GitHub 작업 브랜치에서 `assistant/` 의 바뀐 파일만 받는다(저장소 전체가 아님).
  켤 때 받은 업데이트는 바로 다시 시작해서 적용, 켜져 있을 때 받은 것은 메뉴의 '다시 시작'으로 적용.
  `requirements.txt` 가 바뀌면 필요한 것도 설치한다. 직접 고친 `config.toml`·`modes/*.toml` 은 덮어쓰지 않고 새 기본값을 `.new` 로 둔다.
- 메뉴(다니카나 트레이 아이콘 오른쪽 클릭): 설정 파일 열기(메모장), 업데이트 확인, 다시 시작, 화면 보기 상태(마지막 확인·판단 횟수).

### 대화가 동작하는 방식
- 모든 API 호출은 `ai_client.py` 하나로 모인다. 모델은 `config.toml` 의 `ai.chat_model` / `ai.memory_model`.
- 답은 JSON(`speak`, `message`, `emotion`) 형식으로만 받는다 (structured outputs).
- 한국어 강제: 규칙을 프롬프트 맨 앞에 두고, 답에 영어가 섞이면 한 번 다시 요청, 그래도 영어면 표시하지 않는다.
- 장기기억: 대화가 `memory.consolidate_every` 번 쌓이거나 다음에 켤 때, 캐릭터 본인 시점의 짧은 한국어 메모로
  다시 정리해 프롬프트에 넣는다. 성격 부분과 기억 부분은 따로 캐시해서 비용을 줄인다.
- 비용: 응답의 실제 토큰 수로 계산해 `data/usage.json` 에 쌓는다. 월 예산은 `budget.monthly_usd`(기본 150달러 = Max 크레딧 100 + 50).
  크레딧(`budget.credit_usd`)을 다 쓰면, 예산 80% 와 100% 에서 각각 한 번씩 알린다. 예산을 넘으면 화면 보기만 멈추고 대화는 계속한다.
  Max 크레딧을 쓰려면 크레딧을 연결한 Console 조직에서 만든 API 키를 써야 한다.

## 캐릭터 만들기 (영상 → 바탕화면 캐릭터)

준비: Python 3.12, ffmpeg (`winget install Gyan.FFmpeg`), `pip install -r requirements.txt`

```
python make_character.py scan 영상.mp4                 # 시간표시 썸네일 시트 + 장면 목록 (work/scan/)
python make_character.py new 이름 영상.mp4              # character/이름.toml 레시피 생성
#   → 레시피에 동작별 start/end 를 채운다
python make_character.py build character/이름.toml      # 누끼·정렬·루프·미리보기
python preview_character.py character/이름              # 바탕화면에 띄워 확인
```

- 누끼: 기본은 애니 캐릭터 AI 분할 모델(처음 한 번 약 170MB 자동 다운로드). 단색 배경은 `matte = "chroma"`.
- 결과물(`character/`), 영상, 모델, 작업 폴더는 `.gitignore`로 저장소에 올라가지 않는다.

## 캐릭터 만들기 (그림 한 장, 지금 쓰는 방식)

```
python make_still.py 그림.png --name danika_still   # → character/danika_still/ (config 기본값)
```

- 투명 배경 그림이면 그대로, 배경이 있으면 AI 로 누끼. 불투명이 253·254 인 그림은 255 로 보정, 떨어진 점 정리.
- 평소: 숨쉬기(3.6초). 말할 때: 가슴선 위(목·머리)만 1.5px 살짝 튐 (`--bounce 0` 이면 안 튐).
- 그림 아래가 잘려 있어도 떠 보이지 않게 맨 아래는 고정하고 위로 갈수록 움직인다.
- `--breath`, `--bounce` 로 움직임 폭(px) 조절.
